# v2.1.0 误差驱动曲率尺寸场实施计划

本次改动是替换曲率：将 `cpp_adaiso` 原有基于 CSF 平滑、直方图分级和离散倍率的目标边长控制，替换为最大绝对主曲率和几何近似误差驱动的连续尺寸场。

## Summary

- 使用最大绝对主曲率 `kappa = max(abs(k1), abs(k2))` 作为尺寸场输入。
- 使用近似误差容限 `epsilon` 将曲率直接映射为局部目标边长。
- 删除 remesher 对 CSF Dirichlet 平滑、曲率直方图和 multiplier 的依赖。
- 当前网格维护 per-vertex sizing value，并在 split/collapse 时插值更新。

## Key Changes

- 新增 `maximumAbsolutePrincipalCurvatures(const Mesh&)`，通过 cotangent Laplacian 和角缺陷计算 `H/K`，再用 `H + sqrt(max(H*H - K, 0))` 得到最大绝对主曲率；边界、退化和非有限估计返回 0。
- 新增 `curvatureSizingField(mesh, epsilon, minLength, maxLength)`，用 `sqrt(6*epsilon/kappa - 3*epsilon*epsilon)` 计算目标边长，并截断到 `[minLength, maxLength]`。
- `AdaIsoConfig` 新增 `approximationTolerance`、`minTargetLength`、`maxTargetLength`；CLI 新增 `--epsilon`、`--min-edge-length`、`--max-edge-length`。
- 默认 `0` 表示 auto：`epsilon=0.05*meanEdgeLength`、`min=0.5*meanEdgeLength`、`max=4/3*meanEdgeLength`。
- `--mesh-scale` 保留兼容，但 v2.1.0 不再用它计算目标边长。
- 边目标长度固定为 `min(La, Lb)`；split 新点和 collapse 保留点的 sizing 都取端点平均。
- 切向松弛改为按 incident triangle 的面积和三角形平均 sizing 加权面重心，再投影到顶点切平面。
- Summary JSON 输出 sizing 统计和 per-iteration split/collapse/flip、目标边长误差、质量、最小角和近似几何误差。

## Test Plan

- 平面曲率接近 0，尺寸为 `Lmax`。
- 球面和圆柱最大绝对主曲率接近 `1/R`。
- 翻转整体法向后曲率基本不变。
- 曲率越大目标边长越小，误差容限越小目标边长越小。
- 所有 sizing value 有限且位于 `[Lmin, Lmax]`。
- 保留现有 CSF sparse solver 单测，但 remesher smoke/edge-case 测试改为验证 sizing stats。
