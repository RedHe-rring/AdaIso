# cpp_adaiso v2.1.0 T0-T10 实验结果

## 实验配置

- 版本：`cpp_adaiso 2.1.0`
- 变更：collapse 从“每个 global iteration 最多 10 条边”改为“每个 global iteration 最多 10 轮 batch collapse”。
- 输入：`cpp_adaiso/examples/T0.off` 到 `cpp_adaiso/examples/T10.off`
- 输出目录：`cpp_adaiso/results/v2.1.0_T0_T10/`
- 参数：`--variant code --mesh-scale 1.0 --iters 10 --preprocess 0 --project 1 --quiet`
- 构建与测试：`cmake --build cpp_adaiso/build --target adaiso_cli adaiso_tests` 通过，`ctest --test-dir cpp_adaiso/build --output-on-failure` 通过

命令模板：

```powershell
cpp_adaiso/build/adaiso_cli.exe cpp_adaiso/examples/T{i}.off `
  -o cpp_adaiso/results/v2.1.0_T0_T10/T{i}_v2.1.0_iter10_project1.obj `
  --variant code `
  --mesh-scale 1.0 `
  --iters 10 `
  --preprocess 0 `
  --project 1 `
  --summary-json cpp_adaiso/results/v2.1.0_T0_T10/T{i}_v2.1.0_iter10_project1.json `
  --quiet
```

- 11 个样例全部运行成功。

- 所有 `csf_residual_scaled` 均低于 `1e-10`。
- 所有输出网格的 `qavg` 和 `qmin` 均为正。
- 相比 v2.0.0 记录，batch collapse 后输出网格更轻，平均 `qavg` 和最小 `qmin` 明显提升。
