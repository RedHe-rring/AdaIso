# cpp_adaiso v2.1.0 T0-T10 实验结果

## 实验配置

- 版本：`cpp_adaiso 2.1.0`
- 尺寸场方法：最大绝对主曲率 + 几何近似误差驱动目标边长
- 输入：`cpp_adaiso/examples/T0.off` 到 `cpp_adaiso/examples/T10.off`
- 输出目录：`cpp_adaiso/results/v2.1.0_T0_T10/`
- 对比基准：`cpp_adaiso/results/v2.0.0_T0_T10/*.json`
- v2.1.0 参数：`--variant code --epsilon 0 --min-edge-length 0 --max-edge-length 0 --iters 10 --preprocess 0 --project 1 --quiet`
- v2.1.0 初始 auto sizing：`epsilon=0.01*meanEdgeLength`，`min=0.25*meanEdgeLength`，`max=2.0*meanEdgeLength`
- 构建与测试：`cmake --build cpp_adaiso/build` 通过，`ctest --test-dir cpp_adaiso/build --output-on-failure` 通过

命令模板：

```powershell
cpp_adaiso/build/adaiso_cli.exe cpp_adaiso/examples/T{i}.off `
  -o cpp_adaiso/results/v2.1.0_T0_T10/T{i}_v2.1.0_iter10_project1.obj `
  --variant code `
  --epsilon 0 `
  --min-edge-length 0 `
  --max-edge-length 0 `
  --iters 10 `
  --preprocess 0 `
  --project 1 `
  --summary-json cpp_adaiso/results/v2.1.0_T0_T10/T{i}_v2.1.0_iter10_project1.json `
  --quiet
```

## 结论

按默认行为口径，v2.1.0 相对 v2.0.0 是落后。

主要原因：

- 质量下降：11 个 case 的 `qavg` 和 `qmin` 全部低于 v2.0.0，平均 `qavg` 从 0.798058 降到 0.741022，平均 `qmin` 从 0.246193 降到 0.043736。
- 输出规模失控：平均输出顶点数和面数约为 v2.0.0 的 5.45 倍。
- 运行时间显著增加：平均 runtime 约为 v2.0.0 的 5.73 倍。
- 稳定性方面，v2.1.0 的 11 个 case 都能成功运行，但默认 auto sizing 过密，且没有带来对应的质量收益。

因此，这版最大绝对主曲率 + 误差驱动尺寸场在默认参数下不适合作为 v2.0.0 的直接替代。后续若继续推进，应优先重新标定 `epsilon/min/max` 的 auto 策略，或做同输出规模对比后再判断曲率尺寸场本身是否有价值。

## auto08_133 结论

v2.1.0 默认参数修正有效：它明显缓解了上一轮 auto 参数导致的过密、耗时和质量下降问题。相对初始 v2.1.0，平均运行时间降到 0.15 倍，输出规模降到 0.21 倍，平均 `qavg` 提升 0.053428，平均 `qmin` 提升 0.216018。

相对 v2.0.0，新参数后的 v2.1.0 已经接近同一档默认行为：平均运行时间更低，平均 `qmin` 更高，但平均输出规模仍大约高 16%，平均 `qavg` 低 0.003607，且最差 `qmin` 低 0.025068。逐 case 看，T8/T9/T10 的输出规模仍偏大，T6 的最小质量仍明显弱于 v2.0.0。

因此结论不是单纯落后：这次默认参数修正相对上一轮 v2.1.0 是明确改进；相对 v2.0.0 是接近但仍有权衡，主要优势是平均最小质量和运行时间，主要问题是输出规模略大、平均质量略低、最差 case 稳定性仍弱。
