# cpp_adaiso v2.4.0 连续 h 映射实施计划

## Summary

- v2.4.0 将目标边长从五档 curvature histogram 映射替换为连续经验分位数映射。
- 保留 v2.3.0 的 screened CSF、Gaussian kNN target lookup 和 split/collapse/flip/smooth 主循环。
- 清理旧接口，不保留 `histogram_bins`、五档 `multipliers` 或 `histogramMultipliers()`。

## Implementation

- 新增连续映射参数：
  - `target_min_factor = 0.6`
  - `target_max_factor = 1.8`
  - `target_gamma = 1.0`
- 对每个顶点曲率 `kappa_i` 计算经验分位数 `q_i`，重复值使用 tie block 平均 rank。
- 使用：

```text
alpha_i = q_i ^ target_gamma
h_min = mean_edge_length * mesh_scale * target_min_factor
h_max = mean_edge_length * mesh_scale * target_max_factor
h_i = exp((1 - alpha_i) * log(h_max) + alpha_i * log(h_min))
```

- 常量曲率场直接返回 `mean_edge_length * mesh_scale`。
- 将纯映射逻辑拆到 `adaiso::detail::continuousTargetLengths()`，供 remesher 和测试共享。
- CLI 新增：
  - `--target-min-factor`
  - `--target-max-factor`
  - `--target-gamma`
- summary JSON 写入 `target_min_factor`、`target_max_factor`、`target_gamma`，删除 `histogram_bins`。

## Tests

- 单元测试 `{0, 1, 2}` 映射到 `h_max`、log-space 中点、`h_min`。
- 单元测试重复曲率共享同一 target length。
- 单元测试常量曲率场返回 `base * mesh_scale`。
- 单元测试 target length 随曲率单调不增。
- 配置校验覆盖：
  - `target_min_factor <= 0`
  - `target_max_factor <= 0`
  - `target_min_factor > target_max_factor`
  - `target_gamma <= 0`
- 回归验证：
  - `cmake --build cpp_adaiso/build`
  - `ctest --test-dir cpp_adaiso/build --output-on-failure`
  - CLI smoke 验证新 summary 字段存在，`histogram_bins` 不再输出。

## Assumptions

- `variant` 继续保留，只影响 split/collapse 阈值，不影响 CSF 或 target length 映射。
- 默认 `0.6` 到 `1.8` 沿用旧五档映射的最小/最大目标边长范围。
- 不移动已有 `v2.3.0` tag。
