# v5.3.5 修改方向：Collapse Energy-Only

## Summary

v5.3.5 删除 v5.3.4 中的 collapse `max_target_metric_ratio` slack 硬约束，只保留局部 target metric violation 必须下降。目标是验证“删一半”后是否能释放 collapse，而不造成误差、长边残留或坏角系统性恶化。

## Key Changes

- 版本更新到 `5.3.5`。
- 删除 `kCollapseTargetLengthSlack = 0.05`。
- 删除 `LocalPatchMetrics::max_target_metric_ratio` 和对应计算。
- collapse target-length 拒绝只表示：
  ```text
  after.target_metric_violation > before.target_metric_violation - tol
  ```
- 角度安全线、Stage A 顺序、batch selection、CLI 参数和 summary JSON 字段保持不变。

## Test Plan

- `cmake --build cpp_adaiso/build2 --config Release --target clean`
- `cmake --build cpp_adaiso/build2 --config Release`
- `ctest --test-dir cpp_adaiso/build2 -C Release --output-on-failure`
- T 系列：
  ```text
  python cpp_adaiso/修改计划与实验结果/generate_v5_3_5_T_series.py --workers 2 --cd-samples 100000 --iters 10 --no-resume
  ```

## Expected Judgment

- 如果 v5.3.5 的 violation、RMSE/CD 和坏角指标不恶化，则 max-ratio slack 可以删除。
- 如果长边残留或误差明显恶化，下一步应把 max-ratio 改成 soft penalty，而不是恢复硬拒绝。
