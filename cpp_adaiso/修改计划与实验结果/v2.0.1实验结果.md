## 实验配置

- 版本：`cpp_adaiso 2.0.1`
- 输入：`cpp_adaiso/examples/T0.off` 到 `cpp_adaiso/examples/T10.off`
- 输出目录：`cpp_adaiso/results/v2.0.1_T0_T10/`
- 参数：`--variant code --mesh-scale 1.0 --iters 10 --preprocess 0 --project 1 --quiet`
- 运行方式：使用当前构建的 `adaiso_cli.exe` 批量测试 11 个样例

命令模板：

```powershell
cpp_adaiso/build/adaiso_cli.exe cpp_adaiso/examples/T{i}.off `
  -o cpp_adaiso/results/v2.0.1_T0_T10/T{i}_iter10_project1.obj `
  --variant code `
  --mesh-scale 1.0 `
  --iters 10 `
  --preprocess 0 `
  --project 1 `
  --summary-json cpp_adaiso/results/v2.0.1_T0_T10/T{i}_iter10_project1.json `
  --quiet
```

说明：当前版本的 summary 不再包含旧版的 `csf_iterations` 字段，因此本记录仅整理当前可导出的网格指标与运行时间。
