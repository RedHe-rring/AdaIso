# v5.1.0 T0-T5 auto delta 实验报告

## 1. 实验目的

本实验验证新的默认误差：

```text
h_ref = 0.5 * mean_edge_length
delta_auto = (1 - sqrt(1 - kappa_max^2 * h_ref^2 / 3)) / kappa_max
```

其中 `kappa_max` 使用 CSF 后主曲率最大值。若 `h_ref` 超过公式有效区间，则内部会将 `h_ref` 截断到有效范围内。

## 2. 实验设置

模型：`T0.off` 到 `T5.off`

命令：

```text
adaiso_cli <input> -o <case>/output.obj
  --iters 10
  --preprocess 0
  --curvature-mode principal-max
  --csf-alpha 2.0
  --gt <same input>
  --cd-samples 100000
  --export-target-field <case>/target_field
  --summary-json <case>/summary.json
  --quiet
```

输出目录：

```text
cpp_adaiso/results/v5.1.0_T0_T5_delta_auto_kmax/T/<model>
```

对照：同一版代码的旧默认 `delta = 0.001 * bbox_diagonal`：

```text
cpp_adaiso/results/v5.1.0_T0_T5_delta_default/T/<model>
```

## 4. 与手动 0.0005*bbox 的关系

auto delta 的平均 `delta/bbox = 0.0004806849`，接近手动 `0.0005*bbox`。

相对手动 `0.0005*bbox`：

- CD 平均再降低约 `1.05%`
- RMSE 平均再降低约 `0.54%`
- 输出面数平均增加约 `14.88%`

## 5. 结论

基于最大曲率反解默认 delta 是有效的。它避免了 `0.001*bbox` 默认过粗的问题，在 T0-T5 上明显降低 CD 和 RMSE。

当前代价是输出面数明显增加，且 qmin 下降。后续如果希望在 CD/RMSE 和面数之间折中，可以扫描：

```text
h_ref = {0.5, 0.6, 0.7} * mean_edge_length
```

其中 `h_ref` 越大，自动 delta 越大，输出越粗；`h_ref` 越小，输出越细，CD/RMSE 通常更低。
