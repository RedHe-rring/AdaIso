# cpp_adaiso v2.2.0: Gaussian kNN Target Field + Edge Ratio Stability Metrics

## Summary
- 将 `targetAt(point)` 默认从 nearest-neighbor 改为 Gaussian kNN 加权插值，减少目标边长场的阶跃跳变。
- 保留 nearest 模式用于 v2.1.1 兼容和 A/B 对照。
- 新增逐轮 edge ratio 统计，直接衡量边长是否落在 collapse/split 稳定区间内。

## Key Changes
- 在 `AdaIsoConfig` 新增：
  - `target_lookup_mode = GaussianKnn`
  - `target_knn_k = 8`
  - `target_gaussian_sigma_factor = 1.0`
- CLI 新增：
  - `--target-mode nearest|gaussian`
  - `--target-k <positive int>`
  - `--target-sigma-factor <positive double>`
- `targetAt(point)`：
  - `nearest`: 保持 v2.1.1 行为。
  - `gaussian`: 使用现有 `NearestNeighborIndex::nearestK(point, k)`。
  - 权重 `w_i = exp(-(d_i / h)^2)`。
  - `h = sigma_factor * max(d_k + max(0, d_k - d_{k-1}), 1e-12)`；`k=1` 等价 nearest。
  - 权重异常时 fallback 到 nearest。
- `AdaIsoStats::IterationStats` 新增：
  - `mean_ratio`
  - `std_ratio`
  - `p05_ratio`
  - `p95_ratio`
  - `violation_rate`
- edge ratio 定义：
  - `target(e) = min(targetAt(v0), targetAt(v1))`
  - `ratio(e) = length(e) / target(e)`
  - `violation = ratio < collapseFactor() || ratio > splitFactor()`
  - 每轮在 split/collapse/flip/smooth/cleanup 完成后，对当前网格所有唯一边统计。
  - `std_ratio` 使用 population standard deviation；`p05/p95` 使用线性插值分位数；无边时全部记为 `0`。

## JSON And Docs
- JSON `parameters` 写入 target mode、k、sigma factor。
- JSON 每个 `iterations[]` 记录新增 ratio 指标。
- README / CHANGELOG 更新到 v2.2.0，说明：
  - Gaussian kNN 是局部平滑目标场，不严格声称截断 kNN 全局连续。
  - nearest 在 Voronoi 边界产生目标长度跳变；Gaussian kNN 在固定邻域内连续，并通过实验验证能降低局部操作震荡。

## Tests
- 单元测试：
  - nearest 在两个不同目标长度点之间产生阶跃。
  - gaussian `k=2` 在边界附近返回平滑加权值，左右扰动差值小于 nearest jump。
  - gaussian `k=1` 等价 nearest。
  - edge ratio helper 在简单网格上给出可手算的 mean/std/p05/p95/violation_rate。
  - 非法 `target-k`、`target-sigma-factor` 被 CLI/config 校验拒绝。
- 回归测试：
  - 现有 `adaiso_tests` 全部通过。
  - 默认 gaussian 的 `testRemeshSmoke()` 输出合法网格、正质量、成功 CSF。
  - nearest 兼容 smoke 确认旧查询路径仍可运行。

## Experiment Plan
- 使用同一个 v2.2.0 binary 做 A/B：
  - nearest: `--target-mode nearest`
  - gaussian: `--target-mode gaussian --target-k 8 --target-sigma-factor 1.0`
- 代表集：`hand`、`bunny`、`T0`、`T3`、`T9`、`C0`、`C2`、`C7`。
- 固定参数：
  - `--variant code --mesh-scale 1.0 --iters 10 --preprocess 0 --project 1 --gt <input> --cd-samples 100000 --quiet`
- 稳定性汇总指标：
  - `tail_ops_mean = mean(split+collapse+flip, iter 6..10)`
  - `tail_ops_delta_mean = mean(abs(delta total_ops), iter 7..10)`
  - `tail_violation_rate_mean = mean(violation_rate, iter 6..10)`
  - `final_violation_rate`
  - `final mean_ratio/std_ratio/p05_ratio/p95_ratio`
- 验收口径：
  - gaussian 在多数样例和总体均值上降低 `tail_violation_rate_mean`，并优先观察 `tail_ops_mean`、`tail_ops_delta_mean` 是否同步下降。
  - `qavg/qmin` 和 CD 不明显退化；若存在退化，在 v2.2.0 实验结果中明确标注 tradeoff。

## Assumptions
- `target(e)` 使用用户确认的 `min(targetAt(v0), targetAt(v1))`。
- 默认 `k=8, sigma_factor=1.0`，与当前 MLS 的 kNN Gaussian 风格保持一致。
