# cpp_adaiso v2.0.0 T0-T10 实验结果

## 实验配置

- 版本：`cpp_adaiso 2.0.0`
- CSF 方法：Dirichlet Laplace 稀疏线性系统直解
- 输入：`cpp_adaiso/examples/T0.off` 到 `cpp_adaiso/examples/T10.off`
- 输出目录：`cpp_adaiso/results/v2.0.0_T0_T10/`
- 参数：`--variant code --mesh-scale 1.0 --iters 10 --preprocess 0 --project 1 --quiet`
- 构建与测试：`cmake --build cpp_adaiso/build` 通过，`ctest --test-dir cpp_adaiso/build --output-on-failure` 通过

命令模板：

```powershell
cpp_adaiso/build/adaiso_cli.exe cpp_adaiso/examples/T{i}.off `
  -o cpp_adaiso/results/v2.0.0_T0_T10/T{i}_v2.0.0_iter10_project1.obj `
  --variant code `
  --mesh-scale 1.0 `
  --iters 10 `
  --preprocess 0 `
  --project 1 `
  --summary-json cpp_adaiso/results/v2.0.0_T0_T10/T{i}_v2.0.0_iter10_project1.json `
  --quiet
```

说明：这里的 `--iters 10` 是全局 remesh 迭代轮数，不是 CSF 迭代次数。v2.0.0 中 CSF 已无显式迭代，summary 中也不再包含 `csf_iterations`。
