## 定位结论

- model 系列的平均 `rmse %bbox` 高于 T 系列，说明当前 auto-delta 对不同数据族的尺度/曲率分布仍不完全一致。
- 输出面数增长和 `h range` 高的样例需要优先检查 curvature max 是否过尖、低曲率区是否被 `h_max` 放得过粗。
- Violation 高的样例说明 remesh 操作没有充分追上 target metric，下一步应优先扫描 collapse/split hysteresis，而不是只继续调 delta。
- qmin 低的样例需要单独看 flip 和 collapse validity，尤其是高曲率区域的细边和特征点附近。

## 下一步建议

1. 对 RMSE 高且 violation 高的样例导出 target field 和 stage meshes，先看是曲率场问题还是 remesh 操作不足。
2. 扫描 `h_ref = {0.45, 0.5, 0.6, 0.7} * mean_edge_length`，观察 CD/RMSE 与输出面数的折中。
3. 暴露 `collapseFactor` 和 `splitFactor` 为参数，优先扫描 `collapseFactor = {0.6, 0.7, 0.8}`，`splitFactor = {1.2, 1.33, 1.5}`。
4. 对 h range 很大的样例扫描 `h_max = {3, 4, 5} * mean_edge_length`，判断低曲率区过粗是否是 RMSE 来源。
5. 如果 curvature max 被少数顶点支配，再实验 `kappa_ref = p99(kappa)` 代替 `kappa_max` 反解 auto delta。
