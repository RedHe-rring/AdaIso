# cpp_adaiso v2.1.1 实施计划

## Summary

v2.1.1 目标是在不改变 AdaIso 主算法口径的前提下，补齐工程化输出和评估能力：

- 支持 ASCII PLY 输出，现有 ASCII PLY 输入继续保留。
- 在 summary JSON 中记录每个 global iteration 的过程信息。
- 支持与 ground truth 网格计算面积采样 Chamfer Distance。

## Key Changes

### PLY 输入输出

- 在 `IO.hpp` / `IO.cpp` 中新增 `writeAsciiPly(const std::filesystem::path&, const Mesh&)`。
- 新增 `writeMesh(const std::filesystem::path&, const Mesh&)`，按输出扩展名分发：
  - `.obj` 调用现有 `writeObj()`。
  - `.ply` 调用新增 `writeAsciiPly()`。
  - 其他扩展名报错 `unsupported output mesh format`。
- `main.cpp` 改为调用 `writeMesh()`，默认输出仍为 `<input>_cppadaiso.obj`。
- CLI help 从 `<output.obj>` 改为 `<output.obj|output.ply>`。
- PLY 输出限定为 ASCII triangular mesh：
  - header 写 `format ascii 1.0`。
  - `element vertex <n>`，属性为 `float x/y/z`。
  - `element face <m>`，属性为 `list uchar int vertex_indices`。
  - face 行固定写 `3 i j k`，索引保持 0-based。

### 每轮迭代 JSON

- 在 `AdaIsoStats` 中新增：

```cpp
struct IterationStats {
  int iteration = 0;
  int split_count = 0;
  int collapse_count = 0;
  int flip_count = 0;
  std::size_t vertices = 0;
  std::size_t faces = 0;
  double qavg = 0.0;
  double qmin = 0.0;
};

std::vector<IterationStats> iterations;
```

- `AdaIsoRemesher::remesh()` 每个 global iteration 结束后记录一次：
  - `iteration` 使用 1-based 轮次。
  - `split_count`、`collapse_count`、`flip_count` 使用当前轮实际操作数。
  - `vertices`、`faces`、`qavg`、`qmin` 使用 cleanup/smoothing 后的当前 mesh。
- `main.cpp` 的 summary JSON 增加顶层字段 `"iterations": [...]`。
- `--iters 0` 时 `"iterations": []`。

### GT Chamfer Distance

- CLI 新增：
  - `--gt <mesh>`：可选 ground truth 网格路径，支持现有 `loadMesh()` 输入格式。
  - `--cd-samples <n>`：每个方向面积采样点数，默认 `100000`；要求 `n > 0`。
- 在 `Metrics.hpp` / `Metrics.cpp` 中新增：

```cpp
struct ChamferDistanceSummary {
  std::size_t samples_per_direction = 0;
  double output_to_gt_msd = 0.0;
  double gt_to_output_msd = 0.0;
  double chamfer_distance = 0.0;
  double symmetric_rmse = 0.0;
};

ChamferDistanceSummary areaSampledChamferDistance(
    const Mesh& output,
    const Mesh& gt,
    std::size_t samples_per_direction);
```

- 面积采样策略：
  - 仅采样正面积三角形。
  - 按三角形面积占比分配样本数，使用累计面积和确定性低差异序列选择三角形。
  - 三角形内部使用确定性 barycentric 采样，不使用随机 seed。
  - 输出和 GT 各采样 `samples_per_direction` 个点。
- 距离计算：
  - 使用 `NearestNeighborIndex` 在采样点集之间计算最近邻平方距离。
  - `output_to_gt_msd` 为 output 采样点到 GT 采样点的平均平方距离。
  - `gt_to_output_msd` 为 GT 采样点到 output 采样点的平均平方距离。
  - `chamfer_distance = output_to_gt_msd + gt_to_output_msd`。
  - `symmetric_rmse = sqrt(0.5 * chamfer_distance)`。
- JSON 输出：
  - 未传 `--gt` 时不输出 GT/CD 字段。
  - 传 `--gt` 时增加 `gt_summary` 和 `chamfer_distance`。
  - `chamfer_distance.method` 固定为 `"area_sampled"`。
- 错误处理：
  - `--cd-samples <= 0` 报错。
  - output 或 GT 没有正面积三角形时报错，提示无法计算 area-sampled CD。

## Test Plan

- 新增 ASCII PLY load/write roundtrip 测试，验证顶点数、面数和 face index 合法。
- 新增 CLI `.ply` 输出 smoke 测试，输出文件可由 `loadAsciiPly()` 重新读取。
- 新增 iteration stats 测试：
  - `global_iterations = 2` 时 `stats.iterations.size() == 2`。
  - 每项的操作数非负，顶点/面数量与中间 mesh 合法状态一致。
  - `global_iterations = 0` 时数组为空。
- 新增 Chamfer Distance 测试：
  - 同一 mesh 与自身的面积采样 CD 接近 0。
  - 平移后的 mesh 与原 mesh 的 CD 为正。
  - `samples_per_direction == 0` 抛出异常。
  - 空 mesh 或全退化面 mesh 抛出异常。
- 验证命令：

```powershell
cmake --build cpp_adaiso/build --target adaiso_tests
ctest --test-dir cpp_adaiso/build --output-on-failure
```

## Assumptions

- PLY 范围限定为 ASCII，不实现 binary PLY。
- CD 使用面积采样点云近似，不做精确点到三角形表面距离。
- `--gt` 是可选评估参数，不影响正常 remesh 输出。
