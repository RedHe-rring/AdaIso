# v2.11.0 修改方向：主曲率生成初始尺寸场，再平滑尺寸场

## 1. 修改背景

v2.10.x 当前尺寸场管线为：

```text
raw curvature
  -> screened-Laplacian/CSF 平滑曲率
  -> diffused curvature
  -> 曲率到 target_h 的反幂映射
  -> TargetLengthField
```

这条管线先平滑曲率，再进行非线性的曲率到尺寸映射。其主要问题是：

1. 算法真正使用的是目标边长 `target_h`，但正则化对象却是中间曲率信号；
2. 曲率到尺寸的反幂映射是非线性的，平滑曲率并不等价于平滑最终尺寸；
3. 即使 diffused curvature 已经较平滑，映射、截断和目标面数缩放仍可能重新产生较大的相邻尺寸差；
4. 当前 CSF 命名和统计都绑定在“平滑曲率”上，不利于继续扩展成通用尺寸场正则化。

v2.11.0 改成：

```text
principal curvatures (k1, k2)
  -> isotropic curvature magnitude kappa
  -> initial target length h0
  -> screened-Laplacian smooth target length hs
  -> global scale calibration + clamp
  -> final target length h
  -> TargetLengthField
```

更准确地说，本版本不是“不使用曲率”，而是：

```text
不再平滑曲率信号；
使用主曲率构造初始尺寸场，然后直接平滑尺寸场。
```

## 2. 修改目标

v2.11.0 需要实现以下目标：

1. 用每个顶点的两个主曲率 `k1`、`k2` 代替 `normal-angle` 和 `robust-mean` 曲率模式；
2. 从主曲率直接生成有上下界的初始尺寸场 `h0`；
3. 对 `h0` 求解 screened-Laplacian，得到平滑尺寸场 `hs`；
4. 在平滑后重新校准全局尺度，使估算面数尽量等于 `target_faces`；
5. 保持 `TargetLengthField` 及后续 split/collapse/flip/relocation 主流程不变；
6. 完整导出 `k1`、`k2`、`kappa`、`h0`、`hs` 和最终 `h`，保证每一步都可诊断；
7. 清理 `CSF`、`raw_curvature`、`diffused_curvature` 等已经不符合新语义的接口和统计名称。

## 3. 本版本不处理的内容

v2.11.0 初版只替换尺寸场生成与平滑管线，不同时扩大修改范围：

```text
1. 不实现各向异性 remeshing；
2. 不使用主方向控制三角形方向；
3. 不改变 split/collapse/flip 的阈值和执行顺序；
4. 不改变 feature-aware collapse、flip 二面角约束和 relocation；
5. 不在每轮 global iteration 后重新估计主曲率和重建尺寸场；
6. 不在本版本同时搜索新的曲率指数，初版继续使用 p = 0.75。
```

主曲率方向可以计算或保留在内部，但 v2.11.0 的最终场仍然是标量各向同性目标边长。

## 4. 符号约定

对输入网格记：

```text
p_i          顶点 i 的三维坐标
n_i          顶点 i 的单位法向
k1_i, k2_i   顶点 i 的两个有符号主曲率，单位为 1 / length
l_bar        输入网格平均边长
A_i          顶点 i 的 barycentric area/mass
A_f          三角形 f 的面积
h0_i         顶点 i 的初始目标边长
hs_i         Laplacian 平滑后的目标边长
h_i          目标面数校准后的最终目标边长
T            target_faces
p            曲率到尺寸的指数，v2.11.0 固定为 0.75
alpha        尺寸场平滑强度
```

当前边长上下界保持不变：

```text
h_min = 0.05 * l_bar
h_max = 5.00 * l_bar
```

对应当前代码中的：

```text
kTargetMinEdgeFactor = 0.05
kTargetMaxEdgeFactor = 5.0
```

## 5. 主曲率估计

### 5.1 估计方法

v2.11.0 建议使用顶点局部切平面上的二次曲面最小二乘拟合。原因是：

```text
1. 只依赖 Eigen 和现有顶点邻接，不引入新的几何库；
2. 可以同时得到 k1 和 k2；
3. 对法向整体翻转不敏感，因为最终使用主曲率绝对值；
4. 比直接用离散 H、K 再解 k1/k2 更容易处理 H^2 - K < 0 的离散误差。
```

### 5.2 局部坐标系

对顶点 `i`，先计算单位顶点法向 `n_i`，再构造正交切向基 `t1_i`、`t2_i`：

```text
dot(t1_i, n_i) = 0
dot(t2_i, n_i) = 0
dot(t1_i, t2_i) = 0
|t1_i| = |t2_i| = |n_i| = 1
t2_i = n_i cross t1_i
```

为了避免与法向近平行，先从 `x/y/z` 三个坐标轴中选择与 `n_i` 绝对点积最小的轴 `r`，然后：

```text
t1_i = normalize(n_i cross r)
t2_i = n_i cross t1_i
```

如果 `n_i` 非有限、长度过小或无法建立切平面，则该顶点估计失败，执行后文的回退规则。

### 5.3 邻域与归一化坐标

初次拟合使用一环邻域 `N1(i)`。定义局部长度尺度：

```text
l_i = mean(|p_j - p_i|), j in N1(i)
```

若 `l_i` 非有限或 `l_i <= 1e-12 * l_bar`，则估计失败。

对每个邻域顶点 `j`，令：

```text
d_ij  = p_j - p_i
x_ij  = dot(d_ij, t1_i) / l_i
y_ij  = dot(d_ij, t2_i) / l_i
z_ij  = dot(d_ij, n_i)  / l_i
r2_ij = x_ij^2 + y_ij^2
```

这里先除以 `l_i` 是为了改善最小二乘条件数，并保证模型整体缩放后得到尺度一致的主曲率。

### 5.4 二次曲面拟合

在顶点局部切平面上拟合 Monge patch：

```text
z(x, y) = 0.5 * a * x^2 + b * x * y + 0.5 * c * y^2
```

对每个样本 `j`，矩阵的一行为：

```text
q_j = [0.5 * x_ij^2, x_ij * y_ij, 0.5 * y_ij^2]
```

未知量为：

```text
beta = [a, b, c]^T
```

距离权重定义为：

```text
w_ij = exp(-0.5 * r2_ij)
```

求解加权最小二乘：

```text
beta = argmin sum_j w_ij * (q_j * beta - z_ij)^2
```

实现时将每一行和右端项同时乘以 `sqrt(w_ij)`，使用 Eigen 的 SVD 或 rank-revealing QR 求解，不直接求正规方程的逆：

```text
Qw.row(j) = sqrt(w_ij) * q_j
zw(j)     = sqrt(w_ij) * z_ij
Qw * beta ~= zw
```

拟合有效条件：

```text
1. 有效样本数 >= 3；
2. sigma_max > 0；
3. sigma_min / sigma_max >= 1e-6；
4. a、b、c 均为有限值。
```

如果一环不满足条件，则扩展到去重后的二环邻域重新拟合。二环仍失败时执行回退。

### 5.5 从拟合 Hessian 得到主曲率

归一化坐标下的 Hessian 为：

```text
H_hat = [ a  b ]
        [ b  c ]
```

其两个特征值为：

```text
trace_half = 0.5 * (a + c)
disc       = sqrt(0.25 * (a - c)^2 + b^2)
mu1        = trace_half + disc
mu2        = trace_half - disc
```

因为局部坐标除以了 `l_i`，物理单位下的主曲率为：

```text
k1_i = mu1 / l_i
k2_i = mu2 / l_i
```

最终按绝对值从大到小排序，保证：

```text
abs(k1_i) >= abs(k2_i)
```

法向翻转会同时改变 `k1_i`、`k2_i` 的符号，但不会影响后续的各向同性尺寸。

### 5.6 失败回退

以下情况视为主曲率估计失败：

```text
1. 法向无效；
2. 邻域样本不足；
3. 局部尺度无效；
4. SVD/QR rank 不足或条件数过差；
5. 求解结果出现 NaN/Inf。
```

回退规则：

```text
k1_i = 0
k2_i = 0
```

不能因为单个边界顶点或低 valence 顶点拟合失败而中止整个 remesh。需要统计并输出 fallback 顶点数量和比例。

## 6. 主曲率合成为各向同性曲率指标

当前 remesher 使用标量目标边长，因此两个主曲率合成为：

```text
kappa_physical_i = max(abs(k1_i), abs(k2_i))
```

选择最大绝对主曲率的原因：

```text
1. 球面两个方向都弯曲时能够正确响应；
2. 圆柱只有一个方向弯曲时不会被平均值稀释；
3. 鞍面主曲率异号时不会发生抵消；
4. 对锐脊和薄结构优先采用更小的各向同性尺寸。
```

为了保证模型缩放不改变尺寸场的相对分布，将其无量纲化：

```text
kappa_i = l_bar * kappa_physical_i
```

用于反幂映射的安全值：

```text
kappa_safe_i = max(kappa_i, 1e-12)
```

注意：导出的诊断文件需要同时保留有单位的 `k1/k2` 和无量纲的 `kappa`。

## 7. 从主曲率生成初始尺寸场

### 7.1 反幂映射

v2.11.0 初版继续使用当前指数：

```text
p = 0.75
```

给定全局尺度 `lambda`，顶点初始尺寸定义为：

```text
h0_i(lambda) = clamp(
    lambda / pow(kappa_safe_i, p),
    h_min,
    h_max)
```

含义：

```text
kappa 越大 -> h0 越小 -> 高弯曲区域更密；
kappa 越小 -> h0 越大 -> 平坦区域更稀；
h_min/h_max 控制极端主曲率和拟合噪声造成的尺寸范围。
```

### 7.2 目标面数估计

对三角形 `f=(i,j,k)`，先取面上的平均目标边长：

```text
h_f = (h_i + h_j + h_k) / 3
```

边长为 `h_f` 的等边三角形面积为：

```text
A_equilateral(h_f) = sqrt(3) / 4 * h_f^2
```

因此整个网格的估算目标面数为：

```text
N(h) = sum_f A_f / (sqrt(3) / 4 * h_f^2)
```

这与当前 `estimateTargetFaceCount()` 的计算保持一致。

### 7.3 初始 lambda 二分

选择 `lambda0`，使：

```text
N(h0(lambda0)) ~= T
```

二分边界：

```text
lambda_lo = 0
lambda_hi = h_max * pow(max_i(kappa_safe_i), p)
```

在 `lambda_lo`：

```text
h0_i = h_min
N(h0) = N_max_density
```

在足够大的 `lambda_hi`：

```text
h0_i = h_max
N(h0) = N_min_density
```

二分更新规则：

```text
if N(h0(lambda_mid)) > T:
    尺寸过小、估算面数过多
    lambda_lo = lambda_mid
else:
    尺寸过大、估算面数过少
    lambda_hi = lambda_mid
```

默认执行 64 次。若目标面数超出可实现范围：

```text
T >= N(all h_min) -> 初始场全部取 h_min
T <= N(all h_max) -> 初始场全部取 h_max
```

这一步生成 `h0`，并尽可能让平滑前尺寸场已经接近目标面数。

## 8. screened-Laplacian 平滑尺寸场

### 8.1 平滑能量

不再对 `kappa` 求解 CSF，而是直接平滑 `h0`。定义能量：

```text
E(hs) =
    0.5 * sum_i A_i * (hs_i - h0_i)^2
  + 0.5 * tau * sum_(i,j) w_ij * (hs_i - hs_j)^2
```

其中：

```text
A_i = sum_(f incident to i) A_f / 3
tau = alpha * l_bar^2
```

第一项使平滑结果保留初始主曲率尺寸分布，第二项抑制相邻顶点尺寸跳变。

### 8.2 cotangent 权重

内部边 `(i,j)` 两侧对角分别为 `theta_ij^1`、`theta_ij^2` 时：

```text
w_ij = 0.5 * (cot(theta_ij^1) + cot(theta_ij^2))
```

边界边只有一个对角时使用对应的单侧贡献。为了保持矩阵为正权图 Laplacian，并复用当前求解器策略：

```text
if w_ij is non-finite or w_ij <= 0:
    w_ij = eta

eta = 1e-4
```

### 8.3 线性系统

令质量矩阵和 Laplacian 为：

```text
M_ii = A_i

L_ii = sum_j w_ij
L_ij = -w_ij, i != j 且 (i,j) 为网格边
```

能量一阶最优条件为：

```text
(M + tau * L) * hs = M * h0
```

其中：

```text
tau = alpha * l_bar^2
```

默认暂时保留：

```text
alpha = 2.0
```

但该参数语义必须从 `csf_smoothing_alpha` 改为 `target_smoothing_alpha`。默认值是否合适由后续 alpha 消融实验决定，不能直接根据旧 CSF 实验下结论。

### 8.4 平滑结果的性质

该系统不是纯 `L * h = 0`：

```text
alpha 有限时：在接近 h0 和相邻平滑之间折中；
alpha -> 0 时：hs -> h0；
alpha -> infinity 时：每个连通分量上的 hs 趋近常量。
```

因此 v2.11.0 的目标不是强制所有相邻点严格满足 `hs_i = hs_j`，而是降低：

```text
sum_(i,j) w_ij * (hs_i - hs_j)^2
```

由于 `M + tau*L` 使用正质量和正边权，正的 `h0` 应得到正的 `hs`，并满足离散最大值原理。求解后仍需执行有限性检查，并用数值保护：

```text
hs_i = clamp(hs_i, h_min, h_max)
```

### 8.5 求解器

复用当前 `solveScreenedScalarField()` 的矩阵装配、`Eigen::SimplicialLDLT`、残差检查和计时逻辑。

求解残差仍定义为：

```text
r = (M + tau*L) * hs - M*h0
```

scaled residual 保持当前实现的归一化方式，阈值保持：

```text
residual_scaled <= 1e-10
```

## 9. 平滑后的目标面数再校准

### 9.1 为什么必须再校准

`h0` 满足：

```text
N(h0) ~= T
```

但 screened-Laplacian 改变了尺寸分布，一般不能保证：

```text
N(hs) = N(h0)
```

因此平滑后需要重新校准全局尺度。

### 9.2 全局缩放不破坏相对平滑性

先定义未截断的全局缩放：

```text
h_i(s) = s * hs_i
```

它保持所有相对尺寸：

```text
h_i(s) / h_j(s) = hs_i / hs_j
```

相邻差为：

```text
h_i(s) - h_j(s) = s * (hs_i - hs_j)
```

因此：

```text
如果 hs_i = hs_j，缩放后仍相等；
如果 hs 的相对变化平滑，缩放后相对变化不变。
```

目标面数校准只调整场的全局尺度，不重新引入局部振荡。

### 9.3 无截断时的解析比例

如果所有顶点都不触发 `h_min/h_max`，则：

```text
N(s * hs) = N(hs) / s^2
```

因此解析比例为：

```text
s_analytic = sqrt(N(hs) / T)
```

该值可作为诊断值或二分初值。

### 9.4 有上下界时的最终定义

实际最终尺寸定义为：

```text
h_i(s) = clamp(s * hs_i, h_min, h_max)
```

截断后 `N(h(s))` 不再严格等于 `N(hs)/s^2`，但它仍随 `s` 单调不增，因此使用二分求：

```text
N(h(s_final)) ~= T
```

二分边界：

```text
s_lo = 0
s_hi = h_max / min_i(hs_i)
```

在 `s_lo=0` 时，经过 clamp 后所有尺寸为 `h_min`；在 `s_hi` 时，所有尺寸都达到 `h_max`。

更新规则：

```text
if N(h(s_mid)) > T:
    尺寸过小、估算面数过多
    s_lo = s_mid
else:
    尺寸过大、估算面数过少
    s_hi = s_mid
```

同样执行 64 次。最终记录：

```text
scale = 0.5 * (s_lo + s_hi)
h_i = clamp(scale * hs_i, h_min, h_max)
estimated_faces = N(h)
face_error = estimated_faces - T
relative_face_error = face_error / T
```

如果 `T` 超出 `[N(all h_max), N(all h_min)]`，最终尺寸场饱和到相应边界，并明确记录 `target_faces_reachable=false`。

### 9.5 性能要求

不能在每次目标面数二分中重新装配和分解 Laplacian 系统。

正确执行顺序为：

```text
1. lambda 二分生成一次 h0；
2. 对 h0 进行一次 sparse factorization/solve，得到 hs；
3. 只对全局 scale 做标量二分和面数估计。
```

即每次构建 target field 只进行一次 screened-Laplacian 稀疏求解。

## 10. 最终 buildTargetLengths() 流程

建议将 `buildTargetLengths()` 明确改成以下顺序：

```text
1. mesh.validate()
2. l_bar = meanEdgeLength(mesh)
3. principal = computePrincipalCurvatures(mesh)
4. kappa_i = l_bar * max(abs(k1_i), abs(k2_i))
5. h0 = buildInitialTargetLengths(mesh, kappa, target_faces)
6. hs = smoothTargetLengths(mesh, h0, target_smoothing_alpha)
7. h = calibrateTargetLengths(mesh, hs, target_faces, h_min, h_max)
8. writeTargetFieldDiagnostics(...)
9. target_field_.build(mesh, h)
```

所有进入 `TargetLengthField::build()` 的最终尺寸必须满足：

```text
isfinite(h_i)
h_min <= h_i <= h_max
h_i > 0
```

## 14. 单元测试计划

### 14.1 主曲率解析模型

平面：

```text
k1 ~= 0
k2 ~= 0
kappa ~= 0
最终 target_h 应接近常量场
```

半径为 `R` 的球面：

```text
abs(k1) ~= 1/R
abs(k2) ~= 1/R
```

半径为 `R` 的圆柱面：

```text
max(abs(k1), abs(k2)) ~= 1/R
min(abs(k1), abs(k2)) ~= 0
```

鞍面 `z = 0.5 * (a*x^2 - b*y^2)` 原点附近：

```text
k1、k2 异号
abs(k1) ~= a
abs(k2) ~= b
kappa 使用最大绝对值，不发生符号抵消
```

允许误差应根据离散采样密度设置，不能对粗网格使用机器精度断言。

### 14.2 退化与边界测试

```text
1. 单三角形和低 valence 顶点不崩溃，允许 fallback；
2. 一环 rank 不足时能够尝试二环；
3. 退化邻域不产生 NaN/Inf；
4. fallback 数量与导出统计一致。
```

### 14.3 尺寸映射测试

```text
1. kappa 越大，h0 单调不增；
2. 所有 h0 均位于 [h_min,h_max]；
3. 常量 kappa 生成常量 h0；
4. 可达时 initial estimated faces 接近 target_faces；
5. 不可达时正确饱和到 h_min 或 h_max。
```

### 14.4 Laplacian 测试

```text
1. 常量 h0 求解后 hs 不变；
2. 非常量 h0 求解后 R(hs) <= R(h0)；
3. alpha 增大时相邻尺寸差整体减小；
4. hs 全部 finite、positive 且在上下界内；
5. 线性系统 scaled residual <= 1e-10。
```

### 14.5 最终校准测试

```text
1. 不触发 clamp 时，scale 接近 sqrt(N(hs)/T)；
2. 触发 clamp 时，二分仍保持单调并收敛；
3. 可达目标的 relative face error <= 1e-6；
4. scale 前后 hs_i/hs_j 保持不变，触发 clamp 的顶点除外；
5. 最终 h 全部位于 [h_min,h_max]。
```

### 14.6 尺度不变性测试

将同一个模型坐标整体乘以 `s`：

```text
k1、k2 应除以 s；
l_bar 应乘以 s；
kappa = l_bar * max(abs(k1),abs(k2)) 应基本不变；
h0、hs、h 应乘以 s；
estimated_faces 和最终拓扑规模应基本不变。
```

### 14.7 remesh smoke test

```text
1. global_iterations=0 能完成主曲率、平滑和最终校准；
2. global_iterations>0 的输出 mesh 合法；
3. split/collapse/flip 能继续查询新的 TargetLengthField；
4. target smoothing solver success；
5. 所有 iteration stats 为有限值。
```

## 16. 风险与处理

### 风险 1：主曲率拟合对网格噪声敏感

处理：

```text
1. 使用距离加权最小二乘；
2. 一环失败时使用二环；
3. 检查奇异值比；
4. 通过 h_min/h_max 限制极端结果；
5. 导出 fallback 和饱和比例。
```

### 风险 2：边界处邻域不对称

处理：

```text
1. 边界允许使用二环样本；
2. 不足时回退为零曲率；
3. 单独统计 boundary fallback rate；
4. 若边界成为主要误差来源，再考虑专门的一侧曲面拟合，不纳入首版。
```

### 风险 3：平滑抹掉小而重要的高曲率区域

处理：

```text
1. 先固定 p=0.75，只消融 alpha；
2. 对比 initial_h/smoothed_h common-scale 热力图；
3. 统计 h_min 饱和区域平滑前后的变化；
4. 如果普通 cotan Laplacian 跨特征扩散过强，再单独研究 edge-stopping 权重。
```

### 风险 4：目标面数可达但最终实际面数仍有偏差

说明：

```text
estimateTargetFaceCount() 是基于等边三角形面积的连续估计；
它能校准尺寸场密度积分，但不能保证离散 split/collapse 后的实际 faces 严格等于 T。
```

处理：继续同时记录 `estimated_faces` 和 remesh 最终 `faces`，不能混为同一个指标。

### 风险 5：旧 CLI 和实验脚本失效

处理：

```text
1. --csf-alpha 暂时作为 deprecated alias；
2. summary 只输出新语义字段；
3. 旧版本报告生成脚本不批量重写；
4. 新增 v2.11.0 专用实验脚本。
```

## 18. 最终公式汇总

主曲率局部拟合：

```text
z = 0.5*a*x^2 + b*x*y + 0.5*c*y^2

mu1,2 = 0.5*(a+c) +/- sqrt(0.25*(a-c)^2 + b^2)
k1,2  = mu1,2 / l_i
```

无量纲各向同性曲率：

```text
kappa_i = l_bar * max(abs(k1_i), abs(k2_i))
```

初始尺寸：

```text
h0_i = clamp(lambda / max(kappa_i, 1e-12)^0.75, h_min, h_max)
```

目标面数估计：

```text
h_f  = (h_i + h_j + h_k) / 3
N(h) = sum_f A_f / ((sqrt(3)/4) * h_f^2)
```

尺寸场平滑：

```text
tau = alpha * l_bar^2
(M + tau*L) * hs = M*h0
```

最终校准：

```text
h_i = clamp(scale * hs_i, h_min, h_max)
N(h) ~= target_faces
```

这五组公式共同构成 v2.11.0 的完整 target field 定义，后续代码、测试、诊断和实验必须以此为准。
