# v2.9.0 T21 no-MLS relocation 对比实验报告

## 实验目的

验证关闭 relocation 内部 MLS 投影后，T21 的 Chamfer Distance、symmetric RMSE、网格质量和收敛稳定性是否相对当前 v2.9.0 MLS-on 方案改善。

本次代码新增 CLI 开关：

```text
--relocation-mls <0|1>
```

默认值为 `0`。因此默认每轮流程为：

```text
split -> collapse -> flip -> feature-aware tangent smoothing
```

只有显式传入 `--relocation-mls 1` 时才执行 smooth 顶点的 MLS projection。

## 实验参数

```text
model = T21
iters = 10
preprocess = 0
curvature_mode = robust-mean
csf_alpha = 2.0
target_min_factor = 0.20
target_max_factor = 1.8
target_size_gamma = 2.0
max_flip_dihedral_degrees = 45
feature_aware_collapse = true
collapse_feature_omega = 0.15
relocation_mls = false
cd_samples = 100000
```

输出目录：

```text
cpp_adaiso/results/v2.9.0_T21_relocation_no_mls_defaultoff/T21_hmin020_iter10/
```

运行命令：

```powershell
.\cpp_adaiso\build\adaiso_cli.exe .\cpp_adaiso\examples\T21.off `
  -o .\cpp_adaiso\results\v2.9.0_T21_relocation_no_mls_defaultoff\T21_hmin020_iter10\T21.ply `
  --iters 10 --preprocess 0 `
  --curvature-mode robust-mean --csf-alpha 2.0 `
  --target-min-factor 0.20 --target-max-factor 1.8 --target-size-gamma 2.0 `
  --max-flip-dihedral-deg 45 `
  --feature-aware-collapse 1 --collapse-feature-omega 0.15 `
  --relocation-mls 0 `
  --gt .\cpp_adaiso\examples\T21.off --cd-samples 100000 `
  --export-target-field .\cpp_adaiso\results\v2.9.0_T21_relocation_no_mls_defaultoff\T21_hmin020_iter10\target_field `
  --export-iteration-meshes .\cpp_adaiso\results\v2.9.0_T21_relocation_no_mls_defaultoff\T21_hmin020_iter10\iteration_meshes `
  --export-all-stage-meshes .\cpp_adaiso\results\v2.9.0_T21_relocation_no_mls_defaultoff\T21_hmin020_iter10\stage_meshes `
  --summary-json .\cpp_adaiso\results\v2.9.0_T21_relocation_no_mls_defaultoff\T21_hmin020_iter10\summary.json `
  --quiet
```

## 观察

1. 关闭 MLS 后，CD 从 v2.9.0 MLS-on 的 `1.360237E-05` 降到 `6.995289E-06`，相对下降 `48.57%`；RMSE 下降 `28.29%`。
2. 相对 v2.8.3 `omega=0.15`，no-MLS 的 CD 也下降 `36.37%`，RMSE 下降 `20.23%`，说明当前 MLS-on 是 v2.9.0 CD 退化的主要来源之一。
3. no-MLS 的 Qavg、Qmin、violation 和 tail ops avg 都明显优于 v2.9.0 MLS-on，但仍弱于 v2.8.3：`Qmin=0.005582` 仍远低于 v2.8.3 的 `0.122351`，`violation=0.086676` 仍高于 `0.058786`。
4. 关闭 MLS 后后半程拓扑操作显著减少，tail ops avg 从 `2991.2` 降到 `1584.4`，说明每轮 MLS projection 确实在放大后续 split/collapse/flip 修补压力。
5. no-MLS 第 9 轮 Qmin 曾降到 `9.413E-04`，说明仅关闭 MLS 不能完全解决 feature-aware tangent smoothing 或硬分类固定带来的局部质量风险。

## 结论

本次 T21 `hmin=0.20, iter=10` 消融实验支持默认关闭 relocation MLS。

```text
v2.9.0 MLS-on:
CD   = 1.360237E-05
RMSE = 2.607908E-03

v2.9.0 no-MLS:
CD   = 6.995289E-06
RMSE = 1.870199E-03
```

关闭 MLS 后，几何误差显著改善，收敛稳定性也恢复了一部分。因此当前实现下，MLS 不应作为 relocation 的默认组成部分。

但 no-MLS 仍存在明显质量代价：Qmin 和 violation 未恢复到 v2.8.3 水平。后续如果继续推进 v2.9.x，优先方向应是给 tangent smoothing 增加局部质量保护、位移步长限制，或将 hard corner/crease/smooth 分类改为连续 feature 权重。
