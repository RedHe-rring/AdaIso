## 结论

以 high-curvature top10 RMSE 为主指标，`inverse-linear` 在 1 个模型上优于 `inverse-sqrt`，0 个模型上变差，3 个模型差异小于 1%。
如果 `inverse-linear` 的 top5/top10 RMSE 下降但 global CD 上升，说明它确实把预算更偏向尖锐区域，代价是平坦区域/整体误差。
如果 high-curvature RMSE 没有稳定下降，则不开根号不能作为默认策略，只适合作为高曲率细节优先的可选模式。

本次实验还看到一个需要控制的混杂因素：虽然两组使用相同 `target_faces` 输入预算，但 `inverse-linear` 的最终输出面数比 `inverse-sqrt` 高 6.23%-16.16%。因此当前结论应表述为：在相同目标预算配置下，`inverse-linear` 会明显压低高曲率区域的 `target_h`，但没有稳定带来高曲率局部误差下降；若要做最终定论，需要再做一轮“匹配最终面数”的校准实验。
