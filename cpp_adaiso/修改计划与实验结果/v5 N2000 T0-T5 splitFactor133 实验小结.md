# N=2000 T0-T5 splitFactor=1.33 实验小结

## 设置

在当前 v5.0.2 metric edge length 判据下，将 code variant 的 `splitFactor()` 从 `1.65` 改为 `1.33`，重新运行 T0-T5。其他参数保持：

```text
--target-faces 2000
--iters 10
--preprocess 0
--curvature-mode robust-mean
--csf-alpha 2.0
--cd-samples 100000
```

- 新结果目录：`cpp_adaiso/results/v5_N2000_T0_T5_compare/v5.0.2_split133/`
- 对比 CSV：`cpp_adaiso/results/v5_N2000_T0_T5_compare/split133_comparison.csv`

## 结论

- 相比 v5.0.2 split=1.65，split=1.33 在 6/6 个模型上 CD 更低，且 6/6 个模型面数更接近 2000。
- 相比 v5.0.1，split=1.33 在 6/6 个模型上 CD 更低。
- split=1.33 解决了 v5.0.2 split=1.65 在 N=2000 下的欠采样问题，平均 faces 从 1592 提高到 2152，平均 CD 从 `9.559e-05` 降到 `7.000e-05`。
- 代价是 qmin 明显下降，平均 qmin 从 v5.0.2 split=1.65 的 `0.249689` 降到 `0.160095`，final violation 也从 `0.043076` 升到 `0.189215`。这是预期的：降低 splitFactor 会保留/制造更多短边和局部高密度区域，几何误差下降，但 metric interval violation 增加。
- 对 N=2000 的几何精度目标，splitFactor=1.33 明显优于 1.65；如果要兼顾质量和 violation，下一步应在 `1.33~1.50` 之间扫描 splitFactor，并同时降低 collapseFactor。
