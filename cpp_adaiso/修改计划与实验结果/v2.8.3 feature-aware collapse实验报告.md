# v2.8.3 实验报告：feature-aware collapse placement

## 实验目的

验证 v2.8.3 的特征感知边塌缩是否能保持或改善 CD。

本实验只改变 collapse placement：

```text
baseline: feature_aware_collapse = false，继续使用 midpoint
v2.8.3:   feature_aware_collapse = true，根据端点特征强度选择 midpoint 或强特征端点
```

其余参数固定为 v2.8.2 当前设置：

```text
split_factor = 1.65
collapse_factor = 0.8
max_flip_dihedral_degrees = 45
curvature_mode = robust-mean
csf_alpha = 2.0
target_min_factor = 0.20
target_max_factor = 1.8
target_size_gamma = 2.0
iters = 10
preprocess = 0
project = 1
cd_samples = 100000
```

## 观察

1. 三组 feature-aware collapse 的 CD 均明显低于 midpoint 基线，说明该修改在本实验中不仅能保持 CD，还能改善 CD。
2. `omega=0.15` 的 CD 最低，从 `1.559091E-05` 降到 `1.099372E-05`，相对下降 `29.49%`；RMSE 下降 `16.03%`。
3. feature-aware 组的输出顶点数更高，说明一部分 collapse 被端点保留和后续约束影响后，整体网格保留了更多几何自由度。CD 改善不能完全解释为纯 placement 收益，也包含较高输出规模的影响。
4. `omega=0.10` 端点保留更激进，CD 改善明显，但 Qmin 降到 `0.059909`，质量风险偏高。
5. `omega=0.25` 是更均衡的结果：CD 仍下降 `23.87%`，RMSE 下降 `12.75%`，并且 Qmin 从 `0.135278` 提升到 `0.190348`，violation 增幅也最小。
6. feature-aware 组的 total collapse 明显减少，从 `17407` 降到 `14590~15112`，符合预期：特征端点保留会降低部分短边塌缩带来的几何收缩。

## 结论

本次 T21 `hmin=0.20, iter=10` 实验支持保留 feature-aware collapse placement。

如果目标只看 CD/RMSE，`omega=0.15` 最优：

```text
CD:   -29.49%
RMSE: -16.03%
```

如果目标同时考虑 CD 和三角形最差质量，`omega=0.25` 更稳：

```text
CD:   -23.87%
RMSE: -12.75%
Qmin: +0.055070
```

因此建议：

```text
1. v2.8.3 可以保留 feature_aware_collapse=true；
2. 默认 omega 建议从 0.15 继续观察，若后续多模型实验发现 Qmin 风险，可考虑改为 0.25；
3. 下一步应在 T30、T124 或 model_001 上复验，确认 CD 改善不是 T21 单模型特例。
```

## 后续建议

1. 补做 ROI inward 分析，直接验证鸟边缘/翅膀边缘 collapse 后收缩是否下降。
2. 增加 `omega=0.20`，检查是否能同时接近 `omega=0.15` 的 CD 和 `omega=0.25` 的 Qmin。
3. 若多模型上 `omega=0.15` Qmin 波动较大，优先把默认值调整为 `0.25`。
