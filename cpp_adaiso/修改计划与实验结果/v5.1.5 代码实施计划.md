# v5.1.5 代码修改计划：替换旧 auto-delta 尺寸场

## Summary

- 将 v5.1.4 的 `kappa_ref + h_ref_factor` 自动容差逻辑整体删除，替换为“输入局部边长 + CSF 后曲率”的 v5.1.5 尺寸场。
- 只清理核心库、CLI、summary JSON、target-field 诊断和测试；历史实验脚本/报告保留为旧版本记录，不纳入本次清理。
- 版本元数据更新到 `5.1.5`，CHANGELOG 增加本版条目。

## Key Changes

- 公共接口清理：
  - 删除 `TargetErrorCurvatureReference`、`parseTargetErrorCurvatureReference()`、对应 `toString()` 分支。
  - 删除 `AdaIsoConfig::target_error_h_ref_factor` 和 `AdaIsoConfig::target_error_curvature_reference`。
  - 删除 CLI 参数 `--target-error-h-ref-factor`、`--auto-delta-kappa-ref`，帮助文本、参数解析、校验和 summary JSON 一并删除。
  - 新增 `AdaIsoConfig::auto_delta_quantile = 0.5`，CLI 新增 `--auto-delta-quantile <0..1>`。

- 新尺寸场计算：
  - 保留现有主流程：`raw curvature -> solveCsf -> targetErrorCurvatureLengths -> target_field_.build`。
  - 在 sizing 内部新增：
    - `incidentMedianEdgeLengths(mesh)`：每个顶点取 incident edge length 中位数；如果发现没有 incident edge 的孤立点，直接报错。
    - `areaWeightedQuantile(values, weights, q)`：使用 barycentric vertex area 作为权重。
    - `local_delta_i = max(csf_curvature_i, kTargetKappaMin) * l_i^2 / 6`。
  - 当 `target_error_delta == 0` 时：
    - `target_error_delta = areaWeightedQuantile(local_delta_i, vertex_area_i, auto_delta_quantile)`。
  - 当 `target_error_delta > 0` 时：
    - 继续作为手动覆盖值，但目标边长仍使用 v5.1.5 新公式，不回到旧 `kappa_ref` 公式。
  - 每点目标边长：
    - `h_i = sqrt(6 * delta / max(csf_curvature_i, kTargetKappaMin) - 3 * delta^2)`。
    - 根号内非正或非有限时回退为 `h_max`。
    - 最终 `clamp(h_i, 0.25 * mean_edge_length, h_max)`。
    - `h_max = target_h_max_factor * mean_edge_length`。

- 旧代码删除/替换：
  - 删除 `maxCurvatureDefaultDelta()` 和 `referenceCurvature()`。
  - 删除 `TargetErrorSizingResult::kappa_ref`，保留 `kappa_max`。
  - 删除 verbose 输出、summary JSON、field diagnostics 中的 `kappa_reference` 和 `kappa_ref`。
  - 删除旧参数相关测试，不保留无效兼容入口。

- 诊断和可视化：
  - 保留仍可复用的 `raw_curvature_*`、`csf_curvature_*`、`target_h_*` 可视化。
  - `vertices.csv` 增加 `local_edge_median,local_delta` 两列。
  - `field_stats.json` 增加：
    - `auto_delta_source: "input_resolution_csf_curvature"`
    - `auto_delta_quantile`
    - `h_min_safe_factor: 0.25`
    - `local_delta_min`
    - `local_delta_q50`
    - `local_delta_q95`
    - `local_delta_max`
  - 增加 `local_delta_heat.ply` 和对应 `color_scales.json` 条目。
  - 删除/更新所有断言旧 `kappa_reference/kappa_ref` 的诊断测试。

## Assumptions

- 默认自动容差分位数固定为 `q = 0.5`。
- `h_min_safe` 第一版不暴露 CLI，内部固定为 `0.25 * mean_edge_length`。
- 孤立点不参与尺寸场；在 sizing 辅助函数中发现即报错。
- `target_error_delta > 0` 保留为手动绝对容差入口，但只覆盖 `delta_0`，不恢复旧 v5.1.4 计算路径。
- 本次只清理核心代码和测试，不改旧实验脚本/历史报告。
