# v2.5.0 实施计划

## Summary

- 将本计划保存为 `cpp_adaiso/v2.5.0实施计划.md`，作为 v2.5.0 的实施基准。
- `v2.4.0` 已在 `7444fa1` 提交并打 tag，v2.5.0 不移动、不重写该 tag。
- v2.5.0 实现曲面感知、梯度受控的 `log(h)` 尺寸场；允许使用外部库，优先低运行时间和代码干净。
- 最近三角形查询使用 vcpkg 中已安装的 `libigl::AABB`；不实现 Gaussian/nearest target lookup 的旧版本兼容。

## Implementation Changes

- 依赖与构建：
  - `CMakeLists.txt` 版本改为 `2.5.0`。
  - 增加 `find_package(Libigl CONFIG REQUIRED)`，链接 `igl::igl_core`。
  - 使用 vcpkg toolchain 配置，例如 `-DCMAKE_TOOLCHAIN_FILE=E:/dev/vcpkg/scripts/buildsystems/vcpkg.cmake`；当前环境实际发现的是 `E:/dev/vcpkg`。
- TargetLengthField 重构：
  - 保存输入 `Mesh`、顶点 `log_size x_i`、`igl::AABB` 三角形查询树。
  - 接口改为 `build(const Mesh& input, const std::vector<double>& log_lengths)` 和 `valueAt(point)`。
  - `valueAt(p)`：用 libigl AABB 找输入曲面最近三角形，取最近点重心坐标，插值 `x(p*)`，返回 `exp(x(p*))`。
  - 删除 target field 中的 `Nearest`、`GaussianKnn`、`target_k`、`target_sigma_factor` 逻辑。
- 尺寸场构建：
  - CSF 曲率求解保持 v2.4.0 screened solve。
  - 将连续分位数映射输出从 `h_i` 改为 `x0_i = log(h0_i)`。
  - 用 screened scalar smoothing 计算 `x`：`(M + alpha_h * l_bar^2 * L)x = Mx0`。
  - 对 `x` 做范围 clamp 和 gradation projection，使相邻边满足 `|x_i - x_j| <= log(target_max_adjacent_ratio)`。
  - 新增配置：`target_smooth_alpha = 0.3`、`target_max_adjacent_ratio = 1.30`、`target_gradation_iterations = 20`。
- 清理旧接口：
  - 删除 `TargetLookupMode`、`parseTargetLookupMode()`、`toString(TargetLookupMode)`。
  - CLI 删除 `--target-mode`、`--target-k`、`--target-sigma-factor`。
  - summary JSON 删除旧 lookup 字段，新增 v2.5.0 尺寸场参数。
  - 保留 `KDTree`，因为 MLS projection 和 metrics 仍使用它。

## Test Plan

- 单元测试 log-size 映射：
  - 常量曲率返回 `log(base * mesh_scale)`。
  - 曲率越大，`x0` 越小。
  - 重复曲率使用相同 `x0`。
- 单元测试 gradation projection：
  - 链式网格和三角网格上所有相邻边满足 `h_i / h_j <= target_max_adjacent_ratio`。
  - clamp 后仍满足 `[log(h_min), log(h_max)]`。
- 单元测试 surface target lookup：
  - 单三角形顶点、边中点、面内点的重心插值正确。
  - 面外点投影到三角形后查询正确。
  - 两三角形共享边处 `x(p)` 连续。
- 回归验证：
  - `cmake --build cpp_adaiso/build`
  - `ctest --test-dir cpp_adaiso/build --output-on-failure`
  - CLI smoke 确认新 summary 字段存在，旧 target lookup 字段不存在。

## Assumptions

- v2.5.0 首版不引入 QP solver；精确 QP 保留为理论定义，工程实现采用 screened smoothing + gradation projection。
- libigl AABB 是 v2.5.0 最近三角形查询的唯一主实现，不保留 Gaussian kNN target lookup 作为运行时模式。
- 若 libigl 不可用，配置阶段直接失败并提示使用 vcpkg toolchain；不在核心代码中维护第二套 BVH fallback。
- 最近点投影在边界、尖锐边、等距三角形处允许选择任意最近三角形；这类退化不作为 v2.5.0 首版复杂化处理。
