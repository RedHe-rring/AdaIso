# v2.9.0 修改方向：feature-aware relocation 与内层 MLS 投影

MLS投影有问题，先不用这个，给smooth添上约束后翅膀收缩的问题得到了一些改善，但是翅膀骨头、马的脊背问题的曲率还没有得到完全解决
下个版本还是考虑曲率场到尺寸场的映射问题

## 1. 修改目标

当前版本的 MLS 投影发生在整个 `remesh()` 结束之后，只对最终结果做一次投影。v2.9.0 计划删除这个最终投影逻辑，将 smooth 与 MLS 合并成每轮 remesh 内部的顶点重定位步骤，观察是否能更好地保持原始形状，尤其是减少边缘、尖角和折痕附近的收缩。

新的每轮 remesh 流程保持四个主阶段：

```text
split -> collapse -> flip -> relocation
```

其中：

```text
relocation = feature-aware tangent smoothing + MLS projection
```

`after_smooth` 快照表示完整 `relocation` 之后的 mesh，不再单独导出 `after_project`。

## 2. 需要删除或替换的旧逻辑

1. 删除 remesh 全部迭代结束后的最终 MLS 投影。
2. 删除原有 `project_to_surface` 配置项和 CLI 参数 `--project`。
3. MLS 投影不再是可选流程，而是 relocation 的固定组成部分。
4. 内层 MLS 投影不使用当前最终投影里的 `qmin` 质量保护逻辑。

## 3. MLS 投影参考对象

MLS 始终投影到输入清理后的原始 mesh：

```cpp
Mesh original_for_projection = removeDegenerateFaces(input);
```

如果开启 `preprocess`，`original_for_projection` 仍然使用 preprocess 之前的清理 mesh。这样可以把 relocation 后的 smooth 顶点约束回原始输入形状，而不是约束到预处理后的网格。

## 4. 顶点特征强度

对每个顶点 `v`，使用当前已有的特征强度计算逻辑：

```cpp
F(v) = computeVertexFeatureStrengths(mesh)[v]
```

`F(v)` 综合角缺陷和邻接面的法向夹角，代表顶点局部特征显著性。

新增两个固定常量用于本版本实验：

```text
feature_eps = 1e-12
zeta = 0.5
```

当 `F(v) <= feature_eps` 时，直接将 `v` 视为 `smooth` 顶点，避免普通光滑区域因为 `T_v = 0` 导致分类异常。

## 5. 顶点分类规则

目标是将每个顶点分类为：

```text
corner / crease / smooth
```

其中：

- `corner`：角点或孤立强特征点；
- `crease`：折痕点；
- `smooth`：普通光滑点。

### 5.1 一环邻点集合

对顶点 `v`，记一环邻点集合为：

```text
N(v) = {v1, v2, ..., vn}
```

其中 `n = |N(v)|`。

如果 `n == 0`，该顶点没有可用于判断的邻接结构，本版本按保守策略分类为 `corner`，在 relocation 中固定。

### 5.2 相对强度阈值

对中心顶点 `v`，计算相对强度阈值：

```text
T_v = zeta * F(v)
```

其中论文默认值取：

```text
zeta = 0.5
```

### 5.3 重要邻点集合

对每个邻点 `vi in N(v)`，如果满足：

```text
F(vi) >= T_v
```

则认为 `vi` 是 `v` 的候选重要邻点。

本版本先不启用边重要度过滤。也就是说，重要邻点集合定义为：

```text
I(v) = {vi in N(v) : F(vi) >= zeta * F(v)}
```

后续版本可以补充边重要性条件，用于排除伪折痕连接：

```text
I(v) = {vi in N(v) : F(vi) >= zeta * F(v) 且 edge(v, vi) 重要}
```

记重要邻点数量为：

```text
k = |I(v)|
```

### 5.4 理想分类

理想情况下：

```text
k = 0 -> corner
k = 2 -> crease
k = n -> smooth
```

解释：

- 强角点通常是局部特征强度峰值，`F(v) >> F(vi)`，因此没有邻点满足 `F(vi) >= zeta * F(v)`，对应 `k = 0`。
- 折痕通常沿一条曲线延伸，中心点前后方向各有一个重要邻点，对应 `k = 2`。
- 光滑区域内邻点强度与中心点接近，重要邻点数量接近整个一环，对应 `k = n`。

### 5.5 非理想分类

实际网格中可能出现：

```text
k = 1, 3, 4, ...
```

此时按距离最近的理想类别分类：

```text
d_corner = |k - 0|
d_crease = |k - 2|
d_smooth = |k - n|
```

选择距离最小的类别：

```text
C(v) = argmin(d_corner, d_crease, d_smooth)
```

例如：

- `n = 7, k = 1`：更接近 `0`，分类为 `corner`；
- `n = 7, k = 3`：更接近 `2`，分类为 `crease`；
- `n = 7, k = 6`：更接近 `7`，分类为 `smooth`。

如果距离相同，使用保守优先级：

```text
corner > crease > smooth
```

即宁可多保护一个特征点，也不要把真实角点或折痕点误认为光滑点。

## 6. relocation 中不同类别的移动规则

v2.9.0 先采用强保护策略，后续版本再研究更柔性的特征保护。

### 6.1 corner

`corner` 顶点完全固定：

- 不参与 tangent smoothing；
- 不参与 MLS projection；
- relocation 前后位置保持不变。

### 6.2 crease

`crease` 顶点本版本也完全固定：

- 不做一维平滑；
- 不参与 MLS projection；
- relocation 前后位置保持不变。

原因：当前实验优先验证“强保护特征点 + smooth 区域重定位”是否能缓解边缘收缩。一维折痕平滑留到后续版本单独验证，避免一次引入过多变量。

### 6.3 smooth

`smooth` 顶点执行完整 relocation：

1. 使用当前已有的切向平滑逻辑计算候选位置；
2. 对平滑后的 smooth 顶点执行 MLS projection；
3. MLS 投影到 `original_for_projection`；
4. 不做 `qmin` 质量保护；
5. 如果 MLS 结果非有限值，则保留投影前位置。

## 7. 边界顶点策略

本版本延续当前保守策略：boundary 顶点固定。

也就是说，boundary 顶点优先于 feature 分类处理：

```text
if v is boundary:
    fixed
else:
    classify by feature strength
```

boundary 顶点不参与 tangent smoothing，也不参与 MLS projection。

## 8. 代码结构建议

新增或调整以下内部函数：

```cpp
enum class VertexRelocationClass {
  Corner,
  Crease,
  Smooth
};

std::vector<VertexRelocationClass> classifyVerticesForRelocation(const Mesh& mesh) const;

void relocateVertices(Mesh& mesh, const Mesh& original_for_projection);
```

`remesh()` 主循环中原来的：

```cpp
tangentSmoothing(mesh);
mesh = removeDegenerateFaces(mesh);
write_stage_mesh("smooth");
```

替换为：

```cpp
relocateVertices(mesh, original_for_projection);
mesh = removeDegenerateFaces(mesh);
write_stage_mesh("smooth");
```

`relocateVertices()` 内部执行：

```text
1. 计算 boundary 顶点；
2. 计算 feature strength；
3. 分类 corner / crease / smooth；
4. 仅对 smooth 顶点做 tangent smoothing；
5. 仅对 smooth 顶点做 MLS projection；
6. corner、crease、boundary 顶点保持原位置。
```

## 9. 测试和实验观察指标

### 9.1 单元测试

需要更新或新增测试：

1. 删除 `project_to_surface=false` 相关依赖；
2. 确认 CLI 不再接受 `--project`；
3. 确认 stage 导出仍然只有：

```text
after_split
after_collapse
after_flip
after_smooth
```

4. 构造简单 mesh，验证 boundary/corner/crease 顶点在 relocation 后不移动；
5. 验证 smooth 顶点允许移动且输出 mesh 仍可 validate。

### 9.2 实验指标

重点对比 v2.8.x 与 v2.9.0：

- Chamfer Distance / symmetric RMSE；
- `qavg` / `qmin`；
- edge ratio violation；
- 边界点位移；
- 高 feature strength 顶点位移；
- T21 鸟模型边缘收缩快照对比。

## 10. 后续版本可能方向

v2.9.0 先使用强保护策略。如果结果显示形状保持改善但网格质量或局部均匀性下降，后续可以继续尝试：

1. `crease` 沿 PCA 主方向做一维平滑；
2. `corner` 使用小权重移动，而不是完全固定；
3. MLS 位移按 `F(v)` 衰减；
4. 对 `crease` 顶点投影到局部特征曲线，而不是普通 surface MLS；
5. 增加边重要度过滤，减少伪折痕误分类。
