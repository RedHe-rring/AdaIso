# v2.6.0 修改计划：使用 Robust Cotan Mean Curvature

## Summary

- 将 v2.6.0 默认初始曲率从当前 `normal-angle` 改为 `robust-mean`：受限 cotan Laplacian mean curvature magnitude。
- 保留当前曲率计算方式，通过 `--curvature-mode normal-angle` 用于对照实验。
- 不引入隐式 fallback：`robust-mean` 模式下曲率唯一来源就是 robust mean curvature；旧算法不参与计算。

## Key Changes

- 新增配置与 CLI：
  - `enum class CurvatureMode { NormalAngle, RobustMean }`
  - `AdaIsoConfig::curvature_mode = CurvatureMode::RobustMean`
  - CLI 新增 `--curvature-mode normal-angle|robust-mean`
  - summary JSON 新增 `"curvature_mode"` 字段。
- 重构曲率入口：
  - 当前 `computeRawCurvatureField` 改名为 `computeNormalAngleCurvatureField`。
  - 新增统一入口 `computeRawCurvatureField(mesh, config_.curvature_mode)`。
  - `buildTargetLengths()` 和 `computeCsf()` 都走统一入口。
- `robust-mean` 定义：
  - 使用 barycentric vertex area。
  - 对每条边计算 `0.5 * (cot alpha + cot beta)`。
  - cot 权重策略：非有限或负值置 `0`，正值截断到 `cot_max = 10.0`。
  - 面积下限：`area_floor = 1e-8 * mean_edge_length^2`。
  - 曲率信号：`signal_i = log1p(H_i * mean_edge_length)`。
  - `H_i = 0.5 * ||sum_j w_ij * (p_j - p_i)|| / max(area_i, area_floor)`。
  - 若产生非有限值，直接报错，不回退旧曲率。
- 诊断输出保持现有文件名：
  - `raw_curvature_heat.ply` 表示当前模式的扩散前曲率。
  - `csf_curvature_heat.ply` 表示当前模式的 CSF 扩散后曲率。
  - `vertices.csv` 继续记录 `raw_curvature` 和 `csf_curvature`，由 summary 中的 `curvature_mode` 解释来源。

## Test Plan

- Build and unit tests：
  - `cmake --build cpp_adaiso/build --config Release --target adaiso_cli adaiso_tests`
  - `ctest --test-dir cpp_adaiso/build --output-on-failure`
- Focused tests：
  - CLI accepts `normal-angle` and `robust-mean`; rejects unknown mode.
  - Flat/simple mesh produces finite robust-mean values.
  - Bad/sliver triangles do not produce nonfinite robust-mean values because cot/area are bounded.
  - Summary JSON records selected `curvature_mode`。
- Acceptance checks：
  - T21 normal-angle and robust-mean both export `raw_curvature_heat.ply` and `csf_curvature_heat.ply`。
  - T21 robust-mean summary has finite CD, positive output vertices/faces, and `csf_solver_success = true`。
  - Experiment record compares raw/CSF heatmaps, final target field, CD, Qavg/Qmin, and wing-edge visual retention。

## Assumptions

- v2.6.0 intentionally changes default behavior to `robust-mean`。
- No fallback from `robust-mean` to `normal-angle`。
- `normal-angle` is retained only as an explicit comparison mode。
- Constants `cot_max = 10.0` and `area_floor = 1e-8 * mean_edge_length^2` are fixed implementation defaults for v2.6.0, not exposed as CLI options unless later experiments show they need tuning。
