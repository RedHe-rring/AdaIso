# v5.3.7 修改方向：连续目标尺寸场能量

## Summary

- 将“靠近目标尺寸场”的评价从区间越界统计升级为连续能量：
  `E_size = mean(log(r_e)^2)`，其中 `r_e = target_metric_edge_length(e)`。
- Stage A split 仍按长边阈值触发；collapse 的主接受准则改为局部 `E_size` 下降。
- Stage B 的质量目标不改，但尺寸场保护统一改为 `E_size` 不恶化。
- 旧 `target_metric_violation` 保留为诊断和历史对比指标。

## Key Changes

- `EdgeRatioStats` 增加 short/long violation 和 `target_log_energy`。
- iteration stats、summary JSON、target-field output diagnostics 同步输出新指标。
- `LocalPatchMetrics` 同时计算旧 hinge violation 和新 log energy。
- collapse 中 `size_stage_collapse_rejected_by_target_length` 表示局部 `target_log_energy` 未下降。
- flip/relocation 仍以最小角质量改善为主，但尺寸场保护使用 `target_log_energy`。

## Test Plan

- 更新 `computeEdgeRatioStats()` 单元测试，覆盖 short/long violation 拆分和 `target_log_energy`。
- 更新 remesh smoke、target-field export 测试，检查新增字段有限且输出存在。
- 保留 collapse reject reason 闭合断言。
- 构建并运行：
  ```text
  cmake --build cpp_adaiso/build2 --config Release --target clean
  cmake --build cpp_adaiso/build2 --config Release
  ctest --test-dir cpp_adaiso/build2 -C Release --output-on-failure
  ```
- 先跑 `T0-T9` 小样本，再跑全 T，对比 v5.3.6。

## Acceptance

- `target_log_energy` 成为 v5.3.7 之后的 Stage A 连续尺寸场距离主指标。
- `mean_ratio` 应更接近 `1`，`short_violation_rate` 应下降或不明显恶化。
- RMSE/CD、坏角比例和 runtime 不应系统性恶化。
