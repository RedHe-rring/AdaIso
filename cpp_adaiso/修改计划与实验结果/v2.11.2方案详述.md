# AdaIso v2.11.2 方案详述

## 1. 文档目的与代码口径

本文从当前 `cpp_adaiso` v2.11.2 代码出发，自零梳理一次完整运行：程序接收什么、每个阶段产生什么、数学关系是什么、这些量怎样驱动重网格，以及最终输出什么。

本文描述的是当前 C++ 实现，不把论文描述、旧版 README 或实验设想当作现行行为。主要代码依据如下：

| 职责 | 实现文件 |
|---|---|
| CLI、参数解析、总输出 JSON | `src/main.cpp` |
| 总流程、目标场查询、重网格、诊断导出 | `src/AdaIsoRemesher.cpp` |
| 配置和统计结构 | `include/adaiso/AdaIsoRemesher.hpp` |
| 网格读写 | `src/IO.cpp` |
| 网格清理和拓扑基本量 | `src/Mesh.cpp`、`src/Geometry.cpp` |
| 主曲率二次曲面拟合 | `src/PrincipalCurvature.cpp` |
| 曲率异常值过滤 | `src/CurvatureFilter.cpp` |
| screened-Laplacian 曲率平滑 | `src/ScreenedLaplacian.cpp` |
| 曲率到初始目标边长、目标面数标定 | `src/TargetFaceSizing.cpp` |
| `log(h)` 向下渐变限制 | `src/TargetGradation.cpp` |
| 网格质量和 Chamfer Distance | `src/Metrics.cpp` |

一句话概括整个系统：

> 输入一个三角网格，在输入表面上建立“曲率越大、目标边长越小”的连续尺寸场，再反复执行长边拆分、短边坍缩、边翻转和切向重定位，输出接近目标尺寸、较为各向同性的三角网格。

## 2. 系统级输入与输出

### 2.1 必需输入

命令形式：

```powershell
adaiso_cli <input.obj|input.ply|input.off> -o <output.obj|output.ply> [options]
```

必需的业务输入是一个表面网格：

\[
\mathcal M=(V,F),
\qquad
V=\{\mathbf p_i\in\mathbb R^3\}_{i=0}^{n-1},
\qquad
F=\{(i,j,k)\}_{f=0}^{m-1}.
\]

- `V` 是三维顶点坐标。
- `F` 是顶点索引组成的面。
- OBJ、ASCII PLY、OFF 中的多边形面会以第一个顶点为扇心做 fan triangulation，进入算法后全部是三角形。
- 输入只使用几何坐标和面索引；文件里的法向、纹理、颜色、材质等属性不进入本算法，也不会保留到普通输出网格。
- PLY 只支持 ASCII，输出只支持 OBJ 或 ASCII PLY。

### 2.2 可选输入

- 一组运行参数，控制目标场、重网格轮数、诊断导出等。
- 可选 GT 网格 `--gt <mesh>`，只用于结束后的 Chamfer Distance 评估，不参与重网格。
- 可选诊断输出目录和迭代快照目录。

### 2.3 主输出

主输出是新的三角网格：

\[
\mathcal M'=(V',F').
\]

它满足的是工程上的近似目标，而不是严格约束：

- 局部边长尽量接近目标尺寸场 `h(x)`；
- 三角形尽量接近各向同性；
- 通过特征感知坍缩、翻转限制和切向移动减少明显几何破坏；
- 若启用 MLS，仅对被分类为光滑点的顶点做输入表面投影。

### 2.4 附加输出

程序总会把完整 summary JSON 打印到标准输出；若给出 `--summary-json`，同一内容还写入文件。可选输出还包括：

- 目标场逐顶点、逐边、逐面 CSV；
- 目标场统计 JSON 和彩色 PLY；
- 每轮网格快照；
- split/collapse/flip/smooth 分阶段快照；
- GT 存在时的面积采样 Chamfer Distance。

`--quiet` 只关闭写到标准错误的进度日志，不关闭标准输出中的 summary JSON。

## 3. 记号与核心数据

后文统一使用以下记号：

| 记号 | 含义 |
|---|---|
| `n,m` | 当前网格顶点数、三角面数 |
| `E` | 当前网格唯一无向边集合 |
| `A_f` | 三角形 `f` 的面积 |
| `\bar\ell` | 当前网格所有唯一边的平均长度，代码中为 `base_len` |
| `k_{1,i},k_{2,i}` | 顶点 `i` 的两个主曲率估计 |
| `\kappa_i` | 无量纲曲率标量 `\bar\ell\max(|k_1|,|k_2|)` |
| `\tilde\kappa_i` | 异常过滤后的曲率 |
| `\hat\kappa_i` | screened-Laplacian 平滑后的曲率 |
| `h_i^{(0)}` | 曲率直接映射得到的初始尺寸 |
| `h_i^{(g)}` | gradation limiter 处理后的尺寸 |
| `h_i` | 面数标定并截断后的最终顶点目标边长 |
| `h(\mathbf x)` | 输入支撑表面上的连续目标尺寸查询函数 |
| `N_*` | 目标面数，默认是清理后的输入面数 |

核心中间数据不是新网格，而是定义在目标场支撑网格顶点上的一个正标量数组：

\[
\mathbf h=(h_0,h_1,\ldots,h_{n-1}),\qquad h_i>0.
\]

该数组只建立一次，之后在所有全局重网格迭代中固定不变。当前网格的顶点即使经过拆分、坍缩或移动，也通过空间位置到支撑表面查询 `h(x)`，而不是重新计算曲率和尺寸场。

## 6. 阶段 0：读取、三角化和网格清理

### 6.1 输入

- 文件路径；
- OBJ、ASCII PLY 或 OFF 中的顶点和多边形面。

### 6.2 处理

多边形 `(v_0,v_1,\ldots,v_{r-1})` 被展开为：

\[
(v_0,v_1,v_2),(v_0,v_2,v_3),\ldots,(v_0,v_{r-2},v_{r-1}).
\]

`removeDegenerateFaces` 依次删除：

1. 三个索引中有重复的面；
2. 负索引或越界索引面；
3. 双倍面积不大于 `1e-14` 的面；
4. 顶点集合相同的重复面，不区分朝向；
5. 最后压缩未使用顶点并重映射索引。

三角形面积为：

\[
A(a,b,c)=\frac12\| (b-a)\times(c-a)\|.
\]

### 6.3 输出

- 一个只含有效三角面的紧凑 `Mesh`；
- 清理后的顶点数、面数和质量统计；
- 若 `--target-faces` 未指定，目标面数取正式清理后的面数。

注意：`original_for_projection` 在可选预处理之前保存，因此若启用 MLS，投影参考面是“清理后、预拆分前”的输入网格。

## 7. 阶段 1：可选极长边预拆分

该阶段由 `--preprocess 1` 启用，目的只是处理输入中远大于平均尺度的边，不使用目标尺寸场。

### 7.1 输入

- 清理后的网格；
- `subremesh_multiplier=1.5`；
- `max_subremesh_rounds=8`。

### 7.2 数学与规则

先计算唯一边平均长度：

\[
\bar\ell=\frac1{|E|}\sum_{(i,j)\in E}\|\mathbf p_i-\mathbf p_j\|.
\]

预拆分阈值为：

\[
T_{pre}=2\times1.5\times\bar\ell=3\bar\ell.
\]

每轮收集所有 `\ell_{ij}>T_pre` 的边，按长度降序，只拆当前最长的一条；新点放在中点：

\[
\mathbf p_m=\frac{\mathbf p_i+\mathbf p_j}{2}.
\]

一条边相邻的每个三角形被拆成两个三角形。最多执行 8 轮，且 `\bar\ell` 和阈值在该阶段开始时计算一次，不随拆分更新。

### 7.3 输出

- 预拆分并再次清理后的网格；
- 该网格成为目标曲率和目标尺寸场的支撑网格。

## 8. 阶段 2：主曲率估计

这是目标场的几何输入阶段。

### 8.1 输入

- 目标场支撑网格 `\mathcal M`；
- 其平均边长 `\bar\ell`。

### 8.2 面法向与顶点法向

三角形单位法向：

\[
\mathbf n_f=\frac{(\mathbf p_j-\mathbf p_i)\times(\mathbf p_k-\mathbf p_i)}
{\|(\mathbf p_j-\mathbf p_i)\times(\mathbf p_k-\mathbf p_i)\|}.
\]

顶点法向使用相邻面面积加权后归一化：

\[
\mathbf n_i=operatorname{normalize}\left(\sum_{f\ni i}A_f\mathbf n_f\right).
\]

### 8.3 局部坐标与尺度归一化

在顶点 `i` 处，从法向 `n_i` 构造正交切向基 `t_1,t_2`。局部尺度取一环邻边平均长度：

\[
s_i=\frac1{|N_1(i)|}\sum_{j\in N_1(i)}\|\mathbf p_j-\mathbf p_i\|.
\]

对样本点 `j`，归一化坐标为：

\[
x_j=\frac{(\mathbf p_j-\mathbf p_i)\cdot\mathbf t_1}{s_i},\quad
y_j=\frac{(\mathbf p_j-\mathbf p_i)\cdot\mathbf t_2}{s_i},\quad
z_j=\frac{(\mathbf p_j-\mathbf p_i)\cdot\mathbf n_i}{s_i}.
\]

尺度归一化使拟合系数先处于无量纲坐标中，再除以 `s_i` 还原曲率量纲。

### 8.4 加权二次曲面拟合

拟合 Monge patch：

\[
z\approx\frac12ax^2+bxy+\frac12cy^2.
\]

代码使用距离衰减权重。矩阵一行和右端为：

\[
\sqrt{w_j}\,[\tfrac12x_j^2,\ x_jy_j,\ \tfrac12y_j^2],
\qquad
\sqrt{w_j}\,z_j,
\]

其中：

\[
\sqrt{w_j}=\exp\left(-\frac14(x_j^2+y_j^2)\right),
\quad
w_j=\exp\left(-\frac12(x_j^2+y_j^2)\right).
\]

用 Jacobi SVD 解三未知量最小二乘问题。若奇异值为 `\sigma_1\ge\sigma_2\ge\sigma_3`，要求：

\[
\frac{\sigma_3}{\sigma_1}\ge10^{-6}.
\]

还要求至少 3 个有效样本、法向和局部尺度有效、解与残差有限。

### 8.5 主曲率

局部 Hessian 为：

\[
H=\begin{bmatrix}a&b\\b&c\end{bmatrix}.
\]

其两个特征值除以局部尺度后给出主曲率：

\[
k_{1,2}=\frac1{s_i}\left[
\frac{a+c}{2}\pm
\sqrt{\frac{(a-c)^2}{4}+b^2}
\right].
\]

实现会交换结果，保证 `|k_1|\ge|k_2|`。

最后构造无量纲标量：

\[
\kappa_i=\bar\ell\max(|k_{1,i}|,|k_{2,i}|).
\]

`\kappa` 无量纲，因此整体等比例缩放输入几何时，理想情况下目标场形状不变，而实际长度随 `\bar\ell` 同比例变化。

### 8.6 回退策略与可靠性输出

算法先用一环样本拟合。失败后改用两环样本，但局部归一化尺度仍是一环平均边长 `s_i`。两环仍失败时：

\[
k_{1,i}=k_{2,i}=\kappa_i=0.
\]

每个顶点输出：

- 实际使用的一环或两环；
- 有效样本数；
- `local_scale=s_i`；
- `singular_ratio=\sigma_3/\sigma_1`；
- 归一化拟合残差 RMS；
- 是否 fallback。

v2.11.2 增加这些诊断，是因为“小样本、近病态但刚好越过阈值”的拟合可能产生极大曲率，而小残差本身并不能证明曲率可信。

### 8.7 输出

`k1[]`、`k2[]`、`raw_kappa[]`、逐点拟合诊断和 fallback 数量。

## 9. 阶段 3：可选曲率异常值过滤

### 9.1 输入

- `raw_kappa`；
- 主曲率拟合的 `local_scale`；
- 过滤模式和参数。

### 9.2 `none`：默认行为

\[
\tilde\kappa_i=\kappa_i.
\]

该模式不修改 v2.11.1 默认目标场。

### 9.3 `topk_median`

1. 按 `\kappa` 从大到小排序；相同值按顶点编号排序。
2. 取前 `K` 个顶点。
3. 对每个入选点收集其两环邻点的原始 `\kappa`，不含自身。
4. 计算中位数 `m_i`。
5. 只允许向下替换：

\[
\tilde\kappa_i=\min(\kappa_i,m_i).
\]

注意，各入选点都读取原始 `principal.kappa`，不是按处理顺序读取已经修改的值，因此结果不依赖入选点之间的更新顺序。

### 9.4 `sampling_cap`

对局部采样尺度为 `s_i` 的顶点定义无量纲曲率上限：

\[
c_i=\beta\frac{\bar\ell}{s_i},
\qquad
\tilde\kappa_i=\min(\kappa_i,c_i).
\]

因为 `\kappa_i=\bar\ell|k_i|`，上式等价于限制：

\[
|k_i|s_i\le\beta.
\]

它表达的是“局部采样间距无法可靠分辨任意大的曲率”。若 `local_scale` 无效，则该点跳过 cap。

### 9.5 输出

- `filtered_kappa[]`；
- 每个顶点实际 cap，未受限点为正无穷；
- 修改顶点数及比例；
- 过滤前后最大曲率。

## 10. 阶段 4：screened-Laplacian 曲率平滑

该阶段平滑的是无量纲曲率，不是目标边长。

### 10.1 输入

- 网格；
- `filtered_kappa`；
- `curvature_smoothing_alpha=\alpha`。

若 `\alpha=0`，直接令：

\[
\hat\kappa=\tilde\kappa.
\]

### 10.2 质量矩阵

使用重心顶点质量：

\[
M_{ii}=m_i=\sum_{f\ni i}\frac{A_f}{3}.
\]

所有顶点质量必须为正且有限。

### 10.3 余切权图与 Laplacian

对于内边 `(i,j)`，标准余切权为：

\[
w_{ij}=\frac12(\cot\alpha_{ij}+\cot\beta_{ij}).
\]

边界边只有一个对角贡献。若合计权重非正或非有限，代码将其替换为：

\[
\eta=10^{-4}.
\]

因此实际使用的是严格正权图。图 Laplacian 为：

\[
L_{ii}=\sum_{j\in N(i)}w_{ij},
\qquad
L_{ij}=-w_{ij}.
\]

### 10.4 稀疏线性系统

扩散强度：

\[
\lambda=\alpha\bar\ell^2.
\]

求解：

\[
(M+\lambda L)\hat{\boldsymbol\kappa}
=M\tilde{\boldsymbol\kappa}.
\]

等价于最小化：

\[
E(\mathbf x)=
\frac12(\mathbf x-\tilde{\boldsymbol\kappa})^TM
(\mathbf x-\tilde{\boldsymbol\kappa})
+\frac\lambda2\mathbf x^TL\mathbf x.
\]

第一项保真，第二项抑制相邻顶点差异。系统使用 Eigen `SimplicialLDLT` 分解。

### 10.5 求解验收

设残差 `r=A x-b`，代码记录绝对残差 `||r||_2` 和缩放残差：

\[
r_s=
\frac{2\|Ax-b\|_2}
{\|A\|_\infty\|x\|_\infty+\|b\|_\infty+\epsilon}.
\]

要求：

\[
r_s\le10^{-10}.
\]

解中负数在返回主流程后截成 0：

\[
\hat\kappa_i\leftarrow\max(\hat\kappa_i,0).
\]

### 10.6 输出

- `smoothed_kappa[]`；
- 装配、分解、求解耗时；
- 非零元数；
- 绝对/缩放残差和 solver success。

## 11. 阶段 5：曲率映射为初始目标边长

### 11.1 输入

- `smoothed_kappa`；
- 平均边长 `\bar\ell`；
- 最大尺寸倍率 `f_{max}`，默认 5。

### 11.2 尺寸上下界

最小倍率固定为 0.05：

\[
h_{min}=0.05\bar\ell,
\qquad
h_{max}=f_{max}\bar\ell.
\]

要求 `f_max>0.05`。

### 11.3 逆幂映射

曲率指数固定为：

\[
\gamma=0.75.
\]

为避免除零，先取：

\[
\kappa_i^{safe}=\max(\hat\kappa_i,10^{-12}).
\]

初始形状尺寸为：

\[
h_i^{(0)}=
\frac{\bar\ell}{(\kappa_i^{safe})^{\gamma}}.
\]

此时故意不截断到 `[h_min,h_max]`。截断放在最后的全局标定阶段完成，因为当前阶段只表达相对尺寸形状：

- 曲率大 `→ h^{(0)}` 小；
- 曲率小 `→ h^{(0)}` 大；
- `\hat\kappa=0` 时会得到非常大的有限尺寸，最终通常被截到 `h_max`。

### 11.4 输出

- `initial_h=h^(0)`；
- `h_min` 和 `h_max`。

---

## 12. 阶段 6：向下 `log(h)` 渐变限制

这是 v2.11.1 起与曲率去噪明确分离的阶段。它不消除小尺寸源，只阻止尺寸从小值向外过快变大。

### 12.1 输入

- `initial_h`；
- 网格边长 `\ell_{ij}`；
- 平均边长 `\bar\ell`；
- 渐变倍率 `q>1`，默认 `1.30`。

### 12.2 局部硬约束

令：

\[
u_i=\log h_i.
\]

希望任意网格边满足：

\[
|u_i-u_j|
\le
\log(q)\frac{\ell_{ij}}{\bar\ell}.
\]

等价地，定义归一化 log slope：

\[
s_{ij}=
|\log h_i-\log h_j|\frac{\bar\ell}{\ell_{ij}},
\]

则必须有：

\[
s_{ij}\le\log q.
\]

当 `\ell_{ij}=\bar\ell` 时，相邻目标尺寸比不超过 `q`。

### 12.3 全局最短路形式

对每条边设置代价：

\[
c_{ij}=\log(q)\frac{\ell_{ij}}{\bar\ell}.
\]

对所有顶点同时作为源运行 Dijkstra 式松弛，得到：

\[
u_j^{(g)}=min_s\left(u_s^{(0)}+d_c(s,j)\right),
\]

其中 `d_c` 是沿网格图的累计边代价。于是：

\[
h_j^{(g)}=\exp(u_j^{(g)})\le h_j^{(0)}.
\]

这是“downward-only”的准确含义：limiter 只会减小较大尺寸以满足小尺寸源向外传播的梯度上界，绝不增大任何输入尺寸。

### 12.4 溯源输出

每次某个源通过松弛控制顶点 `j` 时，同时传播：

- `source_vertex[j]`：最终控制 `j` 的原始源顶点；
- `normalized_source_distance[j]`：该路径的几何长度除以 `\bar\ell`。

这使异常小 `h` 的传播范围可以被定位和汇总。

### 12.5 关闭 limiter

若 `--target-gradation 0`：

\[
h^{(g)}=h^{(0)},
\]

每个顶点的 source 是自身，距离为 0，before/after 指标相同。

### 12.6 输出

- `limited_h=h^(g)`；
- source 与距离；
- queue pop、松弛次数；
- 修改顶点数和 log reduction；
- 前后最大/P95/P99 normalized log slope；
- 前后最大相邻尺寸比。

`pre_limiter_estimated_faces` 和 `post_limiter_estimated_faces` 都调用面数估计的默认 `mean` 口径；即使后续标定选择 `--target-face-representative min`，这两个用于观察 limiter 影响的阶段量仍是 mean 估计。

---

## 13. 阶段 7：按目标面数做全局标定

limiter 决定相对形状，标定阶段用一个全局 scale 把该形状对齐到目标面数，并施加硬上下界。

### 13.1 面数估计模型

边长为 `h` 的正三角形面积是：

\[
A_{eq}(h)=\frac{\sqrt3}{4}h^2
=0.4330127018922193\,h^2.
\]

因此输入三角形 `f` 对目标面数的估计贡献为：

\[
\hat N_f=
\frac{A_f}{(\sqrt3/4)h_f^2},
\qquad
\hat N=\sum_f\hat N_f.
\]

`h_f` 有两种口径：

mean：

\[
h_f^{mean}=\frac{h_i+h_j+h_k}{3}.
\]

minimum：

\[
h_f^{min}=\min(h_i,h_j,h_k).
\]

默认用 mean。由于 `h_f^{min}\le h_f^{mean}`，同一尺寸场通常有：

\[
\hat N_{min}\ge\hat N_{mean}.
\]

这里的 `min` 是更保守的密度估计口径，不代表实际 remesher 一定能达到该面数。

### 13.2 最终尺寸族

以 limiter 输出作为 shape：

\[
g_i=h_i^{(g)}.
\]

给定全局 scale `s`：

\[
h_i(s)=\operatorname{clamp}(s g_i,h_{min},h_{max}).
\]

随着 `s` 增大，目标边长非减，估计面数 `\hat N(s)` 非增。

### 13.3 可达范围

全 `h_min` 时是理论最大密度：

\[
N_{dense}=\hat N(h_i\equiv h_{min}).
\]

全 `h_max` 时是理论最小密度：

\[
N_{coarse}=\hat N(h_i\equiv h_{max}).
\]

- 若 `N_*\ge N_dense`，返回全 `h_min`；只有等号时严格可达。
- 若 `N_*\le N_coarse`，返回全 `h_max`；只有等号时严格可达。
- 否则在内部范围内二分。

二分上界为：

\[
s_{max}=\frac{h_{max}}{\min_i g_i}.
\]

### 13.4 二分规则

初始：

\[
s_{lo}=0,\qquad s_{hi}=s_{max}.
\]

每轮令 `s_mid=(s_lo+s_hi)/2`：

- 若 `\hat N(s_mid)>N_*`，当前过密，需要增大尺寸，令 `s_lo=s_mid`；
- 否则令 `s_hi=s_mid`。

默认执行 64 轮，最后取区间中点。输出相对误差：

\[
e_N=\frac{|\hat N-N_*|}{N_*}.
\]

### 13.5 为什么最后标定不破坏 gradation 上界

统一乘 `s` 不改变任意 `log(h)` 差：

\[
\log(sg_i)-\log(sg_j)=\log g_i-\log g_j.
\]

再对所有点使用同一上下界 clamp 只会压缩差异，不会扩大差异。因此若 limiter 后满足边约束，最终尺寸也应满足。代码会再次测量并以 `1e-10` 量级容差做硬检查，违反则抛错。

### 13.6 输出

- 最终顶点目标尺寸 `target_h[]`；
- 全局 `target_scale`；
- 标定口径下的估计面数和相对误差；
- `target_faces_reachable`。

## 14. 阶段 8：目标场健康度诊断

v2.11.2 在最终尺寸场上同时计算以下指标，但它们不改变算法结果。

### 14.1 mean/min 双口径差异

同时输出 `final_estimated_faces_mean` 和 `final_estimated_faces_min`，以及：

\[
R_{min/mean}=\frac{\hat N_{min}}{\hat N_{mean}}.
\]

比值大说明同一面内尺寸变化强，mean 口径与“短边控制局部操作”的 remesher 之间可能存在明显预算偏差。

### 14.2 上下界饱和率

以容差 `10^{-12}\max(1,h_bound)` 判断：

\[
r_{min}=\frac{\#\{i:h_i=h_{min}\}}n,
\qquad
r_{max}=\frac{\#\{i:h_i=h_{max}\}}n.
\]

大量 `h_max` 饱和通常说明全局标定为补偿少量极小尺寸，把大部分区域推到了最大尺寸。

### 14.3 最小 5% 尺寸区域的面预算集中度

按每个输入面的 mean `h_f` 从小到大排序，取面数上最小的 `ceil(5%m)` 个面，计算它们的估计面数贡献占比：

\[
C_{5\%}=\frac{\sum_{f\in S_{5\%}}
A_f/[(\sqrt3/4)(h_f^{mean})^2]}
{\sum_f A_f/[(\sqrt3/4)(h_f^{mean})^2]}.
\]

该值很高时，少量小尺寸区域占用了绝大多数理论面预算。

### 14.4 输入边相对最终目标的违规率

对目标场支撑网格每条边：

\[
r_{ij}=\frac{\ell_{ij}}{\min(h_i,h_j)}.
\]

若：

\[
r_{ij}<f_c\quad\text{或}\quad r_{ij}>f_s
\]

则记为违规，其中 `f_c=0.8`，`code` 的 `f_s=1.65`，`paper` 的 `f_s=5/3`。该指标表示进入重网格之前有多少边已经需要操作。

## 15. 阶段 9：连续表面目标尺寸场

最终 `h_i` 定义在目标场支撑网格顶点上，而重网格过程中会产生新顶点并移动旧顶点，因此需要从空间位置查询尺寸。

### 15.1 构建

保存：

- 构建目标场时的支撑网格；
- 该网格每个顶点的最终 `h_i`；
- libigl AABB 最近三角形查询树。

### 15.2 查询

对任意空间点 `x`：

1. 在支撑表面上找最近点 `x_c` 及其三角形 `(a,b,c)`；
2. 求 `x_c` 在该三角形上的重心坐标 `(\lambda_a,\lambda_b,\lambda_c)`；
3. 线性插值：

\[
h(\mathbf x)=\lambda_a h_a+\lambda_b h_b+\lambda_c h_c,
\qquad
\lambda_a+\lambda_b+\lambda_c=1.
\]

若三角形退化，重心坐标退化为最近顶点 one-hot。正常情况下重心分量先截到 `[0,1]` 再归一化。

### 15.3 关键语义

- 这是“最近输入表面点上的分片线性场”，不是三维空间中的全局平滑函数。
- 所有全局迭代共享同一个场，不随输出拓扑更新。
- 当前顶点经过平滑稍微离开支撑面时，仍用最近三角形投回去查询。

## 16. 阶段 10：全局重网格循环

每轮固定执行：

```text
split → collapse → cleanup → flip → tangent smoothing → optional MLS → cleanup
```

默认 5 轮。每个子阶段不是求全局最优，而是受约束的局部离散操作。

### 16.1 边的目标参考值

对边 `(i,j)`，先分别查询：

\[
h_i=h(\mathbf p_i),\qquad h_j=h(\mathbf p_j).
\]

拆分始终用：

\[
h_{ij}^{split}=\min(h_i,h_j).
\]

坍缩参考取决于 variant：

\[
h_{ij}^{collapse}=
\begin{cases}
\min(h_i,h_j),&\text{code},\\
\max(h_i,h_j),&\text{paper}.
\end{cases}
\]

默认 `code`。

---

## 17. 子阶段 A：长边拆分

### 17.1 候选判据

边长：

\[
\ell_{ij}=\|\mathbf p_i-\mathbf p_j\|.
\]

若：

\[
\ell_{ij}>f_s\min(h_i,h_j),
\]

则为长边，其中：

\[
f_s=
\begin{cases}
1.65,&\text{code},\\
5/3,&\text{paper}.
\end{cases}
\]

### 17.2 批处理规则

- 候选按当前实际长度降序；
- 同一批中两条边不能共享端点；
- 选择前重新计算长度和目标，仍超阈值才保留；
- 一批同时建立所有中点，并拆分相邻三角形；
- 每个全局轮次最多 5 个 split pass。

新顶点：

\[
\mathbf p_m=\frac12(\mathbf p_i+\mathbf p_j).
\]

由于同批边不共享顶点，一个三角形至多命中一条本批拆分边，代码每个面也只执行第一次命中的拆分。

### 17.3 输出

- 拆分后的网格；
- 本轮累计 split 边数。

---

## 18. 子阶段 B：短边批量坍缩

### 18.1 候选判据

坍缩倍率固定：

\[
f_c=\frac45=0.8.
\]

若两端都不是边界点，且：

\[
\ell_{ij}<f_c h_{ij}^{collapse},
\]

则进入候选集合。候选按 `\ell/h` 升序，再按实际长度升序，优先处理最短、最违规的边。

### 18.2 特征强度

先计算顶点角亏。内部点参考角为 `2\pi`，边界点参考角为 `\pi`：

\[
\delta_i=\theta_i^{ref}-\sum_{f\ni i}\theta_{f,i}.
\]

再计算顶点相邻边上的最大面法向夹角 `\phi_i^{max}`。定义：

\[
\tau(x)=\min(\pi,2x),
\]

\[
K_i=\tau(|\delta_i|),
\qquad
E_i=\tau(\phi_i^{max}),
\]

\[
F_i=(K_i+1)(E_i+1)-1.
\]

`F_i` 同时结合角亏和折痕二面角。

### 18.3 坍缩点

默认中点：

\[
\mathbf p_m=\frac12(\mathbf p_i+\mathbf p_j).
\]

启用特征感知时，若：

\[
\max(F_i,F_j)>10^{-12}
\]

且两端特征的相对差异足够大：

\[
|F_i-F_j|\ge\omega\max(F_i,F_j),
\qquad \omega=0.15,
\]

则坍缩点直接选择特征更强的端点；否则仍取中点。

### 18.4 合法性约束

候选必须同时通过：

1. **非流形边约束**：相邻面数不能大于 2。
2. **link condition**：两端一环邻点交集必须恰好等于该边相邻面的对顶点集合，防止改变局部拓扑为非流形。
3. **剩余邻点数**：合并后相关邻点至少 3 个。
4. **不制造新的过长边**：对每个剩余邻点 `n`：

   \[
   \|\mathbf p_m-\mathbf p_n\|
   \le f_s\min(h(\mathbf p_m),h(\mathbf p_n)).
   \]

5. **局部三角形质量**：合并后非退化受影响面均要求：

   \[
   Q\ge0.05.
   \]

代码中的三角形质量为：

\[
Q=\frac{6A}{\sqrt3\,s\,\ell_{max}},
\qquad
s=\frac{\ell_0+\ell_1+\ell_2}{2}.
\]

正三角形 `Q=1`，退化三角形趋近 0。

### 18.5 无冲突批处理

一条候选边的 footprint 包含两端及其一环邻点。同批选中的不同候选 footprint 不得相交，避免批量坍缩互相影响。实际合并保留较小顶点编号、删除较大编号，但保留点坐标改为前述坍缩点，之后删除退化/重复面并压缩顶点。

每个全局轮次最多 5 个 collapse pass。

### 18.6 输出

- 坍缩并清理后的网格；
- 本轮累计 collapse 数。

---

## 19. 子阶段 C：边翻转

对有两个相邻面的内边 `(a,b)`，设两相邻三角形的对顶点为 `c,d`，翻转即：

\[
(a,b)\longrightarrow(c,d).
\]

### 19.1 必要条件

1. 原边恰有两个相邻面；
2. 原两面二面角不超过默认 `45°`；
3. `c\ne d`，且新边 `(c,d)` 当前不存在；
4. 新边长度在目标带内：

   \[
   0.8\min(h_c,h_d)
   \le\ell_{cd}\le
   f_s\min(h_c,h_d).
   \]

5. 翻转严格改善价数误差。

### 19.2 价数目标

内部点理想价数为 6，边界点为 4。定义局部误差：

\[
D=\sum_{v\in\{a,b,c,d\}}|val(v)-val_*(v)|.
\]

翻转后 `a,b` 价数各减 1，`c,d` 各加 1。仅当：

\[
D_{after}<D_{before}
\]

时允许翻转。

当前实现的价数数组在每个 flip pass 开始时计算一次，同一 pass 内前面翻转后不会增量更新；下一 pass 会基于新拓扑重新计算。

### 19.3 几何质量限制

- 新三角形方向按原两面法向和进行校正；
- 新两面二面角仍不得超过阈值；
- 默认 `avoid_obtuse_flip=true`，任一新三角形最大内角大于 `90°` 则拒绝。

每个全局轮次最多 5 个 flip pass，某一 pass 没有翻转则提前停止。

### 19.4 输出

- 翻转后的网格；
- 本轮累计 flip 数。

---

## 20. 子阶段 D：特征分类与切向重定位

重定位不改变拓扑，只调整点的位置。

### 20.1 顶点分类

复用特征强度 `F_i`。

- 边界点直接归为 `Corner`，不移动。
- `F_i\le10^{-12}` 的点归为 `Smooth`。
- 其余点统计一环中满足：

  \[
  F_j\ge\zeta F_i,\qquad\zeta=0.5
  \]

  的重要邻点数 `r_i`，并比较它到三种理想计数的距离：

  \[
  d_{corner}=|r_i-0|=r_i,
  \]

  \[
  d_{crease}=|r_i-2|,
  \]

  \[
  d_{smooth}=|r_i-|N(i)||.
  \]

  距离最小者决定分类；平局优先 `Corner`，其次 `Crease`，最后 `Smooth`。

只有 `Smooth` 点参与位置移动。

### 20.2 目标尺寸加权邻域质心

对光滑点 `i`，每个邻点 `j` 的基础权重，是所有同时包含 `i,j` 的面的面积之和：

\[
a_{ij}=\sum_{f\supset(i,j)}A_f.
\]

再乘邻点处目标尺寸：

\[
w_{ij}=a_{ij}h(\mathbf p_j).
\]

邻域质心：

\[
\mathbf c_i=
\frac{\sum_{j\in N(i)}w_{ij}\mathbf p_j}
{\sum_{j\in N(i)}w_{ij}}.
\]

### 20.3 切向投影和更新

位移：

\[
\mathbf d_i=\mathbf c_i-\mathbf p_i.
\]

去掉法向分量：

\[
\mathbf d_i^T=
\mathbf d_i-(\mathbf d_i\cdot\mathbf n_i)\mathbf n_i.
\]

同步更新：

\[
\mathbf p_i'=\mathbf p_i+\lambda_t\mathbf d_i^T,
\qquad
\lambda_t=0.6.
\]

所有新位置先写到副本，最后整体替换，因此同一轮内不会读取已经更新的邻点坐标。

### 20.4 输出

- Corner/Crease 原位不动；
- Smooth 点经过切向平滑的网格。

---

## 21. 子阶段 E：可选 MLS 投影

默认关闭。开启后，只把分类为 `Smooth` 的点替换为 MLS 结果，Corner/Crease 保持切向阶段后的坐标。

### 21.1 输入

- 待投影点 `p`；
- 清理后、预拆分前的原始输入网格顶点及其面积加权法向；
- `k=8`、最多 5 次、误差阈值 `1e-4`。

### 21.2 局部邻域和带宽

在当前迭代位置 `p_x` 周围查找 kNN，距离排序为 `d_1\le\cdots\le d_k`。带宽为：

\[
h_{MLS}=d_k+\max(0,d_k-d_{k-1}),
\]

再下限截到 `10^{-12}`。

权重：

\[
w_j=\exp\left[-\left(\frac{d_j}{h_{MLS}}\right)^2\right].
\]

加权点和法向：

\[
\mathbf a=\frac{\sum_jw_j\mathbf p_j}{\sum_jw_j},
\qquad
\mathbf n=\operatorname{normalize}
\left(\frac{\sum_jw_j\mathbf n_j}{\sum_jw_j}\right).
\]

### 21.3 投影

当前局部平面误差：

\[
e=|\mathbf n\cdot(\mathbf p-\mathbf a)|.
\]

投影位置：

\[
\mathbf p_x=
\mathbf p-[\mathbf n\cdot(\mathbf p-\mathbf a)]\mathbf n.
\]

注意公式始终以本点进入 MLS 时的原始 `p` 为基准；`p_x` 只影响下一轮 kNN 邻域。若误差相对上一轮增大则停止，若 `e<1e-4` 也停止。

### 21.4 输出

- 对有效 Smooth 点采用 MLS 投影位置；
- 投影后主流程再次删除退化和重复面。

当前实现没有“MLS 后若全局 Qmin 下降则整体回退”的守卫，判断现行行为时应以代码为准，而不是旧版 README 的说明。

## 22. 每轮与最终质量指标

### 22.1 三角形质量

每轮和最终 summary 中的 `qavg`、`qmin` 都来自：

\[
Q_f=\frac{6A_f}{\sqrt3\,s_f\,\ell_{max,f}}.
\]

\[
Q_{avg}=\frac1m\sum_fQ_f,
\qquad
Q_{min}=\min_fQ_f.
\]

### 22.2 边长/目标比

对当前输出网格每条边，统计时统一使用两端目标最小值，即使 variant 是 paper：

\[
r_{ij}=\frac{\ell_{ij}}
{\min(h(\mathbf p_i),h(\mathbf p_j))}.
\]

输出：

- mean ratio；
- population standard deviation；
- 线性插值 P05/P95；
- `r<0.8` 或 `r>f_s` 的违规率。

这些是观测指标，不是迭代停止条件；算法固定执行 `--iters` 指定的轮数。

## 23. GT Chamfer Distance

仅当给出 `--gt` 时执行。

### 23.1 面积采样

两个网格分别构建三角形面积 CDF，用 radical inverse 低差异序列：

- base 2 选择面积位置；
- base 3、5 生成三角形内二维参数；
- 若 `u+v>1`，使用 `(1-u,1-v)` 映射回单位三角形。

每个方向默认采样 100000 点。

### 23.2 双向距离

\[
D_{out\to gt}=
\frac1N\sum_{x\in S_{out}}
\min_{y\in S_{gt}}\|x-y\|^2,
\]

\[
D_{gt\to out}=
\frac1N\sum_{y\in S_{gt}}
\min_{x\in S_{out}}\|y-x\|^2.
\]

代码定义：

\[
CD=D_{out\to gt}+D_{gt\to out},
\]

\[
RMSE_{sym}=\sqrt{\frac{CD}{2}}.
\]

这里使用的是“采样点集到采样点集”的最近邻距离，不是点到连续三角面的精确距离。

| `filtered_kappa_heat.ply` | 过滤后曲率热图 |
| `smoothed_kappa_heat.ply` | 平滑曲率热图 |
| `initial_h_heat.ply` | 曲率映射后的初始 h 热图 |
| `limited_h_heat.ply` | limiter 后 h 热图 |
| `target_h_heat.ply` | 标定后最终 h 热图 |

曲率热图共用 raw/filtered/smoothed 合并后的 2%–98% 分位色标，便于阶段间直接比较；h 热图使用 `[h_min,h_max]` 且颜色反转，使小尺寸区域更醒目。热图裁色只影响显示，不改变 CSV 原值。

诊断 CSV 中几个容易混淆的数学量如下。对边 `(i,j)`：

\[
\texttt{target\_ratio}=\frac{\max(h_i,h_j)}{\min(h_i,h_j)},
\]

\[
\texttt{edge\_length\_to\_min\_target}
=\frac{\ell_{ij}}{\min(h_i,h_j)},
\]

\[
\texttt{h\_slope}=\frac{|h_i-h_j|}{\ell_{ij}},
\qquad
\texttt{normalized\_log\_slope}
=\frac{|\log h_i-\log h_j|\bar\ell}{\ell_{ij}}.
\]

对三角形 `(p_0,p_1,p_2)`，`grad_h_norm` 是该面上线性插值尺寸场的梯度模。令 `e_1=p_1-p_0`、`e_2=p_2-p_0`，先解：

\[
\begin{bmatrix}
e_1\cdot e_1&e_1\cdot e_2\\
e_1\cdot e_2&e_2\cdot e_2
\end{bmatrix}
\begin{bmatrix}a\\b\end{bmatrix}
=
\begin{bmatrix}h_1-h_0\\h_2-h_0\end{bmatrix},
\]

再计算：

\[
\texttt{grad\_h\_norm}=\|a e_1+b e_2\|.
\]

另外，summary JSON 中的 `stats.input_edge_target_violation_rate` 使用当前 variant 的 split factor；目标场目录内 `field_stats.json` 的同名诊断在现行代码中固定使用 `[0.8,1.65]`，因此 `paper` 模式下两处可能略有差异。

### 24.4 网格快照

- `--export-iteration-meshes <dir>`：`iter000.ply` 和每轮结束后的 `iterNNN.ply`；
- `--export-stage-meshes <dir>`：只输出第一轮的 `iter001_after_split/collapse/flip/smooth.ply`；
- `--export-all-stage-meshes <dir>`：每轮四个阶段全部输出。

`iter000.ply` 是目标场构建之后、第一轮全局操作之前的网格；若启用 preprocess，它已经包含预拆分结果。

## 26. T21 异常链条在数学上的解释

v2.11.2 实验记录验证的故障传播链可以直接由上述公式解释：

```text
近病态小样本二次拟合
  → 极大 raw κ
  → 逆幂映射产生极小 initial h
  → downward limiter 把小 h 向周围传播
  → 小区域以 1/h² 占据大量理论面预算
  → 全局 scale 被迫增大
  → 大部分普通区域撞到 hmax
  → mean 面数标定与 min-h 驱动的局部操作出现跟踪偏差
```

关键放大关系有两个：

第一，曲率到尺寸是逆幂：

\[
h\propto\kappa^{-0.75}.
\]

第二，尺寸到面预算是平方反比：

\[
\hat N_f\propto h_f^{-2}.
\]

合起来，在未考虑 limiter 和 clamp 的局部理想关系下：

\[
\hat N_f\propto\kappa^{1.5}.
\]

因此少量虚假大曲率可以超线性地占据面预算。screened smoothing 能降低单点峰值，但只要异常仍明显存在，limiter 仍可能把它扩散为一片小尺寸区域。sampling cap 的作用点在链条最前端，因而比单独放宽 limiter 更接近根因修复。

实验同时表明，直接切换到 min 口径会过度保守，sampling cap 候选虽然明显修复 T21/T36 失稳，但尚未全面达到旧基线的 Qavg、Qmin 和 violation 验收。因此 v2.11.2 保留这些能力为实验选项而不修改默认值。

## 27. 失败条件与边界行为

### 27.1 会直接报错的典型输入

- 不支持的输入/输出扩展名；
- binary PLY；
- 面索引越界；
- 清理后空网格；
- 无有效边或平均边长非正；
- 主曲率、尺寸或线性系统中出现非有限值；
- screened solve 分解/求解失败或缩放残差超过 `1e-10`；
- `gradation_ratio<=1`；
- `target_max_factor<=0.05`；
- sampling cap 模式下 `beta<=0`；
- 最终尺寸场违反配置的 gradation 硬约束。

### 27.2 特殊参数行为

- `--iters 0`：仍完整构建目标场和诊断，但不做全局 split/collapse/flip/smooth；输出是清理后、可能预拆分后的网格。
- `--curvature-smoothing-alpha 0`：完全跳过稀疏求解，filtered kappa 直接进入尺寸映射。
- `--target-gradation 0`：不传播小尺寸，但仍做最终全局标定和 clamp。
- 目标面数超出 `[全 hmax, 全 hmin]` 可达范围时，不报错，返回相应全边界场并将 `target_faces_reachable=false`。
- 开放边界不会被坍缩，且边界点在重定位分类中固定为 Corner，因此边界点既不坍缩也不平滑移动；边界边仍可能被 split。

### 27.3 当前实现不是严格保证的事项

- `target_faces` 是尺寸场的理论标定目标，不保证最终拓扑面数等于它。
- 固定迭代数结束后可能仍存在边长违规。
- 目标场的边上 log-gradation 有硬检查，但对三角形内部和跨非邻接最近表面片不提供同样的全局 Lipschitz 保证。
- 拓扑清理删除重复/退化面，但没有全局检查输入是否封闭、可定向、自交或整体流形。
- 特征保持是启发式规则，不是精确 CAD 约束。

## 28. 复杂度与主要耗时

设目标场支撑网格有 `n` 点、`m` 面、`e` 边，输出迭代中当前边数为 `e_t`。

| 阶段 | 典型复杂度/瓶颈 |
|---|---|
| 邻接、法向、面积、曲率样本 | 近似 `O(n+m+e)`，局部 SVD 是小矩阵 |
| screened-Laplacian | 稀疏装配 `O(n+e)`；主要耗时是稀疏 LDLT，依赖网格稀疏结构 |
| gradation limiter | 多源 Dijkstra，约 `O((n+e)log n)` |
| 面数二分 | 每轮扫全部面，`O(I_b m)`，默认 `I_b=64` |
| 目标场查询 | AABB 最近三角形查询，通常近似对数级但依赖几何分布 |
| split/collapse/flip | 每 pass 重建若干拓扑映射并扫描边，主要随 `e_t` 和 pass 数增长 |
| MLS | 每个输出点、每轮 MLS 做 kNN，默认最多 `5n_t` 次查询 |
| Chamfer | 两边各采样 N 点并做最近邻查询，默认 N=100000 |

目标场只建立一次，避免每个全局轮次重复曲率拟合、稀疏求解和面数二分。

## 30. 阅读一次结果时的建议顺序

为了快速判断失败发生在哪一层，建议按以下顺序查看：

1. `principal_fit_*`、`vertices.csv` 中的 sample count、SVD ratio、`|k|*local_scale`：先排除曲率拟合失真。
2. `raw_kappa_max → filtered_kappa_max → smoothed_kappa_max`：看过滤和平滑是否真正压住异常。
3. `initial_h → limited_h` 及 limiter source：看小尺寸传播范围。
4. `pre_limiter_estimated_faces → post_limiter_estimated_faces`：量化 limiter 增加了多少理论密度。
5. `hmin/hmax saturation` 和 `smallest_five_percent_face_budget_rate`：看预算是否被少量区域垄断。
6. `final_estimated_faces_mean/min`：看标定模型口径差异。
7. `input_edge_target_violation_rate`：看进入 remesher 时任务量有多大。
8. 每轮 split/collapse/flip 和 violation：看拓扑操作是否收敛到目标带。
9. Qavg/Qmin 与 CD：最后判断网格质量和几何保真。

这样能把“目标场本身错误”和“目标场正确但 remesher 跟踪不足”区分开来。

## 31. 最终方案总结

v2.11.2 的完整方案可以分成两个相对独立的子系统：

1. **目标尺寸场构建**：从局部二次曲面主曲率出发，经可选稳健过滤、screened 曲率去噪、逆幂尺寸映射、向下 `log(h)` 渐变限制和全局面数标定，得到定义在输入表面上的连续 `h(x)`。
2. **目标场驱动重网格**：固定使用 `h(x)`，以边长阈值控制 split/collapse，以价数与几何约束控制 flip，以特征分类控制切向重定位和可选 MLS 投影。

输入是带坐标和面的表面网格及参数；核心中间输出是可查询的连续目标边长场；最终输出是新的三角网格、完整运行统计以及可选的逐阶段诊断。

在数学上，方案的主链条是：

\[
(V,F)
\xrightarrow{\text{quadratic fit}}
(k_1,k_2)
\xrightarrow{\bar\ell\max|k|}
\kappa
\xrightarrow{\text{filter+screened solve}}
\hat\kappa
\xrightarrow{\bar\ell/\hat\kappa^{0.75}}
h^{(0)}
\xrightarrow{\text{log-gradation}}
h^{(g)}
\xrightarrow{\text{scale+clamp}}
h
\xrightarrow{\text{surface interpolation}}
h(\mathbf x)
\xrightarrow{\text{remesh}}
(V',F').
\]

v2.11.2 的价值不只是多了几个参数，而是把“拟合是否可靠、异常从哪里产生、limiter 由谁控制、面预算在哪里集中、标定口径是否偏离实际操作”变成了可以逐点、逐边、逐面验证的可观测流程。
