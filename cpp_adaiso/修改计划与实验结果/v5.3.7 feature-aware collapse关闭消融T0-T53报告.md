# v5.3.7 feature-aware collapse 关闭消融报告（T0-T53）

## 1. 诊断目的

- 验证 Stage A collapse 几何误差是否与 feature-aware collapse placement 有关。
- 消融组只改一个参数：
  ```text
  --feature-aware-collapse 0
  ```
- 其余参数保持 v5.3.7 默认 T 系列实验一致。
- 样本为 20 个模型：
  ```text
  T0-T9
  T10, T21, T30, T33, T36, T38, T44, T48, T51, T53
  ```

## 4. 判断

- 关闭 feature-aware collapse 会让 collapse 更激进：
  - `faces out/in` 平均下降 `0.068841`；
  - Stage A violation 平均下降 `0.021104`；
  - output violation 平均下降 `0.009178`；
  - runtime 平均下降 `4.6973s`。
- 质量指标也明显变好：
  - final min angle 平均上升 `5.7349`；
  - angle<10% 平均下降 `0.010883`。
- 但几何误差系统性变差：
  - 20/20 个模型 RMSE 上升；
  - 20/20 个模型 CD 上升；
  - 平均 RMSE %bbox 上升 `0.003500`；
  - 平均 CD/bbox2 上升 `1.703875E-07`。

## 5. 结论

- feature-aware collapse 不是造成几何误差的主因；相反，它目前在保护几何/特征。
- 关闭它可以更贴近尺寸场、减少面数并提升角度质量，但会稳定牺牲 RMSE/CD。
- 因此下一步不应关闭 feature-aware collapse。
- 更合理的方向是保留 feature-aware collapse，并给 Stage A collapse 增加 soft geometry guard 或 guarded projection，避免在尺寸场能量下降时过度偏离原曲面。
