还是尺寸场的计算，修改尺寸场映射过程，使得 高曲率区域保持较小尺寸，但不要让尺寸场剧烈变化；低曲率区域允许快速趋向大尺寸，因为那里细节不敏感。

使用反比例饱和函数进行映射

$
h(t)=
h_{min}
+
(h_{max}-h_{min})
\left(
1-t
\right)^\gamma
$

其中：

$
t \in [0,1]
$

表示归一化曲率，曲率越大，(t) 越接近 1。

这个函数满足：

* (t=0)，低曲率：
$
h=h_{max}
$

* (t=1)，高曲率：
$
h=h_{min}
$

* 如果 (\gamma>1)，高曲率端变化会变慢。

因为：

$
\frac{dh}{dt}
=-\gamma(h_{max}-h_{min})(1-t)^{\gamma-1}
$

当 $t \to 1$ 时：
$
\frac{dh}{dt} \to 0
$

这正好符合你的想法：

```text
高曲率区域尺寸场变化慢，形成小尺寸平台
低曲率区域可以较快变大
```

## 5. 推荐公式

我建议把当前线性映射：

[
h_i =
h_{max}-t_i(h_{max}-h_{min})
]

改成：

[
h_i =
h_{min}
+
(h_{max}-h_{min})(1-t_i)^\gamma
]

其中：

[
\gamma > 1
]

建议先试：

```cpp
gamma = 2.0
```

或者：

```cpp
gamma = 3.0
```

效果：

| gamma | 效果             |
| ----: | -------------- |
|   1.0 | 当前线性映射         |
|   1.5 | 稍微减缓高曲率区尺寸变化   |
|   2.0 | 推荐起点           |
|   3.0 | 高曲率区更明显形成小尺寸平台 |
|  >4.0 | 可能过度压缩高曲率响应    |

## 6. C++ 代码怎么改

在 `linearTargetLengths()` 里，当前核心循环大概是：

```cpp
const double denom = *max_it - *min_it;
for (std::size_t i = 0; i < curvature.size(); ++i) {
  const double t = (curvature[i] - *min_it) / denom;
  const double h = std::clamp(h_max - t * (h_max - h_min), h_min, h_max);
  result[i] = h;
}
```

建议改成：

```cpp
const double denom = *max_it - *min_it;
for (std::size_t i = 0; i < curvature.size(); ++i) {
  const double t = std::clamp((curvature[i] - *min_it) / denom, 0.0, 1.0);

  const double response = std::pow(1.0 - t, target_size_gamma);

  const double h = std::clamp(
      h_min + (h_max - h_min) * response,
      h_min,
      h_max);

  if (!std::isfinite(h) || h <= 0.0) {
    throw std::runtime_error("computed target length must be positive");
  }

  result[i] = h;
}
```

然后给 `linearTargetLengths()` 增加一个参数：

```cpp
double target_size_gamma
```

并检查：

```cpp
if (target_size_gamma <= 0.0 || !std::isfinite(target_size_gamma)) {
  throw std::runtime_error("target size gamma must be positive");
}
```

如果：

```cpp
target_size_gamma = 1.0
```

就退化回线性映射。论文实验里这就是 baseline，很好做消融。
