# v2.9.0 T21 relocation 实验报告

## 实验目的

验证 v2.9.0 的 feature-aware relocation 是否能在 T21 上降低 Chamfer Distance 和 symmetric RMSE。

本次实验使用当前 v2.9.0 代码：

```text
split -> collapse -> flip -> relocation
relocation = feature-aware tangent smoothing + MLS projection
```

其中 `corner / crease / boundary` 顶点固定，只有 `smooth` 顶点执行切向平滑和 MLS。当前 CLI 已删除 `--project`，MLS relocation 是固定流程。`after_smooth` 快照表示完整 relocation 后的 mesh。

## 实验参数

```text
model = T21
iters = 10
preprocess = 0
curvature_mode = robust-mean
csf_alpha = 2.0
target_min_factor = 0.20
target_max_factor = 1.8
target_size_gamma = 2.0
max_flip_dihedral_degrees = 45
feature_aware_collapse = true
collapse_feature_omega = 0.15
cd_samples = 100000
```

输出目录：

```text
cpp_adaiso/results/v2.9.0_T21_relocation/T21_hmin020_iter10/
```

运行命令：

```powershell
.\cpp_adaiso\build\adaiso_cli.exe .\cpp_adaiso\examples\T21.off `
  -o .\cpp_adaiso\results\v2.9.0_T21_relocation\T21_hmin020_iter10\T21.ply `
  --iters 10 --preprocess 0 `
  --curvature-mode robust-mean --csf-alpha 2.0 `
  --target-min-factor 0.20 --target-max-factor 1.8 --target-size-gamma 2.0 `
  --max-flip-dihedral-deg 45 `
  --feature-aware-collapse 1 --collapse-feature-omega 0.15 `
  --gt .\cpp_adaiso\examples\T21.off --cd-samples 100000 `
  --export-target-field .\cpp_adaiso\results\v2.9.0_T21_relocation\T21_hmin020_iter10\target_field `
  --export-iteration-meshes .\cpp_adaiso\results\v2.9.0_T21_relocation\T21_hmin020_iter10\iteration_meshes `
  --export-all-stage-meshes .\cpp_adaiso\results\v2.9.0_T21_relocation\T21_hmin020_iter10\stage_meshes `
  --summary-json .\cpp_adaiso\results\v2.9.0_T21_relocation\T21_hmin020_iter10\summary.json `
  --quiet
```

## 观察

1. v2.9.0 relocation 没有降低 T21 的 CD 和 RMSE。相对 v2.8.3 `omega=0.15`，CD 上升 `23.73%`，RMSE 上升 `11.23%`。
2. 输出顶点和面数明显增加，说明 relocation 后的几何状态触发了更多 split/collapse/flip 操作；总 split、collapse、flip 都高于 v2.8.3 基线。
3. 最差质量明显退化，`Qmin` 从 `0.122351` 降到 `0.000572`，并且第 8、9 轮曾降到 `1e-4` 和 `2e-5` 量级。
4. violation 从 `0.058786` 上升到 `0.119634`，说明当前 relocation 对目标边长分布的稳定性不利。
5. tail ops avg 从 `1140.8` 上升到 `2991.2`，说明后半程仍有大量拓扑操作，未进入更稳定的收敛状态。

## 结论

本次 T21 `hmin=0.20, iter=10` 实验不支持当前 v2.9.0 relocation 方案。

按预设判定标准：

```text
CD:   未改善，1.099372E-05 -> 1.360237E-05
RMSE: 未改善，2.344538E-03 -> 2.607908E-03
```

同时，Qmin 和 violation 均明显恶化。因此当前“corner/crease/boundary 强固定 + smooth 内层 MLS”的组合不应直接作为默认方案保留。

## 后续建议

1. 优先检查 `after_smooth` stage mesh 中 relocation 是否制造局部极差三角形，重点看第 7-9 轮。
2. 尝试恢复 MLS 的局部质量保护，或至少对 smooth 顶点 MLS 位移设置步长限制。
3. 单独做消融：只启用 feature-aware smoothing、不启用 MLS；或只内层 MLS、不启用 corner/crease 强固定。
4. 如果继续使用强固定策略，需要考虑固定点附近 smooth 点的过度拉扯，可能需要 feature strength 连续权重而不是硬分类。
