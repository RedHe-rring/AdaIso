# v2.10.2 曲率指数修改计划

## 目标

v2.10.1 去掉了 robust-mean 曲率信号中的 `log1p`，T0 上 `target_h max/min` 从 `3.01x` 增加到 `3.38x`，但尖峰区域的 target_h 仍偏大。数据表明尖峰处没有被 `h_abs_min` 卡住：T0 的 `h_abs_min=0.000999`，实际 `observed_h_min=0.011277`。因此问题不是最小边长下限，而是 `1/sqrt(kappa)` 的尺寸响应仍偏弱。

v2.10.2 将尺寸公式从固定平方根响应改为内部固定指数响应：

```text
h_i(lambda) = clamp(lambda / pow(max(kappa_i, kappa_min), alpha), h_abs_min, h_abs_max)
alpha = 0.75
```

其中 `kappa` 仍是 CSF 扩散后的 logless robust-mean 曲率信号。

## 代码修改

- 新增内部常量 `kTargetCurvatureExponent = 0.75`。
- `targetFaceCurvatureLengths()` 中：
  - `lambda / sqrt(kappa)` 改为 `lambda / pow(kappa, kTargetCurvatureExponent)`。
  - 二分上界 `hi_lambda` 同步改为 `h_max * pow(max_kappa, kTargetCurvatureExponent)`。
- 不新增 CLI 参数，不恢复旧尺寸场映射，不暴露 alpha。
- 保留 v2.10.1 的 `target_h_heat_observed.ply` 诊断输出。
- summary 中 `target_size_mapping` 改为 `target_faces_inverse_power_diffused_curvature`，并记录 `target_curvature_exponent=0.75`，避免继续写 inverse-sqrt 造成误读。

## 实验计划

- 构建并运行 `adaiso_tests.exe`。
- 对 `cpp_adaiso/examples` 下 31 个 `T*.off` 运行：
  - `--iters 10`
  - `--preprocess 0`
  - `--curvature-mode robust-mean`
  - `--csf-alpha 2.0`
  - `--gt <same model>`
  - `--cd-samples 100000`
  - `--export-target-field`
  - `--summary-json`
- 输出目录：`cpp_adaiso/results/v2.10.2_alpha075/T_all_iter10/<model>/`。
- 汇总并对比 v2.10.0：
  - CD 是否降低。
  - Qmin/violation 是否有明显代价。
  - `target_h p95/p05`、`target_h max/min` 是否明显增大。
  - target-field 可视化文件是否完整。

## 预期

T0 的 what-if 估算显示 alpha 从 `0.5` 提到 `0.75` 时：

```text
target_h p95/p05: 1.50x -> 1.83x
target_h max/min: 3.38x -> 6.22x
尖峰 0.1% 平均 h: 0.0118 -> 0.0094
```

预期 v2.10.2 会让尖峰区域更密，但可能带来更高的 `grad_h_norm`、更低的 Qmin 或更高的 edge-target violation，需要用全 T 系列实验判断是否值得继续。
