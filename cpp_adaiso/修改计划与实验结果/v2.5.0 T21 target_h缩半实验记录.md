# v2.6.0 T21 target_h 缩半诊断实验记录

## 实验目的

T21 在翅膀边缘出现几何信息丢失。本实验用于判断该问题是否主要由目标边长 `target_h` 过大导致。

当前代码中目标边长的绝对尺度来自：

```text
scaled_base = mean_edge_length * mesh_scale
h_min = scaled_base * target_min_factor
h_max = scaled_base * target_max_factor
```

因此本实验不改源码，使用 `--mesh-scale 0.5` 等价地把整张 target field 的目标边长整体缩为默认值的一半。对比默认 `h`、缩半 `h`、以及关闭最终 MLS 投影后的结果，判断信息丢失更可能来自目标边长、remesh 操作，还是最终投影。

## 实验设置

- 代码版本：`4f91ea7 Update CSF defaults and v2.5 experiment report`
- 输入模型：`cpp_adaiso/examples/T21.off`
- 迭代次数：`--iters 10`
- GT/CD：使用原始 `T21.off` 作为 `--gt`
- CD 采样：默认 `100000` samples per direction
- 曲率场可视化：每组均导出 `raw_curvature_heat.ply` 和 `csf_curvature_heat.ply`
- 构建状态：`adaiso_cli` 已是最新，`ninja: no work to do`

- CD 降低约 `61.76%`。
- symmetric RMSE 降低约 `38.16%`。

- Qmin 从 `0.170683` 提高到 `0.260197`。
- final violation 从 `0.038010` 降到 `0.012276`。

## 观察

- `--mesh-scale 0.5` 成功把 observed target_h 范围整体缩半：`0.007634-0.022825` 变为 `0.003817-0.011412`。
- 缩半后输出网格明显加密，顶点/面数约增至默认组的 4.19 倍，符合二维曲面上线性边长减半会带来约 4 倍面数的预期。
- 缩半后 CD 明显下降，说明默认 target_h 下的几何采样确实偏粗，容易造成 T21 翅膀边缘一类细节丢失。
- `project=1` 和 `project=0` 的缩半结果完全一致，因为开启投影时最终 MLS projection 被质量保护拒绝：

```text
projection rejected: qmin would drop from 0.260197 to 0.0192265
```

因此本次缩半实验的最终输出没有实际经过 MLS 投影；它主要反映 remesh 阶段和 target_h 尺度的影响。

## 结论

本实验支持判断：T21 翅膀边缘信息丢失与默认 target_h 过大有明显关系。把 target_h 整体缩半后，CD 和 RMSE 明显下降，输出网格更密，Qmin 和 edge-ratio violation 也没有恶化，反而改善。

但全局缩半 target_h 的代价很高：输出规模从 `7042/14084` 增至 `29516/59029`，约 4.19 倍。因此它更适合作为诊断，不适合作为最终默认方案。

下一步更合理的 v2.6.0 方向是局部化地缩小 h，而不是全局 `mesh_scale=0.5`：

- 针对薄片、边界、翼尖/翅膀边缘等区域降低 target_h。
- 保持平坦大面积区域的 h 接近默认值，避免全局面数暴涨。
- 增加边缘/特征保护或 collapse 限制，避免跨细节区域合并。
- 重新设计 MLS projection，使投影能局部接受/拒绝或投影后修复，而不是当前全局质量门控。
