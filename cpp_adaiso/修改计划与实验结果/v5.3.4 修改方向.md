# v5.3.4 修改方向：Collapse Target-Energy 接受准则

## Summary

v5.3.3 诊断显示 Stage A collapse 的主要拒绝来源是 `target_length`，其次是 `batch_conflict`，角度拒绝占比很低。v5.3.4 只处理第一主因，不改 batch 选择。

## Key Changes

- 版本更新到 `5.3.4`。
- Stage A 默认继续使用 `split_collapse_no_guard`。
- `LocalPatchMetrics` 增加 `max_target_metric_ratio`。
- collapse 删除旧的逐边硬拒绝：
  ```text
  any after edge ratio > split_factor
  ```
- collapse 改用局部 target metric energy 接受：
  ```text
  after.target_metric_violation <= before.target_metric_violation - tol
  after.max_target_metric_ratio <= max(before.max_target_metric_ratio, split_factor) + 0.05
  ```
- 角度安全线不变：
  ```text
  after_min_angle >= min(before_min_angle, min_angle_floor)
  ```
- v5.3.3 的 collapse reject reason 诊断继续保留。

## Expected Judgment

- `target_length` 拒绝应明显下降。
- collapse 接受率应高于 v5.3.3 的 `4.20%`。
- 若 `batch_conflict` 成为主因，下一版再做 mini-batch 或 sequential collapse 消融。
- 不接受 RMSE/CD/violation 或坏角指标的系统性恶化。
