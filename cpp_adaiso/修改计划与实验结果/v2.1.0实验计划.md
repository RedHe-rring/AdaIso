# 批量 Collapse 修改计划

## Summary
- 将当前“每个 global iteration 最多 collapse 10 条边”改为“每个 global iteration 最多执行 10 轮 batch collapse”。
- `max_collapse_passes` 默认仍为 `10`，但语义从“最多 10 次单边 collapse”变为“最多 10 轮批量选择并 collapse”。
- `collapse_count` 日志继续表示实际 collapse 的边数，不表示 batch 轮数。

## Key Changes
- 在 `collapseShortEdges()` 中改为每个 pass 批量选择候选短边：
  - 候选条件仍为非边界边，且 `length < collapseFactor() * target`。
  - 候选排序改为按 `length / target` 升序，优先处理相对目标长度最短的边；同值时可用 `length` 升序稳定排序。
  - 对每个候选边继续保留非流形保护：`edgeFaces(edge).size() > 2` 时跳过。
  - 调用现有 `collapseValid()` 做拓扑、长度和局部质量检查。
  - 用 `blocked_vertices` 防止同一 batch 内局部冲突；footprint 取 `{a, b}` 加上 `a`、`b` 的一环邻点。
  - 每轮 batch 完成后重建 `boundary/e2f/neigh/vf`，再进入下一 pass。
- 用新的私有 helper 替代单边 helper：
  - 新增 `int collapseEdgesBatch(Mesh& mesh, const std::vector<Edge>& selected) const`。
  - 删除或停用原 `collapseOneEdge()` 调用，避免每条边 collapse 后立刻 `removeDegenerateFaces()` 导致后续边索引失效。
  - batch helper 对所有 selected 边先计算 `keep = min(a,b)`、`remove = max(a,b)` 和 midpoint，更新 keep 顶点位置，统一替换所有 face 中的 remove 顶点，最后只调用一次 `removeDegenerateFaces(mesh)`。
  - helper 返回实际处理的 selected 边数，累加到 `total`。

## Public Interface / Docs
- 不新增 CLI 参数；`main.cpp` 不需要改。
- `AdaIsoConfig::max_collapse_passes` 字段保留，默认值仍为 `10`。
- 更新设计文档中“collapse 每 pass 只 collapse 一个候选边”的限制说明，改为说明当前已支持同一 pass 内批量选择互不冲突短边。

## Test Plan
- 在 `basic_tests.cpp` 增加一个回归测试：
  - 构造两个互不相连的闭合小网格组件，例如两个平移后的 octahedron。
  - 配置 `global_iterations = 1`、`max_collapse_passes = 1`、`mesh_scale` 设大、`project_to_surface = false`、`preprocess = false`、`min_quality_after_collapse = 0.0`、`verbose = false`。
  - 断言输出 mesh 合法，且顶点数至少减少 2，证明同一个 collapse pass 内可以 collapse 多条互不冲突边。
- 保留现有 smoke 和 edge case 测试，确认批量 collapse 不破坏常规 remesh。
- 验证命令：
  - `cmake --build cpp_adaiso/build --target adaiso_tests`
  - `ctest --test-dir cpp_adaiso/build --output-on-failure`

## Assumptions
- batch 内只 collapse footprint 不相交的边；这是保证 `collapseValid()` 基于 batch 前拓扑仍然可信的核心约束。
- 不在本次修改中暴露 `max_collapse_passes` 到 CLI。
- 不改变 split、flip、smooth、MLS 投影流程。
