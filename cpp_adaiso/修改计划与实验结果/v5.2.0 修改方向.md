# 建议的论文方法

## 题目定位

可以将方法定位为：

> **Feature-Decoupled Adaptive Isotropic Remeshing with Confidence-Aware Constraints**
> 基于特征解耦与置信度约束的自适应各向同性重网格化

论文主线不是“提出新的 Split/Collapse/Flip”，因为这套增量式操作流程已经相当成熟：长边分裂、短边折叠、翻边、切向重定位和投影构成经典局部 remeshing 框架。([不列颠哥伦比亚大学计算机科学系][1])

真正应强调的是：

[
\boxed{
\text{尺寸估计不依赖精确特征分割}
}
]

以及：

[
\boxed{
\text{低置信度特征由连续几何误差保护，高置信度特征由离散约束保护}
}
]

这比单纯的“曲率自适应 + crease 检测”更有明确的方法论。

---

# 1. 问题定义

输入：

[
\mathcal M_0=(V_0,F_0),
]

其中 (\mathcal M_0) 是参考三角网格；同时给定：

* 目标面数 (N^\star)；
* 最小和最大目标边长 (h_{\min},h_{\max})；
* 几何距离容差 (\varepsilon_d)；
* 法向偏差容差 (\varepsilon_n)；
* 硬特征置信度阈值 (\tau_h)。

输出重网格：

[
\mathcal M=(V,F),
]

要求同时满足：

1. 局部边长接近目标尺寸场；
2. 面数接近 (N^\star)；
3. 三角形质量较好；
4. 与参考曲面的几何误差受控；
5. 高置信度 crease、corner 和 boundary 拓扑不被破坏。

可以定义三个评估目标：

### 尺寸一致性

[
E_{\mathrm{size}}
=================

\frac{1}{|E|}
\sum_{e\in E}
\left(
\log\frac{l_e}{h_e}
\right)^2.
]

### 网格质量

令 (q_f\in[0,1]) 为三角形质量，例如

[
q_f
===

\frac{4\sqrt{3}A_f}
{l_1^2+l_2^2+l_3^2},
]

则

[
E_{\mathrm{quality}}
====================

\frac{1}{|F|}
\sum_{f\in F}(1-q_f).
]

### 几何误差

[
E_{\mathrm{geom}}
=================

d_{\mathrm{sampled}}
(\mathcal M,\mathcal M_0).
]

算法不必求解一个完整的全局优化，而是在满足拓扑与几何约束的前提下，通过局部操作逐步降低尺寸误差和质量误差。将几何误差设为硬约束、质量和复杂度作为优化目标，是已有 error-bounded remeshing 中采用过的有效组织方式。([arXiv][2])

---

# 2. 整体框架

论文中的方法流程可以压缩为：

[
\boxed{
\begin{aligned}
\text{Reference Construction}
&\rightarrow
\text{Global Sizing Field}\
&\rightarrow
\text{Confidence-Aware Feature Complex}\
&\rightarrow
\text{Error-Gated Local Remeshing}\
&\rightarrow
\text{Face-Budget Feedback}.
\end{aligned}
}
]

核心只保留四个模块：

1. 全局、特征解耦的尺寸场；
2. 高置信度硬特征图；
3. 几何误差约束下的局部操作；
4. 目标面数闭环控制。

不再保留多套功能重叠的特征机制。

---

# 3. 特征解耦的全局尺寸场

## 3.1 构建参考网格

清理后的输入网格作为不可变参考曲面：

[
\mathcal M_{\mathrm{ref}}.
]

工作网格记为：

[
\mathcal M_{\mathrm{work}}.
]

在参考网格上构建：

* AABB Tree，用于最近点和局部距离查询；
* 面法向和顶点法向；
* 原始几何复杂度；
* 目标尺寸场；
* feature edge graph。

之后所有投影、误差计算和尺寸查询都相对于参考网格完成。

这样可以避免尺寸场随着 remeshing 迭代发生漂移。

---

## 3.2 稳健几何复杂度信号

保留当前的正余切截断方案，但不再将其称为严格平均曲率，而称为：

> **robust geometric complexity response**

首先计算顶点重心面积：

[
A_i=\sum_{f\in N(i)}\frac{A_f}{3}.
]

余切权重为：

[
\widehat{\cot\theta}
====================

\operatorname{clamp}(\cot\theta,0,c_{\max}),
]

[
w_{ij}
======

\frac{1}{2}
\sum_{f\supset(i,j)}
\widehat{\cot\theta_f}.
]

位置拉普拉斯：

[
\mathbf L_i
===========

\sum_{j\in N(i)}
w_{ij}(\mathbf p_j-\mathbf p_i).
]

最终定义无量纲响应：

[
r_i
===

\frac{\bar l}
{2\max(A_i,A_{\mathrm{floor}})}
\left|\mathbf L_i\right|.
]

这里 (r_i) 只需要反映“当前区域是否需要更密的采样”。

它可以同时响应：

* 光滑高曲率；
* crease；
* corner；
* 局部异常几何。

在 crease 上，即使 (r_i) 不能被解释为严格曲率，也不会构成方法错误，因为尺寸场只使用它决定采样密度。

因此，尺寸模块**不进行 crease 检测，也不划分 smooth patches**。

---

## 3.3 保守平滑

对原始响应 (r) 使用现有 CSF 模块得到平滑结果：

[
\bar r=\operatorname{CSF}(r;\mu).
]

为防止局部高响应被完全平滑掉，可以采用保守融合：

[
s_i
===

\max
\left(
\bar r_i,\eta r_i
\right),
\qquad 0\leq\eta\leq1.
]

其中：

* (\bar r_i) 提供抗噪性；
* (\eta r_i) 保留局部峰值。

第一版实验可以令：

[
\eta=0.25\sim0.5.
]

不建议主方法同时加入法向变化、拟合残差和多套曲率量。它们可以作为消融或替代信号，但不应全部放进主方法。

---

## 3.4 从复杂度映射到尺寸

定义：

[
h_i(\lambda)
============

\operatorname{clamp}
\left(
\frac{\lambda}
{\sqrt{s_i+\epsilon}},
h_{\min},
h_{\max}
\right).
]

其中 (\lambda) 是全局尺寸尺度。

这种尺寸场在整个参考网格上都有定义，不区分 smooth、crease 和 corner。成熟 remeshing 接口同样将 sizing field 抽象为局部目标边长，长边依据该长度被分裂、短边被折叠。([doc.cgal.org][3])

---

## 3.5 目标面数初始化

对于接近等边的三角形，边长为 (h) 时面积近似为：

[
A_{\mathrm{eq}}(h)
==================

\frac{\sqrt3}{4}h^2.
]

因此估算输出面数：

[
\widehat N(\lambda)
===================

\frac{4}{\sqrt3}
\sum_{f\in F_0}
\frac{A_f}{h_f(\lambda)^2},
]

其中 (h_f) 可取三个顶点目标尺寸的调和平均或几何平均。

通过二分搜索求解：

[
\widehat N(\lambda)\approx N^\star.
]

这是初始化，不要求一次精确预测最终面数。

---

## 3.6 尺寸渐变约束

计算出 (h_i) 后，施加 Lipschitz 型渐变限制：

[
h_i
\leq
h_j+\gamma l_{ij}.
]

可以通过边松弛实现：

[
h_i
\leftarrow
\min(h_i,h_j+\gamma l_{ij}),
]

对所有边迭代若干轮。

这一步比对曲率场进行强平滑更重要，因为它直接防止目标边长突变。已有密度驱动 remeshing 也会通过低通处理控制最终采样渐变。([斯坦福计算机图形学][4])

---

# 4. 置信度感知的硬特征图

尺寸场不依赖 crease，但严格的特征拓扑保护仍然需要高置信度特征图。

## 4.1 边级 crease 置信度

二面角定义在边上，因此首先构造边级响应：

[
\phi_e
======

\arccos
\left(
\operatorname{clamp}
(\mathbf n_{f_1}\cdot\mathbf n_{f_2},-1,1)
\right).
]

映射为连续置信度：

[
q_e
===

\operatorname{smoothstep}
\left(
\phi_{\mathrm{low}},
\phi_{\mathrm{high}},
\phi_e
\right),
\qquad q_e\in[0,1].
]

其中：

* (\phi_e\leq\phi_{\mathrm{low}}) 时 (q_e=0)；
* (\phi_e\geq\phi_{\mathrm{high}}) 时 (q_e=1)。

硬 feature edge 集合为：

[
E_H
===

{e\mid q_e\geq\tau_h}.
]

可以用滞后连接减少碎裂：

* (q_e\geq\tau_{\mathrm{seed}}) 的边作为种子；
* 沿连接方向吸收 (q_e\geq\tau_{\mathrm{grow}}) 的边；
* 满足 (\tau_{\mathrm{grow}}<\tau_{\mathrm{seed}})。

---

## 4.2 顶点分类

不再使用“高特征邻居数量接近 0、2 或全部邻居”的分类方式。

直接根据硬 feature graph 分类：

* 没有 incident feature edge：`Smooth`；
* 恰有两条、且切向连续：`Crease`；
* feature 度数不等于 2：`Corner`；
* 度数为 2 但两条 feature edge 切向明显不连续：`Corner`；
* 普通边界链内部：`Boundary`；
* 边界链端点或转角：`BoundaryCorner`。

角亏损只作为 corner 置信度的辅助量，不再与二面角通过

[
(K_i+1)(E_i+1)-1
]

这样的经验公式融合。

---

## 4.3 软响应的唯一用途

定义顶点软特征置信度：

[
q_i=\max_{e\ni i}q_e.
]

软响应只用于调节顶点重定位步长：

[
\alpha_i
========

\alpha_0(1-q_i)^p.
]

不让软响应同时影响：

* 尺寸场；
* Collapse 位置；
* Flip 判定；
* 多种分类。

这能显著减少模块耦合。

---

# 5. 误差门控的局部重网格操作

每轮采用经典顺序：

[
\text{Split}
\rightarrow
\text{Collapse}
\rightarrow
\text{Flip}
\rightarrow
\text{Relocate}
\rightarrow
\text{Project}.
]

经典增量式 remeshing 使用的也是这一类局部操作序列。([不列颠哥伦比亚大学计算机科学系][1])

对于工作网格上的边 (e=(i,j))，目标边长取：

[
h_e
===

\frac{2h_i h_j}{h_i+h_j}.
]

工作顶点的 (h_i) 通过其在参考网格上的投影位置进行重心插值查询，而不是在工作网格上重新估计曲率。

---

## 5.1 Split

若：

[
l_e>\alpha_s h_e,
]

则分裂该边。

可以取：

[
\alpha_s=\frac43.
]

普通边：

1. 在边中点插入顶点；
2. 将新顶点投影到参考曲面；
3. 从参考网格插值得到尺寸值和软特征置信度。

硬 feature edge：

1. 在参考 feature polyline 上插入新点；
2. 两条子边继承 feature 标签；
3. 新顶点分类为 Crease 或 Boundary；
4. feature graph 连通性保持不变。

---

## 5.2 Collapse

若：

[
l_e<\alpha_c h_e,
]

则进入 Collapse 候选集合，可取：

[
\alpha_c=\frac45.
]

不再使用“特征强度差异较大时保留强端点”作为主策略。

对普通边考虑三个候选位置：

[
\mathcal C_e
============

{
\mathbf p_i,
\mathbf p_j,
(\mathbf p_i+\mathbf p_j)/2
}.
]

所有候选点先投影回参考曲面，再计算局部代价：

[
E_{\mathrm{local}}(x)
=====================

w_sE_{\mathrm{size}}(x)
+
w_qE_{\mathrm{quality}}(x)
+
w_nE_{\mathrm{normal}}(x).
]

选择合法候选中代价最小的位置。

Collapse 必须满足：

* link condition；
* 不产生非流形结构；
* 不产生翻转或退化面；
* 新边长度不过长；
* 局部最小角不低于阈值；
* 局部位置误差不超过 (\varepsilon_d)；
* 局部法向偏差不超过 (\varepsilon_n)。

硬特征边的规则为：

* Corner 不允许被删除；
* feature edge 只能沿同一 feature chain 折叠；
* 新位置必须位于参考 feature curve 上；
* 折叠不能改变 feature graph 的分支数；
* 不同 feature chains 之间不能合并；
* 普通顶点不能跨越硬 crease 合并。

---

## 5.3 Flip

对于具有两个相邻面的非约束内部边，构造翻转后的局部网格。

满足以下条件时才接受：

[
E_{\mathrm{local}}^{\mathrm{after}}
<
E_{\mathrm{local}}^{\mathrm{before}},
]

并且：

* 新边长度在目标范围内；
* 最小角不下降；
* 顶点度数误差减小，或三角形质量明显改善；
* 不超过位置和法向误差阈值。

硬 feature edge 不允许 Flip。

Flip 也不能生成穿过 feature graph 的新对角线。

---

## 5.4 Relocate

### Smooth 顶点

计算加权邻域中心：

[
\mathbf c_i
===========

\frac{\sum_{j\in N(i)}w_{ij}\mathbf p_j}
{\sum_{j\in N(i)}w_{ij}}.
]

原始位移：

[
\mathbf d_i=\mathbf c_i-\mathbf p_i.
]

切向分量：

[
\mathbf d_i^T
=============

## \mathbf d_i

(\mathbf d_i\cdot\mathbf n_i)\mathbf n_i.
]

更新：

[
\mathbf p_i'
============

\mathbf p_i+\alpha_i\mathbf d_i^T,
]

其中：

[
\alpha_i=\alpha_0(1-q_i)^p.
]

随后投影到参考曲面。

### Crease 顶点

令 (\mathbf t_i) 为参考 feature curve 的切向：

[
\mathbf d_i^F
=============

(\mathbf d_i\cdot\mathbf t_i)\mathbf t_i.
]

更新后投影回参考 feature curve。

### Boundary 顶点

只允许沿边界切向移动，并投影回参考边界链。

### Corner 和 BoundaryCorner

固定不动。

主方法中不使用 MLS。普通顶点直接投影到参考三角网格，feature 顶点投影到参考 feature polyline。MLS 可以作为补充实验，但不应成为主方法的一部分。

# 6. 局部几何误差门控

这是降低算法对 feature detector 依赖的关键。

对 Collapse、Flip 和 Relocate 操作 (O)，在受影响三角形上选择采样点集合：

[
Q(O).
]

计算操作后到参考曲面的最大局部距离：

[
d_O
===

\max_{x\in Q(O)}
d(x,\mathcal M_{\mathrm{ref}}).
]

计算局部法向偏差：

[
n_O
===

\max_{f\in F(O)}
\angle
\left(
\mathbf n_f,
\mathbf n_{\mathrm{ref}}(\pi(\mathbf c_f))
\right).
]

只有满足：

[
d_O\leq\varepsilon_d,
\qquad
n_O\leq\varepsilon_n
]

时，操作才允许执行。

它具有两个作用：

1. 限制普通高曲率区域的几何损失；
2. 当 crease 漏检时，阻止严重圆化或跨 feature 操作。

已有工作表明，局部误差估计可以用于门控局部操作，并通过专门重定位实现隐式特征保持。([arXiv][2])

因此，你的方法不是完全依赖 crease detection：

[
\boxed{
\begin{aligned}
\text{检测正确}
&\Rightarrow
\text{硬约束严格保护};\
\text{检测遗漏}
&\Rightarrow
\text{尺寸细化和误差门控提供退化保护}.
\end{aligned}
}
]

---

# 7. 目标面数闭环控制

初始二分搜索只能给出近似 (\lambda)，因为边界、质量检查和 feature constraints 会影响实际面数。

每隔 (K) 轮，根据当前面数 (N_t) 修正：

[
\lambda
\leftarrow
\lambda
\left(
\frac{N_t}{N^\star}
\right)^{\beta/2},
\qquad 0<\beta\leq1.
]

理由是：

[
N\propto\frac{1}{h^2}
\propto\frac{1}{\lambda^2}.
]

* 若 (N_t>N^\star)，则增大 (\lambda)，令整体目标边长变大；
* 若 (N_t<N^\star)，则减小 (\lambda)。

取较小的 (\beta)，例如 (0.2\sim0.5)，可防止面数震荡。

更新 (\lambda) 后重新计算尺寸场并执行 gradation。

停止条件可定义为：

[
\frac{|N_t-N^\star|}{N^\star}<\epsilon_N,
]

且：

[
\frac{
|{e:l_e\notin[\alpha_c h_e,\alpha_s h_e]}|
}{|E|}
<\epsilon_E.
]

# 8. 完整算法

```text
Input:
    reference mesh M0
    target face count N*
    hmin, hmax
    geometry tolerances εd, εn
    feature thresholds

1. Clean M0 and construct immutable reference mesh Mref
2. Build AABB tree and reference feature polylines
3. Compute robust global geometry response r on Mref
4. Apply CSF smoothing and conservative peak preservation
5. Solve λ from the estimated face-budget equation
6. Construct target sizing field h and enforce gradation
7. Compute edge feature confidence qe
8. Extract only high-confidence hard feature graph EH

9. Initialize Mwork = Mref

10. Repeat:
       a. Query h from Mref for vertices and edges of Mwork
       b. Split edges longer than αs h
       c. Collapse edges shorter than αc h
          subject to topology, feature and error constraints
       d. Flip non-feature edges if local energy decreases
       e. Relocate:
              Smooth   -> tangent plane
              Crease   -> feature tangent
              Boundary -> boundary tangent
              Corner   -> fixed
       f. Project vertices to Mref or reference feature curves
       g. Remove degeneracies
       h. Update λ using face-budget feedback
   until convergence

Output:
    remeshed mesh M
```

# 9. 论文应声称的贡献

建议将贡献控制为三点。

### 贡献一：特征解耦尺寸场

提出一种不依赖 smooth-patch segmentation 的全局自适应尺寸场。非光滑区域中的高响应被解释为保守的几何复杂度信号，而不是要求严格的曲率估计。

### 贡献二：置信度分层的特征保护

仅将高置信度 crease 和 corner 提升为硬拓扑约束；连续特征置信度只用于控制 relocation，不参与多套重复决策。

### 贡献三：误差门控与面数闭环

通过参考曲面上的局部位置/法向误差门控降低漏检特征的破坏风险，并使用反馈控制使最终面数接近用户指定预算。

---

# 10. 应从原方案删除的内容

主方法中建议删除：

* (F_i=(K_i+1)(E_i+1)-1) 的经验融合；
* 通过高特征邻居个数判断 Corner/Crease/Smooth；
* 所有边界点均视为 Corner；
* Collapse 单纯偏向高特征端点；
* feature response 再次缩小目标尺寸；
* Laplacian、normal variation、fit residual 三套尺寸信号同时使用；
* MLS 作为核心投影机制；
* Crease 顶点完全冻结。

这些机制并非一定无效，但会模糊论文主线。

---

# 11. 实验设计

实验必须直接验证“特征解耦”这一主张。

## 比较方法

至少包含：

1. 均匀增量式 remeshing；
2. 仅使用自适应尺寸场；
3. 自适应尺寸场 + 软 relocation；
4. 自适应尺寸场 + 硬 feature constraints；
5. 完整方法：尺寸场 + 硬约束 + error gate + budget feedback。

还可以将公开的 curvature-adaptive sizing implementation 作为工程基线；例如 CGAL 提供基于局部离散曲率的 adaptive sizing field。([doc.cgal.org][3])

## 主要指标

* 面数相对误差；
* 边长比 (l_e/h_e) 的分布；
* 最小角、平均质量及低质量面比例；
* 双向 sampled Hausdorff distance；
* 法向偏差；
* feature curve Chamfer distance；
* corner 位移；
* feature graph 连通性；
* 运行时间。

## 最关键的鲁棒性实验

人为改变二面角检测阈值：

[
\phi_{\mathrm{high}}
\in
{20^\circ,30^\circ,40^\circ,50^\circ,60^\circ}.
]

比较：

* 尺寸分布是否基本稳定；
* 漏检时几何误差是否平缓增加；
* 硬约束数量是否变化；
* 是否发生 feature chain 断裂。

如果尺寸场几乎不受 feature threshold 影响，而完整方法对漏检表现出渐进退化而不是突然失效，就真正支撑了论文的核心论点。

## 方法定位评价

这一版本适合作为硕士论文或工程型方法论文。其逻辑是完整的，也比“曲率 + feature heuristic + 若干特殊判断”更干净。

但需要坦率地说，以下单独都不是强创新：

* Split/Collapse/Flip；
* 曲率自适应目标边长；
* 二面角 crease 检测；
* constrained feature edges；
* reference-surface projection。

论文价值主要来自它们被组织成一个明确的机制：

[
\boxed{
\text{feature-independent sampling}
+
\text{confidence-dependent constraints}
+
\text{feature-independent error safeguard}
}
]

论文中最好将核心问题表述为：

> 如何在不让自适应尺寸估计依赖脆弱的硬特征分割结果的情况下，同时获得稳定的采样分布和可控的尖锐特征保持。

这个问题定义比“实现一个曲率自适应 remesher”更集中，也更容易形成有说服力的消融实验。
