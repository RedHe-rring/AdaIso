# v2.11.1 修改方向：screened 曲率场与单向 log 尺寸渐变约束

## 1. 修改背景

v2.11.0 使用以下尺寸场管线：

```text
主曲率 k1、k2
  -> dimensionless kappa = mean_edge_length * max(|k1|, |k2|)
  -> 反幂映射并第一次校准到 target_faces，得到 initial_h
  -> screened-Laplacian 直接平滑 initial_h
  -> 第二次全局尺度校准 + clamp
  -> final target_h
```

T 系列实验中，v2.11.0 相对 v2.10.2 的平均 `Qavg`、平均 `Qmin` 和
`violation_rate` 有改善，但它仍存在两个结构性问题：

1. screened-Laplacian 最小化的是带数据保真项的全局二次能量，只能降低总体粗糙度，不能保证每条边都满足给定的尺寸渐变上限；
2. 直接平滑 `h` 会同时抬高局部小尺寸和压低局部大尺寸，可能削弱高曲率区域原本需要的加密。

v2.11.1 将两个目标拆开处理：

```text
曲率场去噪：screened-Laplacian；
最终尺寸渐变：单向下降 log-gradation limiter。
```

screened smoothing 只负责抑制主曲率估计噪声。曲率经过非线性反幂映射后，
再由硬渐变约束直接处理最终尺寸场，避免把“曲率较平滑”误当成“尺寸场逐边受限”。

## 2. v2.11.1 最终管线

```text
principal curvatures k1, k2
  -> raw isotropic curvature magnitude kappa
  -> screened-Laplacian smoothed curvature kappa_s
  -> inverse-power initial target shape h0
  -> downward-only limiter on u0 = log(h0)
  -> limited target shape h_g
  -> global multiplicative calibration to target_faces
  -> common clamp to [h_min, h_max]
  -> verify gradation and face-count diagnostics
  -> final target_h
  -> existing TargetLengthField and remeshing stages
```

v2.11.1 只修改输入网格上的标量尺寸场生成过程，不修改：

- `TargetLengthField` 的空间查询方式；
- split/collapse/flip/relocation 的阈值、顺序和实现；
- feature-aware collapse、flip 二面角约束与 MLS relocation；
- 主曲率的局部二次曲面拟合方法；
- remeshing 过程中目标场固定、不逐轮重建的行为。

## 3. 符号约定

```text
p_i              顶点 i 的位置
k1_i, k2_i       两个有符号主曲率，单位 1 / length
kappa_i          无量纲原始各向同性曲率幅值
kappa_s_i        screened-Laplacian 平滑后的无量纲曲率
l_ij             输入网格边 (i,j) 的长度
l_bar            输入网格平均边长
M                 barycentric lumped mass matrix
L                 使用正权重的离散 Laplacian
alpha             曲率 screened smoothing 强度
p                 曲率到尺寸的反幂指数，固定为 0.75
h0_i              曲率映射得到的未校准初始尺寸
u0_i              log(h0_i)
q                 一个平均边长距离允许的最大尺寸倍率，q > 1
gamma             log(q)
u_g_i             单向 gradation limiter 输出
h_g_i             exp(u_g_i)
s                 target_faces 全局校准尺度
h_i               最终目标边长
T                 target_faces
```

保持 v2.11.0 的最终边长上下界：

```text
h_min = 0.05 * l_bar
h_max = 5.00 * l_bar
```

## 4. 原始主曲率幅值

继续使用 v2.11.0 的主曲率估计器。物理曲率幅值定义为：

\[
\kappa_i^{\mathrm{physical}}
=
\max\left(|k_{1,i}|,|k_{2,i}|\right).
\]

用于后续计算的无量纲曲率为：

\[
\kappa_i
=
\bar l\,\kappa_i^{\mathrm{physical}}.
\]

不分别平滑带符号的 `k1` 和 `k2`，原因是：

1. 正负主曲率可能在平滑中相互抵消；
2. 鞍点不能因为符号抵消被错误识别为平坦区域；
3. `k1/k2` 的编号可能在脐点附近交换；
4. v2.11.1 最终只需要各向同性标量尺寸，不使用主方向。

主曲率拟合失败时继续沿用 v2.11.0 的回退值，并保留
`principal_curvature_fallback_vertices/rate` 统计。

## 5. screened-Laplacian 平滑曲率

### 5.1 求解形式

对无量纲原始曲率 `kappa` 求解：

\[
\left(M+\tau L\right)\kappa_s=M\kappa,
\qquad
\tau=\alpha\bar l^2.
\]

它等价于最小化：

\[
E(\kappa_s)
=
\frac12\sum_i M_i(\kappa_{s,i}-\kappa_i)^2
+
\frac{\tau}{2}
\sum_{(i,j)\in E}w_{ij}(\kappa_{s,i}-\kappa_{s,j})^2.
\]

第一项保留原始主曲率信号，第二项抑制局部曲率噪声。

### 5.2 权重与非负性

第一版复用 `ScreenedLaplacian.cpp` 当前的：

- barycentric vertex mass；
- cotangent edge weight；
- 非正或非有限权重回退到 `kScreenedLaplacianEta`；
- `Eigen::SimplicialLDLT`；
- scaled residual 验收。

正质量与正边权使系统矩阵为 M-matrix。输入 `kappa >= 0` 时，理论上应保持
`kappa_s >= 0`。求解后仍执行数值保护：

\[
\kappa_{s,i}\leftarrow\max(\kappa_{s,i},0).
\]

任何非有限结果必须报错，不能静默回退。

### 5.3 alpha 语义

v2.11.1 默认从 v2.10.2 已使用的量级开始：

```text
curvature_smoothing_alpha = 0.75
```

为了支持严格消融，允许：

```text
alpha = 0
```

此时跳过稀疏求解并令 `kappa_s = kappa`。`alpha > 0` 时执行 screened solve。
最终默认值仍需由 `0 / 0.25 / 0.5 / 0.75 / 1.0 / 2.0` 消融确认。

## 6. 从平滑曲率映射到初始尺寸场

令：

\[
\kappa_{safe,i}=\max(\kappa_{s,i},\kappa_{min}),
\qquad
\kappa_{min}=10^{-12}.
\]

初始尺寸场只用于表达相对尺寸形状：

\[
h_{0,i}
=
\frac{\bar l}{\kappa_{safe,i}^{p}},
\qquad p=0.75.
\]

这里不再像 v2.11.0 一样先对 `lambda` 做一次目标面数二分。原因是后续单向
limiter 会改变尺寸分布，第一次面数校准会立即失效。v2.11.1 只在 limiter 后进行
一次最终尺度校准。

`h0` 在这一阶段不执行 `[h_min,h_max]` clamp。`kappa_min` 保证 `h0` 为正且有限，
最终物理范围在全局校准阶段统一处理。

## 7. 单向下降 log-gradation limiter

### 7.1 为什么在 log(h) 上限制

令：

\[
u_{0,i}=\log h_{0,i}.
\]

对输入网格边 `(i,j)` 定义允许的 log 尺寸变化：

\[
c_{ij}
=
\gamma\frac{l_{ij}}{\bar l},
\qquad
\gamma=\log q,
\qquad q>1.
\]

最终约束为：

\[
|u_i-u_j|\le c_{ij}.
\]

等价的尺寸比例约束为：

\[
\exp(-c_{ij})
\le
\frac{h_i}{h_j}
\le
\exp(c_{ij}).
\]

当 `l_ij = l_bar` 时，相邻尺寸比例最多为 `q`。使用 `l_ij/l_bar` 后，模型整体缩放
不会改变约束语义，短边受到更严格的变化限制，长边允许更大的累计变化。

### 7.2 单向更新

如果 `u_i` 相对 `u_j` 过大，只降低较大值：

\[
u_i
\leftarrow
\min(u_i,u_j+c_{ij}).
\]

对反方向执行相同检查：

\[
u_j
\leftarrow
\min(u_j,u_i+c_{ij}).
\]

整个过程从不抬高小尺寸，因此不会像普通拉普拉斯尺寸平滑那样直接削弱局部加密源。

### 7.3 全局解

把每个顶点都视为具有初始值 `u0_j` 的源点，定义带权最短路距离：

\[
d_c(i,j)
=
\min_{P:j\rightsquigarrow i}
\sum_{(a,b)\in P}c_{ab}.
\]

单向 limiter 的收敛解为：

\[
u_{g,i}
=
\min_j\left(u_{0,j}+d_c(i,j)\right).
\]

然后：

\[
h_{g,i}=\exp(u_{g,i}).
\]

该解具有以下性质：

1. `u_g_i <= u0_i`，因此 limiter 本身只减小尺寸；
2. 每条边满足 `|u_g_i-u_g_j| <= c_ij`；
3. 在所有不高于 `u0` 且满足约束的场中，`u_g` 是逐点最大的可行场；
4. 每个连通分量独立求解，断开的组件不会互相传播尺寸；
5. `q -> 1` 时每个连通分量趋向其最小 `h0`，会造成全局过密，因此配置必须要求 `q > 1`。

### 7.4 算法

不使用固定轮数的全边扫描。实现多源 Dijkstra：

```text
u = log(h0)
priority_queue 中加入全部顶点，key = u[i]

while queue 非空:
    取出当前最小 (value, i)
    如果 value 已过期则跳过
    对每个邻点 j:
        candidate = u[i] + log(q) * length(i,j) / mean_edge_length
        if candidate < u[j]:
            u[j] = candidate
            push(candidate, j)

limited_h[i] = exp(u[i])
```

边代价非负，因此复杂度为：

\[
O((|V|+|E|)\log|V|).
\]

结果不依赖边遍历顺序，也不需要人为设置最大迭代轮数。

## 8. 目标面数全局校准与 clamp

limiter 后只改变相对尺寸形状。最终场写成：

\[
h_i(s)
=
\operatorname{clamp}
\left(
s h_{g,i},
h_{min},
h_{max}
\right).
\]

面数连续估计继续使用：

\[
\widehat N(h)
=
\sum_{f\in F}
\frac{A_f}
{(\sqrt3/4)\,h_f^2},
\]

其中：

\[
h_f=\frac{h_i+h_j+h_k}{3}.
\]

用二分求解全局尺度 `s`，使：

\[
\widehat N(h(s))\approx T.
\]

`clamp` 必须包含在每次二分的面数估计内部，不能先求无界尺度再在最后单独截断，
否则饱和顶点会使最终估算面数偏离 `target_faces`。

### 8.1 为什么通常不需要第二次 limiter

全局乘法缩放在 log 空间只增加常数：

\[
\log(sh_i)-\log(sh_j)
=
\log h_i-\log h_j.
\]

因此它不改变已有的 log-gradation 约束。

公共 clamp 等价于在 log 空间投影到固定区间：

\[
u\mapsto
\operatorname{clamp}(u,\log h_{min},\log h_{max}),
\]

该投影为 1-Lipschitz，不会增大任意两个值之间的差。因此正常情况下：

```text
limiter -> global scale -> clamp
```

之后仍应满足逐边约束，不需要第二次 limiter。最终只做验证；若超过容差，应视为实现错误
或浮点误差，而不是无条件再次修改场。再次 limiter 会降低尺寸并破坏刚完成的面数校准。

## 9. 最终验收约束

对每条输入边 `(i,j)` 计算：

\[
g_{ij}
=
\frac{|\log h_i-\log h_j|}
{l_{ij}/\bar l}.
\]

当 gradation 启用时必须满足：

\[
\max_{(i,j)\in E}g_{ij}
\le
\log q+\varepsilon_g.
\]

建议：

```text
epsilon_g = 1e-10 * max(1, abs(log(q)))
```

同时记录但不作为同一约束混淆：

```text
max_adjacent_ratio = max max(h_i,h_j) / min(h_i,h_j)
max_normalized_log_slope = max g_ij
p95/p99 normalized_log_slope
estimated_faces relative error
```

`max_adjacent_ratio` 会受到边长不同的影响，真正与配置 `q` 对应的验收量是
`max_normalized_log_slope`。

### 10.3 新增 `src/TargetGradation.cpp`

实现：

1. 从 `uniqueEdges(mesh)` 构造带物理边长的无向邻接；
2. 检查每条边长度正且有限；
3. 初始化 `u = log(initial_lengths)`；

- limiter 中抬高任意 `h`；

```text
tests/target_face_sizing_tests.cpp
```

可以先链接为一个 `adaiso_tests` 可执行文件，也可以拆成三个 CTest target；优先选择拆分，
使失败信息直接指向模块。

## 11. 测试计划

### 11.1 screened curvature tests

1. 常量非负曲率经过任意 `alpha > 0` 后保持常量；
2. `alpha = 0` 调用层严格返回输入；
3. 单脉冲曲率平滑后峰值下降但结果非负；
4. `alpha` 增大时曲率 roughness 不增；
5. 网格整体缩放时，无量纲 `kappa_s` 基本不变；
6. 非有限输入、错误数组大小和非法 alpha 报错。

### 11.2 gradation limiter tests

使用 path、triangle、disconnected components 和不等长边网格：

1. 已满足约束的输入完全不变；
2. 单个小尺寸源向外按允许比例逐层扩散；
3. 输出逐点满足 `limited_h <= initial_h`；
4. 每条边满足 normalized log slope 上限；
5. 对输入顶点重新编号后，映射回原编号的结果一致；
6. 两个断开组件互不影响；
7. 全局乘以常数后，limit 结果也只乘同一常数；
8. `q <= 1`、非有限 q、零或负尺寸必须报错；
9. Dijkstra 结果与小网格上的迭代松弛参考解一致。

### 11.3 target-face calibration tests

1. 无 clamp 饱和时恢复给定 target；
2. clamp 饱和时二分仍在可达范围内收敛；
3. 不可达 target 正确设置 `target_faces_reachable=false`；
4. 校准前后 gradation normalized log slope 不增；
5. 常量尺寸场保持常量；
6. target-face 相对误差在离散估计容差内。

### 11.4 integration smoke test

对小型 mesh 运行：

```text
curvature smoothing
-> initial h
-> limiter
-> calibration
-> TargetLengthField build
-> 1 global remesh iteration
```

检查输出 mesh 有效、所有尺寸为正且有限、solver 成功、gradation 验收通过。

## 12. 实验计划

### 12.1 单变量消融

为了判断每个阶段的独立作用，至少比较：

```text
A: raw kappa -> h0 -> calibration
B: screened kappa -> h0 -> calibration
C: raw kappa -> h0 -> limiter -> calibration
D: screened kappa -> h0 -> limiter -> calibration
```

所有组固定：

```text
principal curvature estimator
p = 0.75
target_faces
h_min / h_max
remesh iterations
split/collapse/flip/relocation 参数
CD samples 与随机种子
```

这样才能分别回答：

1. screened 曲率平滑是否抑制噪声；
2. gradation limiter 是否改善最终尺寸约束；
3. 两者组合是否提高三角形质量；
4. 改善是否只是由实际输出面数变化造成。

### 12.2 参数消融

先固定 `p=0.75`：

```text
alpha = 0, 0.25, 0.5, 0.75, 1.0, 2.0
q     = disabled, 1.20, 1.30, 1.50, 2.00
```

不需要一开始运行完整笛卡尔积。先在代表模型上筛选，再对候选组合运行全部 T 系列。

### 12.3 记录指标

曲率场：

```text
raw/smoothed min, p05, p50, p95, max
roughness before/after
solver residual and runtime
```

尺寸场：

```text
initial/limited/final estimated faces
limiter changed vertex rate

max adjacent size ratio

final scale
```

最终 mesh：

```text

violation_rate
edge-target ratio statistics
Chamfer Distance / symmetric RMSE
split/collapse/flip counts
runtime
```

## 13. 风险与处理

### 风险 1：错误的小 h 源被 limiter 扩散

单向 limiter 会保留并传播局部小尺寸。如果主曲率存在孤立异常峰值，影响范围可能比无 limiter
更大。因此必须先做 screened 曲率去噪，并导出 `raw_kappa/smoothed_kappa` 热力图检查。

如果 screened smoothing 仍无法处理离群点，再单独研究 robust cap、median 或 bilateral/edge-aware
权重；v2.11.1 初版不同时加入这些额外变量。

### 风险 2：q 太小导致大范围加密

`q` 越接近 1，小尺寸传播越远，limiter 后估算面数会显著增加。虽然后续全局尺度可以恢复
目标面数，但这会同时放大最小尺寸区域，可能损失几何精度。

必须统计 limiter 前后估算面数、最终 scale 和尺寸下降分布，不能只检查最终 target_faces。

### 风险 3：普通图距离跨尖锐特征传播

第一版沿所有网格边使用几何长度，便于建立清晰基线。它可能让尖锐特征一侧的小尺寸跨 crease
传播到另一侧。若实验确认存在过度传播，再研究：

```text
normal-aware edge cost
crease barrier
feature-segmented components
```

这些扩展不进入 v2.11.1 初版，避免与核心 limiter 同时改变。

### 风险 4：最终 mesh 质量仍不受硬保证

gradation limiter 硬约束的是输入顶点上的目标尺寸场，不直接约束 remeshing 后每个三角形的形状。
它可以降低尺寸突变引起的拓扑冲突，但不能保证 `Qmin` 一定提高。最终质量仍取决于
split/collapse/flip/relocation 和 feature 约束。

## 14. 完成标准

v2.11.1 只有同时满足以下条件才算完成：

1. screened solver 的对象从 `initial_h` 改为 `raw_kappa`；
2. `h0` 映射后执行多源 Dijkstra 单向 log-gradation limiter；
3. limiter 后只执行一次 target-face 全局尺度校准；
4. 最终 target_h 对全部输入边通过 normalized log slope 验收；
5. 导出 `raw_kappa/smoothed_kappa/initial_h/limited_h/target_h`；
6. JSON 中不再混用 `target_smoothing` 与 `curvature_smoothing` 命名；
7. 单元测试、集成 smoke test 和 Release 构建通过；
8. 至少完成 A/B/C/D 单变量消融；
9. 在相同 target_faces 和 remesh 参数下与 v2.11.0、v2.10.2 对比；
10. 报告明确区分“尺寸场逐边约束通过”和“最终三角网格质量提高”，不把前者当成后者的充分条件。
