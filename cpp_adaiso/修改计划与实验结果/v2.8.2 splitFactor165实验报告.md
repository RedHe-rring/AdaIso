# v2.8.2 实验报告：splitFactor 调整为 1.65

## 修改内容

本次代码修改只调整 `code` variant 的分裂阈值：

```cpp
double AdaIsoConfig::splitFactor() const {
  return variant == Variant::Paper ? 5.0 / 3.0 : 1.65;
}
```

修改位置：

```text
cpp_adaiso/src/AdaIsoRemesher.cpp
```

修改目的：扩大 split/collapse 阈值迟滞区间，使 `splitFactor = 1.65 > 2 * collapseFactor = 1.6`，降低刚分裂出的半边立即进入 collapse 候选的概率。

T21 的 v2.8.2 尺寸场跳变明显大于 v2.8.0 hmin=0.20。虽然最终 CD 改善，但 `max_edge_target_ratio` 和 `max_grad_h_norm` 同时显著升高，说明当前收益可能依赖更激进的局部尺寸变化和更多采样点。

## 结论

1. `splitFactor=1.65` 已生效，summary 中记录的 `split_factor` 为 `1.65`。
2. T21 hmin=0.20 相比 v2.8.0 hmin=0.20，CD 下降 `6.53%`，RMSE 下降 `3.32%`。
3. 代价是 T21 输出规模增加约 `39.64%`，Qmin 降到 `0.094679`，尺寸场跳变指标明显增大。
4. 当前结果不能证明单独提高 `splitFactor` 一定优于 v2.8.0，因为同时存在尺寸场版本和 `mls_iterations` 默认值差异。
5. 若要隔离阈值修改的贡献，下一步应在同一代码版本内跑 `splitFactor=1.33` 与 `1.65` 的对照，其他参数保持完全一致。
