# v2.8.0 饱和尺寸场映射计划

## Summary
把 v2.7 的线性尺寸场映射替换为 v2.8 文档中的饱和幂函数：

`h = h_min + (h_max - h_min) * pow(1 - t, target_size_gamma)`

默认 `target_size_gamma = 2.0`。高曲率仍对应小尺寸，但高曲率端变化变慢；不保留旧线性映射函数或兼容包装。

## Key Changes
- 将 `detail::linearTargetLengths` 重命名为 `detail::saturatedTargetLengths`，所有调用和测试同步改名，不留下旧函数。
- 新增 `AdaIsoConfig::target_size_gamma = 2.0`，并在 helper、`AdaIsoRemesher::remesh`、CLI 入口统一校验：必须有限且 `> 0`。
- 新增 CLI 参数 `--target-size-gamma <v>`，写入 help 和 summary JSON；不添加旧参数别名。
- `buildTargetLengths()` 调用新映射函数并传入 `config_.target_size_gamma`。
- 保留 `mesh_scale`、`target_min_factor`、`target_max_factor`，因为它们仍定义 v2.8 公式的 `h_min/h_max`；不恢复分位数、log、平滑或 gradation 旧逻辑。
- 更新 `CMakeLists.txt` 项目版本到 `2.8.0`，在 `CHANGELOG.md` 增加 v2.8.0 条目。

## Test Plan
- 更新 `testLinearTargetLengthMapping` 为饱和映射测试：
  - `gamma=2.0` 下 `{0,1,2}` 映射为 `{h_max, h_min + 0.25*(h_max-h_min), h_min}`。
  - `gamma=1.0` 退化为旧线性数值，仅作为新函数特例测试。
  - 常量曲率仍返回 `mean_edge_length * mesh_scale` 的 clamp 值。
  - 非有限曲率、`gamma<=0`、非有限 gamma 抛异常。
- 更新配置校验测试，覆盖 `AdaIsoConfig::target_size_gamma` 无效值。
- 构建并运行：
  - `cmake --build cpp_adaiso/build --target adaiso_tests adaiso_cli`
  - `cpp_adaiso/build/adaiso_tests.exe`

## Assumptions
- 按你刚才选择，gamma 暴露为配置和 CLI，默认 2.0。
- 不触碰当前无关的 `.gitignore` 修改，也不修改未跟踪的 `v2.8.0 修改方向.md`。
