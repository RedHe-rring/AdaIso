# v5.3.1 修改方向：稳定 Stage A 的 collapse/split 尺寸场循环

## 1. 背景

v5.3.0 已经把 remesh 拆成：

```text
Stage A: split + collapse
Stage B: flip + relocation
Stage C: projection + cleanup
```

T 系列实验显示阶段化结构是可诊断的，但第一版 Stage A 不够稳定：

```text
after Stage A:
  violation = 0.11360
  angle<10% = 0.2380%
  angle<20% = 1.6075%

after Stage B:
  violation = 0.05894
  angle<10% = 0.1161%
  angle<20% = 0.3749%
```

Stage B 相对 Stage A 是正向的，但最终结果仍差于 v5.2.1，说明问题主要在 Stage A：只用 split/collapse 时，split 过冲并制造了较多坏角，collapse 没有充分回收。

v5.3.1 的目标不是推翻阶段化结构，而是稳定 Stage A。

## 2. 核心修改

### 2.1 Stage A 顺序改为 collapse -> split

v5.3.0 的 Stage A 顺序是：

```text
split
collapse
```

v5.3.1 改为：

```text
collapse
split
```

理由：

- 先回收已经过密或过短的边，再补欠采样长边。
- 避免每轮先 split 制造大量新点，让 collapse 总是在追赶。
- collapse 后已有“新边不能超过 split 阈值”的限制，因此同轮再 split 的抵消风险相对可控。

### 2.2 split 增加局部角度保护

v5.3.0 中 split 主要按尺寸场长边触发，角度保护不足。v5.3.1 给 split 增加局部质量 guard。

局部 patch 定义为待 split edge 的 incident faces。

接受准则：

```text
before = edge incident faces before split
after  = faces replacing those incident faces after split

reject if after patch invalid
reject if after_min_angle + tol < before_min_angle
reject if split creates or worsens obtuse triangles
```

钝角规则不要写成“split 后不能存在任何钝角”，因为输入 patch 可能本身已有钝角。更稳的规则是：

```text
if before_max_angle <= 90°:
  reject if after_max_angle > 90° + tol

else:
  reject if after_max_angle > before_max_angle + tol
```

含义：

- 原本没有钝角时，不允许 split 制造新钝角。
- 原本已有钝角时，不允许 split 让最大角更差。

### 2.3 不引入 Stage A relocation

v5.3.1 暂不把 relocation 放回 Stage A。

原因：

- 当前需要先确认 split/collapse 自身是否能稳定。
- 如果现在加入 relocation，会模糊问题来源：不知道是 collapse 回收不足，还是 relocation 在掩盖 split 过冲。
- Stage A 的第一目标仍是尺寸场逼近，不应过早加入点位平滑目标。

## 3. 代码修改方向

### 3.1 修改 Stage A 调度

将：

```cpp
splitLongEdges(mesh);
collapseShortEdges(mesh);
```

改为：

```cpp
collapseShortEdges(mesh);
splitLongEdges(mesh);
```

对应 stage snapshot 命名保持阶段化风格：

```text
size_iter001_after_collapse.ply
size_iter001_after_split.ply
```

### 3.2 新增 split 局部评价 helper

在 `AdaIsoRemesher.cpp` 内部新增 split 候选评价：

```text
splitAcceptedByAngleGuard(mesh, edge, midpoint)
```

需要计算：

```text
before_min_angle
before_max_angle
after_min_angle
after_max_angle
```

复用现有三角形角度 helper：

- `minInnerAngleDegrees(a, b, c)`
- 新增或复用 `maxInnerAngle(...)` 的 degree 版本
- `splitFaceOnEdge(...)`
- `evaluateLocalPatch(...)` 可继续用于 min angle 和合法性检查

### 3.3 修改 splitLongEdges()

当前 split 候选只检查 metric length。v5.3.1 应在真正加入 batch candidate 前增加：

```text
if !splitAcceptedByAngleGuard(mesh, edge, midpoint):
  reject
```

注意：

- 角度 guard 必须基于 split placement 的实际 midpoint，而不是简单边中点。
- batch split 前的候选选择仍要保持不共享顶点，避免同批修改互相污染。
- 不保留绕过角度 guard 的兼容入口。

### 3.4 统计和诊断

第一版不新增 CLI 参数。

summary 可继续沿用 v5.3.0 的阶段统计。若实现成本不高，可在内部 verbose 中增加 split rejection 计数，但不要新增公开 JSON 字段，避免报告字段继续膨胀。

## 4. 测试计划

### 4.1 单元测试

需要更新或新增测试：

- Stage A 顺序测试：
  - `stage_mesh_export_dir` 下第一轮应输出 `size_iter001_after_collapse.ply` 再输出 `size_iter001_after_split.ply`。
  - 统计中 size stage 仍只包含 collapse/split，quality stage 仍只包含 flip/relocation。

- split angle guard 测试：
  - 构造一个长边 split 会降低局部最小角的 patch，确认 split 被拒绝。
  - 构造一个长边 split 不降低局部最小角且不制造钝角的 patch，确认 split 被接受。

- 回归测试：
  - 既有 remesh smoke、target metric split placement、stage export 测试继续通过。

### 4.2 构建和测试

```text
cmake --build cpp_adaiso/build2 --config Release
ctest --test-dir cpp_adaiso/build2 -C Release --output-on-failure
```

### 4.3 后续实验

v5.3.1 代码通过后再跑 T 系列，对比 v5.3.0 和 v5.2.1。

验收重点：

```text
v5.3.1 vs v5.3.0:
  faces out/in 下降或不升
  violation 下降
  angle<10% / angle<20% 下降

v5.3.1 vs v5.2.1:
  faces/violation 接近 v5.2.1
  min_angle 不明显低于 v5.2.1
```

## 5. 暂不做

- 不做 split-until-stable 再 collapse-until-stable。
- 不在 Stage A 加 relocation。
- 不新增公开 CLI 参数。
- 不改 v5.1.5 尺寸场计算。
- 不把 qmin 重新作为局部主目标。
- 不引入 feature graph。

## 6. 预期判断

v5.3.1 如果有效，应表现为：

```text
Stage A 不再大量制造坏角
Stage A 面数过冲下降
Stage B 仍能在 Stage A 结果上继续修复质量
最终结果比 v5.3.0 更接近 v5.2.1，同时保留阶段化结构的可解释性
```

如果 v5.3.1 仍然失败，下一步再考虑 Stage A 的轻量 size-field preserving relocation，而不是继续放宽 split/collapse 的几何安全条件。
