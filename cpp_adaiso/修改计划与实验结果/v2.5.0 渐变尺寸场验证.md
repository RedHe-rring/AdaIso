# v2.5.0 渐变尺寸场验证实验计划

## Summary

直接验证 v2.5.0 构建出的尺寸场 `h`，而不是只看 remesh 后的网格质量。实验分三层：数学判据、数值统计、可视化场验证。核心结论标准是最终 `x_i = log(h_i)` 在输入网格每条边上满足相邻尺寸比例上限，并且在曲面上形成连续、可见的过渡带。

## 数学判据

- 将最终尺寸场写成 `x_i = log(h_i)`。对每条输入边 `(i,j)` 定义：
  ```text
  G_ij = max(h_i / h_j, h_j / h_i) = exp(|x_i - x_j|)
  ```
  若对所有边都有：
  ```text
  G_ij <= g
  ```
  则该离散尺寸场满足 v2.5.0 的局部 gradation 约束。默认 `g = 1.30`。

- 等价 log 形式：
  ```text
  |x_i - x_j| <= delta,  delta = log(g)
  ```
  对默认参数，`delta = log(1.30)`。若尺寸从 `h_min` 过渡到 `h_max`，理论最少边环数为：
  ```text
  K_min = ceil(log(h_max / h_min) / log(g))
  ```
  默认 `h_max / h_min = 1.8 / 0.6 = 3`，所以：
  ```text
  K_min = ceil(log(3) / log(1.30)) = 5
  ```
  因此可视化中不应出现一条边内从最小尺寸跳到最大尺寸的情况，至少应形成多层过渡。

- 因 v2.5.0 查询场在三角形内采用 `log(h)` 重心插值：
  ```text
  x(p) = lambda_i x_i + lambda_j x_j + lambda_k x_k
  h(p) = exp(x(p))
  ```
  所以需要同时验证：
  - 顶点场满足每边 gradation。
  - 三角形内 `x` 为 P1 连续场。
  - 共享边两侧插值值一致。
  - 面梯度 `||grad_T x||` 没有集中尖峰。

## 实验前置导出

- 增加一个诊断导出入口，不改变 remeshing 算法。推荐新增 CLI 开关：
  ```text
  --export-target-field <out_dir>
  ```
  执行到尺寸场构建后导出，不依赖最终 remesh 结果。

- 每个模型和参数组合输出：
  - `vertices.csv`：`vertex_id, x,y,z, raw_curvature, csf_curvature, x0_log, xsmooth_log, xfinal_log, h0, hsmooth, hfinal`
  - `edges.csv`：`i,j, edge_length, abs_dx, ratio, log_slope, violated`
  - `faces.csv`：`face_id, grad_log_h_norm, max_edge_ratio`
  - PLY 热图：raw curvature、CSF、raw target `h0`、final target `h`、`x_final - x0`、edge ratio hotspot、violation mask、face log-gradient。

- 参数固定项：

  ```text
  target_min_factor = 0.6

  ```

- 对比组：

  - `B1_smooth_only`：`target_smooth_alpha=0.3`, `target_max_adjacent_ratio=1.0`, `target_gradation_iterations=0`
  - `V25_default`：`target_smooth_alpha=0.3`, `target_max_adjacent_ratio=1.30`, `target_gradation_iterations=20`
  - `V25_strict`：`target_smooth_alpha=0.5`, `target_max_adjacent_ratio=1.25`, `target_gradation_iterations=20`

- 测试模型：
  - 合成 ridge strip：`u in [-1,1]`, `v in [-0.3,0.3]`, `z = 0.12 exp(-(u/0.08)^2)`，用规则三角网格生成，专门观察从高曲率 ridge 到平坦区的过渡。
  - 真实模型：`cpp_adaiso/examples/bunny.obj`、`hand.obj`、`T1.off`、`Th2.ply`。

## 可视化验证

- 对每个模型使用固定色标，避免不同组自动归一化造成误判：
  - `log(h)` 色标固定到 `[log(h_min), log(h_max)]`。
  - edge ratio 色标固定到 `[1, g]`，超过 `g` 的边用红色标记。
  - `x_final - x0` 用发散色标，显示哪些区域被平滑或投影改变。

- 导出的可视化模型含义和颜色对应：
  - 所有 `.ply` 可视化模型都保留输入网格几何，只改变顶点色或面色；因此它们用于看标量场分布，不表示 remesh 后的新网格。
  - 顺序热图色标为：
    ```text
    蓝色 -> 青色 -> 绿色 -> 黄色 -> 红色
    low  ->                         high
    ```
    即蓝色表示该文件对应标量较小，红色表示较大。
  - `raw_curvature_heat.ply`：原始法向夹角曲率 `r_i`。蓝色表示局部法向变化小，红色表示局部法向变化大。该图按当前 case 的 `min(r)` 到 `max(r)` 自动归一化，只适合看同一模型内曲率高低位置。
  - `csf_curvature_heat.ply`：screened CSF 后的曲率 `c_i`。蓝色表示平滑后低曲率，红色表示平滑后高曲率。该图同样按当前 case 自动归一化，用于观察 CSF 是否去除了局部噪声并保留主要高曲率区域。
  - `raw_target_h_heat.ply`：由 CSF 分位数直接映射得到的原始目标尺寸 `h0_i`，实际着色量是 `x0_i = log(h0_i)`。色标固定到 `[log(h_min), log(h_max)]`：蓝色表示小目标尺寸，红色表示大目标尺寸。高曲率细节区应更偏蓝，平坦低曲率区应更偏红。
  - `smoothed_target_h_heat.ply`：screened log-size smoothing 后、gradation projection 前的目标尺寸 `hsmooth_i`。颜色含义同 `raw_target_h_heat.ply`。它用于检查 screened smoothing 是否已经让高低尺寸交界变宽。
  - `final_target_h_heat.ply`：最终使用的目标尺寸 `h_i`，即 smoothing 加 gradation projection 后的尺寸场。颜色含义同上。该图是判断 v2.5.0 尺寸场是否形成连续过渡带的主图。
  - `target_delta_log_heat.ply`：最终场相对原始映射的变化量 `x_final - x0`，使用发散色标：
    ```text
    蓝色: x_final < x0, 最终尺寸比原始映射更小
    白色: x_final ~= x0, 基本未改变
    红色: x_final > x0, 最终尺寸比原始映射更大
    ```
    该图用于定位 smoothing/projection 对尺寸场的修改区域。
  - `edge_ratio_hotspot.ply`：每个顶点关联边中的最大相邻尺寸比例：
    ```text
    max_{j in N(i)} exp(|x_i - x_j|)
    ```
    蓝色表示相邻尺寸变化接近 `1`，红色表示接近或达到上限。对 `V25_default` 和 `V25_strict`，色标分别固定到 `[1, 1.30]` 和 `[1, 1.25]`；对未启用 gradation 的对照组，色标按该 case 的实际最大比值归一化。
  - `violation_mask.ply`：违反 gradation 约束的顶点掩码。灰色表示该顶点所有 incident edge 都满足约束；红色表示至少有一条相邻边满足：
    ```text
    exp(|x_i - x_j|) > g + 1e-10
    ```
    在 `V25_default` 和 `V25_strict` 中，理想结果应全部为灰色。
  - `face_log_gradient_heat.ply`：每个三角面上的 P1 `log(h)` 梯度范数 `||grad_T log(h)||`，是面色而不是顶点色。蓝色表示面内尺寸变化平缓，红色表示面内尺寸变化陡。该图按当前 case 自动归一化，用于查找局部尖峰区域。
  - `edge_ratio_histogram.csv` 不是模型文件，但与可视化配套使用；它给出 `G_ij` 的直方图和 CDF，用于量化 `edge_ratio_hotspot.ply` 中红色区域是否只是少数尾部。

- 合成 ridge strip 额外输出剖面图：
  - 沿 `v=0` 绘制 `h0(u)`、`hsmooth(u)`、`hfinal(u)`。
  - 绘制相邻采样点 `G(u)`，默认组必须全部低于 `1.30`。
  - 标出从 ridge 小尺寸区到平坦大尺寸区的过渡宽度，验证是否至少接近理论 `K_min` 边环。

- 真实模型输出：
  - `G_ij` 的直方图和 CDF。
  - `max(G_ij)`, `p95(G_ij)`, `p99(G_ij)`, `violation_rate`。
  - `||grad_T log(h)||` 热图，用于检查是否仍有局部尖峰。
  - final target heatmap，用于人工确认高曲率区保持小尺寸、低曲率区保持大尺寸，中间为连续过渡带。

## 验收标准

- `V25_default` 在所有测试模型上满足：
  ```text
  max_edge_ratio <= 1.30 + 1e-10
  violation_rate = 0
  h_min <= h_i <= h_max
  ```
- `B0_raw_mapping` 应出现更高的 `max_edge_ratio` 或更集中的 ratio hotspot；`B1_smooth_only` 应降低平均梯度但不作为严格 gradation 证明。
- PLY 热图中 `V25_default` 不应出现孤立的尺寸跳变红边，高低尺寸交界处应形成多层过渡带。
- 若默认 20 次 gradation projection 后仍有违反边，则记录为实现或迭代次数问题；追加运行更高 `target_gradation_iterations`，区分“理论设计可满足”和“当前默认未收敛”。

## 验收结论

1. `V25_default` 在 `ridge_strip`、`bunny`、`hand`、`T1`、`Th2` 全部满足：
   ```text
   max_edge_ratio <= 1.30 + 1e-10
   violation_rate = 0
   h_min <= h_i <= h_max
   ```
   对应 `acceptance_pass=True`。

2. `B0_raw_mapping` 不是渐变尺寸场。真实模型上的 `max G` 达到：
   - `bunny`: `2.077410`
   - `hand`: `2.315172`
   - `T1`: `2.476277`
   - `Th2`: `2.174563`

3. `B1_smooth_only` 能降低梯度和极端跳变，但不能提供严格上界。例如：
   - `T1`: `max G = 2.003722`
   - `hand`: `max G = 1.882592`
   - `Th2`: `max G = 1.782805`

4. `V25_default` 的显式 gradation projection 生效。真实模型上 `max G` 被压到 `1.30`，且没有 violation。部分模型的 `p99 G` 正好达到 `1.30`，说明投影约束确实在高低尺寸交界区起作用。

5. `V25_strict` 进一步将上界收紧到 `1.25`，所有模型仍然 `violation_rate=0`，并且 `p95 ||grad log h||` 相比默认组整体下降。

因此，本次实验支持结论：v2.5.0 构建出的最终尺寸场 `h` 是一个在输入网格边上满足显式相邻尺寸比例约束的渐变尺寸场；其曲面内查询由连续的 P1 `log(h)` 场定义，热图和剖面输出可用于人工检查过渡带。

## iter=10 结论

1. 将 remeshing 迭代数改为 `10` 不改变尺寸场本身；因此尺寸场是否满足 gradation 仍应看 `field_stats.json`，而不是看输出网格边长统计。
2. `V25_default` 和 `V25_strict` 在 iter=10 下仍全部满足尺寸场 gradation 验收。
3. 从输出网格统计看，`V25_strict` 的平均 `Qavg` 最高、平均 final violation 最低；但 `Th2` 的 `Qmin` 在 `V25_default` 下低于对照组，说明更平滑/受限的尺寸场并不单独保证所有模型的最坏三角质量。
4. iter=10 的主要价值是验证使用该尺寸场进入完整 remeshing 后，边长/目标尺寸跟踪仍稳定；它不是尺寸场 gradation 的必要证明，因为 gradation 已在尺寸场构建阶段完成。
