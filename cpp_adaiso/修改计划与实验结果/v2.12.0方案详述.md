# AdaIso v2.12.0 方案详述

## 1. 文档口径

本文基于当前 `cpp_adaiso` 代码中的 v2.12.0 实现，而不是旧论文描述、历史实验入口或 v2.11.x 的多参数诊断管线。当前项目版本在 `CMakeLists.txt` 中为 `2.12.0`。

v2.12.0 的定位是收敛版默认管线：

```text
robust mean curvature
-> screened-Laplacian diffusion
-> q=0.995 curvature cap
-> target_faces inverse-sqrt target length calibration
-> surface barycentric target lookup
-> split / feature-aware collapse / constrained flip / feature-classified tangent smoothing
```

相对 v2.11.2，v2.12.0 的核心变化不是继续增加实验开关，而是把已经验证较稳的路径固定下来，并删除或隐藏旧版本的分支参数。

当前代码中仍存在 `smoothLogDomainSmallSizeOutliers()`，但默认 `targetFaceCurvatureLengths()` 没有调用它。因此本文把它作为“已实现的候选稳定层”，不把它写成默认行为。

## 2. 目标与评价口径

v2.12.0 的目标可以分成四层：

1. 几何保真：保持 v2.10.0 target-face inverse-sqrt 尺寸场带来的低 CD/RMSE。
2. 尺寸跟踪：输出边长尽量落在目标区间 `[0.8h, 1.65h]`。
3. 局部质量：通过 collapse 质量门槛、flip 二面角门槛和 obtuse protection 抑制极差三角形。
4. 可维护性：公开 CLI 只保留生产必要参数，旧实验矩阵不再污染默认路径。

当前全 T 31 模型 iter10 验收结论是：

| 指标 | 结果 |
|---|---|
| 平均 CD | 基本持平 v2.10.0，通过 |
| 平均 violation | 基本持平 v2.10.0，通过 |
| runtime | 略优于 v2.10.0，通过 |
| 最低 Qmin | 仍为 `0.003598`，未达到 `>0.02` 目标 |

因此 v2.12.0 当前代码是“默认路径已收敛、CD/violation 稳定，但最低 Qmin 尚未解决”的版本。

## 3. 系统输入输出

### 3.1 输入

命令形式：

```powershell
adaiso_cli <input.obj|input.ply|input.off> -o <output.obj|output.ply> [options]
```

输入网格记为：

\[
\mathcal M=(V,F),\qquad
V=\{\mathbf p_i\in\mathbb R^3\}_{i=0}^{n-1},\qquad
F=\{(i,j,k)\}_{f=0}^{m-1}.
\]

当前 CLI 保留的参数是：

| 参数 | 默认值 | 作用 |
|---|---:|---|
| `--target-faces` | 清理后输入面数 | 目标面预算 |
| `--preprocess` | `0` | 是否执行极长边预拆分 |
| `--iters` | `5` | 全局重网格迭代轮数 |
| `--gt` | 无 | 仅用于最终 Chamfer Distance 评估 |
| `--cd-samples` | `100000` | CD 双向采样数 |
| `--summary-json` | 无 | 写出 summary JSON |
| `--quiet` | false | 关闭进度日志 |

已删除或不再公开的入口包括 `variant`、多曲率模式、`csf-alpha`、诊断导出目录、flip/collapse 实验参数、MLS 开关等。

### 3.2 输出

主输出是重网格后的三角网格：

\[
\mathcal M'=(V',F').
\]

附加输出是 summary JSON，包含：

- 输入/输出路径、运行时间；
- 实际参数；
- 输入/输出网格 `vertices/faces/qavg/qmin`；
- 每轮 split/collapse/flip 数量和边长目标比统计；
- target sizing 的 `lambda`、估计面数、`h_min/h_max`、观测最小最大目标边长；
- curvature cap 的阈值和修改比例；
- screened-Laplacian 的耗时、残差和矩阵非零元；
- 可选 CD/RMSE。

代码主链路如下：

```text

 │       └─ relocateVertices
 ├─ writeMesh

```

数学主链条可以写成：

\[
\mathcal M
\xrightarrow{\text{robust mean curvature}}
\kappa
\xrightarrow{\text{screened solve}}
\hat\kappa
\xrightarrow{\text{quantile cap}}
\bar\kappa
\xrightarrow{h_i=\lambda/\sqrt{\bar\kappa_i}}
h_i
\xrightarrow{\text{surface interpolation}}
h(\mathbf x)
\xrightarrow{\text{local remesh}}
\mathcal M'.
\]

## 5. 输入清理与预处理

输入会先删除退化面、重复面、非法索引面，并压缩未使用顶点。三角形面积为：

\[
A(a,b,c)=\frac12\|(b-a)\times(c-a)\|.
\]

若启用 `--preprocess 1`，代码计算当前唯一边平均长度：

\[
\bar\ell=\frac1{|E|}\sum_{(i,j)\in E}\|\mathbf p_i-\mathbf p_j\|.
\]

预拆分阈值为：

\[
T_{pre}=2\cdot 1.5\cdot \bar\ell=3\bar\ell.
\]

每轮只拆当前最长候选边，最多 `8` 轮。预处理不使用目标尺寸场，只用于消除远大于平均尺度的输入边。

## 6. 曲率场构建

### 6.1 robust mean curvature

v2.12.0 不再使用 v2.11.x 的主曲率二次拟合默认路径，而是使用稳健 cotan mean curvature。

对每个顶点构造 cotan Laplacian：

\[
\Delta\mathbf p_i=\sum_{j\in N(i)} w_{ij}(\mathbf p_j-\mathbf p_i).
\]

边权来自相邻三角形的 cotangent 权：

\[
w_{ij}=\frac12(\cot\alpha_{ij}+\cot\beta_{ij}).
\]

当前实现为了稳健性做了两层保护：

- 非正、非有限 cotangent 权置为 `0`；
- 正 cotangent 权上限截断到 `10.0`。

顶点面积使用重心面积：

\[
A_i=\sum_{f\ni i}\frac{A_f}{3}.
\]

为避免极小面积导致曲率爆炸，面积下界为：

\[
A_i\leftarrow\max(A_i,10^{-8}\bar\ell^2).
\]

mean curvature magnitude 估计为：

\[
H_i=\frac12\frac{\|\Delta\mathbf p_i\|}{A_i}.
\]

代码最终返回的无量纲曲率信号是：

\[
\kappa_i=\log(1+H_i\bar\ell).
\]

这里的 `log1p` 有两个作用：

1. 将长度缩放影响归一到 `H_i\bar\ell`；
2. 压缩极端曲率动态范围，减少少量尖峰对目标尺寸场的支配。

### 6.2 screened-Laplacian smoothing

曲率扩散求解如下 screened-Laplacian 系统：

\[
(M+\lambda L)\hat{\boldsymbol\kappa}
=M\boldsymbol\kappa.
\]

其中：

\[
\lambda=\alpha\bar\ell^2,\qquad \alpha=2.0.
\]

`M` 是重心顶点质量矩阵：

\[
M_{ii}=\sum_{f\ni i}\frac{A_f}{3}.
\]

`L` 是正权 cotan 图 Laplacian：

\[
L_{ii}=\sum_jw_{ij},\qquad L_{ij}=-w_{ij}.
\]

该线性系统等价于最小化能量：

\[
E(\mathbf x)=
\frac12(\mathbf x-\boldsymbol\kappa)^TM(\mathbf x-\boldsymbol\kappa)
+\frac{\lambda}{2}\mathbf x^TL\mathbf x.
\]

第一项保留原曲率信号，第二项惩罚邻接差异。残差检查使用缩放残差：

\[
r_s=
\frac{2\|A\mathbf x-\mathbf b\|_2}
{\|A\|_\infty\|\mathbf x\|_\infty+\|\mathbf b\|_\infty+\epsilon},
\]

要求：

\[
r_s\le 10^{-10}.
\]

## 7. 曲率 cap 与目标尺寸映射

### 7.1 q=0.995 曲率 cap

screened 曲率进入尺寸映射前，先执行分位数 cap：

\[
c=Q_{0.995}(\hat\kappa),
\qquad
\bar\kappa_i=\min(\max(\hat\kappa_i,10^{-12}),c).
\]

cap 修改比例写入 summary：

\[
\rho=\frac{|\{i:\hat\kappa_i>c\}|}{n}.
\]

T 系列验收中平均修改比例约 `0.5025%`。这说明 cap 只处理极少数尾部尖峰，不是大范围重塑曲率场。

### 7.2 尺寸上下界

设输入支撑网格平均边长为 `base_len = \bar\ell`，目标边长上下界固定为：

\[
h_{min}=0.05\bar\ell,\qquad
h_{max}=5.0\bar\ell.
\]

这两个值在 v2.12.0 中是内部常量，不再通过 CLI 做实验矩阵。

### 7.3 inverse-sqrt 尺寸映射

v2.12.0 的目标尺寸主公式是：

\[
h_i(\lambda)=
\operatorname{clamp}
\left(
\frac{\lambda}{\sqrt{\bar\kappa_i}},
h_{min},
h_{max}
\right).
\]

曲率越大，目标边长越小；曲率越小，目标边长越大。

相比 v2.11.2 方案中的 `h\propto \kappa^{-0.75}`，v2.12.0 当前代码使用的是 `-1/2` 指数。对应的面预算近似关系是：

\[
\hat N_f\propto\frac1{h_f^2}\propto \bar\kappa_f.
\]

这比 `-0.75` 时的：

\[
\hat N_f\propto \kappa^{1.5}
\]

更温和，降低了曲率异常对面预算的超线性放大。

### 7.4 target_faces 标定

每个三角形若使用等边目标边长 `h`，面积近似为：

\[
A_{eq}(h)=\frac{\sqrt3}{4}h^2.
\]

因此目标面数估计为：

\[
\hat N(\lambda)=
\sum_{f\in F}
\frac{A_f}
{\frac{\sqrt3}{4}\bar h_f(\lambda)^2},
\qquad
\bar h_f=\frac{h_i+h_j+h_k}{3}.
\]

随着 `lambda` 增大，所有未撞边界的 `h_i` 增大，估计面数 `\hat N` 单调下降。代码用 64 次二分寻找使 `\hat N` 接近 `target_faces` 的 `lambda`。

若目标面数超出 `[全 h_min, 全 h_max]` 可达范围，代码返回对应边界场：

- 目标过密：全场接近 `h_min`；
- 目标过稀：全场接近 `h_max`。

## 8. 连续目标尺寸场

目标长度只在输入支撑网格顶点上构建一次。之后当前网格的任意点 `x` 查询 `h(x)` 时：

1. 使用 libigl AABB 找到输入支撑网格上离 `x` 最近的三角形；
2. 在该三角形上计算最近点的重心坐标；
3. 对三角形三个顶点的 `h_i` 做线性插值。

若最近三角形为 `(a,b,c)`，重心坐标为：

\[
\boldsymbol\beta=(\beta_a,\beta_b,\beta_c),
\qquad
\beta_a+\beta_b+\beta_c=1,
\]

则：

\[
h(\mathbf x)=
\beta_a h_a+\beta_b h_b+\beta_c h_c.
\]

这使得目标场在整个输入表面上连续定义；重网格过程中不重新计算曲率。

## 9. 局部重网格算子

每轮迭代固定执行：

```text
split -> collapse -> cleanup -> flip -> relocate -> cleanup
```

### 9.1 长边拆分

对当前边 `(i,j)`，目标边长使用两端查询值的较小值：

\[
h_{ij}=\min(h(\mathbf p_i),h(\mathbf p_j)).
\]

若：

\[
\ell_{ij}>1.65h_{ij},
\]

则进入 split 候选。候选按边长降序，同一批中端点不能冲突。拆分点为中点：

\[
\mathbf p_m=\frac12(\mathbf p_i+\mathbf p_j).
\]

### 9.2 短边坍缩

非边界边若满足：

\[
\ell_{ij}<0.8h_{ij},
\]

则进入 collapse 候选。候选按 `length / target` 升序处理，优先处理最短且最违规的边。

坍缩合法性包括：

1. 相邻面数不大于 2；
2. link condition 成立；
3. 合并后一环剩余邻点不少于 3；
4. 合并点到相关邻点不会制造新的过长边；
5. 合并后受影响三角形质量不低于 `0.05`。

其中质量指标为：

\[
Q=\frac{6A}{\sqrt3\,s\,\ell_{max}},
\qquad
s=\frac{\ell_0+\ell_1+\ell_2}{2}.
\]

正三角形 `Q=1`，退化三角形 `Q\to0`。

### 9.3 特征感知坍缩点

v2.12.0 默认启用 feature-aware collapse，不再作为开关。

顶点角亏：

\[
\delta_i=\theta_i^{ref}-\sum_{f\ni i}\theta_{f,i},
\]

内部点：

\[
\theta_i^{ref}=2\pi,
\]

边界点：

\[
\theta_i^{ref}=\pi.
\]

再取顶点相邻边最大二面角：

\[
\phi_i^{max}.
\]

定义截断函数：

\[
\tau(x)=\min(\pi,2x).
\]

几何特征强度为：

\[
K_i=\tau(|\delta_i|),
\qquad
E_i=\tau(\phi_i^{max}),
\]

\[
F_i=(K_i+1)(E_i+1)-1.
\]

若待坍缩边两端特征强度差异不显著，则用中点：

\[
\mathbf p_m=\frac12(\mathbf p_i+\mathbf p_j).
\]

若：

\[
\max(F_i,F_j)>10^{-12}
\]

且：

\[
|F_i-F_j|\ge0.15\max(F_i,F_j),
\]

则坍缩点选择特征更强的端点。该规则的目标是避免尖锐特征被普通中点坍缩抹平。

### 9.4 边翻转

对内边 `(a,b)`，两侧对顶点为 `c,d`。翻转：

\[
(a,b)\rightarrow(c,d).
\]

允许翻转必须同时满足：

- 原边恰有两个相邻面；
- 翻转前两个相邻面二面角不超过 `45°`；
- 新边 `(c,d)` 当前不存在；
- 新边长度满足：

\[
0.8h_{cd}\le\ell_{cd}\le1.65h_{cd};
\]

- 翻转后价数误差严格降低；
- 翻转后两个新面二面角仍不超过 `45°`；
- 翻转后新三角形不出现大于 `90°` 的内角。

价数目标为：

\[
v_*(i)=
\begin{cases}
6,& i\ \text{为内部点},\\
4,& i\ \text{为边界点}.
\end{cases}
\]

局部价数误差：

\[
D=\sum_{u\in\{a,b,c,d\}}|\operatorname{val}(u)-v_*(u)|.
\]

只接受：

\[
D_{after}<D_{before}.
\]

### 9.5 特征分类与切向平滑

重定位前按特征强度分类：

- 边界点直接为 `Corner`；
- 特征强度近零为 `Smooth`；
- 其余点统计重要邻点数并在 `Corner/Crease/Smooth` 中选择最接近的类别。

只有 `Smooth` 点参与切向平滑。

对光滑点 `i`，邻点权重为相邻面面积和乘以邻点目标尺寸：

\[
w_{ij}=a_{ij}h(\mathbf p_j),
\qquad
a_{ij}=\sum_{f\supset(i,j)}A_f.
\]

目标加权邻域质心：

\[
\mathbf c_i=
\frac{\sum_{j\in N(i)}w_{ij}\mathbf p_j}
{\sum_{j\in N(i)}w_{ij}}.
\]

位移投影到切平面：

\[
\mathbf d_i=\mathbf c_i-\mathbf p_i,
\qquad
\mathbf d_i^T=\mathbf d_i-(\mathbf d_i\cdot\mathbf n_i)\mathbf n_i.
\]

更新：

\[
\mathbf p_i'=\mathbf p_i+0.6\mathbf d_i^T.
\]

Corner 和 Crease 不移动。v2.12.0 当前默认没有 MLS 投影阶段。

## 10. 统计指标

### 10.1 边长目标比

对输出边：

\[
r_{ij}=
\frac{\ell_{ij}}{\min(h(\mathbf p_i),h(\mathbf p_j))}.
\]

统计：

- mean；
- std；
- P05/P95；
- violation rate。

违规定义为：

\[
r_{ij}<0.8\quad \text{or}\quad r_{ij}>1.65.
\]

### 10.2 Chamfer Distance

若提供 `--gt`，程序执行面积采样双向 Chamfer。两个方向均使用采样点到采样点最近邻距离：

\[
D_{out\to gt}=
\frac1N\sum_{x\in S_{out}}\min_{y\in S_{gt}}\|x-y\|^2,
\]

\[
D_{gt\to out}=
\frac1N\sum_{y\in S_{gt}}\min_{x\in S_{out}}\|y-x\|^2.
\]

代码定义：

\[
CD=D_{out\to gt}+D_{gt\to out},
\qquad
RMSE_{sym}=\sqrt{\frac{CD}{2}}.
\]

## 11. 已实现但默认未接入的 log-domain 稳定层

`TargetFaceSizing.cpp` 中存在：

```cpp
smoothLogDomainSmallSizeOutliers(...)
```

它的设计目的是只抬高孤立异常小尺寸，而不是恢复 v2.5.0 完整 gradation pipeline。

令：

\[
x_i=\log h_i.
\]

对每个点计算邻域中位数 `median_N(x)`，若当前点比邻域显著更小，则：

\[
w_i=
\operatorname{clamp}
\left(
\frac{\operatorname{median}_{j\in N(i)}x_j-x_i-\tau}{\tau},
0,1
\right),
\qquad
\tau=0.35.
\]

平滑强度：

\[
\eta_i=0.35w_i.
\]

一次更新：

\[
x_i'=(1-\eta_i)x_i+\eta_i\frac1{|N(i)|}\sum_{j\in N(i)}x_j.
\]

再还原：

\[
h_i'=\exp(x_i').
\]

最后用全局比例修正保持目标面数语义：

\[
s=\sqrt{\frac{\hat N(h')}{N_*}},
\qquad
h_i''=\operatorname{clamp}(s h_i',h_{min},h_{max}).
\]

当前默认不调用该函数。若后续继续攻关最低 Qmin，可以把它作为候选消融之一，但需要重新跑全 T 验收，因为它可能改变 CD 和目标面数分布。

## 12. 当前问题与下一步方案角度

当前 v2.12.0 的实验结果显示：曲率 cap 对 CD、violation、runtime 基本没有负面影响，但最低 Qmin 没有改善。说明最低 Qmin 的根因很可能不在目标场尾部曲率尖峰，而在局部拓扑操作或某些模型的原始几何局部形态。

下一步建议按以下优先级推进：

1. 定位最低 Qmin 面的来源。记录最终最低质量三角形所在迭代、是否来自 collapse、flip 还是 tangent smoothing 后产生。
2. 给 tangent smoothing 增加局部质量回退。当前 smooth 更新只检查坐标有限性，没有检查移动后局部三角形质量是否下降。
3. 给 flip 增加质量下界或质量改善判据。当前 flip 有二面角和 obtuse 保护，但没有直接的 `Q_after >= Q_before` 或 `Q_after >= q_min` 约束。
4. 调整 collapse 后质量阈值。当前 `min_quality_after_collapse=0.05`，但最低 Qmin 仍可能由非 collapse 阶段产生。先定位再决定是否提高到 `0.08/0.10`。
5. 对 log-domain outlier smoothing 做小集合消融。优先测试 T36、T87、T125 等低 Qmin 模型，确认它是否影响局部极小尺寸带来的算子压力。

## 13. 最终方案总结

v2.12.0 的完整方案可以概括为：

1. 用 robust cotan mean curvature 代替脆弱的主曲率拟合默认路径，得到缩放归一的曲率信号。
2. 用 screened-Laplacian 在保真和扩散之间做平衡，减少局部噪声。
3. 用 q=0.995 分位数 cap 抑制极少数曲率尾部尖峰。
4. 用 `h=lambda/sqrt(kappa)` 建立相对尺寸分布，并通过目标面数二分确定全局 `lambda`。
5. 用 AABB 最近三角形和重心插值把离散顶点尺寸扩展为连续 `h(x)`。
6. 用目标带 `[0.8h,1.65h]` 驱动 split/collapse/flip，用特征强度保护 collapse 点和 smoothing 点。
7. 用 summary JSON 保留验收所需的关键统计，而不再保留旧实验的大量诊断导出入口。

从数学上看，v2.12.0 的关键收敛点是把面预算与曲率近似降为线性关系：

\[
h\propto \kappa^{-1/2}
\quad\Rightarrow\quad
\hat N\propto h^{-2}\propto \kappa.
\]

这比历史上更激进的指数更稳定，也解释了为什么当前版本能保持 v2.10.0 的 CD/violation 优势。但最低 Qmin 仍未达到验收目标，后续优化应从“目标场构建”转向“局部算子后的质量守卫”，尤其是 tangent smoothing 和 flip 的局部质量回退机制。
