# v2.8.2 实验报告：flip 二面角约束

## 修改内容

在 `flipEdges()` 中加入二面角约束，默认阈值为 `45°`：

```text
max_flip_dihedral_degrees = 45.0
```

判断逻辑：

```text
1. 待翻转旧边两侧三角形法向夹角 > 45°：跳过 flip；
2. 翻转后新边两侧三角形法向夹角 > 45°：跳过 flip。
```

修改位置：

```text
cpp_adaiso/include/adaiso/AdaIsoRemesher.hpp
cpp_adaiso/src/AdaIsoRemesher.cpp
cpp_adaiso/src/main.cpp
```

同时新增 CLI 参数：

```text
--max-flip-dihedral-deg <v>
```

summary JSON 新增字段：

```json
"max_flip_dihedral_degrees": 45
```

该修改已经写入：

```text

```

## 结论

1. 45° 二面角约束使 T21 的 `flip_count` 从 `3459` 降到 `3128`，减少 `9.57%`，说明约束确实过滤了一部分几何上更激进的 flip。
2. 加入约束后 Qmin 从 `0.094679` 提升到 `0.135278`，局部最差三角形质量改善明显。
3. CD 从 `1.613154E-05` 降到 `1.559091E-05`，相对改善 `3.35%`；RMSE 下降 `1.69%`。
4. 输出规模几乎不变，仅增加 `31` 个顶点，因此这次收益不是由明显增密造成的。
5. 当前结果支持保留 flip 二面角约束；后续建议继续测试 `30° / 45° / 60° / 180°`，确认阈值对 Qmin、CD 和局部特征保护的影响。
