## 4. Pyramid 基线

参数：

```text
--mesh-scale 0.8
--variant code
--preprocess 1
--iters 2
--project 1
--target-mode gaussian（默认）
--target-k 8（默认）
--target-sigma-factor 1.0（默认）
--csf-alpha 0.5（默认）
```

结果：

| 指标 | 输入 | 输出 |
|---|---:|---:|
| vertices | 5 | 5 |
| faces | 6 | 6 |
| qavg | 0.8709762509 | 0.9246720989 |
| qmin | 0.7174389352 | 0.9141924519 |

其他结果：

- 第 1 轮：split `9`，collapse `9`，flip `0`。
- 第 2 轮：split `0`，collapse `0`，flip `0`。
- 最终 edge-ratio violation：`0`。
- CSF solver：成功。
- CSF scaled residual：`2.682720227E-16`。
- MLS 候选使 `qmin` 从 `0.914192` 降至 `0.515651`，因此按 v2.3 全局质量保护规则回退。
