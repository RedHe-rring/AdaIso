# v2.6.0 model_001 实验记录

## 实验目的

本实验用于检查当前 v2.6.0 默认设置下，`robust-mean` 曲率模式在 `model_001` 上的重网格表现，并结合可视化结果判断特征是否被保留。

重点关注：

- `robust-mean` 曲率和当前 target field 是否能维持模型特征。
- remesh 后的几何是否出现特征约束丢失。
- 后续是否需要检查 split/collapse/flip/smoothing/projection 全流程中的特征约束。

## 实验设置

- 输入模型：`cpp_adaiso/examples/model_001.off`
- 输出目录：`cpp_adaiso/results/v2.6.0_current/model_001_iter10/`
- 曲率模式：`robust-mean`
- 参数：
  - `--iters 10`
  - `--preprocess 0`
  - `--project 1`
  - `--gt cpp_adaiso/examples/model_001.off`
  - `--export-target-field cpp_adaiso/results/v2.6.0_current/model_001_iter10/target_field`

```powershell

  -o cpp_adaiso/results/v2.6.0_current/model_001_iter10/model_001_iter10_project1.ply `
```

## 可视化观察

从 `model_001_iter10_project1.ply` 与原始 `model_001.off` 的可视化对比中可以看到：当前结果存在特征约束丢失。也就是说，虽然 `robust-mean` 曲率场和 target field 能正常生成，且 target field 本身满足 gradation 约束，但 remesh 结果没有可靠保留模型特征。

这一现象说明问题不应只归因于初始曲率定义。当前 remesh 全流程中缺少显式特征约束，导致特征可能在局部操作中被破坏或抹平。

需要重点检查的阶段：

- split：是否沿特征边保留或继承 feature 标记。
- collapse：是否允许跨特征边或高曲率脊线合并。
- flip：是否翻转了应保留的特征边。
- tangent smoothing：是否沿切向平滑抹掉尖锐特征。
- MLS projection：是否只贴回曲面而没有维护特征线/边界约束。

## 结论

`model_001` 实验表明：仅将初始曲率替换为 `robust-mean` 不足以解决特征保留问题。当前可视化结果显示存在特征约束丢失，需要检查 remesh 的整个过程中的约束。

v2.6.0 后续修改方向应从“曲率场驱动 target_h”扩展到“特征约束驱动 remesh 操作”：

- 在输入网格上识别 feature edge / boundary / high-dihedral edge。
- 将 feature 标记传递到 split 后的新边和新点。
- 在 collapse 和 flip 中禁止破坏 feature 拓扑。
- 对 smoothing 和 projection 增加 feature-aware 约束。
- 在实验记录中单独比较开启/关闭 feature constraints 对 CD、Qmin、特征保留的影响。
