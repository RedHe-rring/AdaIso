# AdaIso v2.10.0 方案详述

## 1. 文档范围与版本依据

本文从 v2.10.0 当时的 C++ 源码出发，自零梳理一次完整运行：输入是什么、每个阶段输出什么、数学关系是什么，以及这些量如何驱动最终重网格。

本文采用的历史代码基线是：

```text
commit 606388fa3910bdb8d87644629062d4b00aa8b3d5
message: Implement v2.10 target-face curvature sizing
date:    2026-07-10 18:08:25 +0800
```

必须先说明两个版本管理事实：

1. 仓库中没有名为 `v2.10.0` 的 Git tag，v2.10.0 对应的是上述提交 `606388f`；下一批已有标签是 `v2.10.1`。
2. 该提交的 `CMakeLists.txt` 中 `project(cpp_adaiso VERSION 2.8.0)` 没有同步更新，属于版本元数据滞后；算法身份应以提交内容、提交说明及 v2.10.0 实验脚本为准。

本文只描述 `606388f` 中实际存在的行为，不把 v2.10.1、v2.10.2、v2.11.x 的实现倒推到 v2.10.0。

主要代码依据：

| 职责 | v2.10.0 文件 |
|---|---|
| CLI、参数解析、summary JSON | `src/main.cpp` |
| 总流程、原始曲率、目标场、重网格、诊断导出 | `src/AdaIsoRemesher.cpp` |
| 配置和运行统计 | `include/adaiso/AdaIsoRemesher.hpp` |

| 网格读写 | `src/IO.cpp` |
| 网格清理与几何基本量 | `src/Mesh.cpp`、`src/Geometry.cpp` |
| 质量与 Chamfer Distance | `src/Metrics.cpp` |

一句话概括 v2.10.0：

> 输入一个三角网格，计算无量纲原始曲率并用 screened Laplacian 得到 CSF 曲率，再通过 `h=λ/√κ` 和目标面数二分得到输入表面上的连续目标边长场，最后反复执行 split、collapse、flip 和重定位，输出自适应各向同性三角网格。

## 2. 系统级输入与输出

### 2.1 必需输入

命令形式：

```powershell
adaiso_cli <input.obj|input.ply|input.off> -o <output.obj|output.ply> [options]
```

算法输入是表面网格：

\[
\mathcal M=(V,F),
\qquad
V=\{\mathbf p_i\in\mathbb R^3\}_{i=0}^{n-1},
\qquad
F=\{(i,j,k)\}_{f=0}^{m-1}.
\]

- `V` 是三维顶点坐标。
- `F` 最终全部是三角形索引。
- OBJ、ASCII PLY、OFF 中的多边形面会用 fan triangulation 转为三角形。
- 输入法向、纹理、颜色、材质不参与计算，也不会保留到普通输出网格。
- PLY 只支持 ASCII。

### 2.2 可选输入

- 曲率模式：`robust-mean` 或 `normal-angle`；
- CSF 平滑强度 `alpha`；
- 目标面数 `target_faces`；
- 重网格参数和迭代次数；
- 可选 GT 网格，仅用于结束后的 Chamfer Distance；
- 可选目标场与迭代快照输出目录。

### 2.3 主输出

主输出是新三角网格：

\[
\mathcal M'=(V',F').
\]

它追求：

- 局部边长落入目标尺寸带；
- 内部点价数接近 6、边界点价数接近 4；
- 三角形尽量各向同性；
- 边界、折痕和角点尽量不被平滑破坏；
- 可选 MLS 把光滑点投向原始输入点云的局部拟合平面。

### 2.4 附加输出

- 标准输出上的完整 summary JSON；
- `--summary-json` 指定的同内容 JSON 文件；
- 每轮 split/collapse/flip 数、网格规模、质量和边长违规率；
- 可选目标场 CSV、统计 JSON、彩色 PLY；
- 可选迭代/阶段网格快照；
- 有 GT 时的双向面积采样 Chamfer Distance。

`--quiet` 只关闭标准错误上的进度日志，不关闭标准输出中的 summary JSON。

## 3. 记号与核心中间量

| 记号 | 含义 |
|---|---|
| `E` | 网格唯一无向边集合 |
| `A_f` | 三角形 `f` 的面积 |
| `\bar\ell` | 目标场支撑网格的平均边长 |
| `r_i` | 顶点原始曲率信号，代码中 `raw_curvature` |
| `\kappa_i` | screened CSF 后的扩散曲率，代码中 `csf_curvature` |
| `\lambda_h` | 尺寸映射的全局系数；与 CSF 扩散系数不是同一个量 |
| `h_i` | 支撑网格顶点 `i` 的最终目标边长 |
| `h(\mathbf x)` | 在输入支撑表面上查询的连续目标边长 |
| `N_*` | 用户目标面数，默认是清理后输入面数 |

为避免符号混淆，本文把 CSF 系统中的扩散强度记为：

\[
\lambda_{csf}=\alpha\bar\ell^2,
\]

把尺寸映射二分得到的代码变量 `lambda` 记为 `\lambda_h`。

v2.10.0 的核心中间输出是一个正的顶点尺寸数组：

\[
\mathbf h=(h_0,h_1,\ldots,h_{n-1}),\qquad h_i>0.
\]

该数组及其支撑网格只构建一次，所有全局重网格轮次共享它，不会每轮重新计算曲率。

```text
main

 ├─ loadMesh(input)
 ├─ removeDegenerateFaces(input)                 用于 input_summary
 ├─ AdaIsoRemesher::remesh(input)
 │   ├─ removeDegenerateFaces                    正式清理
 │   ├─ 确定 effective_target_faces
 │   ├─ 保存 original_for_projection
 │   ├─ [可选] subRemesh                         极长边预拆分
 │   ├─ buildTargetLengths                       只执行一次
 │   │   ├─ computeRawCurvatureField
 │   │   │   ├─ robust-mean（默认）
 │   │   │   └─ normal-angle
 │   │   ├─ solveScreenedCsf
 │   │   ├─ targetFaceCurvatureLengths
 │   │   │   ├─ h(λ)=clamp(λ/√κ,hmin,hmax)
 │   │   │   ├─ 正三角形面积模型估计面数
 │   │   │   └─ 64 次二分匹配 target_faces
 │   │   ├─ [可选] writeTargetFieldDiagnostics
 │   │   └─ TargetLengthField::build             AABB + 顶点 h
 │   └─ 重复 global_iterations 次
 │       ├─ splitLongEdges
 │       ├─ collapseShortEdges + cleanup
 │       ├─ flipEdges
 │       └─ relocateVertices + cleanup
 ├─ writeMesh(output)
 ├─ summarizeMesh(output)
 ├─ [可选] areaSampledChamferDistance(output,gt)
 └─ 打印/写入 summary JSON
```

核心数据流：

```text
输入几何
  → 原始无量纲曲率 r
  → screened CSF 曲率 κ
  → 逆平方根尺寸族 h(λ)
  → 目标面数二分确定 λ
  → 最终顶点尺寸 h
  → 最近表面三角形重心插值 h(x)
  → split / collapse / flip / relocation
  → 输出网格
```

## 6. 阶段 0：读取、三角化与清理

### 6.1 输入

- OBJ、ASCII PLY 或 OFF 文件；
- 三维顶点与多边形面索引。

### 6.2 三角化

多边形：

\[
(v_0,v_1,\ldots,v_{r-1})
\]

展开为：

\[
(v_0,v_1,v_2),(v_0,v_2,v_3),\ldots,(v_0,v_{r-2},v_{r-1}).
\]

### 6.3 清理

`removeDegenerateFaces` 删除：

1. 有重复顶点索引的面；
2. 负索引或越界面；
3. 双倍面积不大于 `1e-14` 的面；
4. 顶点集合相同的重复面，不区分朝向；
5. 随后压缩未使用顶点并重映射面索引。

三角形面积：

\[
A(a,b,c)=\frac12\|(b-a)\times(c-a)\|.
\]

### 6.4 输出

- 清理后的紧凑三角网格；
- 清理后面数作为未显式指定时的 `N_*`。

`effective_target_faces` 在可选 preprocess 之前确定，因此开启预拆分不会把新增面自动加入目标面数。`original_for_projection` 也在 preprocess 之前保存，后续 MLS 参考的是清理后、预拆分前的输入网格。

---

## 7. 阶段 1：可选极长边预拆分

### 7.1 输入

- 清理后的网格；
- `subremesh_multiplier=1.5`；
- `max_subremesh_rounds=8`。

### 7.2 数学

唯一边平均长度：

\[
\bar\ell=\frac1{|E|}\sum_{(i,j)\in E}\|\mathbf p_i-\mathbf p_j\|.
\]

预拆分阈值：

\[
T_{pre}=2\times1.5\times\bar\ell=3\bar\ell.
\]

每轮找所有 `\ell_{ij}>T_pre` 的边，只拆当前最长边，新点为：

\[
\mathbf p_m=\frac{\mathbf p_i+\mathbf p_j}{2}.
\]

每个相邻三角形被拆为两个。最多 8 轮，阶段内不重新计算 `\bar\ell` 和阈值。

### 7.3 输出

- 预拆分并再次清理后的网格；
- 该网格成为原始曲率、CSF 和目标尺寸场的支撑网格。

---

## 8. 阶段 2：面法向和顶点法向

三角形单位法向：

\[
\mathbf n_f=
\operatorname{normalize}
\left[(\mathbf p_j-\mathbf p_i)\times(\mathbf p_k-\mathbf p_i)\right].
\]

顶点法向采用面面积加权：

\[
\mathbf n_i=
\operatorname{normalize}
\left(\sum_{f\ni i}A_f\mathbf n_f\right).
\]

这些法向用于 `normal-angle` 原始曲率、特征强度、切向重定位和 MLS。

---

## 9. 阶段 3A：默认 robust-mean 原始曲率

v2.10.0 默认 `curvature_mode=robust-mean`。

### 9.1 输入

- 支撑网格；
- 唯一边平均长度 `\bar\ell`。

### 9.2 顶点重心面积

\[
A_i=\sum_{f\ni i}\frac{A_f}{3}.
\]

为避免细长面或极小局部面积造成除零放大，使用：

\[
A_i^{safe}=\max(A_i,10^{-8}\bar\ell^2).
\]

### 9.3 稳健余切权

对三角形角 `\theta`：

\[
\cot\theta=\frac{\mathbf u\cdot\mathbf v}{\|\mathbf u\times\mathbf v\|}.
\]

单角贡献先处理为：

\[
\widetilde{\cot\theta}=
\begin{cases}
0,&\cot\theta\le0\text{ 或非有限},\\
\min(\cot\theta,10),&\cot\theta>0.
\end{cases}
\]

边权为其相邻对角贡献的一半之和：

\[
w_{ij}^{raw}=\frac12
\sum_{f\supset(i,j)}\widetilde{\cot\theta_f}.
\]

因此钝角的负余切不会进入该原始曲率算子，过大的正余切也被截到 10。

### 9.4 离散 Laplacian 与平均曲率幅值

位置 Laplacian 向量：

\[
\Delta\mathbf p_i=
\sum_{j\in N(i)}w_{ij}^{raw}(\mathbf p_j-\mathbf p_i).
\]

平均曲率幅值估计：

\[
H_i=\frac12\frac{\|\Delta\mathbf p_i\|}{A_i^{safe}}.
\]

`H_i` 量纲为长度的倒数。

### 9.5 无量纲压缩信号

最终原始曲率信号：

\[
r_i=\log(1+H_i\bar\ell).
\]

它有三个作用：

- `H_i\bar\ell` 消除整体尺度量纲；
- `log1p` 压缩极大曲率动态范围；
- 结果非负且平面区域接近 0。

### 9.6 输出

- 每个顶点一个 `raw_curvature=r_i`；
- 默认后续把它送入 screened CSF。

---

## 10. 阶段 3B：可选 normal-angle 原始曲率

若指定 `--curvature-mode normal-angle`，不使用余切平均曲率，而是计算相邻顶点法向夹角均值：

\[
r_i=
\frac1{|N(i)|}
\sum_{j\in N(i)}
\arccos\left[
\operatorname{clamp}(\mathbf n_i\cdot\mathbf n_j,-1,1)
\right].
\]

无邻点时 `r_i=0`。

该信号单位可视为弧度，本身也是无量纲的。它没有按边长、面积或邻点距离加权，因此与 robust mean 的几何含义和数值分布不同。

输出仍统一命名为 `raw_curvature`。

---

## 11. 阶段 4：screened Curvature Smoothed Field

### 11.1 输入

- 顶点原始曲率 `r`；
- 网格；
- `csf_alpha=\alpha`，默认 2.0 且必须严格大于 0。

v2.10.0 不允许通过 `alpha=0` 跳过 CSF。

### 11.2 CSF 顶点质量

使用与 robust mean 面积相同形式的重心质量，但这里不使用面积 floor：

\[
M_{ii}=m_i=\sum_{f\ni i}\frac{A_f}{3}.
\]

所有 `m_i` 必须正且有限。

### 11.3 CSF 余切权

CSF 使用 `Geometry.cpp::cotangentEdgeWeights`，它和上一阶段 robust mean 的稳健余切权不是同一个规则。

先累加标准对角余切并乘 `1/2`：

\[
w_{ij}^{csf}=\frac12
\sum_{f\supset(i,j)}\cot\theta_f.
\]

若边的合计权重非正或非有限，则整条边权替换为：

\[
\eta=10^{-4}.
\]

这里没有单角正值截断到 10；只有最终边权非正/非有限时才替换为 `eta`。

定义图 Laplacian：

\[
L_{ii}=\sum_{j\in N(i)}w_{ij}^{csf},
\qquad
L_{ij}=-w_{ij}^{csf}.
\]

### 11.4 稀疏系统

扩散强度：

\[
\lambda_{csf}=\alpha\bar\ell^2.
\]

求解：

\[
(M+\lambda_{csf}L)\boldsymbol\kappa=M\mathbf r.
\]

逐点形式：

\[
m_i(\kappa_i-r_i)
+\lambda_{csf}
\sum_{j\in N(i)}w_{ij}^{csf}(\kappa_i-\kappa_j)=0.
\]

等价于最小化：

\[
E(\mathbf x)=
\frac12(\mathbf x-\mathbf r)^TM(\mathbf x-\mathbf r)
+\frac{\lambda_{csf}}2\mathbf x^TL\mathbf x.
\]

第一项保留原始曲率，第二项抑制相邻差异。代码使用 Eigen `SimplicialLDLT`。

### 11.5 残差验收

绝对残差：

\[
r_{abs}=\|A\boldsymbol\kappa-b\|_2.
\]

缩放残差：

\[
r_s=
\frac{2\|A\boldsymbol\kappa-b\|_2}
{\|A\|_\infty\|\boldsymbol\kappa\|_\infty+
\|b\|_\infty+\epsilon}.
\]

要求：

\[
r_s\le10^{-10}.
\]

否则整次运行报错。

### 11.6 输出

- `csf_curvature=κ`；
- 装配、分解、求解耗时；
- 稀疏矩阵非零元数；
- 绝对/缩放残差；
- `csf_solver_success`。

---

## 12. 阶段 5：由 CSF 曲率建立目标尺寸族

### 12.1 输入

- `csf_curvature=κ`；
- 平均边长 `\bar\ell`；
- 目标面数 `N_*`。

### 12.2 安全曲率

对所有顶点：

\[
\kappa_i^{safe}=\max(\kappa_i,10^{-12}).
\]

同时记录：

\[
\kappa_{max}=\max_i\kappa_i^{safe}.
\]

输入 CSF 只要求有限，没有额外异常点过滤、分位数截断或可靠性判断。

### 12.3 尺寸硬边界

\[
h_{min}=0.05\bar\ell,
\qquad
h_{max}=5\bar\ell.
\]

两者在 v2.10.0 中是固定常量，CLI 不能修改。

### 12.4 逆平方根映射

给定全局系数 `\lambda_h`：

\[
h_i(\lambda_h)=
\operatorname{clamp}
\left(
\frac{\lambda_h}{\sqrt{\kappa_i^{safe}}},
h_{min},h_{max}
\right).
\]

因此在未触发 clamp 的区域：

\[
h_i\propto\kappa_i^{-1/2}.
\]

- 曲率越大，目标边长越小；
- 曲率比增大 4 倍，目标边长缩小为 1/2；
- `\lambda_h` 同时控制全局密度；
- clamp 防止尺寸无限小或无限大。

### 12.5 输出

此时不是一个固定目标场，而是一族随 `\lambda_h` 单调变化的尺寸场 `h(λ_h)`，下一阶段通过目标面数确定唯一 `\lambda_h`。

---

## 13. 阶段 6：目标面数估计与 lambda 二分

### 13.1 正三角形面积模型

边长为 `h` 的正三角形面积：

\[
A_{eq}(h)=\frac{\sqrt3}{4}h^2
=0.4330127018922193h^2.
\]

对于输入面 `f=(i,j,k)`，先取三顶点目标边长的算术均值：

\[
h_f=\frac{h_i+h_j+h_k}{3}.
\]

该面估计会产生的目标三角形数为：

\[
\widehat N_f=
\frac{A_f}{(\sqrt3/4)h_f^2}.
\]

全网格估计：

\[
\widehat N(\lambda_h)=
\sum_{f\in F}\widehat N_f.
\]

这只是连续面积预算模型，不是对离散 remesher 最终面数的硬约束。

### 13.2 二分区间

下界：

\[
\lambda_{lo}=0.
\]

此时所有点都被 clamp 到 `h_min`，得到理论最大密度：

\[
N_{dense}=\widehat N(h_i\equiv h_{min}).
\]

上界：

\[
\lambda_{hi}=h_{max}\sqrt{\kappa_{max}}.
\]

因为每个 `\kappa_i^{safe}\le\kappa_{max}`，所以：

\[
\frac{\lambda_{hi}}{\sqrt{\kappa_i^{safe}}}\ge h_{max},
\]

所有点都被 clamp 到 `h_max`，得到理论最小密度：

\[
N_{coarse}=\widehat N(h_i\equiv h_{max}).
\]

### 13.3 不可达目标

- 若 `N_*\ge N_dense`，直接返回全 `h_min` 和 `\lambda_h=0`；
- 若 `N_*\le N_coarse`，直接返回全 `h_max` 和 `\lambda_h=\lambda_{hi}`。

v2.10.0 没有 `target_faces_reachable` 标志，也不记录相对误差；调用方只能从返回的 `estimated_faces` 与目标值比较是否撞到边界。

### 13.4 固定 64 次二分

若目标在可达区间内，重复 64 次：

\[
\lambda_{mid}=\frac{\lambda_{lo}+\lambda_{hi}}2.
\]

- 若 `\widehat N(\lambda_mid)>N_*`，当前过密，需要增大目标边长：

  \[
  \lambda_{lo}=\lambda_{mid}.
  \]

- 否则：

  \[
  \lambda_{hi}=\lambda_{mid}.
  \]

最后：

\[
\lambda_h=\frac{\lambda_{lo}+\lambda_{hi}}2.
\]

重新生成最终 `target_h` 并计算 `estimated_faces`。

### 13.5 数学上的密度关系

在某一面内不触发 clamp 且三顶点曲率接近时：

\[
h_f\approx\frac{\lambda_h}{\sqrt\kappa_f}.
\]

代入面积预算：

\[
\widehat N_f
\approx
\frac{A_f\kappa_f}
{(\sqrt3/4)\lambda_h^2}.
\]

因此 v2.10.0 的局部理论面密度近似与 CSF 曲率成正比，与 `\lambda_h^2` 成反比。这正是“inverse sqrt diffused curvature + target faces”设计的核心。

### 13.6 输出

- `target_lengths[]`；
- `lambda`；
- `estimated_faces`；
- `h_min`、`h_max`；
- `target_faces`。

但主流程只把 `target_lengths` 用于重网格，只有 verbose 日志打印 `lambda` 和 `estimated_faces`；v2.10.0 的 summary JSON 与目标场诊断 JSON 都没有保存这两个量。

## 14. v2.10.0 中不存在的目标场阶段

为避免和后续版本混淆，v2.10.0 明确没有：

- 主曲率 `k1/k2` 二次曲面拟合；
- 主曲率拟合 SVD 可靠性诊断；
- `topk_median` 或 sampling cap 曲率异常过滤；
- 独立的 `log(h)` gradation limiter；
- limiter source/distance 溯源；
- 曲率平滑后先映射 shape、再做第二次 scale 标定的双阶段结构；
- mean/min 两种面代表尺寸选择；
- 可配置 `h_max`；
- hmin/hmax 饱和率、预算集中度等健康度统计。

v2.10.0 的尺寸场路径只有：

```text
raw curvature → screened CSF κ → clamp(λ/√κ,hmin,hmax)
```

曲率的空间平滑由 CSF 完成，目标边长本身不再单独平滑或做相邻边渐变投影。

## 15. 阶段 7：连续表面目标尺寸场

### 15.1 输入

- 构建目标场时的支撑网格；
- 每个支撑顶点的最终 `h_i`。

### 15.2 构建

`TargetLengthField` 保存：

- 支撑网格；
- 顶点目标边长；
- libigl AABB 最近三角形树。

### 15.3 查询

对任意空间位置 `x`：

1. 在支撑表面上找最近点 `x_c` 及其所在三角形 `(a,b,c)`；
2. 求 `x_c` 的重心坐标 `(\beta_a,\beta_b,\beta_c)`；
3. 插值：

\[
h(\mathbf x)=
\beta_a h_a+\beta_b h_b+\beta_c h_c,
\qquad
\beta_a+\beta_b+\beta_c=1.
\]

重心分量先截到 `[0,1]` 再归一化。若三角形退化，则退化为最近顶点 one-hot。

### 15.4 输出语义

- `h(x)` 是“最近支撑表面点上的分片线性尺寸场”；
- 不是三维空间中的解析距离函数；
- 新增、删除或移动后的输出顶点都通过空间位置查询；
- 目标场在所有全局迭代中固定不变。

## 16. 阶段 8：全局重网格循环

默认执行 5 轮，每轮顺序固定：

```text
split → collapse → cleanup → flip → tangent smoothing → optional MLS → cleanup
```

每轮结束记录：

- split/collapse/flip 数量；
- 顶点数和面数；
- `Qavg`、`Qmin`；
- 边长/目标比的均值、标准差、P05、P95 和违规率。

迭代次数固定，不按违规率自动提前终止整个全局循环。

## 17. 边目标值和 variant 差异

对当前边 `(i,j)`：

\[
h_i=h(\mathbf p_i),
\qquad
h_j=h(\mathbf p_j).
\]

split 始终用：

\[
h_{ij}^{split}=\min(h_i,h_j).
\]

collapse 使用：

\[
h_{ij}^{collapse}=
\begin{cases}
\min(h_i,h_j),&\text{code},\\
\max(h_i,h_j),&\text{paper}.
\end{cases}
\]

拆分倍率：

\[
f_s=
\begin{cases}
1.65,&\text{code},\\
5/3,&\text{paper}.
\end{cases}
\]

坍缩倍率固定：

\[
f_c=4/5=0.8.
\]

默认 variant 是 `code`。

## 18. 子阶段 A：长边拆分

### 18.1 候选

边长：

\[
\ell_{ij}=\|\mathbf p_i-\mathbf p_j\|.
\]

若：

\[
\ell_{ij}>f_s\min(h_i,h_j),
\]

则为拆分候选。

### 18.2 批处理

- 候选按实际长度降序；
- 同一批两条边不能共享端点；
- 选中前重新检查阈值；
- 新点为中点：

  \[
  \mathbf p_m=\frac{\mathbf p_i+\mathbf p_j}{2};
  \]

- 相邻三角形各拆为两个；
- 每个全局轮次最多 5 个 split pass。

### 18.3 输出

- 增加顶点和面的网格；
- 本轮累计 split 边数。

---

## 19. 子阶段 B：短边批量坍缩

### 19.1 候选

两端都不是边界点，且：

\[
\ell_{ij}<0.8h_{ij}^{collapse}
\]

时进入候选。候选按 `\ell/h` 升序，再按长度升序。

### 19.2 顶点特征强度

顶点角和：

\[
\Theta_i=\sum_{f\ni i}\theta_{f,i}.
\]

参考角：

\[
\Theta_i^{ref}=
\begin{cases}
2\pi,&\text{内部点},\\
\pi,&\text{边界点}.
\end{cases}
\]

角亏：

\[
\delta_i=\Theta_i^{ref}-\Theta_i.
\]

令 `\phi_i^{max}` 为相邻内边上的最大二面角，定义：

\[
\tau(x)=\min(\pi,2x),
\]

\[
K_i=\tau(|\delta_i|),
\qquad
E_i=\tau(\phi_i^{max}),
\]

\[
F_i=(K_i+1)(E_i+1)-1.
\]

### 19.3 坍缩点

默认中点：

\[
\mathbf p_m=\frac12(\mathbf p_i+\mathbf p_j).
\]

启用特征感知时，若 `F_max>1e-12` 且：

\[
|F_i-F_j|\ge0.15\max(F_i,F_j),
\]

则直接保留特征更强端点的位置；否则仍取中点。

### 19.4 合法性

候选必须通过：

1. 边相邻面数不能大于 2；
2. 两端一环交集必须等于该边相邻面的对顶点集合，即 link condition；
3. 合并后相关邻点至少 3 个；
4. 合并后不制造过长新边：

   \[
   \|\mathbf p_m-\mathbf p_n\|
   \le f_s\min[h(\mathbf p_m),h(\mathbf p_n)];
   \]

5. 非退化局部三角形质量不低于 0.05。

三角形质量：

\[
Q=\frac{6A}{\sqrt3\,s\,\ell_{max}},
\qquad
s=\frac{\ell_0+\ell_1+\ell_2}{2}.
\]

正三角形 `Q=1`，退化三角形趋近 0。

### 19.5 无冲突批次

每条候选的 footprint 包含两端和两端一环邻点。同批 footprint 不得相交。实际操作保留较小顶点编号、删除较大编号，把保留点移动到坍缩点，随后删除退化/重复面并压缩顶点。

每轮最多 5 个 collapse pass。

### 19.6 输出

- 坍缩并清理后的网格；
- 本轮累计 collapse 数。

## 20. 子阶段 C：边翻转

内边 `(a,b)` 的两个对顶点为 `c,d`，翻转为新边 `(c,d)`。

### 20.1 条件

1. 原边恰有两个相邻面；
2. 原两面二面角不超过默认 `45°`；
3. `c\ne d` 且 `(c,d)` 尚不存在；
4. 新边长度满足：

   \[
   0.8\min(h_c,h_d)
   \le\ell_{cd}\le
   f_s\min(h_c,h_d);
   \]

5. 翻转严格改善价数误差；
6. 新两面二面角仍不超过阈值；
7. 默认不允许任一新三角形出现大于 `90°` 的内角。

### 20.2 价数目标

\[
val_*(v)=
\begin{cases}
6,&\text{内部点},\\
4,&\text{边界点}.
\end{cases}
\]

局部误差：

\[
D=\sum_{v\in\{a,b,c,d\}}|val(v)-val_*(v)|.
\]

翻转后 `a,b` 价数各减 1，`c,d` 各加 1，仅当：

\[
D_{after}<D_{before}
\]

时接受。

价数数组在每个 flip pass 开始时计算一次，同一 pass 内不随前面翻转增量更新；下一 pass 重新计算。每轮最多 5 个 pass，无翻转时提前结束。

### 20.3 输出

- 拓扑翻转后的网格；
- 本轮累计 flip 数。

---

## 21. 子阶段 D：特征分类与切向平滑

### 21.1 分类

复用特征强度 `F_i`：

- 边界点强制为 `Corner`；
- `F_i<=1e-12` 为 `Smooth`；
- 其他点统计满足：

  \[
  F_j\ge0.5F_i
  \]

  的重要邻点数 `r_i`，比较：

  \[
  d_{corner}=|r_i-0|,
  \quad
  d_{crease}=|r_i-2|,
  \quad
  d_{smooth}=|r_i-|N(i)||.
  \]

距离最小者决定类别；平局优先 Corner，再 Crease，再 Smooth。只有 Smooth 点移动。

### 21.2 目标尺寸加权质心

邻点 `j` 的面积权重：

\[
a_{ij}=\sum_{f\supset(i,j)}A_f.
\]

实际权重还乘以邻点目标尺寸：

\[
w_{ij}=a_{ij}h(\mathbf p_j).
\]

质心：

\[
\mathbf c_i=
\frac{\sum_{j\in N(i)}w_{ij}\mathbf p_j}
{\sum_{j\in N(i)}w_{ij}}.
\]

### 21.3 切向更新

\[
\mathbf d_i=\mathbf c_i-\mathbf p_i,
\]

\[
\mathbf d_i^T=
\mathbf d_i-(\mathbf d_i\cdot\mathbf n_i)\mathbf n_i,
\]

\[
\mathbf p_i'=\mathbf p_i+0.6\mathbf d_i^T.
\]

所有点同步更新，不读取同轮已更新邻点。

### 21.4 输出

- Smooth 点切向移动；
- Corner/Crease 保持不动。

## 22. 子阶段 E：可选 MLS 投影

默认关闭。开启后只替换 Smooth 点。

### 22.1 输入

- 切向平滑后的点 `p`；
- 清理后、preprocess 前的原输入顶点及面积加权法向；
- `k=8`、最多 5 次、误差阈值 `1e-4`。

### 22.2 邻域、带宽和权重

当前迭代位置 `p_x` 的 kNN 距离：

\[
d_1\le\cdots\le d_k.
\]

带宽：

\[
h_{MLS}=d_k+\max(0,d_k-d_{k-1}),
\]

并下限截到 `1e-12`。

\[
w_j=\exp\left[-(d_j/h_{MLS})^2\right].
\]

局部加权点与法向：

\[
\mathbf a=\frac{\sum_jw_j\mathbf p_j}{\sum_jw_j},
\]

\[
\mathbf n=\operatorname{normalize}
\left(\frac{\sum_jw_j\mathbf n_j}{\sum_jw_j}\right).
\]

### 22.3 投影

\[
e=|\mathbf n\cdot(\mathbf p-\mathbf a)|,
\]

\[
\mathbf p_x=
\mathbf p-[\mathbf n\cdot(\mathbf p-\mathbf a)]\mathbf n.
\]

公式始终以进入 MLS 时的原始 `p` 为基准，迭代位置 `p_x` 只用于下一轮 kNN。误差相对上轮增大或低于 `1e-4` 时停止。

### 22.4 输出

- 有效 Smooth 点采用 MLS 结果；
- Corner/Crease 保持切向阶段后的坐标；
- 主流程随后再次删除退化和重复面。

v2.10.0 代码没有“MLS 后若全局 Qmin 下降则整体回滚”的检查。

---

## 23. 每轮质量与边长指标

### 23.1 三角形质量

\[
Q_f=\frac{6A_f}{\sqrt3\,s_f\,\ell_{max,f}}.
\]

\[
Q_{avg}=\frac1m\sum_fQ_f,
\qquad
Q_{min}=\min_fQ_f.
\]

### 23.2 边长/目标比

统计阶段对所有 variant 都使用端点目标最小值：

\[
R_{ij}=\frac{\ell_{ij}}
{\min[h(\mathbf p_i),h(\mathbf p_j)]}.
\]

输出 mean、population standard deviation、线性插值 P05/P95，以及：

\[
R_{ij}<0.8
\quad\text{或}\quad
R_{ij}>f_s
\]

的违规率。

目标面数只标定输入尺寸场，最终输出面数没有作为循环终止条件，因此最终面数通常不会精确等于 `N_*`。

### 24.1 `vertices.csv`

```text

```

对边 `(i,j)`：

\[
\texttt{abs\_dh}=|h_i-h_j|,
\]

\[
\texttt{target\_ratio}=
\frac{\max(h_i,h_j)}{\min(h_i,h_j)},
\]

\[
\texttt{h\_slope}=rac{|h_i-h_j|}{\ell_{ij}}.
\]

表头：

```text
i,j,edge_length,abs_dh,target_ratio,h_slope
```

### 24.3 `faces.csv`

对三角形 `p0,p1,p2`，令：

\[
e_1=p_1-p_0,
\qquad
e_2=p_2-p_0.
\]

解：

\[
\begin{bmatrix}
e_1\cdot e_1&e_1\cdot e_2\\
e_1\cdot e_2&e_2\cdot e_2
\end{bmatrix}
\begin{bmatrix}a\\b\end{bmatrix}
=
\begin{bmatrix}h_1-h_0\\h_2-h_0\end{bmatrix}.
\]

面内线性尺寸梯度模：

\[
\texttt{grad\_h\_norm}=\|ae_1+be_2\|.
\]

`max_edge_target_ratio` 是该面三边 `max(h_i,h_j)/min(h_i,h_j)` 的最大值。

- shared 曲率热图使用 raw 与 CSF 两个完整数值范围的并集；

- target h 使用 `[h_min,h_max]`，颜色反转，使小 h 显示为更热的颜色。

`field_stats.json` 没有记录：

- `target_faces`；
- 二分得到的 `lambda`；
- `estimated_faces`；
- 上下界饱和率；
- 目标面数可达性或误差；
- CSF 求解统计。

这些缺口是 v2.10.0 后续版本继续增加诊断的原因之一。

## 27. GT Chamfer Distance

仅在提供 `--gt` 时执行。

### 27.1 面积采样

两个网格分别按三角形面积构建 CDF。radical inverse 低差异序列：

- base 2 选择面积位置；
- base 3、5 生成三角形内 `(u,v)`；
- 若 `u+v>1`，替换为 `(1-u,1-v)`。

三角形内采样点：

\[
\mathbf x=\mathbf a+u(\mathbf b-\mathbf a)+v(\mathbf c-\mathbf a).
\]

### 27.2 双向点集距离

\[
D_{out\to gt}=
\frac1N\sum_{x\in S_{out}}
\min_{y\in S_{gt}}\|x-y\|^2,
\]

\[
D_{gt\to out}=
\frac1N\sum_{y\in S_{gt}}
\min_{x\in S_{out}}\|y-x\|^2.
\]

\[
CD=D_{out\to gt}+D_{gt\to out},
\]

\[
RMSE_{sym}=\sqrt{CD/2}.
\]

它是“采样点到采样点”的最近邻距离，不是精确点到连续三角面的距离。

| `solveScreenedCsf` | 网格、raw curvature、alpha | 每顶点 `csf_curvature` + 求解统计 |
| `targetFaceCurvatureLengths` | 网格、CSF 曲率、目标面数、平均边长 | target h、lambda、理论面数、h 上下界 |
| `TargetLengthField::build` | 支撑网格、顶点 h | AABB 支撑的连续查询场 |
| `TargetLengthField::valueAt` | 三维位置 | 最近表面点重心插值 h |
| `splitLongEdges` | 当前网格、固定 h(x) | 拆分网格、split 数 |
| `collapseShortEdges` | 当前网格、固定 h(x) | 坍缩网格、collapse 数 |
| `flipEdges` | 当前网格、固定 h(x) | 翻转网格、flip 数 |
| `relocateVertices` | 当前网格、原输入参考网格 | 切向平滑/可选 MLS 后网格 |
| `areaSampledChamferDistance` | 输出网格、GT、采样数 | 双向 MSD、CD、symmetric RMSE |

### 28.2 系统主链

\[
(V,F)
\xrightarrow{\text{raw curvature}}
\mathbf r
\xrightarrow{(M+\alpha\bar\ell^2L)^{-1}M}
\boldsymbol\kappa
\xrightarrow{\operatorname{clamp}(\lambda_h/\sqrt\kappa)}
\mathbf h
\xrightarrow{\text{surface barycentric}}
h(\mathbf x)
\xrightarrow{\text{remesh}}
(V',F').
\]

其中 `\lambda_h` 通过：

\[
\sum_f
\frac{A_f}
{(\sqrt3/4)[(h_i+h_j+h_k)/3]^2}
=N_*
\]

的单调二分近似确定。

## 29. 失败条件与边界行为

### 29.1 直接报错

- 不支持的输入/输出扩展名；
- binary PLY；
- 越界面索引；
- 清理后空网格或无有效边；
- `csf_alpha<=0` 或非有限；
- CSF 邻接为空、顶点质量非正；
- CSF 稀疏分解/求解失败；
- CSF 缩放残差大于 `1e-10`；
- 目标面数为 0；
- 曲率、目标边长或中间量非有限；
- collapse feature omega 为负或非有限。

### 29.2 特殊行为

- `--iters 0`：仍完整构建 raw curvature、CSF 和 target h，但不做全局重网格；
- target faces 超出 `[N_coarse,N_dense]`：不报错，返回全 `h_max` 或全 `h_min`，且不提供不可达标志；
- 边界点不能成为 collapse 边端点，且重定位时被固定为 Corner；
- 边界边可以 split；
- 目标场只构建一次，即使输出拓扑和平均边长已经明显变化也不更新；
- `--quiet` 会隐藏唯一包含 lambda 与 estimated faces 的日志。

### 29.3 不保证

- 最终离散面数等于 `target_faces`；
- 固定迭代结束后所有边都进入 `[0.8,f_s]`；
- target h 的相邻梯度有硬上界；
- 输入网格封闭、整体流形、无自交或可定向；
- 特征保持达到 CAD 约束级精度。

## 30. 复杂度

设支撑网格有 `n` 点、`m` 面、`e` 边，当前输出边数为 `e_t`。

| 阶段 | 典型复杂度/瓶颈 |
|---|---|
| 原始曲率 | 邻接、面积、余切扫描，约 `O(n+m+e)` |
| screened CSF | 装配 `O(n+e)`；主要成本是稀疏 LDLT |
| lambda 二分 | 每次生成 n 个 h 并扫描 m 个面，固定约 `O(64(n+m))` |
| AABB 场查询 | 通常近似对数级，依赖几何分布 |
| split/collapse/flip | 每 pass 重建拓扑映射并扫描当前边，随 `e_t` 和 pass 数增长 |
| MLS | 每点每轮做 kNN，最多约 `5n_t` 次查询 |
| Chamfer | 两边各 N 个采样点和最近邻查询，默认 N=100000 |

目标场只构建一次，因此稀疏 CSF 和 64 次 lambda 二分不随全局迭代数重复。

## 31. v2.10.0 相对前后版本的定位

### 31.1 相对 v2.8.x/v2.9.0

v2.10.0 的关键变化是：

- 删除手动 `mesh_scale`；
- 删除百分位归一化的目标尺寸映射；
- 删除可调 `target_min_factor`、`target_max_factor` 和 `target_size_gamma`；
- 改为 `h=clamp(lambda/sqrt(CSF curvature),0.05·lbar,5·lbar)`；
- 用目标面数理论模型自动二分全局 `lambda`；
- 默认目标面数等于清理后的输入面数。

它把“用户指定全局尺度”改成“用户指定理论目标复杂度”。

### 31.2 相对 v2.11.x

v2.10.0 仍使用 robust mean/normal-angle 曲率和单阶段 `lambda/sqrt(kappa)` 标定。它没有后续的主曲率估计、异常曲率稳健化、独立渐变限制和更完整的面预算诊断。

因此不能用 v2.11.x 的 `initial_h → limited_h → target_h` 三阶段解释 v2.10.0；v2.10.0 从 CSF 曲率到最终 h 是在同一个 lambda 二分函数中一次完成的。

## 33. 如何阅读一次 v2.10.0 结果

建议顺序：

1. 看 `csf_solver_success` 和 scaled residual，先确认稀疏求解有效。
2. 对比 `raw_curvature` 与 `csf_curvature` 热图，确认平滑是否保留主要高曲率结构。
3. 查看 `target_h_heat.ply` 和 `vertices.csv`，确认高曲率是否对应小 h。
4. 查看 `field_stats.json` 的 max/P95/P99 edge target ratio 和 grad h，判断目标场是否存在剧烈局部变化。
5. 查看每轮 split/collapse 数和最终边长 violation，判断 remesher 是否能跟上该尺寸场。
6. 查看最终输出面数与目标面数的差距；不要把理论 `target_faces` 当成硬面数约束。
7. 最后结合 Qavg、Qmin 与 CD 判断各向同性质量和几何保真。

由于 summary 缺少 lambda 和 estimated faces，若需要审计目标面数二分结果，不能使用 `--quiet`，或需要修改代码/脚本额外捕获 verbose 日志。

## 34. 最终方案总结

v2.10.0 包含两个主要子系统。

第一部分是目标场构建：

\[
\text{输入网格}
\to
\text{raw curvature}
\to
\text{screened CSF}
\to
\frac{\lambda_h}{\sqrt\kappa}
\to
\text{目标面数二分}
\to
h(\mathbf x).
\]

第二部分是固定目标场驱动的重网格：

\[
h(\mathbf x)
\to
\text{split}
\to
\text{collapse}
\to
\text{flip}
\to
\text{tangent/MLS relocation}
\to
(V',F').
\]

输入是三角表面网格、曲率/CSF参数、理论目标面数和重网格参数；核心中间输出是定义在输入表面上的连续目标边长场；最终输出是新的三角网格、迭代质量统计、可选场诊断和可选 Chamfer Distance。

v2.10.0 最核心的数学设计是：

\[
h_i=\operatorname{clamp}
\left(\frac{\lambda_h}{\sqrt{\kappa_i^{safe}}},h_{min},h_{max}\right),
\]

并用：

\[
\widehat N=
\sum_f\frac{A_f}{(\sqrt3/4)h_f^2}
\]

反求 `\lambda_h`。这一设计把 CSF 曲率变成局部相对密度，把 `target_faces` 变成全局密度预算；但理论面预算与离散 remesher 最终面数之间仍存在模型和操作层面的差异。
