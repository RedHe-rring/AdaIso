# v2.8.0 hmin-CD 实验报告：T21/T30

## 实验目的

本实验用于判断 v2.8.0 饱和尺寸场中降低 `hmin`，即降低 `--target-min-factor`，是否会让 T21 和 T30 的 Chamfer Distance 下降。本文把“CD 提高”定义为几何精度提高，即 `chamfer_distance` 下降；表格同时保留 CD 数值变化方向。

只改变 `target_min_factor`，其余参数固定：`iters=10`、`preprocess=0`、`project=1`、`curvature-mode=robust-mean`、`csf-alpha=2.0`、`target-max-factor=1.8`、`target-size-gamma=2.0`、`cd-samples=100000`。

实验输出目录：`cpp_adaiso/results/v2.8.0_hmin_cd_T21_T30/`

汇总 CSV：`cpp_adaiso/results/v2.8.0_hmin_cd_T21_T30/run_summary.csv`

## 判定标准

- 以每个模型的 `hmin=0.60` 作为基线。
- `chamfer_distance` 下降超过 5% 判定为明显改善。
- `chamfer_distance` 变化在 ±5% 内判定为变化不显著。
- `chamfer_distance` 上升超过 5% 判定为变差。
- 若改善伴随 `qmin < 0.10`、`violation_rate > 0.06` 或 `max_edge_target_ratio > 2.5`，标记为高质量风险。

## 当前方案暴露的问题

1. 默认 `hmin=0.60` 对部分高曲率细节偏粗。T21 在 `hmin=0.30` 时 CD 相对基线下降 `52.24%`，说明默认尺寸下限会限制高曲率区域采样，导致细节保留不足。

2. 全局降低 `hmin` 不是稳定解法。T30 在 `hmin=0.45` 时 CD 反而上升 `6.78%`，`hmin=0.30` 也没有达到明显改善，只有 `hmin=0.20` 小幅改善 `5.86%`。这说明当前方案不能保证把新增点稳定分配到真正降低 CD 的区域。

3. 尺寸场跳变随 `hmin` 降低明显增大。T30 的 `max_edge_target_ratio` 从 `1.979111` 增至 `3.232361`，说明扩大 `hmax/hmin` 区间后目标边长场过渡更陡，局部 remesh 操作更容易面对不连续或过强的尺寸约束。

4. CD 改善依赖更高网格密度，代价不小。T21 从 `5488/10976` 增至 `8288/16575` 时 CD 最优；T30 从 `8280/16555` 增至 `18736/37467` 才得到小幅 CD 改善。这更像是用大量增密换几何误差，而不是当前映射本身已经可靠地区分了该细化和不该细化的位置。

5. 主要问题来自曲率到尺寸场的响应和尺寸场使用，而不是 hmin 改变了曲率场。raw/CSF 曲率在不同 hmin 组之间完全一致，因此问题集中在 `target_h` 映射、尺寸场梯度控制和 remesh 质量保护上。

## 当前 min-max 饱和映射的缺点

当前 v2.8.0 使用全局最小/最大曲率做归一化：

```text
t = (k - k_min) / (k_max - k_min)
h = h_min + (h_max - h_min) * (1 - t)^gamma
```

这比 v2.7.0 的线性映射更偏向保护高曲率区域，但从本实验看仍有几个明显缺点：

1. 对极端曲率值敏感。少数极高或极低曲率点会拉大 `k_max - k_min`，压缩大部分普通特征区域的 `t` 分布，使得中高曲率区域未必获得足够小的目标尺寸。

2. 不能控制细化区域比例。降低 `hmin` 后，新增细化区域完全由曲率绝对范围决定，而不是由“最高多少比例的可靠特征区域”决定。因此 T21 能明显受益，但 T30 在 `hmin=0.45/0.30` 下并没有稳定改善。

3. 跨模型稳定性不足。不同模型的曲率绝对值分布、极值和噪声水平不同，同一组 `target_min_factor`、`target_max_factor`、`gamma` 不一定产生可比较的尺寸响应。这解释了 T21 和 T30 对降低 hmin 的反应差异。

4. 缺少曲率绝对强度与相对排名的互补。当前方法只看绝对 min-max 归一化，不利用分位数/rank 信息；而纯分位数又会丢掉曲率绝对强度。更稳的方案应考虑 robust percentile clipping 或绝对曲率归一化与分位数归一化的混合。

5. 映射本身不约束尺寸场梯度。饱和函数只能改变曲率到尺寸的响应形状，不能保证相邻顶点的 `target_h` 比例受控。T30 在 `hmin=0.20` 下 `max_edge_target_ratio=3.232361`，说明当前映射仍会产生过陡尺寸过渡。

6. 容易把 CD 改善变成单纯增密。当前方案降低 CD 的主要方式是压低 hmin、增加顶点数，但缺少 feature-aware 选择性约束和质量保护，因此不能证明新增采样都集中在最有效的几何细节处。

## 总体结论

T21 和 T30 都至少有一个更低 hmin 组 CD 明显下降，因此降低 hmin 对几何误差有帮助，但收益不稳定，并且会带来尺寸场跳变、网格密度增加和局部质量风险。

因此，后续不应只继续降低 `target_min_factor`。更合理的改进方向是：引入 feature-aware 的局部尺寸控制、恢复或重设尺寸场 gradation 约束，并在 split/collapse/flip 中加入更明确的局部质量保护。否则 v2.8.0 容易停留在“用更多点换更低 CD”的状态，难以同时保证 CD、网格质量和尺寸场平稳性。
