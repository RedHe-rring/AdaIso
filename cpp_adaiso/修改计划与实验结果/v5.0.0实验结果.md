## CD 尺度说明

本报告中的 `CD` 和 `symmetric RMSE` 是未归一化的绝对坐标尺度指标。当前实现按面积采样计算双向最近点平方距离，并令 `chamfer_distance = output_to_gt_msd + gt_to_output_msd`、`symmetric_rmse = sqrt(0.5 * chamfer_distance)`；没有除以包围盒、平均边长或表面积尺度。

因此不同系列之间的 CD 不宜直接横向比较。模型坐标整体放大 `k` 倍时，`symmetric RMSE` 约放大 `k` 倍，`CD` 约放大 `k^2` 倍。本次结果中 T 系列的 `base_length` 多在 0.008-0.030，而 C/model 系列常在 0.2-3.0，C/model 的绝对 CD 显著大于 T 系列主要受模型尺度差异影响，并不必然表示重网格质量更差。

后续若要跨系列比较几何误差，建议补充归一化指标，例如 `symmetric_rmse / base_length` 和 `chamfer_distance / (base_length^2)`，或使用包围盒对角线归一化后的 RMSE/CD。

## 可视化输出

`target_field/` 中的 PLY 文件可直接用于查看 raw curvature、CSF curvature、target_h 和 observed target_h 的热力图；CSV 文件保存顶点、边、面级诊断数据。

### 新增最终网格尺寸场诊断

当前代码在重新运行 `--export-target-field` 时，会在 `target_field/` 下额外导出最终输出网格上的目标尺寸场采样和边长比例可视化。PLY 文件使用顶点颜色，可直接在 MeshLab、ParaView 或 CloudCompare 中打开。

| 文件 | 色标/数值 | 含义 | 用途 |
|---|---|---|---|
| `output_target_h_samebar.ply` | 与 `target_h_heat.ply` 相同的理论目标长度色标 `[h_min, h_max]`，并使用 inverted heat 映射 | 在最终输出模型顶点位置采样目标尺寸场 `h` 后着色 | 与原始 `target_h_heat.ply` 做公平颜色对比，观察最终网格落在目标尺寸场的哪些区域 |
| `target_h_heat_observed.ply` | 使用目标场实际观测范围 `[observed_h_min, observed_h_max]` | 原始目标场自身的高对比度版本 | 更容易看目标场内部细节，但不适合与 `output_target_h_samebar.ply` 严格同色标比较 |
| `output_edge_ratio_min_heat.ply` | ratio 色标固定为 `[0.8, 1.65]` | 每个顶点取所有邻接边中最小的 `edge_length / min(h_i, h_j)` | 查找过短边区域；偏蓝表示局部存在短于 collapse 阈值的边 |
| `output_edge_ratio_max_heat.ply` | ratio 色标固定为 `[0.8, 1.65]` | 每个顶点取所有邻接边中最大的 `edge_length / min(h_i, h_j)` | 查找过长边区域；偏黄/红表示局部存在接近或超过 split 阈值的边 |
| `output_edge_ratios.csv` | 每条边一行 | 保存 `edge_length,target_i,target_j,target_min,target_max,ratio` | 精确定位哪条边超出目标尺寸范围 |
| `output_visualization_stats.json` | JSON 统计 | 保存上述可视化的色标范围、ratio 分布和 violation rate | 与 `summary.json` 中末轮 ratio 指标互相核对 |

其中 ratio 定义为：

```text
ratio(e) = edge_length(e) / min(target_h(a), target_h(b))
```

当前 `code` variant 的合法区间是 `[0.8, 1.65]`。`ratio < 0.8` 表示边偏短，理论上应触发 collapse；`ratio > 1.65` 表示边偏长，理论上应触发 split。由于 PLY 顶点颜色不能直接给边着色，`output_edge_ratio_min_heat.ply` 和 `output_edge_ratio_max_heat.ply` 都是把边 ratio 聚合到其端点顶点上。
