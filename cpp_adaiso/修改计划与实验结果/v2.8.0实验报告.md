# v2.8.0 实验报告：饱和尺寸场映射 T 系列 iter10

## 实验目的

v2.8.0 将 v2.7.0 的线性曲率到尺寸映射改为饱和幂函数：

```text
h = h_min + (h_max - h_min) * (1 - t)^gamma
t = (k - k_min) / (k_max - k_min)
```

默认参数为：

| 参数 | 值 |
|---|---:|
| curvature_mode | robust-mean |
| csf_alpha | 2.0 |
| target_min_factor | 0.6 |
| target_max_factor | 1.8 |
| target_size_gamma | 2.0 |
| iters | 10 |
| preprocess | 0 |
| project | 1 |

本实验对 `cpp_adaiso/examples` 下全部 `T*.off` 模型运行 iter10，并记录 remesh 结果、GT Chamfer Distance、target field 诊断，以及曲率扩散前后可视化文件。重点比较 `T21` 和 `T30` 相对 v2.7.0 默认 iter10 是否改善。

## 总体结论

1. v2.8.0 默认饱和映射在全部 31 个 T 模型上可运行，CSF 求解均成功，所有曲率扩散前后热力图和 target field 诊断均已生成。
2. 与 v2.7.0 默认线性映射相比，T21 和 T30 的 CD/RMSE 均下降，说明饱和映射确实让高曲率区域得到更多保留，几何贴近度提高。
3. 代价也很明确：T21/T30 都输出更多顶点，运行时间增加，Qavg/Qmin 下降，violation、edge target ratio 和 p95 grad_h_norm 上升。
4. T21 的质量退化较严重，尤其 Qmin 降到 `0.137`，后续需要检查局部低质量三角形位置；T30 的质量退化相对可接受，但尺寸场稳定性仍弱于 v2.7.0。
5. v2.8.0 的方向适合“优先降低几何误差/保细节”的目标；如果目标是整体网格质量和边长场平稳性，默认 `gamma=2.0` 还需要配合质量保护、局部 feature 约束或更稳的尺寸场 gradation 控制。
