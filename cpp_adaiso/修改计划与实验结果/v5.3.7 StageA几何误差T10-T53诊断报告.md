# v5.3.7 Stage A 几何误差诊断报告（T10-T53）

## 1. 诊断目的

- 在 `T0-T9` 之外，再取从 `T10` 开始的 10 个 T 系列模型验证 Stage A 几何误差。
- 样本为：`T10, T21, T30, T33, T36, T38, T44, T48, T51, T53`。
- 使用 `--export-all-stage-meshes` 导出每轮 stage mesh。
- 取最后一轮 `size_iter010_after_collapse.ply` 作为 Stage A 结束网格。
- 使用 `adaiso_eval --cd-samples 100000` 计算 Stage A mesh 相对输入网格的 RMSE/CD。

## 4. 判断

- 第二组结果和 `T0-T9` 一致：Stage A 结束时的 RMSE/CD 与 final 输出几乎完全相同。
- 平均 `Stage A - Final RMSE = 0.000001 %bbox`，平均 `Stage A - Final CD = 2.663121E-10`，差异可以视为采样噪声量级。
- Stage B 明显改善质量：平均最小角从 `3.4259` 提到 `5.0395`，`angle<10%` 从 `0.0280` 降到 `0.0170`。
- 因此，v5.3.7 的几何误差代价主要在 Stage A 尺寸场贴合时已经形成，而不是 Stage B 质量修复造成。
- 下一步若要控制 RMSE/CD，应优先考虑 Stage A guarded projection 或 Stage A collapse/split 的 soft geometry guard。
