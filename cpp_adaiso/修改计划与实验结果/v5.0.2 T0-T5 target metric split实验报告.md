# v5.0.2 T0-T5 target metric edge length 实验报告

## 1. 实验目的

本报告更新原 `v5.0.1 T0-T5 target metric split` 报告，用已有 v5.0.1 结果作为对照，评估本次 v5.0.2 修改是否有收益。

v5.0.1 只改变 split 插点位置；v5.0.2 进一步把 split、collapse、collapse-validity 和 flip 新边检查统一改为 target metric edge length 判据：

```text
M_ab = integral_edge ds / h(s)
M_ab = length * (log(h_b) - log(h_a)) / (h_b - h_a)
h_a ~= h_b 时退化为 M_ab = length / h_a

M_ab > splitFactor()    -> split
M_ab < collapseFactor() -> collapse
otherwise              -> keep
```

## 2. 实验设置

- 测试模型：`T0.off` 到 `T5.off`。
- 对照数据：`cpp_adaiso/results/v5.0.1_T0_T5_target_metric_split/T/<model>/summary.json`。
- 当前数据：`cpp_adaiso/results/v5.0.2_T0_T5_target_metric_edge_length/T/<model>/summary.json`。
- 参数一致：`--iters 10 --preprocess 0 --curvature-mode robust-mean --csf-alpha 2.0 --gt <same input> --cd-samples 100000 --export-target-field <case>/target_field --summary-json <case>/summary.json --quiet`。
- 当前构建：`cpp_adaiso/build2/adaiso_cli.exe`；`adaiso_tests.exe` 通过，T0-T5 CLI 全部成功。

注意：v5.0.1 的 summary 中 `mean_ratio/std_ratio/violation_rate` 仍是旧口径 `edge_length / min(endpoint target_h)`；v5.0.2 的同名字段已改为 `target_metric_edge_length`。所以下表的 final violation 是“各自版本判据下的最终 violation”，不是完全同口径的物理量。

## 3. 总体结论

- 综合判定：benefit=6，mixed=0，regression=0。
- 总操作量 split+collapse+flip：61590 -> 56419（-5171，-8.40%）。
- 平均最终 violation：0.022617 -> 0.018746（-0.003871）。
- 平均 qmin：0.028471 -> 0.030885（+0.002415）。
- 平均 CD：1.565e-05 -> 1.574e-05（+0.54%）。

结论：v5.0.2 在 T0-T5 上对“metric 判据一致性、最终 violation、操作次数”有明确收益；但 Chamfer Distance 全部小幅上升，因此不能说它在几何误差上也直接收益。更准确地说，这次修改是数学口径和 remesh 稳定性收益，几何精度需要继续校准阈值。

## 6. 解读

- T0-T5 的最终 violation 全部下降，说明用统一 `M_ab` 做 split/collapse 判据后，算法确实更贴近新的 target metric 目标。
- split 和 collapse 总次数全部下降，说明旧的 min/max endpoint target 判据存在过度触发，v5.0.2 减少了不必要的拓扑操作。
- qmin 在 T0 明显提升，T1/T2 略降或略升，T3-T5 基本不变；最小角除 T0/T2 外变化很小。
- CD 在 6 个模型上都小幅上升，幅度约 0.18% 到 0.96%。这说明“更一致的 metric 判据”不自动等价于“更低几何误差”。
- 后续如果目标是保留 v5.0.2 的数学一致性同时恢复 CD，优先实验方向是重新扫描 `splitFactor/collapseFactor`，因为阈值从旧 ratio 口径迁移到 `M_ab` 后，1.65/0.8 未必仍是最优 hysteresis。
