# v5.3.7 Stage A Collapse 几何误差归因报告

## 1. 诊断目的

- 验证 Stage A 几何误差是否主要由 collapse 造成。
- 使用已有 `T0-T9` 和 `T10-T53` 两组 stage mesh，不重新修改代码。
- 对每轮：
  - `size_iterXXX_after_split.ply`
  - `size_iterXXX_after_collapse.ply`
- 分别计算 RMSE/CD，并统计：
  ```text
  collapse_delta = after_collapse - after_split
  ```

## 5. 判断

- collapse 归因成立：在 200 个 `after_split -> after_collapse` 步骤中，RMSE/CD 增量有 151 次为正。
- 更重要的是，按模型累积后 20/20 个模型的 collapse 总 RMSE 增量都为正。
- collapse 平均每轮减少约 `3732` 个 faces，同时平均提升最小角、降低 `angle<10%`，所以它确实在用几何误差换取尺寸场回收和质量改善。
- split 不是当前几何误差的首要嫌疑；下一版优先约束 collapse 更合理。

## 6. 下一步建议

- v5.3.8 不应先做全局裸投影。
- 更合适的是给 Stage A collapse 增加 soft geometry guard：
  ```text
  accept if target_log_energy decreases
  and local geometry/projection displacement does not exceed tolerance
  and angle safety still holds
  ```
- 如果先做 projection，也应是 guarded projection，并且只在 Stage A 后执行，不能无条件投影。
