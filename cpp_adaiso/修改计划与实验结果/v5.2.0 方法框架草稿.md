# v5.2.0 方法框架草稿：density / constraint / admissibility 三层解耦与算子职责分离

## 1. 核心担心

当前方法如果写成：

```text
尺寸场 + 特征保护 + 质量控制 + 若干参数
```

很容易被理解成工程拼接。尤其是后续如果继续给 collapse、flip、relocation 添加局部规则，审稿人可能会认为这些规则和前面的尺寸场没有统一逻辑，只是在补实验短板。

v5.2.0 需要先把论文主线重新组织清楚：尺寸场不是完整方法，而是 adaptive remeshing 中的 density layer。特征保护和质量控制不是补丁，而是另外两个必要决策层。

建议把方法总框架定义为：

```text
Decoupled Adaptive Isotropic Remeshing
```

或更具体：

```text
Feature-Decoupled Quality-Safe Adaptive Isotropic Remeshing
```

核心思想：

```text
把 adaptive isotropic remeshing 拆成三个相互解耦但协同的决策层：

1. density layer：哪里需要多少采样密度？
2. constraint layer：哪些几何结构不能被操作破坏？
3. admissibility layer：哪些局部操作允许被执行？
```

在具体局部操作上，再进一步采用职责分离：

```text
split / collapse：负责调节采样密度，使边长接近目标尺寸场；
flip / relocation：负责改善连接关系和顶点位置，提高局部单元质量。
```

这样后续 feature 保护和质量控制就不是外加补丁，而是 remeshing 问题本身的不同子问题；局部算子也不是同时混合优化所有目标，而是每类算子有主职责，其他目标只作为操作可接受性的安全约束。

## 2. 三层框架

### 2.1 Density layer：尺寸场

输入：

```text
input mesh M
CSF-smoothed curvature kappa_tilde
input local resolution l_i
```

输出：

```text
target edge length field h(x)
```

当前 v5.1.5 的尺寸场可作为这一层的第一版：

```text
local_delta_i = max(kappa_tilde_i, epsilon_k) * l_i^2 / 6
delta_0 = area_weighted_quantile(local_delta_i, q)
h_i = sqrt(6 * delta_0 / max(kappa_tilde_i, epsilon_k) - 3 * delta_0^2)
h_i = clamp(h_i, h_min_safe, h_max)
```

这一层只回答采样密度问题，不负责保证 hard feature 保留，也不负责保证所有局部三角形质量。

论文表述：

```text
The sizing field specifies the desired sampling density, not the admissibility of local operations.
```

### 2.2 Constraint layer：特征约束

输入：

```text
boundary / crease / corner candidates
feature confidence
patch or feature graph classification
```

输出：

```text
vertex / edge / face operation constraints
```

这一层回答哪些结构不能被随意破坏：

```text
boundary vertices stay on boundary
crease vertices move only along feature curve
corner vertices remain fixed or strongly constrained
feature edges cannot be arbitrarily flipped/collapsed
```

重要的是：hard feature 不应该靠尺寸场间接保护。尺寸场只能让局部更密，不能保证 crease edge 对齐、corner 存在、feature graph 拓扑不变。

论文表述：

```text
Hard features are modeled as operation constraints rather than as high-density regions in the sizing field.
```

### 2.3 Admissibility layer：操作可接受性

输入：

```text
candidate split / collapse / flip / relocate
local target metric
local quality before and after
local constraints
```

输出：

```text
accept / reject / choose best candidate
```

这一层不建议一开始写成复杂加权能量：

```text
E = E_size + lambda_q E_quality + lambda_f E_feature + lambda_p E_projection
```

因为 lambda 难解释，容易被认为是调参系统。

更稳的第一版是字典序或门控式准则：

```text
1. hard validity：不翻折、不退化、不破坏拓扑合法性
2. hard constraints：不破坏 boundary / crease / corner / feature graph
3. quality safety：不制造低于质量底线的坏三角形
4. size objective：改善 target metric violation 或 bad edge count
5. tie-break：在可接受候选中选局部 qmin / min angle / valence 更好的
```

这样参数不是一堆权重，而是少量安全阈值：

```text
qmin_floor
quality_drop_tolerance
size_tolerance
```

论文表述：

```text
Local operations are accepted under topology validity, feature constraints, and quality-safety criteria; the sizing field only defines the target metric.
```

## 3. 算子职责分离

三层框架回答“问题如何分层”，算子职责分离回答“每个局部操作具体承担什么职责”。建议把 v5.2.0 的操作逻辑写成：

```text
density field + role-separated local operators
```

或者更像论文标题的表述：

```text
Role-Separated Adaptive Isotropic Remeshing
```

核心原则是：不让所有局部算子同时优化尺寸、质量、特征和投影误差，而是给不同算子分配主要职责。其他指标不进入复杂加权能量，而作为 admissibility constraints。

### 3.1 Density operators：split / collapse

split 和 collapse 是改变采样点数量的拓扑操作，因此它们的主职责应该是让网格接近尺寸场。

```text
split：当边相对 h(x) 过长时增加采样点，降低 long-edge violation；
collapse：当边相对 h(x) 过短时移除冗余采样点，降低 short-edge violation。
```

这两个操作的 primary objective 是 size conformity：

```text
Primary objective:
    reduce target metric violation / bad edge count

Safety conditions:
    no inverted or degenerate local faces
    no violation of boundary / crease / corner constraints
    no creation of severely low-quality local elements
    no unacceptable increase of projection or geometric error
```

关键是 collapse 不能完全不管质量。否则它虽然能减少短边，却可能制造极小角和局部退化三角形。因此 collapse 应该被描述为“以尺寸场为主目标、以质量和几何合法性为安全约束”的 density operator，而不是单纯的边长操作。

### 3.2 Regularization operators：flip / relocation

flip 和 relocation 不改变采样点数量，因此它们不适合作为主要的尺寸场执行器。它们更适合负责 regularization：

```text
flip：不改变顶点位置和顶点数量，改善局部连接关系、角度分布和 valence；
relocation：不改变拓扑和顶点数量，改善顶点位置、局部三角形形状和投影后的几何贴合。
```

这两个操作的 primary objective 是 quality improvement：

```text
Primary objective:
    improve local qmin / min angle / angle distribution / valence

Safety conditions:
    target metric violation does not worsen beyond tolerance
    feature and boundary constraints are preserved
    projection error does not worsen beyond tolerance
    no inverted or degenerate local faces
```

这样 relocation 就不需要被解释成“另一个尺寸场优化器”。它是质量正则化算子，只是在接受时检查不要破坏尺寸场和几何约束。

### 3.3 论文表述

英文草稿：

```text
We assign different roles to topology-changing and geometry-changing operators.
Split and collapse enforce the density field by adjusting the sampling density,
whereas flip and relocation regularize connectivity and vertex placement.
Other objectives are treated as admissibility constraints rather than being
combined into a weighted energy.
```

中文草稿：

```text
我们不让所有局部算子同时优化所有目标，而是为不同算子分配不同职责：
分裂和塌缩负责调节点/边的采样密度，使其接近目标尺寸场；
翻边和重定位负责在不显著破坏尺寸场的前提下改善连接关系和单元质量。
其他目标不作为加权能量混合进去，而作为操作可接受性的安全约束。
```

这一表述能回应“工程拼接”的担心：尺寸场、特征约束和质量控制不是并列补丁，而是通过局部算子的角色分工连接在同一个 remeshing 框架中。

## 4. 和已有方法的区别

不要把 claim 写成：

```text
我们提出了一个尺寸场，然后加了一些 feature 和 quality 规则。
```

应该写成：

```text
已有方法经常把 adaptive density、feature preservation 和 local operator decisions 混在同一套经验规则里。
我们显式分离 density, constraint, admissibility 三层，使每一层有明确职责。
```

当前方法的潜在贡献可以组织为：

```text
1. Input-resolution-aware CSF sizing field
   不预设目标面数 N，而是从输入网格自身局部分辨率估计自动容差。

2. Role-separated local operator framework
   split/collapse 负责采样密度调节，flip/relocation 负责连接和位置正则化。

3. Feature-decoupled formulation
   soft geometric detail 用 density layer 处理，hard feature 用 constraint layer 处理。

4. Quality-safe operation admissibility
   局部操作必须满足质量安全条件，避免 adaptive sizing 带来低质量三角形。

5. Systematic evaluation
   同时报告 success rate、geometry error、element quality、output scale 和 runtime。
```

其中第 1 和第 2 是方法主线，第 3 和第 4 是必要支撑，第 5 是论文说服力。

## 5. 下一步实现建议

不要立即做完整 feature 系统。先做最能支撑三层框架的最小闭环：

```text
v5.2.0-min:
1. 保留 v5.1.5 density layer
2. 增加 quality-safe admissibility layer
3. 暂时只把 boundary 作为 constraint layer 的最小实现
```

### 5.1 Collapse

collapse 是最容易制造坏角的操作，优先改。

接受准则：

```text
candidate collapse is valid if:
1. no degenerate or inverted adjacent face
2. local qmin_after >= qmin_floor
3. local qmin_after >= local qmin_before - quality_drop_tolerance
4. target metric short-edge objective is not made worse beyond size_tolerance
```

这里不要先做复杂能量，也不要给不同模型调不同参数。

### 5.2 Flip

flip 不应只看 valence。

建议改成：

```text
reject if local qmin clearly decreases
otherwise choose by:
1. lower local target metric violation
2. higher local qmin / min angle
3. better valence
```

### 5.3 Relocation / smoothing

先做 rollback，不做复杂优化：

```text
relocate vertex
if one-ring qmin_after < one-ring qmin_before - tolerance:
    rollback
```

这很容易解释，也能直接针对当前 qmin 短板。

### 5.4 Split

split 暂时不要加太多限制。

原因：

```text
split 通常不是坏角主要来源；
过度限制 split 可能影响 target metric violation 收敛。
```

只保留基本合法性和 feature/boundary 约束即可。

## 6. 验收标准

第一阶段只看 T 系列和高风险模型。

必须保持：

```text
T series success = 31/31
```

主要目标：

```text
avg qmin 上升
min qmin 上升
angle_lt_10_pct 下降
angle_lt_20_pct 下降
```

不能接受：

```text
faces out/in 明显回升到 v5.1.3 以上
RMSE/CD 系统性恶化
violation 明显恶化
```

建议重点模型：

```text
T125
T53
T86
T82
T36
T1
T5
T10
```

这些模型覆盖当前高 violation、低 qmin、面数变化大和误差敏感场景。

## 7. 论文写法草稿

可以这样写方法段开头：

```text
We formulate adaptive isotropic remeshing as three decoupled decisions:
estimating the desired sampling density, preserving hard geometric constraints,
and accepting only quality-safe local operations.
The density layer determines where the mesh should be refined or coarsened,
but it does not encode hard feature topology or element-quality guarantees.
Therefore, we separate feature constraints and operation admissibility from
the construction of the sizing field.
In addition, we assign different roles to local operators: split and collapse
adjust sampling density according to the sizing field, while flip and relocation
regularize connectivity and vertex placement under admissibility constraints.
```

中文版本：

```text
我们将自适应各向同性重网格化分解为三个相互解耦的决策：
目标采样密度估计、硬几何特征约束，以及质量安全的局部操作接受准则。
尺寸场只决定局部应具有怎样的采样密度，
并不负责编码硬特征拓扑，也不能单独保证三角形质量。
因此，本文将特征约束和操作可接受性从尺寸场构建中分离出来。
同时，本文为局部算子分配不同职责：分裂和塌缩根据尺寸场调节采样密度，
翻边和重定位则在可接受性约束下正则化连接关系和顶点位置。
```

## 8. 当前判断

v5.1.5 已经说明 density layer 有效果：T 系列平均面数下降，同时 RMSE/CD/violation 没有系统性恶化。

但和 CWF/CGAL 这类成熟方法比，当前最弱的是 element quality，尤其 qmin 和小角比例。因此 v5.2.0 不应继续只调尺寸场，而应补上 admissibility layer。

如果 v5.2.0 能在不显著增加面数和误差的前提下提高 qmin，那么整个方法就会从：

```text
一个有效的 adaptive sizing heuristic
```

变成：

```text
一个完整的 adaptive remeshing framework
```
