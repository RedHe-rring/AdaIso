# v2.7.0 实验报告：线性曲率尺寸场与 T30 耳朵精度测试

## 实验目的

v2.7.0 将旧的分位排序、对数尺寸映射、target smoothing 和 gradation projection 删除，改为直接从 CSF 后曲率场线性映射到真实目标长度：

```text
h = clamp(h_max - t * (h_max - h_min), h_min, h_max)
t = (k - k_min) / (k_max - k_min)
```

本报告记录 v2.7.0 在线性尺寸场下对 `T30.off` 的测试，重点回答三个问题：

- 线性映射默认参数下，T30 iter10 的整体 remesh 质量如何。
- 降低 `target_min_factor` 到 `0.3` 是否能提升马耳朵区域精度。
- 当弱侧耳朵在 `raw_curvature_heat.ply` 中明显、但在 `csf_curvature_heat.ply` 中变弱时，降低 `csf_alpha` 是否说明 CSF 过平滑是主要问题。

## 代码状态与验证

v2.7.0 当前实现已完成以下清理：

- 删除旧 target 映射逻辑：分位排序、对数长度、`target_gamma`、尺寸场平滑、gradation projection。
- 保留 `robust-mean` 作为默认曲率模式，并保留 CSF 曲率扩散。
- target field 使用真实 `target_h`，`TargetLengthField::valueAt` 对真实长度做三角形 barycentric 插值。
- 诊断输出精简为：
  - `raw_curvature_heat.ply`
  - `csf_curvature_heat.ply`
  - `target_h_heat.ply`
  - `vertices.csv`
  - `edges.csv`
  - `faces.csv`
  - `field_stats.json`

## 实验 3：左右耳 target_h 不对称分析

在同一代理区域内按 `y` 中位数分成两侧：

```text
ymid = -0.214569
lower_y / higher_y 分别近似表示两侧耳朵区域
```

`hmin=0.3, csf_alpha=2.0` 下统计：

| 区域 | raw_curvature median | csf_curvature median | target_h median |
|---|---:|---:|---:|
| lower_y | 0.5435459203 | 0.5388769979 | 0.0155234617 |
| higher_y | 0.4371697650 | 0.4590800873 | 0.0182527830 |

观察：

- 两侧在 raw curvature 中已经存在差异，弱侧 median raw curvature 更低。
- CSF 后弱侧曲率仍更低，因此线性映射得到更大的 `target_h`。
- 降低 `hmin` 会让两侧整体变细，但不会消除两侧 target_h 的相对差异。

结论：

- 当前现象说明曲率场或曲率到尺寸场的响应仍不够可靠。
- 仅设置更小 `hmin` 可以提升局部密度，但不能保证两侧耳朵对称地获得足够精度。

观察：

- `alpha=0.5` 确实减弱了 CSF 扩散，曲率场保留了更尖的局部变化。
- 但尺寸场的相邻跳变显著增加，`max_edge_target_ratio` 从 `1.81` 上升到 `3.15`，`max_grad_h_norm` 从 `0.77` 上升到 `2.03`。
- 最终 remesh 质量下降，`Qavg`、`Qmin`、CD 和 violation 都变差。
- 耳朵代理区域输出顶点数没有增加，反而从 91 降到 79。
- 弱侧耳朵的 `target_h` median 从 `0.01825` 变为 `0.01952`，反而更粗。

原因分析：

- v2.7.0 当前线性映射使用全局 `k_min/k_max` 归一化。
- 降低 `csf_alpha` 会保留更尖的全局峰值，使全局曲率范围变宽。
- 在全局 min/max 被尖峰拉开后，耳朵区域即使局部 CSF 值有变化，其归一化位置也可能下降，最终得到更大的 `target_h`。
- 因此，`alpha=0.5` 证明 CSF 过平滑确实可能参与弱化耳朵信号，但它不是单独调参即可解决的主因。

## 总体结论

1. v2.7.0 的线性尺寸场实现是可运行的，构建、测试、诊断导出和 T30 remesh 均通过。
2. 降低 `target_min_factor` 到 `0.3` 可以提升耳朵/头部代理区域的局部密度，说明仅从 `hmin` 角度可以改善一部分细节。
3. 两侧耳朵精度不一致，主要来自曲率场和全局线性映射共同造成的 target_h 不对称，而不是单纯的 `hmin` 太大。
4. 将 `csf_alpha` 降到 `0.5` 不适合作为当前默认方案：它使尺寸场跳变过大，并导致网格质量和 CD 下降。
5. 当前更合理的后续方向不是继续盲目降低 `hmin` 或 `csf_alpha`，而是改进曲率到尺寸的归一化方式，或者加入 feature-aware 约束。

## 后续建议

优先建议做两组小实验：

- `--csf-alpha 1.0 --target-min-factor 0.3`：判断中等扩散是否能在保留耳朵信号和控制尺寸场跳变之间取得更好平衡。
- 保持线性映射形式，但对曲率归一化范围做 robust clamp，例如使用 p1/p99 或 p5/p95 截断后再线性映射。这样不是回到旧的分位排序尺寸映射，而是避免少量尖峰支配全局 `k_min/k_max`。

如果后续可视化仍显示耳朵边界被 remesh 操作抹平，则应进入 feature-aware remeshing：

- 识别高 dihedral feature edge。
- split 后继承 feature 标记。
- collapse / flip 禁止破坏 feature 拓扑。
- tangent smoothing 和 MLS projection 增加 feature-aware 约束。
