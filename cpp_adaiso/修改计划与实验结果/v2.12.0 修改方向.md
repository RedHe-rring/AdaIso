# v2.12.0 修改方向

## 目标

v2.12.0 的目标不是再增加一个实验分支，而是把目前表现最好的模块收敛成一条干净的默认管线：

```text
v2.10.0 target_faces inverse-sqrt 尺寸场主干
+ v2.8.3 feature-aware 局部算子
+ v2.5.0 温和尺寸场稳定化思想
+ v2.7/v2.8.0 的质量保护策略
```

核心评价目标按优先级排列为：

1. 保留 v2.10.0 的 CD/RMSE 优势。
2. 修复 v2.10.0 的 Qmin 过低问题。
3. 保持 v2.10.0 的低 violation 和低 target_h 梯度。
4. 保留 v2.8.3 对特征塌缩的保护。
5. 清理旧实验入口，形成可维护的单一路径实现。

## 当前版本对比结论

| 版本 | 主要优势 | 主要问题 | v2.12.0 是否吸收 |
|---|---|---|---|
| v2.5.0 | log-domain 尺寸场稳定、目标边长跟踪好 | 高曲率细节响应不够强 | 吸收温和稳定化思想，不恢复完整旧管线 |
| v2.7.0 | 线性尺寸映射温和，局部质量好 | 细节保留偏弱 | 吸收质量保护策略 |
| v2.8.0 | 全 T 平均 Qavg/Qmin 最好 | CD 不如 v2.10.0 | 吸收保守局部操作门槛 |
| v2.8.3 | feature-aware collapse 改善特征保留和 CD | 平均 Qavg 略降，仍是多改动混合 | 保留 feature-aware collapse 的核心逻辑 |
| v2.10.0 | 平均 CD、RMSE、violation、尺寸场梯度最好 | Qmin 明显偏低 | 作为 v2.12.0 主干 |

## 默认算法方向

### 1. 曲率场

默认只保留一条曲率路径：

```text
raw curvature -> screened Laplacian smoothing -> diffused curvature
```

raw curvature 使用当前 v2.10/v2.11 方向中的稳健曲率实现。v2.12.0 不再通过 CLI 暴露 `normal-angle` 等旧曲率模式；如果保留旧实现，只能作为单元测试辅助或内部对照，不进入生产路径。

需要新增或固定的防失稳策略：

- 对 raw curvature 做有限性检查。
- 对极端曲率尖峰做温和 cap，优先考虑 p99.5 或局部 sampling cap。
- cap 发生比例写入 summary，但不输出整套热图诊断。

### 2. 尺寸映射

保留 v2.10.0 主公式：

```text
h_i = lambda / sqrt(kappa_i)
```

`lambda` 继续由 `target_faces` 二分校准。默认 `target_faces` 为清理后输入面数。

不采用 v2.11.1 的强硬 gradation limiter 作为默认。原因是已有实验显示：输入尺寸场满足硬 gradation 不等价于最终 remesh 质量提升，且 T21/T36 会失稳。

v2.12.0 的稳定化方向应放在 inverse-sqrt 之前或之后的温和处理：

- 曲率 cap：限制极少数不可靠峰值支配 `lambda`。
- log-domain 轻量 smoothing：只平滑异常尖峰，不把高曲率细节整体抹平。
- 保留 `h_min = 0.05 * mean_edge`、`h_max = 5.0 * mean_edge` 这类固定边界，避免继续增加 hmax/hmin 实验入口。

### 3. 局部 remeshing

局部算子以 v2.8.3/v2.10.0 的组合为默认：

- split：按 target edge ratio 保持当前策略。
- collapse：保留 feature-aware placement，避免强特征顶点被平均到中点。
- collapse validity：保留局部质量门槛，重点提高 v2.10.0 的 Qmin。
- flip：保留二面角上限和 obtuse protection，避免为了 valence 改善破坏特征。
- smoothing：只移动 smooth 顶点，feature/corner 顶点不参与普通切向平滑。
- projection：默认不启用 relocation 内部 MLS；若保留最终 projection，必须有 Qmin 保护。

### 4. 清理原则

v2.12.0 应该是收敛后的实现，不再保留旧版本实验矩阵。

需要删除或隐藏：

- 旧版本算法切换入口。
- 不作为默认路径使用的曲率模式入口。
- 大量中间 PLY/CSV 诊断导出。
- 只服务某次实验报告的统计字段和参数。
- 不再使用的 enum、函数、配置项和 CLI 参数。

保留：

- `--target-faces`
- `--iters`
- `--gt`
- `--cd-samples`
- `--summary-json`
- `--quiet`

是否保留 `--csf-alpha` 需要谨慎。若 v2.12.0 目标是干净默认版本，应先固定为内部常量 `2.0`；如果实验仍需要 alpha 消融，可以通过测试或单独实验脚本注入，而不是公开 CLI 默认入口。

## 验收标准

以全 T 31 模型 iter10 为主验收集。

最低验收：

- 平均 CD 不高于 v2.10.0 的 `1.3061e-05` 超过 5%。
- 平均 violation 不高于 v2.10.0 的 `0.02334` 超过 20%。
- 最低 Qmin 明显高于 v2.10.0 的 `0.00360`，目标至少达到 `0.02`。
- T21/T36 不出现 v2.11.1 式失稳。

理想验收：

- 平均 CD 接近 v2.10.0。
- 平均 Qmin 向 v2.8.0 靠近。
- 最低 Qmin 达到或超过 v2.8.3 feature-on 的 `0.129`。
- 平均 runtime 不明显慢于 v2.10.0。

## 预期风险

1. feature-aware collapse 可能提高 Qmin，但也可能减少有效贴合，导致 CD 回升。
2. 曲率 cap 可能修复 T21/T36，但过强会削弱 v2.10.0 的细节优势。
3. 质量门槛如果过严，collapse 数减少，输出面数可能上升。
4. 删除诊断入口会降低调试便利性，因此必须用 summary 和单元测试覆盖关键统计。

## 推荐实验顺序

1. 先在当前 v2.10.0 主干上接入 v2.8.3 feature-aware collapse 和质量门槛。
2. 跑 T21、T30、T36、T44、T87、T124 小集合。
3. 若 Qmin 改善且 CD 未明显退化，再跑全 T。
4. 再加入曲率 cap，重复小集合和全 T。
5. 最后才考虑 log-domain 轻量 smoothing。
