# v5.0.1 T0-T5 target metric split 实验报告

## 1. 实验目的

本实验验证 v5.0.1 中的非均匀 split 修改是否相对 v5.0.0 有收益。

v5.0.1 的主要变化是：主 remesh 循环中的 split 新点不再固定取几何中点，而是按 target metric 中点放置：

```text
t = sqrt(h_a) / (sqrt(h_a) + sqrt(h_b)), clamped to [0.25, 0.75]
p_m = (1 - t) p_a + t p_b
```

预处理 `subRemesh()` 仍保持中点 split。

## 2. 实验设置

测试模型：`T0.off` 到 `T5.off`。

v5.0.0 基线读取已有结果：

```text
cpp_adaiso/results/v5.0.0_all_series/T/T*/summary.json
```

v5.0.1 当前实现重新运行，结果写入：

```text
cpp_adaiso/results/v5.0.1_T0_T5_target_metric_split/
```

运行参数与 v5.0.0 基线保持一致：

```text
--iters 10
--preprocess 0
--curvature-mode robust-mean
--csf-alpha 2.0
--gt <same input model>
--cd-samples 100000
--export-target-field <case>/target_field
--summary-json <case>/summary.json
--quiet
```

对比输出：

```text
cpp_adaiso/results/v5.0.1_T0_T5_target_metric_split/comparison.csv
cpp_adaiso/results/v5.0.1_T0_T5_target_metric_split/comparison.md
```

## 3. 指标定义

- split 总次数：10 轮 `split_count` 求和。
- collapse 总次数：10 轮 `collapse_count` 求和。
- 每轮 violation rate：summary 中每轮 `violation_rate`。
- 最终面数：`output_summary.faces`。
- edge_length / target 均值：最终一轮 `mean_ratio`。
- edge_length / target 方差：最终一轮 `std_ratio ** 2`。
- 最小三角形质量：`output_summary.qmin`。
- 最小角：从最终 `output.ply` 重新计算所有三角形内角的全局最小值，单位为度。

收益判断：

- split/collapse 总次数更少视为收益。
- 最终 violation rate 更低视为收益。
- edge ratio 方差更低视为收益。
- qmin 和最小角更高视为收益。
- 最终面数更接近 target_faces 视为收益。
- 若质量改善但 violation 或面数明显变差，判为 mixed。

## 6. 结论

整体看，v5.0.1 的 target metric split 在 T0-T5 上表现为局部收益，不是单调全面提升。

- 明确收益：T0、T2、T4。
- 混合结果：T1、T3、T5。
- 操作次数方面，除 T2 外，v5.0.1 都减少了 split 总次数；除 T2 外，也减少了 collapse 总次数。
- 最终 violation 方面，T0、T1、T2、T4 下降，T3、T5 上升。
- edge ratio 方差方面，T0、T2、T3、T4 下降，T1、T5 上升。
- 最小质量和最小角整体变化很小；T0 有最明显的质量与角度提升。

因此，非均匀 split 对部分模型确实能减少操作次数并略微改善 target ratio 分布，但当前公式还可能改变后续 collapse/relocation 的收敛路径，导致 T3/T5 最终 violation 变差。后续如果继续优化，建议重点分析 T3/T5 中非均匀 split 后的局部边长分布和后续 collapse 选择变化。
