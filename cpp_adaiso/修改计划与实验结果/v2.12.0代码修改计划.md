# v2.12.0 代码修改计划

## 原则

v2.12.0 代码目标是干净、单路径、可测试。不要为了保留历史实验能力继续增加分支。

具体原则：

- 默认实现只保留一个算法路径。
- 实验分支不通过 CLI 暴露。
- 旧版本对照函数、参数入口、诊断导出在 v2.12.0 中删除。
- 模块边界按职责拆分，避免 `AdaIsoRemesher.cpp` 继续堆积所有逻辑。
- 每个保留参数都必须服务默认算法或验收评估。

## 目标模块结构

建议形成以下模块：

```text
include/adaiso/
  AdaIsoRemesher.hpp
  TargetSizingOptions.hpp        # 若仍需要公开少量 sizing 常量，否则删除
  detail/
    RawCurvature.hpp
    ScreenedLaplacian.hpp
    TargetFaceSizing.hpp
    FeatureClassification.hpp
    LocalOperators.hpp

src/
  AdaIsoRemesher.cpp             # 只保留流程编排
  RawCurvature.cpp
  ScreenedLaplacian.cpp
  TargetFaceSizing.cpp
  FeatureClassification.cpp
  LocalOperators.cpp
  main.cpp
```

`AdaIsoRemesher.cpp` 的目标是只负责：

1. 输入清理。
2. 构建 target field。
3. 调用 split/collapse/flip/smooth。
4. 收集 summary stats。

不应继续承载大量 feature strength、diagnostic writer、local operator 细节。

## 第 1 步：冻结当前默认路径

当前已提交快照：`48fd637 Snapshot current v2.11.x implementation`。

v2.12.0 从该提交之后开始，不再回填旧版本兼容。

默认路径固定为：

```text
raw curvature
-> screened Laplacian
-> target_faces inverse-sqrt
-> surface barycentric target lookup
-> split/collapse/flip/smooth
-> optional final evaluation
```

## 当前代码盘点与 v2.12.0 真正差异

当前提交 `48fd637` 之后的代码已经不是纯 v2.10.0。它已经混入了一部分 v2.8.3/v2.11.x 能力。因此 v2.12.0 的工作不能理解为“把 v2.8.3 feature-aware 局部算子重新实现一遍”，而应理解为：

```text
把当前已经混合进来的有效能力收敛成一条干净默认路径，
删除不再需要的实验入口和诊断代码，
再补上当前还没有的曲率/尺寸场稳健化。
```

### 当前代码已经具备的能力

| 能力 | 当前代码状态 | 位置 | v2.12.0 处理 |
|---|---|---|---|
| v2.10.0 target_faces inverse-sqrt | 已有 | `TargetFaceSizing.cpp::targetFaceCurvatureLengths` | 保留为尺寸映射主干 |
| target_faces lambda 二分 | 已有 | `TargetFaceSizing.cpp` | 保留，二分次数固定内部常量 |
| surface barycentric target lookup | 已有 | `TargetLengthField` | 保留 |
| feature strength 计算 | 已有 | `AdaIsoRemesher.cpp::computeVertexFeatureStrengths` | 抽到 `FeatureClassification` |
| feature-aware collapse point | 已有 | `AdaIsoRemesher::collapsePoint` | 保留为默认，删除开关 |
| collapse 后局部质量门槛 | 已有 | `AdaIsoRemesher::collapseValid` | 保留，必要时调高默认值 |
| flip 二面角约束 | 已有 | `AdaIsoRemesher::flipEdges` | 保留，删除 CLI 参数入口 |
| obtuse flip 保护 | 已有 | `AdaIsoRemesher::flipEdges` | 保留为固定策略 |
| feature/corner/smooth relocation 分类 | 已有 | `classifyVerticesForRelocation` | 抽到 `FeatureClassification` |

| `Variant`/paper-code 入口 | 已有 | `Variant`, `--variant` | 删除，固定当前 code 行为 |

### 当前代码还缺的 v2.12.0 能力

| 能力 | 当前状态 | v2.12.0 是否实现 | 说明 |
|---|---|---|---|
| 曲率尖峰 cap | 缺失 | 是 | 先在 target sizing 前做 quantile cap，写入 summary |
| inverse-sqrt 后 log-domain 轻量 smoothing | 缺失 | 候选实现 | 只抑制孤立异常小尺寸源，不恢复 v2.5 完整 gradation |
| smoothing 后 target_faces 全局 rescale | 缺失 | 与 log smoothing 同步实现 | 保持目标面数语义 |
| 干净模块边界 | 缺失 | 是 | `AdaIsoRemesher.cpp` 当前过大，需要拆分 |
| 精简 CLI/public config | 缺失 | 是 | 当前仍暴露历史实验开关 |
| 针对 feature-aware collapse 的单元测试 | 不足 | 是 | 当前有实现，但缺稳定测试边界 |

### 真正的 v2.12.0 代码差异

因此，v2.12.0 的代码差异应是：

1. **不是新增 feature-aware collapse**：当前已经有；v2.12.0 要把它变成不可关闭的默认行为，并把实现移出 `AdaIsoRemesher.cpp`。
2. **不是新增 v2.10.0 target sizing**：当前已经有；v2.12.0 要保留它，并删除旧 target mapping 相关残留。
3. **真正新增的是曲率 cap 和可选 log-domain 尺寸稳定层**。
4. **真正删除的是 CLI/config 中用于历史实验的开关和导出诊断代码**。
5. **真正重构的是模块边界和测试覆盖**。

## 第 5 步：抽出 feature 与局部算子

这一步是重构，不是新增算法。当前 feature-aware collapse 已经存在，目标是把已验证逻辑从 `AdaIsoRemesher.cpp` 中拆出来并固定为默认策略。

新增：

```text
include/adaiso/detail/FeatureClassification.hpp
src/FeatureClassification.cpp
```

迁移：

- `computeVertexFeatureStrengths`
- relocation class 相关逻辑

新增：

```text
include/adaiso/detail/LocalOperators.hpp
src/LocalOperators.cpp
```

迁移：

- split edge 操作
- collapse candidate selection
- collapse validity
- feature-aware collapse point
- flip validity
- tangent smoothing

迁移后 `AdaIsoRemesher` 只调用明确的函数：

```cpp
splitLongEdges(mesh, target_field, options);
collapseShortEdges(mesh, target_field, feature_strengths, options);
flipEdges(mesh, target_field, feature_strengths, options);
tangentSmooth(mesh, feature_classes, options);
```

## 第 6 步：实现 v2.12.0 曲率稳健化

在 `TargetFaceSizing` 之前增加 curvature cap。

建议接口：

```cpp
struct CurvatureCapResult {
  std::vector<double> curvature;
  double cap_value = 0.0;
  double changed_rate = 0.0;
};

CurvatureCapResult capCurvatureQuantile(
    const std::vector<double>& curvature,
    double quantile);
```

默认：

```text
quantile = 0.995
```

如果全 T 小集合显示 CD 明显退化，再考虑调到 `0.999` 或改为局部 sampling cap。

不要把 quantile 做成 CLI 参数。先固定为内部常量并写入 summary。

## 第 7 步：保留 v2.10.0 target_faces inverse-sqrt，并补充 log-domain 稳定层

`TargetFaceSizing` 保持主公式：

```text
h = lambda / sqrt(kappa)
```

需要调整：

- 让 `TargetFaceSizingResult` 记录 `lambda`、`estimated_faces`、`h_min`、`h_max`。
- 清理未使用的 `CurvatureOutlierMode`、`TargetFaceRepresentative` 等旧实验枚举。
- 二分次数固定为内部常量 `64`。
- 不保留 hmax/hmin、representative、outlier mode 的 CLI 或 public config。

新增候选稳定层：

```text
h0 = clamp(lambda / sqrt(kappa), h_min, h_max)
x0 = log(h0)
x1 = lightweightSmoothOnlyOutlierSmallSizes(x0)
h1 = exp(x1)
h  = globalRescaleToTargetFaces(h1)
```

注意：

- 这不是恢复 v2.5.0 完整 log(h) gradation pipeline。
- 这不是 v2.11.1 的硬 downward gradation limiter。
- 默认实现应先可开可关地在代码内部实验，但不要暴露 CLI。
- 若小集合显示 CD 退化明显，应先关闭 log smoothing，只保留 curvature cap。

## 第 8 步：质量保护

当前代码已经有 collapse 后局部质量检查。v2.12.0 的任务是保留并测试它，而不是重新设计。

```text
min_quality_after_collapse = 0.05
```

实验若显示 Qmin 仍过低，再评估：

- `0.08`
- `0.10`

该参数先作为内部常量，不进入 CLI。

flip 保留：

- 翻转前后二面角不超过固定阈值。
- 不产生 obtuse 恶化。
- 必须改善 valence。
- 不违反 target edge ratio。

## 第 9 步：测试计划

必须保留或新增的单元测试：

- raw curvature finite / fallback 测试。
- screened Laplacian solve finite / residual 测试。
- target face sizing 单调性测试。
- target face estimate 对 lambda 的单调关系测试。
- curvature cap 不产生 NaN/Inf。
- feature-aware collapse point 选择测试。
- collapse validity 不允许低于质量门槛。
- flip 不允许超过二面角阈值。

端到端小集合：

```text
T21, T30, T36, T44, T87, T124
```

全量验收：

```text
T_all_iter10, 31 models
```

## 第 10 步：验收脚本

新增或整理一个脚本：

```text
cpp_adaiso/修改计划与实验结果/generate_v2_12_0_T_iter10_report.py
```

它只负责：

- 运行全 T。
- 收集 summary JSON。
- 输出 `run_summary.csv`。
- 与 v2.10.0、v2.8.0、v2.8.3 做指标对比。
- 生成 Markdown 报告。

不要让 C++ 主程序承担报告生成逻辑。

## 不做的事情

v2.12.0 不做：

- 不恢复 v2.5.0 完整 log(h) gradation pipeline。
- 不引入 v2.11.1 硬 gradation limiter。
- 不保留多种 target mapping 运行时切换。
- 不保留 hmin/hmax/alpha/beta/representative/outlier 的 CLI 矩阵。
- 不保留大规模 PLY/CSV 诊断导出。
- 不把历史对照逻辑塞进默认代码。

## 最终交付标准

代码层面：

- `AdaIsoRemesher.cpp` 明显变薄。
- CLI 参数数量减少。
- 默认路径无版本分支。
- 未使用函数和 enum 删除。
- 单元测试通过。

实验层面：

- 小集合没有 T21/T36 失稳。
- 全 T 平均 CD 接近 v2.10.0。
- 最低 Qmin 明显高于 v2.10.0。
- 平均 violation 不明显劣化。
