# v2.12.0 代码修改计划

## 原则

v2.12.0 代码目标是干净、单路径、可测试。不要为了保留历史实验能力继续增加分支。

具体原则：

- 默认实现只保留一个算法路径。
- 实验分支不通过 CLI 暴露。
- 旧版本对照函数、参数入口、诊断导出在 v2.12.0 中删除。
- 模块边界按职责拆分，避免 `AdaIsoRemesher.cpp` 继续堆积所有逻辑。
- 每个保留参数都必须服务默认算法或验收评估。

## 目标模块结构

建议形成以下模块：

```text
include/adaiso/
  AdaIsoRemesher.hpp
  TargetSizingOptions.hpp        # 若仍需要公开少量 sizing 常量，否则删除
  detail/
    RawCurvature.hpp
    ScreenedLaplacian.hpp
    TargetFaceSizing.hpp
    FeatureClassification.hpp
    LocalOperators.hpp

src/
  AdaIsoRemesher.cpp             # 只保留流程编排
  RawCurvature.cpp
  ScreenedLaplacian.cpp
  TargetFaceSizing.cpp
  FeatureClassification.cpp
  LocalOperators.cpp
  main.cpp
```

`AdaIsoRemesher.cpp` 的目标是只负责：

1. 输入清理。
2. 构建 target field。
3. 调用 split/collapse/flip/smooth。
4. 收集 summary stats。

不应继续承载大量 feature strength、diagnostic writer、local operator 细节。

## 第 1 步：冻结当前默认路径

当前已提交快照：`48fd637 Snapshot current v2.11.x implementation`。

v2.12.0 从该提交之后开始，不再回填旧版本兼容。

默认路径固定为：

```text
raw curvature
-> screened Laplacian
-> target_faces inverse-sqrt
-> surface barycentric target lookup
-> split/collapse/flip/smooth
-> optional final evaluation
```

## 第 2 步：清理公开配置和 CLI

### 删除或内部化的 CLI 参数

建议从 `src/main.cpp` 删除：

- `--variant`
- `--curvature-mode`
- `--csf-alpha`
- `--export-target-field`
- `--export-iteration-meshes`
- `--export-stage-meshes`
- `--export-all-stage-meshes`
- `--max-flip-dihedral-deg`
- `--feature-aware-collapse`
- `--collapse-feature-omega`
- `--relocation-mls`

保留 CLI：

- input mesh
- `-o/--output`
- `--target-faces`
- `--preprocess`
- `--iters`
- `--gt`
- `--cd-samples`
- `--summary-json`
- `--quiet`
- `--help`

说明：

- feature-aware collapse 在 v2.12.0 中应是默认策略，不再作为开关。
- flip dihedral、collapse omega、csf alpha 先变成内部常量。
- 若后续确实需要参数消融，用独立实验脚本或测试 fixture，不污染生产 CLI。

### 清理 `AdaIsoConfig`

从 `include/adaiso/AdaIsoRemesher.hpp` 中删除或内部化：

- `Variant variant`
- `CurvatureMode curvature_mode`
- `csf_smoothing_alpha`
- `target_field_export_dir`
- `iteration_mesh_export_dir`
- `stage_mesh_export_dir`
- `all_stage_mesh_export_dir`
- `max_flip_dihedral_degrees`
- `feature_aware_collapse`
- `collapse_feature_omega`
- `enable_relocation_mls`
- `mls_k`
- `mls_iterations`
- `mls_tolerance`

保留：

- `target_faces`
- `preprocess`
- `global_iterations`
- split/collapse/flip pass limits
- tangent smoothing lambda
- `min_quality_after_collapse`
- `verbose`

若 `splitFactor()`、`collapseFactor()` 已固定，不需要依赖 `Variant`。

## 第 3 步：删除旧版本兼容函数

删除：

- `Variant`
- `parseVariant`
- `toString(Variant)`
- `collapseUsesMaxReference()`
- `CurvatureMode` CLI 解析入口
- 仅用于旧 `normal-angle` 路径的生产调用

保留 `RawCurvature` 中真正作为默认曲率使用的函数。若 `normal-angle` 只用于历史对照，移入测试辅助或直接删除。

## 第 4 步：删除诊断导出代码

从 `AdaIsoRemesher.cpp` 删除：

- target field CSV/PLY heatmap 导出。
- per-iteration mesh export。
- first-stage mesh export。
- all-stage mesh export。
- `TargetFieldStageData` 及其只服务导出的统计/写文件函数。

保留 summary JSON 中的关键标量：

- input/output V/F
- Qavg/Qmin
- CD/RMSE
- target_faces
- estimated_faces
- lambda
- h_min/h_max/observed_h_min/observed_h_max
- edge target ratio stats
- curvature cap changed rate
- split/collapse/flip total
- runtime

这样可以保留验收能力，同时不把诊断文件写入主流程。

## 第 5 步：抽出 feature 与局部算子

新增：

```text
include/adaiso/detail/FeatureClassification.hpp
src/FeatureClassification.cpp
```

迁移：

- `computeVertexFeatureStrengths`
- relocation class 相关逻辑

新增：

```text
include/adaiso/detail/LocalOperators.hpp
src/LocalOperators.cpp
```

迁移：

- split edge 操作
- collapse candidate selection
- collapse validity
- feature-aware collapse point

迁移后 `AdaIsoRemesher` 只调用明确的函数：

```cpp
splitLongEdges(mesh, target_field, options);
collapseShortEdges(mesh, target_field, feature_strengths, options);
flipEdges(mesh, target_field, feature_strengths, options);
tangentSmooth(mesh, feature_classes, options);
```

## 第 6 步：实现 v2.12.0 曲率稳健化

在 `TargetFaceSizing` 之前增加 curvature cap。

建议接口：

```cpp
struct CurvatureCapResult {
  std::vector<double> curvature;
  double cap_value = 0.0;
  double changed_rate = 0.0;
};

CurvatureCapResult capCurvatureQuantile(
    const std::vector<double>& curvature,
    double quantile);
```

默认：

```text
quantile = 0.995
```

如果全 T 小集合显示 CD 明显退化，再考虑调到 `0.999` 或改为局部 sampling cap。

不要把 quantile 做成 CLI 参数。先固定为内部常量并写入 summary。

## 第 7 步：保留 v2.10.0 target_faces inverse-sqrt

`TargetFaceSizing` 保持主公式：

```text
h = lambda / sqrt(kappa)
```

需要调整：

- 让 `TargetFaceSizingResult` 记录 `lambda`、`estimated_faces`、`h_min`、`h_max`。
- 清理未使用的 `CurvatureOutlierMode`、`TargetFaceRepresentative` 等旧实验枚举。
- 二分次数固定为内部常量 `64`。
- 不保留 hmax/hmin、representative、outlier mode 的 CLI 或 public config。

## 第 8 步：质量保护

保持或增强 collapse 后局部质量检查：

```text
min_quality_after_collapse = 0.05
```

实验若显示 Qmin 仍过低，再评估：

- `0.08`
- `0.10`

该参数先作为内部常量，不进入 CLI。

flip 保留：

- 翻转前后二面角不超过固定阈值。
- 不产生 obtuse 恶化。
- 必须改善 valence。
- 不违反 target edge ratio。

## 第 9 步：测试计划

必须保留或新增的单元测试：

- raw curvature finite / fallback 测试。
- screened Laplacian solve finite / residual 测试。
- target face sizing 单调性测试。
- target face estimate 对 lambda 的单调关系测试。
- curvature cap 不产生 NaN/Inf。
- feature-aware collapse point 选择测试。
- collapse validity 不允许低于质量门槛。
- flip 不允许超过二面角阈值。

端到端小集合：

```text
T21, T30, T36, T44, T87, T124
```

全量验收：

```text
T_all_iter10, 31 models
```

## 第 10 步：验收脚本

新增或整理一个脚本：

```text
cpp_adaiso/修改计划与实验结果/generate_v2_12_0_T_iter10_report.py
```

它只负责：

- 运行全 T。
- 收集 summary JSON。
- 输出 `run_summary.csv`。
- 与 v2.10.0、v2.8.0、v2.8.3 做指标对比。
- 生成 Markdown 报告。

不要让 C++ 主程序承担报告生成逻辑。

## 不做的事情

v2.12.0 不做：

- 不恢复 v2.5.0 完整 log(h) gradation pipeline。
- 不引入 v2.11.1 硬 gradation limiter。
- 不保留多种 target mapping 运行时切换。
- 不保留 hmin/hmax/alpha/beta/representative/outlier 的 CLI 矩阵。
- 不保留大规模 PLY/CSV 诊断导出。
- 不把历史对照逻辑塞进默认代码。

## 最终交付标准

代码层面：

- `AdaIsoRemesher.cpp` 明显变薄。
- CLI 参数数量减少。
- 默认路径无版本分支。
- 未使用函数和 enum 删除。
- 单元测试通过。

实验层面：

- 小集合没有 T21/T36 失稳。
- 全 T 平均 CD 接近 v2.10.0。
- 最低 Qmin 明显高于 v2.10.0。
- 平均 violation 不明显劣化。
