# cpp_adaiso v2.5.0 尺寸场构建理论

## 1. 目标

v2.4.0 已经把旧的五档目标边长映射替换成连续经验分位数映射：

```text
CSF curvature -> empirical quantile -> target length
```

这个映射消除了五档离散跳变，但它仍然主要是逐点映射。也就是说，每个顶点的目标边长只由该顶点的 CSF 曲率排名决定，没有显式约束相邻顶点之间的尺寸变化速度。

v2.5.0 的目标是把尺寸场构建改成：

```text
raw curvature -> screened CSF curvature -> raw target log-size
-> gradient-aware smoothed target log-size -> target length field
```

核心要求：

1. 高曲率区域仍然得到更小目标边长。
2. 低曲率区域仍然得到更大目标边长。
3. 曲率高低交界处不直接从大尺寸跳到小尺寸，而是形成可控过渡带。
4. 尺寸场平滑发生在尺寸场建立阶段，而不是 remesh 后处理阶段。

---

## 2. 网格和记号

设输入三角网格为：

```text
M = (V, E, F)
```

其中：

- `V = {v_i}` 是顶点集合，顶点数为 `n`。
- `E` 是无向边集合。
- `F` 是三角面集合。
- `N(i)` 表示顶点 `i` 的一环邻接顶点集合。
- `p_i in R^3` 表示顶点 `i` 的空间位置。
- `n_i` 表示顶点 `i` 的单位法向。

顶点面积质量取 barycentric mass：

```text
m_i = (1 / 3) * sum_{f contains i} A_f
```

平均边长定义为：

```text
l_bar = (1 / |E|) * sum_{(i,j) in E} ||p_i - p_j||
```

---

## 3. 原始曲率场

原始曲率场 `r_i` 从相邻顶点法向夹角得到。当前 code variant 可写成：

```text
r_i = (1 / |N(i)|) * sum_{j in N(i)}
      acos(clamp(n_i dot n_j, -1, 1))
```

如果 `N(i)` 为空，则取：

```text
r_i = 0
```

这个 `r_i` 是一个离散的法向变化强度。它的性质是：

- 平坦区域中，邻接法向接近一致，`r_i` 小。
- 折痕、细节、曲率大区域中，邻接法向变化大，`r_i` 大。
- 原始场可能含有局部噪声，因为它直接由一环法向差分得到。

因此不能直接把 `r_i` 映射成尺寸场，需要先做曲率场平滑。

---

## 4. Screened CSF 曲率场

v2.5.0 继续使用 screened smoothing 得到 CSF 曲率 `c_i`。它不是纯调和插值，而是带数据保真项的平滑：

```text
E_c(c) =
  1/2 * sum_i m_i (c_i - r_i)^2
  + lambda_c / 2 * sum_{(i,j) in E} w_ij (c_i - c_j)^2
```

其中：

- 第一项要求 `c_i` 接近原始曲率 `r_i`。
- 第二项惩罚相邻顶点的曲率差。
- `w_ij` 是 cotangent edge weight。
- `lambda_c` 是曲率场平滑强度。

cotangent 权重为：

```text
w_ij = 1/2 * (cot alpha_ij + cot beta_ij)
```

其中 `alpha_ij` 和 `beta_ij` 是边 `(i,j)` 对面的两个角。工程实现中，如果权重非正或非有限，可用小正数 `eta` 替代：

```text
w_ij <- max(w_ij, eta)
```

曲率平滑参数使用尺度一致形式：

```text
lambda_c = alpha_c * l_bar^2
```

其中 `alpha_c` 是无量纲参数，对应当前 `csf_alpha`。

对 `E_c(c)` 求一阶最优条件：

```text
m_i (c_i - r_i) + lambda_c * sum_{j in N(i)} w_ij (c_i - c_j) = 0
```

矩阵形式为：

```text
(M + lambda_c L) c = M r
```

其中：

```text
M_ii = m_i
L_ii = sum_j w_ij
L_ij = -w_ij, if (i,j) in E
L_ij = 0, otherwise
```

这个系统的意义是：`c_i` 同时听从自己的原始曲率和邻域平均。`alpha_c` 越大，曲率场越平滑；`alpha_c` 越小，曲率场越接近 raw curvature。

---

## 5. 从 CSF 曲率到原始目标尺寸

得到 CSF 曲率 `c_i` 后，先构建一个原始目标边长 `h0_i`。v2.5.0 沿用 v2.4.0 的连续经验分位数映射。

定义经验分位数：

```text
q_i = F_hat(c_i)
```

其中 `q_i in [0, 1]`。曲率越大，`q_i` 越接近 1。重复曲率值使用 tie block 的平均 rank，避免同值顶点得到不同尺寸。

定义目标边长范围：

```text
h_min = l_bar * mesh_scale * target_min_factor
h_max = l_bar * mesh_scale * target_max_factor
```

其中：

- `h_min` 是高曲率区域允许的最小目标边长。
- `h_max` 是低曲率区域允许的最大目标边长。

令：

```text
a_i = q_i ^ gamma
```

则原始目标边长为：

```text
h0_i = exp((1 - a_i) * log(h_max) + a_i * log(h_min))
```

等价写法：

```text
h0_i = h_max * (h_min / h_max) ^ a_i
```

使用 log-space 映射的原因是：目标尺寸变化本质上是比例变化，而不是加法变化。这样从 `h_max` 到 `h_min` 的过渡在比例意义上更均匀。

如果 CSF 曲率是常量场，则没有可靠的曲率排序，应直接取：

```text
h0_i = l_bar * mesh_scale
```

---

## 6. v2.4.0 尺寸场的局限

v2.4.0 的 `h0_i` 是连续值，但它不是空间上显式平滑的场。

原因是 `h0_i` 只由 `c_i` 的全局 rank 决定：

```text
c_i -> q_i -> h0_i
```

这个映射保证：

```text
c_i >= c_j  =>  h0_i <= h0_j
```

但它不保证：

```text
h0_i / h0_j is small, for every edge (i,j)
```

因此在曲率高低交界处，可能出现：

```text
h0_i small, h0_j large, and (i,j) in E
```

这会造成尺寸场梯度过大。对 remeshing 来说，过大的尺寸梯度会带来几个问题：

1. 过渡区三角形需要同时适应两种目标边长，容易产生瘦长三角形。
2. split/collapse 在尺寸边界附近更容易震荡。
3. 局部最小角可能下降，最大角可能升高。
4. 点云式 kNN 查询只能缓和采样值，不能保证输入尺寸场本身满足梯度约束，也不能保证查询只发生在同一片曲面邻域内。

所以 v2.5.0 应该在尺寸场建立阶段显式考虑空间梯度。

---

## 7. 在 log-size 上构建平滑尺寸场

定义 log-size：

```text
x_i = log(h_i)
x0_i = log(h0_i)
```

v2.5.0 的尺寸场不直接使用 `h0_i`，而是求一个新的 `x_i`：

```text
E_h(x) =
  1/2 * sum_i m_i rho_i (x_i - x0_i)^2
  + lambda_h / 2 * sum_{(i,j) in E} w_ij (x_i - x_j)^2
```

其中：

- `x0_i` 是由曲率映射得到的原始 log-size。
- `x_i` 是最终使用的平滑 log-size。
- `rho_i` 是数据保真权重。
- `lambda_h` 是尺寸场平滑强度。

最简单情况下：

```text
rho_i = 1
```

此时每个顶点同等信任原始目标尺寸。对 `E_h(x)` 求一阶最优条件：

```text
m_i rho_i (x_i - x0_i)
+ lambda_h * sum_{j in N(i)} w_ij (x_i - x_j) = 0
```

矩阵形式为：

```text
(R M + lambda_h L) x = R M x0
```

其中：

```text
R = diag(rho_i)
```

如果 `rho_i = 1`，则退化为：

```text
(M + lambda_h L) x = M x0
```

尺寸平滑参数同样使用尺度一致形式：

```text
lambda_h = alpha_h * l_bar^2
```

最终目标边长为：

```text
h_i = exp(x_i)
```

并 clamp 到合法范围：

```text
h_i <- clamp(h_i, h_min, h_max)
```

---

## 8. 为什么平滑 log(h)，不是直接平滑 h

如果直接平滑 `h`，能量是：

```text
sum (h_i - h0_i)^2 + smoothness
```

这会把尺寸变化当成加法误差。例如 `0.01 -> 0.02` 和 `1.00 -> 1.01` 都差 `0.01`，但前者是 100% 变化，后者只有 1% 变化。

remeshing 中更重要的是比例：

```text
h_i / h_j
```

平滑 `x = log(h)` 时：

```text
x_i - x_j = log(h_i / h_j)
```

因此惩罚 `x_i - x_j` 等价于惩罚相邻尺寸比例变化。这样更符合尺寸场 gradation 的数学含义。

---

## 9. 显式相邻梯度约束

只做 screened smoothing 可以降低平均梯度，但不能严格保证每条边的尺寸比例上限。因此可以加入 gradation constraint：

```text
|x_i - x_j| <= log(g), for every edge (i,j) in E
```

等价于：

```text
1 / g <= h_i / h_j <= g
```

其中 `g > 1` 是最大相邻尺寸比例。推荐起点：

```text
g = 1.25 or 1.30
```

这个约束的意义是：任意一条输入网格边两端，目标边长最多相差 25% 或 30%。这样高曲率小尺寸不会立即跳到低曲率大尺寸，而会沿网格形成若干层过渡。

步骤 6、7、8 可以合并成一个统一的约束优化问题。也就是说，不必先解无约束 screened smoothing，再做范围 clamp 和 gradation projection；可以直接在同一个问题里同时考虑三件事：

1. 接近原始 log-size `x0`。
2. 尺寸场空间平滑。
3. 满足范围和相邻梯度约束。

---

## 10. 统一凸二次规划

令：

```text
ell = log(h_min)
u = log(h_max)
delta = log(g)
```

则最终 log-size `x` 可以由以下凸二次规划一次性定义：

```text
min_x
  1/2 * ||x - x0||^2_{R M}
  + lambda_h / 2 * x^T L x

subject to
  ell <= x_i <= u, for all i
  x_i - x_j <= delta, for all (i,j) in E
  x_j - x_i <= delta, for all (i,j) in E
```

把目标函数展开，得到标准 QP 形式：

```text
min_x
  1/2 * x^T H x - b^T x

subject to
  A x <= a
```

其中：

```text
H = R M + lambda_h L
b = R M x0
```

约束矩阵 `A` 由两类线性约束组成：

```text
box constraints:
  x_i <= u
 -x_i <= -ell

gradation constraints:
  x_i - x_j <= delta
  x_j - x_i <= delta
```

这是一个凸二次规划，原因是：

1. `R M` 是非负对角矩阵；当 `rho_i > 0` 且 `m_i > 0` 时，它是正定对角矩阵。
2. `L` 是 cotangent 图 Laplacian；在权重非负时是半正定矩阵。
3. 因此 `H = R M + lambda_h L` 是半正定；若 `rho_i > 0` 且 `m_i > 0`，则 `H` 正定。
4. 所有约束都是线性不等式，形成凸可行域。

只要 `h_min <= h_max` 且 `g > 1`，可行域非空。例如任意常数 `x_i = const` 且 `const in [ell, u]` 都满足所有 gradation constraints。

因此这个问题有全局最优解；在 `H` 正定时，最优解唯一。

这个 QP 是 v2.5.0 尺寸场最完整的数学定义。它同时完成：

```text
6. Smooth log-size
7. Clamp range
8. Apply gradation limit
```

最终：

```text
h_i = exp(x_i)
```

需要注意的是，对称 gradation constraint 会在冲突区域做折中：大尺寸可能被压低，小尺寸也可能被抬高。如果希望更强地保护高曲率细节，应使用第 12 节的 `rho_i` 设计，提高高曲率顶点对 `x0_i` 的保真权重。

## 11. 工程上可实现的投影式近似

如果暂时不引入 QP solver，v2.5.0 可以采用投影式近似。它不是最严格的数学解，但实现简单，并且能近似同一个目标。

### 11.1 Screened log-size smoothing

先求解：

```text
(M + lambda_h L) x = M x0
```

得到平滑后的 `x`。

### 11.2 Range projection

把 `x_i` 限制在目标范围内：

```text
x_i <- clamp(x_i, log(h_min), log(h_max))
```

### 11.3 Gradation projection

反复扫描所有边 `(i,j)`。如果：

```text
x_i > x_j + log(g)
```

说明 `h_i` 比 `h_j` 大太多。可把较大值压低：

```text
x_i <- x_j + log(g)
```

如果：

```text
x_j > x_i + log(g)
```

则：

```text
x_j <- x_i + log(g)
```

每轮扫描后再做 range clamp。迭代到没有变化，或达到最大迭代次数。

这个投影会优先保留小尺寸区域，并限制大尺寸区域向外增长的速度。结果是高曲率区域的小尺寸向周围扩散，形成过渡带。

如果希望减少方向偏置，可以在每轮扫描中交替边顺序，或先收集候选更新后批量应用。

## 12. 保真权重 rho_i 的可选设计

默认 `rho_i = 1` 已经足够作为 v2.5.0 起点。如果希望更强地保留高曲率细节，可以让高曲率区域的数据保真更强：

```text
rho_i = 1 + beta * q_i
```

其中：

- `q_i` 是 CSF 曲率经验分位数。
- `beta >= 0` 控制高曲率区域的保真增强。

这样高曲率区域的 `x_i` 更接近 `x0_i`，平滑主要发生在过渡区和低曲率区。

也可以使用温和形式：

```text
rho_i = 1 + beta * q_i^gamma_rho
```

但 v2.5.0 初版建议先固定：

```text
rho_i = 1
```

避免引入过多耦合参数。

## 13. TargetLengthField 的曲面重心插值定义

尺寸场建立阶段得到的是输入顶点上的 log-size `x_i`。remesh 过程中，需要在任意点 `p` 查询目标尺寸。

v2.5.0 中，`TargetLengthField` 不应只保存一组点和尺寸值，而应保存输入曲面上的分片线性 log-size 场：

```text
TargetLengthField =
  (M_input, x, surface_query)
```

其中：

- `M_input = (V_input, F_input)` 是建立尺寸场时的输入三角网格。
- `x_i = log(h_i)` 是输入顶点 `i` 上的最终 log-size。
- `surface_query` 是三角形 AABB / BVH / closest-triangle 查询结构。

对于严格位于输入曲面上的点 `p`，若它位于三角形：

```text
T = (i, j, k)
```

并且重心坐标为：

```text
lambda_i + lambda_j + lambda_k = 1
lambda_i, lambda_j, lambda_k >= 0
```

则定义：

```text
x(p) = lambda_i x_i + lambda_j x_j + lambda_k x_k
h(p) = exp(x(p))
```

等价地：

```text
h(p) = h_i^lambda_i * h_j^lambda_j * h_k^lambda_k
```

也就是说，`x = log(h)` 是输入三角网格上的 P1 finite element 标量场，`h` 是它指数化后的比例尺寸场。

对于不严格位于输入曲面上的点，先投影到输入曲面：

```text
p_star = pi_M(p)
```

其中 `pi_M(p)` 是 `p` 到输入三角网格的最近点投影。若 `p_star` 位于最近三角形 `T = (i, j, k)` 中，则：

```text
h(p) = exp(x(p_star))
```

这个定义比 Gaussian kNN lookup 更适合作为 v2.5.0 的理论定义：

1. 它是曲面感知的，不会把空间上接近但曲面上不相邻的薄壳、手指、褶皱另一侧混入查询。
2. `x(p)` 在输入曲面上是分片线性且跨共享边连续的。
3. 插值发生在 `log(h)` 上，保持比例意义下的平滑。
4. 它和第 10 节的 QP 定义一致：QP 解出顶点 log-size，查询阶段只是在同一输入曲面上评价这个有限元场。

需要注意的是，最近点投影在尖锐边、边界、自相交或多个等距三角形处可能不唯一。工程实现中可以选择任意一个最近三角形；如果输入网格没有明显自交，这类非唯一点通常只构成低维集合，对 remeshing 主循环影响有限。

Gaussian kNN on log-size 可以作为无 BVH 实现时的近似 fallback，但不应作为 v2.5.0 的首选理论定义。

## 14. 对 Q、最小角和最大角的预期影响

平滑尺寸场的主要收益来自过渡区。

如果相邻目标边长变化过快，局部网格必须在很短距离内从大三角形过渡到小三角形。这类区域容易产生：

- 很小的最小角。
- 很大的最大角。
- 较低的 `Qmin`。
- split/collapse 操作震荡。

引入 log-size 平滑和 gradation constraint 后，过渡区会变宽。预期效果是：

```text
Qmin increase
minimum angle increase
maximum angle decrease
tail violation decrease
tail ops decrease
```

`Qavg` 可能提高，但不是必然。因为 `Qavg` 受全局大多数三角形影响，而尺寸场平滑主要改善局部过渡区。

需要同时观察 Chamfer Distance。过强的尺寸平滑可能导致：

- 高曲率处目标尺寸变大，细节采样不足。
- 小尺寸向平坦区扩散，顶点数增加。
- CD、runtime 或输出顶点数变差。

因此 v2.5.0 的评估不能只看 `Qavg`，还应看：

```text
Qmin
minimum angle percentile
maximum angle percentile
CD / RMSE
final violation rate
tail violation rate
tail ops
output vertex count
```

## 15. 推荐默认参数

建议 v2.5.0 初版参数：

```text
csf_alpha = 0.5
target_min_factor = 0.6
target_max_factor = 1.8
target_gamma = 1.0
target_smooth_alpha = 0.3
target_max_adjacent_ratio = 1.30
target_lookup_mode = surface_barycentric
target_gradation_iterations = 20
```

其中：

- `target_smooth_alpha = 0` 表示关闭 log-size screened smoothing。
- `target_max_adjacent_ratio <= 1` 表示关闭显式 gradation constraint。
- `target_lookup_mode = surface_barycentric` 表示使用输入曲面最近点投影和三角形重心插值查询 `log(h)`。
- `target_gradation_iterations` 只用于第 11 节的投影式近似；若采用第 10 节的统一 QP，则不需要这个迭代参数。
- `1.30` 是较温和的初始值，避免过度扩散小尺寸区域。

如果实验发现过渡仍然过陡，可以试：

```text
target_smooth_alpha = 0.5
target_max_adjacent_ratio = 1.25
```

如果实验发现细节损失或顶点数过多，可以试：

```text
target_smooth_alpha = 0.15
target_max_adjacent_ratio = 1.40
```

## 16. 完整构建流程

v2.5.0 尺寸场构建可以总结为：

```text
Input mesh M

1. Compute vertex normals n_i.

2. Compute raw curvature:
   r_i = average normal-angle variation around vertex i.

3. Compute screened CSF:
   (M + alpha_c * l_bar^2 * L) c = M r.

4. Compute empirical quantile q_i from c_i.

5. Compute raw target log-size:
   x0_i = (1 - q_i^gamma) * log(h_max)
          + q_i^gamma * log(h_min).

6. Solve the unified convex QP:
   minimize
     1/2 * ||x - x0||^2_{R M}
     + alpha_h * l_bar^2 / 2 * x^T L x
   subject to
     log(h_min) <= x_i <= log(h_max)
     |x_i - x_j| <= log(g), for every mesh edge.

7. Build the surface TargetLengthField:
   store input vertices, input triangles, vertex log-size x_i,
   and a triangle closest-point query structure.

8. Query target length at any point p by:
   p_star = closest point on input surface,
   x(p_star) = barycentric interpolation on the closest triangle,
   h(p) = exp(x(p_star)).
```

最终结果是一个定义在输入曲面上的、比例意义下平滑、相邻梯度受控的目标边长场。它不是点云 kNN 场，而是输入三角网格上的分片线性 log-size 场。

---

## 17. 数学结论

v2.5.0 的关键变化不是改变曲率定义，也不是 remesh 后处理，而是在尺寸场建立阶段加入一个新的变分问题：

```text
x = argmin_x
  1/2 * ||x - x0||^2_M
  + alpha_h * l_bar^2 / 2 * x^T L x
```

并把范围限制和相邻梯度限制作为线性约束同时加入：

```text
log(h_min) <= x_i <= log(h_max)
|x_i - x_j| <= log(g)
```

这里 `x = log(h)`。因此它直接控制相邻目标边长的比例变化。

这比单纯增加 CSF 平滑更准确。CSF 平滑控制的是曲率场噪声，而 v2.5.0 的 log-size 平滑控制的是最终目标边长场的空间梯度。两者作用对象不同：

```text
CSF smoothing:      smooth c_i
Target smoothing:   smooth log(h_i)
Gradation limit:    bound h_i / h_j
Target lookup:      evaluate x = log(h) on the input surface
```

因此 v2.5.0 的尺寸场应被描述为：

```text
surface-aware gradient-constrained log-size target field
```

它保留 v2.4.0 的连续曲率响应，同时补上 v2.4.0 缺失的尺寸过渡控制和曲面感知查询定义。
