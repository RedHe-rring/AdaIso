# v5.3.7 Stage A 几何误差诊断报告（T0-T9）

## 1. 诊断目的

- 判断 v5.3.7 中 RMSE/CD 的小幅上升是在 Stage A 尺寸场贴合后已经出现，还是 Stage B 质量修复继续放大。
- 使用 `--export-all-stage-meshes` 导出每轮 stage mesh。
- 取最后一轮 `size_iter010_after_collapse.ply` 作为 Stage A 结束网格。
- 使用 `adaiso_eval --cd-samples 100000` 计算 Stage A mesh 相对输入网格的 RMSE/CD。

## 4. 判断

- Stage A 结束时的 RMSE/CD 已经和最终输出非常接近，甚至平均略低于 final。
- 因此，v5.3.7 相对 v5.3.6 的几何误差小幅上升，主要不是 Stage B 继续放大的结果，而是 Stage A 更积极贴尺寸场时已经产生。
- Stage B 的主要作用仍是改善质量：平均最小角从 `5.7770` 提到 `7.0840`，`angle<10%` 从 `0.0147` 降到 `0.0106`。
- 如果下一版要控制 RMSE/CD，重点应放在 Stage A 的 collapse/split 几何保护或 Stage A 结束后的 guarded projection，而不是优先限制 Stage B。
