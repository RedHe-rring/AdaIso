# v5.1.0 修改方向

## 1. 当前目标

v5.1.0 的主线目标是把尺寸场从“指定目标面数 N 后反解 target length”改为“由曲率和几何误差自动生成 target length”，并用实验结果继续定位下一步应改的模块。

当前已经完成的方向：

- raw curvature 改为主曲率信号：`kappa_raw = max(abs(k1), abs(k2))`。
- 主曲率估计使用 libigl `principal_curvature`。
- CSF 仍保留：尺寸场使用 CSF 平滑后的主曲率 `kappa_csf`，不是直接使用 raw curvature。
- 移除 `--target-faces` 和 target face budget 驱动的 lambda 反解逻辑。
- 移除 `--target-size-mapping`。
- 默认误差 `delta` 改为由最大曲率和参考边长自动反解，不再用固定 `0.001 * bbox_diagonal`。

## 2. 当前尺寸场公式

主曲率：

```text
kappa_raw(i) = max(abs(k1(i)), abs(k2(i)))
kappa(i)     = CSF(kappa_raw)(i)
kappa_safe(i)= max(kappa(i), kappa_floor)
kappa_max    = max_i kappa_safe(i)
```

默认误差：

```text
h_ref = 0.5 * mean_edge_length
delta_auto = (1 - sqrt(1 - kappa_max^2 * h_ref^2 / 3)) / kappa_max
```

如果 `h_ref` 超过公式有效区间，代码应把 `h_ref` 截断到有效范围内。

显式误差：

```text
如果用户传入 --target-error-delta，则使用用户给定的 absolute delta。
如果 target_error_delta == 0，则使用 delta_auto。
```

目标边长：

```text
h_min = sqrt(6 * delta / kappa_max - 3 * delta^2)
h(i)  = h_min * sqrt(kappa_max / kappa_safe(i))
h(i)  = clamp(h(i), h_min, h_max)
h_max = 5.0 * mean_edge_length
```

当前 `h_max = 5.0 * mean_edge_length` 暂时保留，但全量实验显示它是下一步重点扫描对象。

## 3. 数值边界

需要保持以下边界处理：

- `target_error_delta < 0` 或非有限值：报错。
- `bbox_diagonal <= 0` 或非有限值：报错。
- `mean_edge_length <= 0` 或非有限值：报错。
- `kappa_max <= kappa_floor`：视作近似平坦输入，target length 全部取 `h_max`。
- `target_error_delta == 0`：用 `kappa_max` 和 `h_ref` 反解默认 delta。
- libigl 主曲率结果中的 NaN/Inf：该顶点曲率降为 `kappa_floor`，诊断输出仍保留。

`kappa_floor` 继续沿用 `1e-12`，除非后续实验确认低曲率区域过粗与 floor 有关。

## 6. 当前判断

### 6.1 问题不再主要是 delta 默认值

auto delta 已经显著改善 T0-T5 的 CD/RMSE。全量实验中仍然存在高 RMSE 和高 violation，尤其集中在 model 系列。

这说明下一步不能只继续调 delta，应重点检查 remesh 操作是否能追上 target metric。

### 6.2 model 系列是当前优先级最高的数据族

model 系列：

- 平均 `rmse %bbox = 0.18216`，高于 T 系列的 `0.12032`。
- 平均 `violation = 0.29897`，高于 T 系列的 `0.15636`。
- 输出面数平均只有输入的 `0.515`，说明 auto-delta 在 model 上给出了更强的简化趋势。

优先样例：

```text
model_005
model_010
model_009
model_007
model_001
```

### 6.3 h range 全部顶到 10

报告中的高风险样例 `h range` 基本都为 `10.00`，说明：

```text
h_max / h_min = 5.0 * mean_edge_length / h_min
```

经常达到很大的尺寸跨度。低曲率区可能被放得过粗，高曲率区又很细，导致：

- CD/RMSE 上升；
- violation 高；
- qmin 在部分样例下降；
- 面数在不同模型间波动大。

## 7. 下一步代码修改方向

### 7.1 暴露 remesh hysteresis 参数

当前 `splitFactor()` 和 `collapseFactor()` 是固定函数：

```text
Code variant: split = 1.33
collapse = 0.8
```

下一步应在 `AdaIsoConfig` 和 CLI 中新增：

```cpp
double split_factor = 0.0;    // 0 means variant default
double collapse_factor = 0.0; // 0 means current default
```

CLI：

```text
--split-factor <value>
--collapse-factor <value>
```

建议扫描：

```text
collapseFactor = {0.6, 0.7, 0.8}
splitFactor    = {1.2, 1.33, 1.5}
```

目的：

- 高 violation 样例先看是否是 collapse 太激进或 split 不足。
- model 系列先用小矩阵扫描，不直接全量跑。

### 7.2 暴露 h_ref_factor

当前 auto delta 固定：

```text
h_ref = 0.5 * mean_edge_length
```

新增配置：

```cpp
double auto_delta_h_ref_factor = 0.5;
```

CLI：

```text
--auto-delta-h-ref-factor <value>
```

建议扫描：

```text
h_ref_factor = {0.45, 0.5, 0.6, 0.7}
```

目的：

- 控制 auto delta 的粗细。
- 观察 CD/RMSE 与输出面数的折中。

### 7.3 暴露 h_max_factor

当前：

```text
h_max = 5.0 * mean_edge_length
```

新增配置：

```cpp
double target_h_max_factor = 5.0;
```

CLI：

```text
--target-h-max-factor <value>
```

建议扫描：

```text
h_max_factor = {3.0, 4.0, 5.0}
```

目的：

- 判断低曲率区域是否过粗。
- 优先对 `model_005`, `model_010`, `T125`, `T44`, `T119`, `T82` 做小样本扫描。

### 7.4 增加稳健 kappa_ref 选项

当前默认 delta 使用：

```text
kappa_ref = max(kappa)
```

下一步增加：

```text
--auto-delta-kappa-ref <max|p99|p95>
```

候选：

```text
max
p99
p95
```

目的：

- 判断 `kappa_max` 是否被少数异常顶点支配。
- 若 p99/p95 使面数和 CD/RMSE 更稳定，再考虑作为默认。

注意：这一步应排在 hysteresis 和 h_max 扫描之后，因为当前 model 系列 violation 很高，先改 kappa_ref 可能掩盖 remesh 操作问题。

## 8. 下一步实验计划

### 8.1 小样本定位集

先不要全量扫描。建议选：

```text
model_005  // highest violation, est mismatch
model_010  // highest RMSE, lowest qmin
model_009  // high RMSE and violation
model_007  // high RMSE and violation
T125       // high T RMSE
T10        // face growth and low qmin
T53        // face growth and low qmin
T44        // high T violation
```

### 8.2 必须导出的诊断

对上述样例导出：

```text
--export-target-field <case>/target_field
--export-all-stage-meshes <case>/stages
--summary-json <case>/summary.json
```

重点检查：

- `target_field/field_stats.json`
- `target_field/vertices.csv`
- 每轮 split/collapse/flip/smooth 后的面数和质量变化。

### 8.3 第一轮扫描

固定：

```text
h_ref_factor = 0.5
h_max_factor = 5.0
kappa_ref = max
```

扫描：

```text
collapseFactor = {0.6, 0.7, 0.8}
splitFactor    = {1.2, 1.33, 1.5}
```

判定：

- 如果 violation 明显下降且 CD/RMSE 下降，说明 hysteresis 是主因。
- 如果 violation 仍高，继续看 stage mesh 和 h_max。

### 8.4 第二轮扫描

固定第一轮最优 hysteresis，扫描：

```text
h_max_factor = {3.0, 4.0, 5.0}
h_ref_factor = {0.45, 0.5, 0.6}
```

判定：

- 如果 h_max 降低后 RMSE 下降，说明低曲率区域过粗。
- 如果 h_ref 降低后 RMSE 下降但面数爆炸，需要找折中。

### 8.5 第三轮扫描

仅在前两轮不能解释问题时扫描：

```text
kappa_ref = {max, p99, p95}
```

判定：

- 如果 p99/p95 降低面数波动并改善 qmin/violation，说明 `kappa_max` 被异常点支配。
- 如果 p99/p95 提高 CD/RMSE，则保持 max。

## 9. 验收指标

每次实验至少输出：

| series | model | params | output_faces | face out/in | output/estimated | delta/bbox | h range | rmse %bbox | CD/bbox^2 | qavg | qmin | violation | split | collapse | flip | runtime |
|---|---|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|

优先级：

1. 降低 model 系列 violation。
2. 降低 model 系列 RMSE/CD。
3. 避免 qmin 低于 `0.01`。
4. 控制输出面数，不让 T 系列普遍超过输入面数太多。
5. 保持运行时间可接受。

## 10. 当前不建议优先做的事

- 不建议先关闭 feature-aware collapse。已有 T0-T5 检查显示关闭后 CD/RMSE 更差。
- 不建议先继续只调 `delta`。auto delta 已经解决旧默认过粗问题，剩余问题更像 remesh hysteresis 和 h_max 策略。
- 不建议先全量跑大矩阵。应先在高风险小样本集定位主因，再扩大到全 T/model。

## 11. 下一步实施顺序

按优先级实施，不要一次性把所有方向混在一个版本里。

### 11.1 v5.1.1：暴露 hysteresis 参数

目标：判断高 violation 是否来自 split/collapse 阈值不合适。

代码改动：

- `AdaIsoConfig` 新增：

```cpp
double split_factor_override = 0.0;
double collapse_factor_override = 0.0;
```

- `AdaIsoConfig::splitFactor()`：

```text
如果 split_factor_override > 0，返回 override；
否则保持当前 variant 默认值。
```

- `AdaIsoConfig::collapseFactor()`：

```text
如果 collapse_factor_override > 0，返回 override；
否则保持 0.8。
```

- `main.cpp` 新增：

```text
--split-factor <value>
--collapse-factor <value>
```

- summary JSON 输出实际使用的 split/collapse factor。
- 单元测试覆盖 override 解析和值域校验。

小样本实验：

```text
models = model_005, model_010, model_009, model_007, T125, T10, T53, T44
collapseFactor = {0.6, 0.7, 0.8}
splitFactor    = {1.2, 1.33, 1.5}
```

判定：

- 若 violation 和 RMSE 同时下降，hysteresis 是第一主因。
- 若 violation 降但 RMSE 不降，说明 target metric 追踪和几何误差目标不完全一致。
- 若 violation 不降，继续做 stage mesh 诊断。

### 11.2 v5.1.2：暴露 h_max_factor

- 若 RMSE 明显下降且面数可接受，说明低曲率粗化是主因之一。

### 11.3 v5.1.3：暴露 h_ref_factor

## 13. 最小验收出口

小样本阶段通过后才能全量跑 T/model。

小样本通过条件：

- `model_005/model_010/model_009/model_007` 的平均 violation 明显低于当前高风险水平。
- `model_010` 的 qmin 不再接近 0。
- 高 RMSE 样例的 `rmse %bbox` 有下降趋势。
- 输出面数没有无约束膨胀。

全量通过条件：

- model 系列平均 `violation < 0.25`，优先目标 `< 0.20`。
- model 系列平均 `rmse %bbox < 0.16`，优先目标 `< 0.14`。
- T 系列平均 `qmin >= 0.04`。
- all 系列 `faces out/in` 不超过当前 `0.810` 的 30% 以上，即粗略不超过 `1.05`。

如果 hysteresis、hmax、href 都不能让 model 系列明显改善，再回头检查：

- principal curvature 估计的局部异常；
- CSF alpha 是否过强或过弱；
- feature-aware collapse 的 feature strength 是否和 principal curvature 目标不一致；
- relocation/tangent smoothing 是否把顶点带离输入曲面。
