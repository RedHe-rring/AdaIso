# v5.1.0 T0-T5 delta 默认验收报告

## 1. 验收目的

本次验收检查 v5.1.0 默认尺寸场是否可以作为新默认行为：

- raw curvature 使用 libigl principal curvature。
- `kappa_raw = max(abs(k1), abs(k2))`。
- 尺寸场使用 CSF 后曲率。
- 默认 `delta = 0.001 * bbox_diagonal`。
- 不再指定目标面数 N，输出面数由 delta 和曲率场决定。

## 2. 构建与测试

构建目标：

```text
cmake --build cpp_adaiso/build2 --config Release --target adaiso_tests adaiso_cli
```

单元测试：

```text
ctest --test-dir cpp_adaiso/build2 -C Release --output-on-failure
```

结果：`adaiso_basic_tests` 通过。

备注：构建时 libigl `principal_curvature.cpp` 有 MSVC `C4701` 警告，来自第三方头实现，不影响本次运行。

## 3. 验收命令

对 `T0.off` 到 `T5.off` 运行：

```text
adaiso_cli <input> -o <case>/output.obj
  --iters 10
  --preprocess 0
  --curvature-mode principal-max
  --csf-alpha 2.0
  --gt <same input>
  --cd-samples 100000
  --export-target-field <case>/target_field
  --summary-json <case>/summary.json
  --quiet
```

输出目录：

```text
cpp_adaiso/results/v5.1.0_T0_T5_delta_default/T/<model>
```

对照数据：

```text
cpp_adaiso/results/v5.0.2_T0_T5_target_metric_edge_length/T/<model>/summary.json
```

## 5. 总体结论

默认 `delta = 0.001 * bbox_diagonal` 暂不适合作为可接受默认值。

主要原因：

- 输出面数平均只有 v5.0.2 的约 51.7%，默认网格明显更粗。
- 平均 final violation 比 v5.0.2 高约 0.1193。
- 平均 CD 比 v5.0.2 高约 19.69%。
- 平均 symmetric RMSE 比 v5.0.2 高约 9.38%。
- qmin 平均提升约 0.0745，说明粗化后质量指标更好，但这是以几何误差和 target metric violation 退化为代价。

按验收规则，本组判定为 `regression`。

## 6. 下一步建议

优先扫描更小的 delta：

```text
delta = {0.0005, 0.00025, 0.0001} * bbox_diagonal
```

目标是让 `estimated_faces/output_faces` 回到 v5.0.2 同量级，再比较 CD/RMSE 和 violation。

如果更小 delta 仍然 violation 高，下一步检查：

- principal curvature 的 `kappa_max` 是否被局部异常点支配。
- 是否需要用 `p99(kappa)` 或 capped `kappa_max` 做稳健上界。
- `h_max = 5.0 * mean_edge_length` 是否让低曲率区过粗。
