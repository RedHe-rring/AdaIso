# v5.3.0 修改方向：将尺寸场逼近与网格质量提升分阶段

## 1. 背景

v5.2.0 将局部算子的质量控制目标改为直接提升最小角，实验表明最小角和 qmin 有改善，但面数、尺寸场 violation 和运行时间明显变差。

v5.2.1 将“必须提升最小角”放宽为“禁止生成比当前局部更坏的角”，实验表明面数和尺寸场 violation 回收明显，但最小角收益回撤。

这说明当前问题不只是某一个接受准则的松紧，而是 remesh 主循环把不同目标混在了一起：

```text
split / collapse / flip / relocation
```

在同一个循环中同时服务：

```text
尺寸场逼近
连接关系调整
坏角修复
几何平滑
```

这会导致算子目标互相干扰，也让方法叙事容易被理解成工程拼接。因此 v5.3.0 应把 remesh 阶段拆成清晰的阶段化流程。

本文件只讨论 remesh 操作阶段，不包括尺寸场计算。

## 2. 总体目标

v5.3.0 的核心目标是将 remeshing 明确分成两个主要优化阶段：

```text
Stage A: Size-field fitting
Stage B: Quality repair
Stage C: Projection and cleanup
```

其中：

- Stage A 只负责让边长接近目标尺寸场。
- Stage B 只负责改善网格质量，尤其是坏角。
- Stage C 只负责最终几何投影、退化清理和统计输出。

推荐第一版保持最干净的结构：

```text
Stage A = split + collapse
Stage B = flip + relocation
Stage C = projection + cleanup
```

暂不把 relocation 放进 Stage A。若实验发现 Stage A 输出过于毛躁，再在 v5.3.1 中加入轻量的 size-field preserving relocation。

## 3. Stage A：尺寸场逼近

### 3.1 目标

Stage A 的目标是调整采样密度：

```text
让边长 ratio 接近目标区间 [collapse_factor, split_factor]
```

这里的目标不是修复坏角，也不是优化 valence。

### 3.2 操作

Stage A 只执行：

```text
split
collapse
```

不执行：

```text
flip
relocation
```

原因是 split/collapse 改变采样密度，而 flip/relocation 改变连接和点位质量。先把密度问题收敛，再进入质量修复阶段，目标更清晰。

### 3.3 接受准则

split：

```text
if edge_ratio > split_factor:
  split candidate edge
```

collapse：

```text
if edge_ratio < collapse_factor:
  try collapse candidate edge
```

collapse 需要继续保留已有合法性约束：

- link condition
- boundary skip
- non-manifold skip
- feature-aware collapse point
- collapse 后新边不能超过 split 阈值
- collapse 后 patch 不能退化或翻转

角度约束在 Stage A 中只作为安全底线：

```text
after_min_angle + tol >= min(before_min_angle, angle_floor)
```

含义：

- 如果当前局部已经低于角度底线，不允许继续变坏。
- 如果当前局部高于角度底线，允许略微下降，但不能跌破底线。
- 不要求 Stage A 主动提升最小角。

这样 Stage A 的主职责仍然是尺寸场逼近，而不是坏角修复。

### 3.4 终止条件

Stage A 应有独立循环：

```text
for iter in size_stage_iters:
  split_long_edges
  collapse_short_edges
  cleanup_degenerate_faces
  if no split and no collapse:
    break
```

第一版可以复用现有总迭代次数作为 `size_stage_iters`，暂不新增 CLI 参数。后续如果需要再拆分为 `--size-iters` 和 `--quality-iters`。

## 4. Stage B：质量修复

### 4.1 目标

Stage B 的目标是改善三角形质量，主指标是：

```text
local_min_angle
```

qmin/qavg 继续作为 summary 和实验对比指标，但不作为局部接受准则的主目标。

### 4.2 操作

Stage B 执行：

```text
flip
relocation
```

第一版不做常规 collapse。collapse 已经属于 Stage A 的采样密度操作，若在 Stage B 中常规使用，会重新模糊“质量修复是否也在改密度”的边界。

Stage B 仅保留必要的退化清理，不把 collapse 作为主要质量算子。

### 4.3 flip 接受准则

flip 应以最小角修复为主，不再让 valence 压过角度质量。

基本约束：

```text
reject if new triangles degenerate or inverted
reject if new diagonal target ratio outside [collapse_factor, split_factor]
reject if dihedral exceeds max_flip_dihedral_degrees
reject if avoid_obtuse_flip and new triangles obtuse
```

质量接受准则：

```text
if before_min_angle < angle_floor:
  accept only if after_min_angle > before_min_angle + angle_tol
  and target_metric_violation does not significantly worsen

else:
  accept if after_min_angle + angle_tol >= before_min_angle
  and target_metric_violation does not significantly worsen
```

valence 只作为最后的 tie-break：

```text
if angle is unchanged within tolerance
and target_metric_violation is unchanged within tolerance:
  accept only if valence objective improves
```

### 4.4 relocation 接受准则

relocation 是 Stage B 的主要点位质量修复算子。

流程：

```text
for each smooth vertex:
  generate tangent smoothing candidate
  project candidate if needed
  evaluate one-ring patch before/after
  accept or rollback
```

接受准则：

```text
if candidate non-finite:
  reject

if before_min_angle < angle_floor:
  accept only if after_min_angle > before_min_angle + angle_tol
  and target_metric_violation does not significantly worsen

else:
  accept if after_min_angle + angle_tol >= before_min_angle
  and target_metric_violation does not significantly worsen
```

这里的关键点是：Stage B 可以主动修坏角，但仍然受尺寸场 violation 约束，不能把 Stage A 已经建立的边长分布系统性破坏掉。

### 4.5 终止条件

Stage B 也应有独立循环：

```text
for iter in quality_stage_iters:
  flip_quality_edges
  relocate_quality_vertices
  cleanup_degenerate_faces
  project_if_needed
  if no accepted flip and no accepted relocation:
    break
```

第一版可临时使用现有迭代次数控制，或者内部拆成：

```text
size_stage_iters = remesh_iterations
quality_stage_iters = remesh_iterations
```

是否暴露 CLI 留到实验后决定。

## 5. Stage C：投影、清理与统计

Stage C 不承担主要优化目标，只负责合法化和输出：

```text
project to reference/input surface
cleanup degenerate faces
rebuild topology/connectivity if needed
emit summary and diagnostics
```

统计应保留：

- faces out/in
- RMSE / CD
- min_angle_degrees
- angle_lt_10_pct
- angle_lt_20_pct
- qmin / qavg
- target_metric_violation
- runtime

新增阶段统计建议：

- size_stage_iterations
- size_stage_splits
- size_stage_collapses
- quality_stage_iterations
- quality_stage_flips
- quality_stage_relocations
- quality_stage_rejected_by_angle
- quality_stage_rejected_by_metric

## 6. 代码修改方向

当前代码中 remesh 操作集中在一个主循环内。v5.3.0 应重构为两个明确入口：

```cpp
runSizeFieldFittingStage();
runQualityRepairStage();
```

建议结构：

```text
remesh()
  build target field
  initialize topology/statistics
  runSizeFieldFittingStage()
  runQualityRepairStage()
  finalProjectionAndCleanup()
  write summary/diagnostics
```

不要只在原循环中增加 `if stage == A/B`。两个 stage 应有独立的：

- 迭代终止条件
- 接受准则
- 操作统计
- verbose 输出
- summary 字段

需要清理或调整的旧逻辑：

- 从主 remesh 循环中移除混排的 `split -> collapse -> flip -> relocation` 调度。
- Stage A 中不调用 flip。
- Stage A 中不调用 tangent/MLS relocation。
- Stage B 中不做常规 short-edge collapse。
- 保留 v5.2.1 的角度安全准则作为 Stage A collapse 的硬约束。
- 将 v5.2.0 的“坏角必须改善”逻辑移动到 Stage B 的 flip/relocation 中。

## 7. 实验计划

v5.3.0 实验不应只看最终质量是否提升，还要验证阶段拆分是否让目标更清楚。

### 7.1 基础验证

```text
cmake --build cpp_adaiso/build2 --config Release
ctest --test-dir cpp_adaiso/build2 -C Release --output-on-failure
```

### 7.2 T 系列

运行完整 T 系列，和 v5.2.1、v5.2.0 对比：

- success count 是否仍为 31/31
- faces out/in 是否接近或优于 v5.2.1
- target_metric_violation 是否接近或优于 v5.2.1
- min_angle_degrees 是否高于 v5.2.1
- angle_lt_10_pct / angle_lt_20_pct 是否低于 v5.2.1
- RMSE / CD 是否无系统性恶化
- runtime 是否不明显高于 v5.2.0

### 7.3 阶段诊断

每个模型建议额外记录：

```text
after Stage A:
  faces out/in
  violation
  min_angle
  angle<10%
  angle<20%

after Stage B:
  faces out/in
  violation
  min_angle
  angle<10%
  angle<20%
```

这样可以判断：

- Stage A 是否真正完成尺寸场逼近。
- Stage B 是否在不破坏尺寸场的前提下改善坏角。
- 坏角主要来自 Stage A 的 split/collapse，还是来自输入模型本身。

## 8. 暂不纳入 v5.3.0 的内容

以下内容先不放进 v5.3.0，避免版本目标发散：

- 不修改 v5.1.5 的尺寸场计算公式。
- 不新增 Stage A relocation。
- 不新增 feature graph。
- 不引入新的公开 CLI 调参入口。
- 不把 qmin 重新作为局部主优化目标。
- 不在 Stage B 中做常规 collapse。

## 9. 预期判断

如果 v5.3.0 成功，预期结果应是：

```text
相比 v5.2.1:
  min_angle / angle<10% / angle<20% 改善
  faces out/in 和 violation 不明显恶化

相比 v5.2.0:
  faces out/in / violation / runtime 改善
  最小角收益不完全丢失
```

方法叙事上，v5.3.0 应从“给局部算子不断加限制”转为：

```text
先逼近尺寸场，再在尺寸场约束下修复网格质量。
```

这能更清楚地区分采样密度目标和单元质量目标，也更容易解释各算子的职责。
