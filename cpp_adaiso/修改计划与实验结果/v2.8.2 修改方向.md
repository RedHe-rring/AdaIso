# v2.8.2 修改方向：调整 split/collapse 阈值迟滞关系

## 背景问题

当前观察到一个不稳定现象：同一轮迭代中，刚被 `splitLongEdges()` 分裂出来的新点，随后可能又在 `collapseShortEdges()` 中被塌缩掉。该现象会导致分裂和塌缩互相抵消，并且塌缩可能破坏局部高曲率特征。

当前 `code` variant 的阈值关系为：

```cpp
splitFactor() = 1.33
collapseFactor() = 0.8
```

如果某条边的长度比为：

```text
L / h = 1.4
```

则该边会满足分裂条件：

```text
1.4 > splitFactor = 1.33
```

分裂后产生的两条半边近似为：

```text
(L / 2) / h = 0.7
```

而该值又满足塌缩条件：

```text
0.7 < collapseFactor = 0.8
```

因此，即使尺寸场本身没有问题，也会由于阈值迟滞区间不足，天然出现“刚分裂就可塌缩”的冲突。

## 修改目标

扩大分裂和塌缩之间的迟滞区间，使分裂后的半边不会立即进入塌缩区间。

理论上需要满足：

```text
splitFactor > 2 * collapseFactor
```

当前：

```text
2 * collapseFactor = 1.6
```

因此将 `code` variant 的 `splitFactor` 从 `1.33` 调整为 `1.65`：

```text
1.65 > 1.6
```

这样边刚达到分裂阈值后，分裂产生的半边长度比约为：

```text
1.65 / 2 = 0.825
```

略高于塌缩阈值 `0.8`，不会在同一轮中立即成为塌缩候选。

## 代码修改位置

目标文件：

```text
cpp_adaiso/src/AdaIsoRemesher.cpp
```

目标函数：

```cpp
double AdaIsoConfig::splitFactor() const
```

当前实现：

```cpp
double AdaIsoConfig::splitFactor() const {
  return variant == Variant::Paper ? 5.0 / 3.0 : 1.33;
}
```

建议修改为：

```cpp
double AdaIsoConfig::splitFactor() const {
  return variant == Variant::Paper ? 5.0 / 3.0 : 1.65;
}
```

本次只调整 `code` variant；`paper` variant 保持 `5.0 / 3.0` 不变。

## 追加修改：flip 添加二面角约束

### 背景

当前 `flipEdges()` 已有以下限制：

```text
1. 只翻转内部边；
2. 新边不能已存在；
3. 新边长度必须落在 collapse/split 阈值之间；
4. flip 后必须改善 valence；
5. avoid_obtuse_flip=true 时，翻转后的两个三角形不能是钝角三角形。
```

但当前没有真正的二面角约束。`flipEdges()` 中虽然会用旧三角形法向和来决定新三角形朝向，但这只是 orientation 修正，不会阻止 flip 穿过锐特征，也不会阻止 flip 后生成新的强折角。

### 修改目标

为 flip 添加局部二面角保护：

```text
1. 如果待翻转边两侧旧三角形的法向夹角超过阈值，则跳过 flip；
2. 如果翻转后新边两侧新三角形的法向夹角超过阈值，则跳过 flip。
```

默认阈值：

```text
max_flip_dihedral_degrees = 45.0
```

这样可以同时保护原有锐边，并避免 flip 引入新的强折角。

### 代码修改位置

目标文件：

```text
cpp_adaiso/include/adaiso/AdaIsoRemesher.hpp
cpp_adaiso/src/AdaIsoRemesher.cpp
cpp_adaiso/src/main.cpp
```

新增配置字段：

```cpp
double max_flip_dihedral_degrees = 45.0;
```

新增 CLI 参数：

```text
--max-flip-dihedral-deg <v>
```

新增 summary JSON 字段：

```json
"max_flip_dihedral_degrees": 45
```

核心判断逻辑：

```cpp
const double max_flip_dihedral = config_.max_flip_dihedral_degrees * kPi / 180.0;

if (faceNormalAngle(mesh.vertices, tri1, tri2) > max_flip_dihedral) {
  continue;
}

Eigen::Vector3i new1 = orientTriangle(Eigen::Vector3i(c, d, b), mesh.vertices, ref_normal);
Eigen::Vector3i new2 = orientTriangle(Eigen::Vector3i(d, c, a), mesh.vertices, ref_normal);
if (faceNormalAngle(mesh.vertices, new1, new2) > max_flip_dihedral) {
  continue;
}
```

### 预期影响

- 减少 flip 对局部锐特征和折角区域的破坏。
- 避免 valence 改善驱动的 flip 在几何上引入强法向跳变。
- 可能降低 `flip_count`，使部分 valence 优化无法执行。
- 如果阈值过严，可能导致规则化不足；后续可比较 `30° / 45° / 60°`。

## 预期影响

- 减少同一轮中 split 后立即 collapse 的概率。
- 降低分裂/塌缩互相抵消导致的局部拓扑震荡。
- 可能减少局部特征被塌缩破坏的情况。
- 分裂会变得更保守，输出顶点数可能下降。
- 部分高曲率区域加密可能减少，需要结合 CD、RMSE、edge-target ratio 和可视化判断。

## 风险

该修改只解决阈值迟滞不足的问题，不能完全解决所有特征破坏问题。如果塌缩本身缺少曲率、法向或新点冷却保护，高曲率区域仍可能发生不合理塌缩。

后续如仍出现特征破坏，应继续考虑：

```text
1. 新分裂顶点 age < 1 时禁止参与 collapse；
2. collapse 阶段加入曲率/法向变化保护；
3. 每轮结束后重新计算 curvature -> CSF -> target field；
4. 实验先 collapse 后 split 的迭代顺序。
```

## 建议实验

对比 v2.8.1 基线和 v2.8.2：

```text
baseline: splitFactor = 1.33, collapseFactor = 0.8
v2.8.2:  splitFactor = 1.65, collapseFactor = 0.8
```

重点观察：

```text
split_count
collapse_count
tail ops
violation_rate
max edge-target ratio
Qavg / Qmin
CD / RMSE
局部高曲率区域是否仍被塌缩破坏
```

如果 `split_count` 明显下降但 CD/RMSE 变差，说明分裂阈值可能过保守；可继续测试 `1.60`、`1.62`、`1.70` 等值。
