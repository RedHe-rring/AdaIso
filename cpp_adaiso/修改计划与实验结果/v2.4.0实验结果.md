# cpp_adaiso v2.4.0 实验结果

## 实验配置

- 版本：`cpp_adaiso 2.4.0`。
- 变更：目标边长从五档 histogram 映射改为连续经验分位数映射。
- 输入：`hand.obj`、`bunny.obj`、`T0.off` 到 `T10.off`、`C0.obj` 到 `C7.obj`、`wine_glass3.ply`、`wine_glass24.ply`、`chair36.ply`。
- 缺失输入：`cpp_adaiso/examples/C5.obj`。
- wine glass 和 chair 原始输入为 binary little-endian PLY；因 CLI 仅支持 ASCII PLY，本次追加实验使用等价 ASCII 副本：`wine_glass3_ascii_input.ply`、`wine_glass24_ascii_input.ply`、`chair36_ascii_input.ply`。
- 输出目录：`cpp_adaiso/results/v2.4.0_experiments/`。
- 输出格式：ASCII PLY。
- 参数：`--variant code --mesh-scale 1.0 --iters 10 --preprocess 0 --project 1 --target-mode gaussian --target-k 8 --target-sigma-factor 1.0 --csf-alpha 0.5 --target-min-factor 0.6 --target-max-factor 1.8 --target-gamma 1.0 --quiet`。
- CD 设置：`--gt <input mesh>`，`--cd-samples 100000`。
- 汇总 CSV：`cpp_adaiso/results/v2.4.0_experiments/run_summary.csv`。

命令模板：


## Edge Ratio 指标口径

- `target(e) = min(targetAt(v0), targetAt(v1))`。
- `ratio(e) = length(e) / target(e)`。
- `violation = ratio < collapseFactor || ratio > splitFactor`，本组参数下为 `ratio < 0.8 || ratio > 1.33`。
- `Final Viol.` 为第 10 轮结束后的 `violation_rate`。
- `Tail Viol.` 为第 6-10 轮 `violation_rate` 平均值。
- `Tail Ops` 为第 6-10 轮 `split_count + collapse_count + flip_count` 平均值。
- `Delta Ops` 为第 7-10 轮相邻总操作数绝对变化的平均值。

## 判断

- 质量方面：原 20 个成功样例中，Qavg 提高 15 个，Qmin 提高 17 个；整体平均 Qavg 从 0.873577 提高到 0.878572，最差 Qmin 从 0.051462 提高到 0.173133。连续 h 映射对质量，尤其是最差三角形质量，有明确正收益。
- CD 方面：原 20 个成功样例中，CD 降低 12 个；整体平均 CD 从 8.560E-02 降到 6.250E-02，但 hand、T0、T1、T4、T10、C1、C6、C7 的 CD 变高。CD 平均下降主要受 C2 大幅下降影响，不能认为连续 h 映射稳定降低 CD。
- 分组看：T0-T10 的 Qavg 全部提高，Qmin 10/11 提高，CD 7/11 降低，是本次最稳定的收益组；C0-C7 的平均 CD 明显下降，但平均 Qavg 略低于 v2.3.0，说明不同模型上需要继续调 `target_gamma` 或 target factor 范围。
- 追加 wine_glass：`wine_glass3` 最终 qavg=0.864782、qmin=0.151069、final_viol=0.086002，质量明显改善但 10 轮仍未完全收敛；`wine_glass24` 最终 qavg=0.153868、qmin=3.30372E-05、final_viol=0.639469，当前参数下质量退化且明显未收敛，应视为失败/异常样例。
- 追加 chair36 preprocess1：打开 `--preprocess 1` 后输出规模从 10,563 / 21,138 增到 138,065 / 276,129，运行 990.998 s，final_viol=0.701977，tail_viol=0.699498，qavg 从 0.274514 降到 0.114434。该结果明显未收敛，且预处理造成严重过细化。
- 结论：v2.4.0 连续 h 映射提高了原 20 个样例的网格质量，特别是 Qmin；CD 有平均改善但逐例不稳定。追加 wine_glass 和 chair36 preprocess1 结果显示该参数组对某些细长/退化输入并不稳健，不应把本次修改表述为稳定收敛或稳定降低 CD。
