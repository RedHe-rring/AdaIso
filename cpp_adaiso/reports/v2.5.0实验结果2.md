## 实验设置

- 代码版本：当前工作区代码。
- 可执行文件：`cpp_adaiso/build/adaiso_cli.exe`
- 输入模型：`cpp_adaiso/examples/` 中除 `T0-T10` 外的 T 系列模型。
- 模型列表：`T21, T30, T33, T34, T36, T38, T44, T48, T51, T53, T57, T67, T71, T72, T82, T86, T87, T96`
- 输出目录：`cpp_adaiso/results/v2.5.0_results2_extra_T/remesh_iter10/`
- 参数：
  - `--variant code`
  - `--mesh-scale 1.0`
  - `--iters 10`
  - `--preprocess 0`
  - `--project 1`
  - `--gt <same input mesh>`
  - `--cd-samples 100000`
  - 未显式传入 `--csf-alpha`，使用当前默认值 `2.0`

命令模板：

```powershell

  --mesh-scale 1.0 `

  --summary-json cpp_adaiso/results/v2.5.0_results2_extra_T/remesh_iter10/<model>/summary.json `
  --quiet
```

  - `stats.csf_solver_success = true`

## 分析

整体来看，当前 `csf_alpha = 2.0` 默认配置在额外 T 系列上保持了稳定的平均质量提升。18 个模型的 `Qavg` 全部提升，且大多数输出 `Qmin` 提升到 `0.46` 以上。边长目标跟踪也较稳定，`mean_ratio` 基本集中在 `1.02-1.03`，多数模型 `p95_ratio` 低于 `1.26`。

`T48` 的整体质量最好，输出 `Qavg = 0.9054`、`Qmin = 0.5964`，同时 `violation_rate = 0.0093`。`T71` 的几何保真性最好，CD 为 `3.134e-06`，RMSE 为 `1.252e-03`。`T33` 和 `T72` 也表现较好，CD 分别为 `3.681e-06` 和 `5.306e-06`。

主要异常是 `T34`。它的输出面数从 `18462` 增加到 `21472`，`Qmin` 仍接近退化，`violation_rate = 0.1130`，运行时间也最高。该模型说明当前局部 remeshing 操作对个别退化或复杂区域仍可能持续扰动，尺寸场稳定并不必然保证最坏三角形质量改善。`T36` 和 `T82` 的 CD 偏高，说明在部分模型上质量提升和几何保真性之间仍存在取舍。

结论：额外 T 系列整体支持当前 v2.5.0 尺寸场和 `csf_alpha = 2.0` 默认值的有效性。平均质量提升明显，目标边长跟踪稳定，CD 处于 `1e-05` 量级。但后续如果目标是进一步稳定最坏质量和保真性，需要重点分析 `T34`、`T36`、`T82`、`T87` 这类异常或偏高 CD 样本。
