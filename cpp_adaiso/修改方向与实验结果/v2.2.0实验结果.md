# cpp_adaiso v2.2.0 实验结果

## 实验配置

- 版本：`cpp_adaiso 2.2.0`
- 变更：默认 target field 从 nearest-neighbor 改为 Gaussian kNN 插值，并新增每轮 edge ratio 稳定性指标。
- 输入：`hand.obj`、`bunny.obj`、`C0.obj` 到 `C7.obj`、`T0.off` 到 `T10.off`。
- 缺失输入：`cpp_adaiso/examples/C5.obj`。
- 输出目录：`cpp_adaiso/results/v2.2.0_experiments/`。
- 输出格式：ASCII PLY。
- 参数：`--variant code --mesh-scale 1.0 --iters 10 --preprocess 0 --project 1 --target-mode gaussian --target-k 8 --target-sigma-factor 1.0 --quiet`。
- CD 设置：`--gt <input mesh>`，`--cd-samples 100000`。
- 构建与测试：`ctest --test-dir cpp_adaiso/build --output-on-failure` 通过。

命令模板：

```powershell
cpp_adaiso/build/adaiso_cli.exe <input> `
  -o cpp_adaiso/results/v2.2.0_experiments/<case>_v2.2.0_iter10_project1_gaussian.ply `
  --variant code `
  --mesh-scale 1.0 `
  --iters 10 `

  --project 1 `
  --target-mode gaussian `

  --target-sigma-factor 1.0 `

  --summary-json cpp_adaiso/results/v2.2.0_experiments/<case>_v2.2.0_iter10_project1_gaussian.json `
  --quiet
```

## Edge Ratio 指标口径

- `target(e) = min(targetAt(v0), targetAt(v1))`。
- `ratio(e) = length(e) / target(e)`。
- `violation = ratio < collapseFactor || ratio > splitFactor`，本组参数下为 `ratio < 0.8 || ratio > 1.33`。
- `Final Viol.` 为第 10 轮结束后的 `violation_rate`。
- `Tail Viol.` 为第 6-10 轮 `violation_rate` 平均值。
- `Tail Ops` 为第 6-10 轮 `split_count + collapse_count + flip_count` 平均值。
- `ΔOps` 为第 7-10 轮相邻总操作数绝对变化的平均值。

### 判断

- 从 edge-ratio 稳定性看，Gaussian kNN 有明确效果：20 个成功样例中，Gaussian 的最终 violation_rate 全部低于 nearest；总体均值从 nearest 的 0.019823 降到 0.011842，相对下降 40.3%。
- 从后 5 轮稳定性看，Gaussian 的 tail_violation_rate_mean 在 20 个成功样例中全部低于 nearest；总体均值从 0.020043 降到 0.012352，相对下降 38.4%。这直接支持连续/平滑 target field 减少目标场边界附近边长违规。
- 从局部操作震荡看，Gaussian 的后 5 轮操作数均值从 182.55 降到 95.10，下降 47.9%；后 4 个操作数变化量均值从 16.19 降到 15.61，下降 3.6%。操作总量下降明显，操作数变化幅度改善较弱。
- 从质量看，Gaussian 的平均 qavg 从 0.903499 提高到 0.904602；但最小 qmin 从 nearest 的 0.192271 降到 0.067768，主要来自 C0。这说明高斯插值提升稳定性时，个别复杂模型的最小三角质量需要继续关注。
- 从 CD 看，总体平均 CD 从 nearest 的 8.485E-002 降到 8.423E-002，差异很小；几何误差基本持平。
- 从成本看，Gaussian kNN 查询更贵，总体平均运行时间约为 nearest 的 2.10x。若以收敛稳定性为优先，Gaussian kNN 值得作为默认；若只追求速度，可通过 --target-mode nearest 保持旧行为。
