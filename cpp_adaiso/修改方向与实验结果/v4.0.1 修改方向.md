从选择两个固定点到选择多个固定点-》6-10个
- 1 个低曲率区稳定点
- 1 个高曲率区稳定点
- 剩余点从稳定候选中选择，并要求与已有固定点尽量远


一般可以直接设置：

```cpp
int anchor_count = std::clamp(
    static_cast<int>(std::log2(component.size())),
    4,
    8);
```

例如：

|  分量顶点数 | 固定点数 |
| -----: | ---: |
|  20～31 |    4 |
|    100 |    6 |
|  1,000 |    8 |
| 10,000 |    10 |

上限先设为 10，足够简单，也不容易过度约束。

## 快速选点流程

先计算每个顶点的稳定性：

[
d_i=
\left|
c_i-
\frac{\sum_jw_{ij}c_j}{\sum_jw_{ij}}
\right|.
]

然后：

1. 在曲率最低的 30% 中选 (d_i) 最小的点；
2. 在曲率最高的 30% 中选 (d_i) 最小的点；
3. 将变化量较小的前 30% 顶点作为候选；
4. 每次从候选中选择距已有固定点最远的顶点，直到达到固定点数量。



## 极简实现规则

不想做 BFS，可以采用这个版本：

```cpp
// 候选点按 change 从小到大排列
for (int v : candidates) {
  bool too_close = false;

  for (int anchor : anchors) {
    if (v == anchor ||
        areNeighbors(adjacency, v, anchor) ||
        haveCommonNeighbor(adjacency, v, anchor)) {
      too_close = true;
      break;
    }
  }

  if (!too_close) {
    anchors.push_back(v);
  }

  if (anchors.size() >= anchor_count) {
    break;
  }
}
```

这相当于要求固定点至少相隔约两个图边，虽然粗糙，但比一窝蜂聚在平坦区域强得多。
