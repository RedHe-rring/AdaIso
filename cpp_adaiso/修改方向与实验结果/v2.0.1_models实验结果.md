## 实验配置

- 版本：`cpp_adaiso 2.0.1`
- 输入：`cpp_adaiso/examples/model_001.off` 到 `cpp_adaiso/examples/model_010.off`
- 输出目录：`cpp_adaiso/results/v2.0.1_models/`
- 参数：`--variant code --mesh-scale 1.0 --iters 10 --preprocess 0 --project 1 --quiet`

命令模板：

```powershell
cpp_adaiso/build/adaiso_cli.exe cpp_adaiso/examples/model_{i:000}.off `
  -o cpp_adaiso/results/v2.0.1_models/model_{i:000}_iter10_project1.obj `
  --variant code `
  --mesh-scale 1.0 `
  --iters 10 `
  --preprocess 0 `
  --project 1 `
  --summary-json cpp_adaiso/results/v2.0.1_models/model_{i:000}_iter10_project1.json `
  --quiet
```

说明：我在本地构建的 `adaiso_cli.exe` 上批量运行并采集了可用样例的 summary；如果某个样例缺失 summary（文件不存在），会在下面注明。
