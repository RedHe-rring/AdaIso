# cpp_adaiso v4.0.1 T0-T10 实验结果

## 实验配置

- 版本：当前 `v4.0.1` 工作区代码。
- 变更重点：CSF Dirichlet Laplace 固定点选择从每分量 2 个稳定锚点扩展为每分量 4-10 个多固定点。
- 输入：`T0.off` 到 `T10.off`。
- Remesh 输出目录：`cpp_adaiso/results/v4.0.1_T0_T10/`。
- 曲率可视化输出目录：`cpp_adaiso/results/v4.0.1_curvature_viz/`。
- Remesh 输出格式：ASCII PLY。
- Remesh 参数：`--variant code --mesh-scale 1.0 --iters 10 --preprocess 0 --project 1 --target-mode gaussian --target-k 8 --target-sigma-factor 1.0 --quiet`。
- CD 设置：`--gt <input mesh>`，`--cd-samples 100000`。
- 曲率可视化：`adaiso_curvature_viz --variant code`，raw 与 diffused 独立归一化为 blue-green-red 彩色 PLY。
- 构建与测试：`cmake --build cpp_adaiso/build --config Release` 通过，`ctest --test-dir cpp_adaiso/build --output-on-failure` 通过。

命令模板：

```powershell
cpp_adaiso/build/adaiso_cli.exe cpp_adaiso/examples/<case>.off `
  -o cpp_adaiso/results/v4.0.1_T0_T10/<case>_v4.0.1_iter10_project1_gaussian.ply `
  --variant code `
  --mesh-scale 1.0 `
  --iters 10 `
  --preprocess 0 `
  --project 1 `
  --target-mode gaussian `
  --target-k 8 `
  --target-sigma-factor 1.0 `
  --gt cpp_adaiso/examples/<case>.off `
  --cd-samples 100000 `
  --summary-json cpp_adaiso/results/v4.0.1_T0_T10/<case>_v4.0.1_iter10_project1_gaussian.json `
  --quiet

cpp_adaiso/build/adaiso_curvature_viz.exe cpp_adaiso/examples/<case>.off `
  --output-prefix cpp_adaiso/results/v4.0.1_curvature_viz/<case>_curvature `
  --variant code `
  --summary-json cpp_adaiso/results/v4.0.1_curvature_viz/<case>_curvature.json
```

## Edge Ratio 指标口径

- `Final Viol.` 为第 10 轮结束后的 `violation_rate`。
- `Tail Viol.` 为第 6-10 轮 `violation_rate` 平均值。
- `Tail Ops` 为第 6-10 轮 `split_count + collapse_count + flip_count` 平均值。
- `Delta Ops` 为第 6-10 轮相邻总操作数绝对变化的平均值。
