# CSF Dirichlet Laplace 直解改造

## Summary

将 `cpp_adaiso` 的 CSF 从显式迭代平滑彻底改为 Dirichlet Laplace 稀疏线性系统求解。旧迭代参数、统计字段和实现全部删除，不提供新旧算法切换。当前仓库没有 `--csf-*` CLI 选项或配置文件映射，因此 CLI 清理重点是保持旧参数为 `unknown option`，并更新帮助、summary 与文档。

## Key Changes

- 在 `AdaIsoConfig` 中删除 `csf_max_iterations`、`csf_tolerance`、`csf_mu`，同时把 `cot_min_weight` 收敛为内部常量 `kCsfEta = 1e-4`；`variant=paper|code` 继续控制权重公式。
- 新增内部可测 CSF 求解模块，例如 `src/CsfSolver.hpp/.cpp`，放在 `adaiso::detail` 命名空间：
  - 构建对称正权重邻接图；
  - 按连通分量选择锚点；
  - 直接装配约化系统 `A s_F = b`；
  - 用 `Eigen::SimplicialLDLT<Eigen::SparseMatrix<double>>` 求解；
  - 失败、非有限解或残差超阈值时抛出明确错误，不回退旧算法。
- `computeCsf()` 只负责初始曲率计算、权重图构建、调用直解器并返回平滑曲率；删除所有迭代循环、`mu` 更新、提前停止和迭代计数逻辑。
- 连通分量锚点策略按你的规格实现：普通分量固定局部 `vmax/vmin`，单点保留原值，双点全固定，常数曲率分量跳过求解。
- `AdaIsoStats` 删除 `csf_iterations`，改为输出直解统计：
  - `csf_assembly_time_ms`
  - `csf_factorization_time_ms`
  - `csf_solve_time_ms`
  - `csf_residual_abs`
  - `csf_residual_scaled`
  - `csf_free_vertices`
  - `csf_fixed_vertices`
  - `csf_matrix_nonzeros`
  - `csf_solver_success`
- 更新 `summary` JSON，只保留直解相关 CSF 统计；不再出现旧迭代字段。
- 将 `CMakeLists.txt` 项目版本改为 `2.0.0`，新增 `CHANGELOG.md` 并标记 breaking change。

## Implementation Details

- 权重从无向边只构建一次，再双向写入邻接表：
  - `paper`: 使用当前 cotangent 规则，非有限或非正权重替换为 `kCsfEta`；
  - `code`: 在 `paper` 权重基础上除以 `max(edge_length, kMinEdgeLength)`；
  - 边界边沿用当前 `cotangentEdgeWeights()` 的单相对角规则。
- 约化系统装配规则固定为：
  - `A(ii, ii) += w_ij`
  - 若 `j` 是自由点，`A(ii, jj) -= w_ij`
  - 若 `j` 是固定点，`rhs[ii] += w_ij * fixed_value[j]`
- 残差检查：
  - `abs = ||A*x - rhs||_2`
  - `scaled = 2*abs / (||A||_inf*||x||_inf + ||rhs||_inf + eps)`
  - 默认阈值 `kResidualThreshold = 1e-10`。
- `README.md`、`DESIGN_AND_IMPLEMENTATION.md` 和示例说明改为描述 Dirichlet Laplace 直解；删除“CSF iteration count”相关文字。
- 当前仓库无旧 `--csf-max-iterations` 等 CLI 解析代码；实现后仍通过现有 unknown-option 路径拒绝这些旧参数。

## Test Plan

- 在 `tests/basic_tests.cpp` 中通过内部 `adaiso::detail` 求解器直接测试四点链已知解：固定 `0` 和 `1`，自由点结果为 `1/3`、`2/3`。
- 增加调和残差、最大值原理、断开分量、常数曲率、`paper/code` 权重有限性和对称性测试。
- 扩展网格 smoke 测试：pyramid、开放边界、单三角形、断开网格、空网格、退化三角形、极短边。
- 删除所有关于 `csf_iterations`、`csf_mu` 和旧迭代参数的断言。
- 验证命令：
  - `cmake --build cpp_adaiso/build`
  - `ctest --test-dir cpp_adaiso/build --output-on-failure`
  - 手动跑 `adaiso_cli` 生成 summary，确认无旧字段、求解成功、残差达标、输出网格合法。

## Assumptions

- 接受破坏性接口变更，不保留 deprecated 字段或兼容开关。
- `2.0` 在 CMake 中落为语义化版本 `2.0.0`。
- 新增内部求解模块只用于工程内部和测试，不作为用户 CLI 或算法切换接口。
