# 从 Screened CSF 到渐变尺寸场的数学构建

## 1. 输入三角网格与基本记号

设输入三角网格为

[
\mathcal M=(V,E,F),
]

其中：

* (V={v_i}_{i=1}^n) 为顶点集合；
* (E) 为无向边集合；
* (F) 为三角面集合；
* (N(i)) 为顶点 (v_i) 的一环邻接顶点集合；
* (p_i\in\mathbb R^3) 为顶点位置；
* (n_i\in\mathbb R^3) 为顶点单位法向。

假设每个顶点至少属于一个非退化三角形，因此其面积质量严格为正。

顶点的 barycentric mass 定义为

[
m_i=\frac13\sum_{f\ni i}A_f,
]

其中 (A_f) 为三角形 (f) 的面积。对应质量矩阵为

[
M=\operatorname{diag}(m_1,\ldots,m_n).
]

网格平均边长定义为

[
\bar\ell
========

\frac1{|E|}
\sum_{(i,j)\in E}|p_i-p_j|.
]

---

## 2. 原始法向变化曲率场

对每个顶点 (v_i)，定义原始曲率描述量

[
r_i
===

\begin{cases}
\displaystyle
\frac1{|N(i)|}
\sum_{j\in N(i)}
\arccos!\left(
\operatorname{clamp}(n_i^\top n_j,-1,1)
\right),
&N(i)\neq\varnothing,[12pt]
0,&N(i)=\varnothing.
\end{cases}
]

向量形式记为

[
r=(r_1,\ldots,r_n)^\top.
]

该量衡量顶点法向与其一环邻居法向之间的平均夹角，因此：

[
r_i\geq 0.
]

在局部近似平坦区域，邻接法向接近一致，因此 (r_i) 较小；在折痕、尖锐细节或高弯曲区域，法向变化较大，因此 (r_i) 较大。

需要强调的是，(r_i) 是离散法向变化强度，不必等同于严格的平均曲率或高斯曲率。

---

## 3. Cotangent 拉普拉斯矩阵

对于内部边 ((i,j))，设该边两侧三角形中与边相对的角为 (\alpha_{ij}) 和 (\beta_{ij})，定义 cotangent 权重

[
\widetilde w_{ij}
=================

\frac12
\left(
\cot\alpha_{ij}
+
\cot\beta_{ij}
\right).
]

对于边界边，只使用唯一存在的对角：

[
\widetilde w_{ij}
=================

\frac12\cot\alpha_{ij}.
]

为保证权重非负以及后续系统的稳定性，采用截断权重

[
w_{ij}
======

\begin{cases}
\widetilde w_{ij},
&\widetilde w_{ij}>0
\text{ 且有限},\
\eta,
&\text{否则},
\end{cases}
]

其中 (\eta>0) 是小正数。

定义离散拉普拉斯矩阵 (L\in\mathbb R^{n\times n})：

[
L_{ij}
======

\begin{cases}
-w_{ij}, &(i,j)\in E,\ i\neq j,[4pt]
\displaystyle\sum_{k\in N(i)}w_{ik},&i=j,[8pt]
0,&\text{其他}.
\end{cases}
]

因为 (w_{ij}=w_{ji})，矩阵 (L) 对称。

对任意向量 (z\in\mathbb R^n)，有

[
z^\top Lz
=========

\sum_{(i,j)\in E}
w_{ij}(z_i-z_j)^2
\geq 0.
]

因此 (L) 是半正定矩阵。

---

## 4. Screened CSF 曲率场

### 4.1 能量定义

定义平滑曲率场

[
c=(c_1,\ldots,c_n)^\top
]

为以下能量的最小化解：

[
E_c(c)
======

\frac12(c-r)^\top M(c-r)
+
\frac{\lambda_c}{2}c^\top Lc.
]

展开可写为

[
E_c(c)
======

\frac12\sum_{i=1}^n
m_i(c_i-r_i)^2
+
\frac{\lambda_c}{2}
\sum_{(i,j)\in E}
w_{ij}(c_i-c_j)^2.
]

其中：

* 第一项是数据保真项，使 (c_i) 接近原始曲率 (r_i)；
* 第二项是平滑项，惩罚相邻顶点之间的曲率差；
* (\lambda_c>0) 控制平滑强度。

采用尺度一致参数

[
\lambda_c
=========

\alpha_c\bar\ell^2,
]

其中 (\alpha_c>0) 为无量纲参数。

---

### 4.2 一阶最优条件

对 (c) 求梯度：

[
\nabla E_c(c)
=============

M(c-r)+\lambda_cLc.
]

令梯度为零，得到

[
M(c-r)+\lambda_cLc=0,
]

即

[
\boxed{
(M+\lambda_cL)c=Mr.
}
]

逐顶点形式为

[
m_i(c_i-r_i)
+
\lambda_c
\sum_{j\in N(i)}
w_{ij}(c_i-c_j)
=0.
]

等价地，

[
c_i
===

\frac{
m_ir_i
+
\lambda_c
\sum_{j\in N(i)}w_{ij}c_j
}{
m_i
+
\lambda_c
\sum_{j\in N(i)}w_{ij}
}.
]

因此，(c_i) 是自身原始曲率 (r_i) 与邻域平滑值之间的加权折中。

---

### 4.3 解的存在性与唯一性

定义系统矩阵

[
A_c=M+\lambda_cL.
]

对任意非零向量 (z\neq0)，有

[
z^\top A_cz
===========

\sum_{i=1}^nm_iz_i^2
+
\lambda_c
\sum_{(i,j)\in E}
w_{ij}(z_i-z_j)^2.
]

由于

[
m_i>0,\qquad
w_{ij}\geq0,\qquad
\lambda_c>0,
]

第一项满足

[
\sum_i m_iz_i^2>0
]

对所有 (z\neq0) 成立。因此

[
z^\top A_cz>0.
]

所以 (A_c) 是对称正定矩阵。

由此可得：

[
\boxed{
(M+\lambda_cL)c=Mr
\text{ 存在唯一解。}
}
]

等价地，能量 (E_c) 是严格凸函数，因此具有唯一全局极小点。

---

### 4.4 最大值原理

记

[
r_{\min}=\min_i r_i,
\qquad
r_{\max}=\max_i r_i.
]

在 (m_i>0)、(w_{ij}\geq0) 的条件下，CSF 满足

[
\boxed{
r_{\min}\leq c_i\leq r_{\max},
\qquad i=1,\ldots,n.
}
]

证明如下。

设 (c_k=\max_i c_i)。由顶点方程：

[
c_k
===

\frac{
m_kr_k+
\lambda_c\sum_jw_{kj}c_j
}{
m_k+\lambda_c\sum_jw_{kj}
}.
]

由于 (r_k\leq r_{\max}) 且 (c_j\leq c_k)，若假设

[
c_k>r_{\max},
]

则有

[
m_kr_k+
\lambda_c\sum_jw_{kj}c_j
<
m_kc_k+
\lambda_c\sum_jw_{kj}c_k,
]

从而推出 (c_k<c_k)，产生矛盾。因此

[
c_k\leq r_{\max}.
]

最小值情形同理可得

[
c_i\geq r_{\min}.
]

---

### 4.5 尺度一致性

考虑对网格进行统一缩放：

[
p_i' = sp_i,
\qquad s>0.
]

则：

[
\bar\ell'=s\bar\ell,
\qquad
m_i'=s^2m_i.
]

法向夹角和三角形内角不随统一缩放变化，因此：

[
r'=r,\qquad
L'=L.
]

同时

[
\lambda_c'
==========

# \alpha_c(\bar\ell')^2

s^2\lambda_c.
]

缩放后的系统为

[
(M'+\lambda_c'L')c'
===================

M'r',
]

即

[
s^2(M+\lambda_cL)c'
===================

s^2Mr.
]

消去 (s^2)，得到

[
(M+\lambda_cL)c'=Mr.
]

由解的唯一性：

[
\boxed{c'=c.}
]

因此，采用

[
\lambda_c=\alpha_c\bar\ell^2
]

时，CSF 对网格的统一尺度变化保持不变。

---

## 5. CSF 的稳健归一化

为了将曲率映射到固定尺寸区间，先将 (c_i) 归一化到 ([0,1])。

选择两个稳健统计量：

[
c_{\mathrm{lo}}=P_p(c),
\qquad
c_{\mathrm{hi}}=P_{1-p}(c),
]

其中 (P_p) 表示经验 (p) 分位数，例如可取

[
p=0.05.
]

定义

[
\Delta c
========

c_{\mathrm{hi}}-c_{\mathrm{lo}}.
]

若

[
\Delta c\leq\varepsilon_c,
]

则认为 CSF 近似为常量场，不存在可靠的曲率排序。此时直接使用统一目标尺寸

[
h_i=h_{\mathrm{ref}},
]

其中可取

[
h_{\mathrm{ref}}
================

\operatorname{clamp}
\left(
\bar\ell,s_m,
h_{\min},
h_{\max}
\right),
]

(s_m) 为整体 mesh scale 参数。

若

[
\Delta c>\varepsilon_c,
]

定义归一化曲率

[
\boxed{
u_i
===

\operatorname{clamp}
\left(
\frac{c_i-c_{\mathrm{lo}}}
{c_{\mathrm{hi}}-c_{\mathrm{lo}}},
0,1
\right).
}
]

于是

[
0\leq u_i\leq1.
]

并且 (u_i) 关于 (c_i) 单调不减。

由于投影函数

[
\operatorname{clamp}(\cdot,0,1)
]

是 1-Lipschitz 的，因此对任意两个顶点有

[
|u_i-u_j|
\leq
\frac{|c_i-c_j|}{\Delta c}.
]

这一不等式将在尺寸渐变分析中使用。

---

## 6. 目标尺寸范围

定义最小和最大目标边长：

[
h_{\min}
========

\bar\ell,s_m f_{\min},
]

[
h_{\max}
========

\bar\ell,s_m f_{\max},
]

其中

[
0<f_{\min}\leq f_{\max}.
]

令尺寸动态范围为

[
R_h
===

\frac{h_{\max}}{h_{\min}}
\geq1,
]

并定义

[
\beta
=====

# \log R_h

\log\frac{h_{\max}}{h_{\min}}.
]

---

## 7. 线性 log-size 映射

定义 log-size

[
x_i^0=\log h_i^0.
]

采用关于归一化曲率 (u_i) 的线性映射：

[
\boxed{
x_i^0
=====

(1-u_i)\log h_{\max}
+
u_i\log h_{\min}.
}
]

等价地，

[
\boxed{
x_i^0
=====

## \log h_{\max}

\beta u_i.
}
]

最终原始目标尺寸为

[
\boxed{
h_i^0
=====

# \exp(x_i^0)

h_{\max}
\left(
\frac{h_{\min}}{h_{\max}}
\right)^{u_i}.
}
]

也可以写为几何插值形式：

[
h_i^0
=====

h_{\max}^{1-u_i}
h_{\min}^{u_i}.
]

---

## 8. 线性 log-size 映射的性质

### 8.1 范围保持性

由于

[
0\leq u_i\leq1,
]

有

[
\log h_{\min}
\leq
x_i^0
\leq
\log h_{\max}.
]

指数函数单调递增，因此

[
\boxed{
h_{\min}
\leq
h_i^0
\leq
h_{\max}.
}
]

且端点满足：

[
u_i=0
\quad\Longrightarrow\quad
h_i^0=h_{\max},
]

[
u_i=1
\quad\Longrightarrow\quad
h_i^0=h_{\min}.
]

---

### 8.2 单调性

因为

[
\frac{dx^0}{du}=-\beta\leq0,
]

所以 (x^0) 关于 (u) 单调不增。

又因为

[
h^0(u)
======

h_{\max}e^{-\beta u},
]

有

[
\frac{dh^0}{du}
===============

-\beta h^0(u)
\leq0.
]

因此：

[
\boxed{
u_i>u_j
\quad\Longrightarrow\quad
h_i^0<h_j^0.
}
]

即曲率越大，目标边长越小。

---

### 8.3 恒定相对灵敏度

线性 log-size 映射满足

[
\frac{1}{h^0}
\frac{dh^0}{du}
===============

-\beta.
]

因此

[
\boxed{
\left|
\frac{d\log h^0}{du}
\right|
=======

\beta
}
]

为常数。

这表示单位归一化曲率变化引起的尺寸相对变化率在整个区间内一致，不会在某一曲率区间突然变得特别敏感。

---

## 9. 线性 log-size 映射的最坏斜率最优性

考虑更一般的映射

[
x(u)
====

## \log h_{\max}

\beta\psi(u),
]

其中 (\psi) 满足：

[
\psi(0)=0,\qquad
\psi(1)=1,
\qquad
\psi'(u)\geq0.
]

由于

[
\psi(1)-\psi(0)
===============

# \int_0^1\psi'(u),du

1,
]

必然有

[
\sup_{u\in[0,1]}\psi'(u)\geq1.
]

否则若

[
\sup\psi'(u)<1,
]

则

[
\int_0^1\psi'(u),du<1,
]

与端点条件矛盾。

因此：

[
\sup_{u\in[0,1]}
\left|
\frac{dx}{du}
\right|
=======

\beta
\sup_{u\in[0,1]}\psi'(u)
\geq
\beta.
]

线性映射

[
\psi(u)=u
]

满足

[
\psi'(u)=1,
]

从而达到下界：

[
\boxed{
\sup_{u\in[0,1]}
\left|
\frac{dx}{du}
\right|
=======

\beta.
}
]

因此，在所有满足相同端点值的单调映射中，线性 log-size 映射使最大 log-size 斜率最小。

换言之，它在覆盖完整尺寸区间的同时，具有最小的最坏局部比例变化放大率。

---

## 10. 相邻尺寸比例与 gradation 条件

对任意边 ((i,j)\in E)，有

[
x_i^0-x_j^0
===========

-\beta(u_i-u_j).
]

因此

[
\left|
x_i^0-x_j^0
\right|
=======

\beta|u_i-u_j|.
]

又因为

[
x_i^0-x_j^0
===========

\log\frac{h_i^0}{h_j^0},
]

所以

[
\boxed{
\left|
\log\frac{h_i^0}{h_j^0}
\right|
=======

\beta|u_i-u_j|.
}
]

设允许的最大相邻尺寸比例为 (g>1)。要求

[
\frac1g
\leq
\frac{h_i^0}{h_j^0}
\leq
g
]

等价于

[
\left|
\log\frac{h_i^0}{h_j^0}
\right|
\leq
\log g.
]

因此，对于线性 log-size 映射，逐边 gradation 条件等价于

[
\boxed{
\beta|u_i-u_j|
\leq
\log g,
\qquad
\forall(i,j)\in E.
}
]

定义

[
\delta_u
========

\max_{(i,j)\in E}|u_i-u_j|.
]

则全局满足 gradation 的充要条件为

[
\boxed{
\beta\delta_u
\leq
\log g.
}
]

由于

[
\beta
=====

\log\frac{h_{\max}}{h_{\min}},
]

也可写为

[
\boxed{
\log\frac{h_{\max}}{h_{\min}}
\cdot
\delta_u
\leq
\log g.
}
]

等价地，

[
\boxed{
\frac{h_{\max}}{h_{\min}}
\leq
g^{1/\delta_u}.
}
]

如果使用 CSF 差值进行估计，由

[
|u_i-u_j|
\leq
\frac{|c_i-c_j|}{\Delta c}
]

可得充分条件

[
\boxed{
\frac{\beta}{\Delta c}
\max_{(i,j)\in E}|c_i-c_j|
\leq
\log g.
}
]

---

## 11. 与空间距离相关的渐变约束

若输入网格边长不均匀，仅限制每条边上的比例可能缺乏空间尺度一致性。

更一般地，可以要求

[
|x_i-x_j|
\leq
\kappa_h|p_i-p_j|,
]

其中 (\kappa_h) 表示单位空间距离上允许的最大 log-size 变化率。

对于线性 log-size 映射：

[
\frac{|x_i^0-x_j^0|}
{|p_i-p_j|}
===========

\beta
\frac{|u_i-u_j|}
{|p_i-p_j|}.
]

定义

[
\kappa_u
========

\max_{(i,j)\in E}
\frac{|u_i-u_j|}
{|p_i-p_j|}.
]

则一个充分条件为

[
\boxed{
\beta\kappa_u
\leq
\kappa_h.
}
]

---

## 12. Gradation 约束投影

如果原始映射得到的 (x^0) 已满足

[
|x_i^0-x_j^0|
\leq\log g
]

对所有边成立，则直接取

[
x=x^0.
]

不需要额外平滑尺寸场。

如果存在违反 gradation 的边，则将 (x^0) 投影到合法集合中。

定义可行集合

[
\mathcal C
==========

\left{
x\in\mathbb R^n:
\begin{array}{l}
\log h_{\min}\leq x_i\leq\log h_{\max},[2pt]
|x_i-x_j|\leq\log g,\quad(i,j)\in E
\end{array}
\right}.
]

求解以下凸二次规划：

[
\boxed{
\min_{x\in\mathcal C}
\frac12(x-x^0)^\top M(x-x^0).
}
]

展开为

[
\min_{x\in\mathcal C}
\frac12
\sum_{i=1}^n
m_i(x_i-x_i^0)^2.
]

该优化只修正违反尺寸渐变要求的部分，并尽量保持曲率映射得到的原始尺寸。

---

### 12.1 可行性

任取常数

[
\bar x\in
[\log h_{\min},\log h_{\max}],
]

令

[
x_i=\bar x
]

对所有顶点成立，则

[
|x_i-x_j|=0\leq\log g.
]

因此

[
\mathcal C\neq\varnothing.
]

---

### 12.2 解的唯一性

目标函数的 Hessian 为

[
M.
]

由于

[
m_i>0,
]

所以 (M) 正定，目标函数严格凸。

可行集合 (\mathcal C) 由线性不等式定义，因此是闭凸集。

严格凸函数在非空闭凸集上至多有一个极小点；由于尺寸上下界使可行集有界，极小点必然存在。

因此：

[
\boxed{
\text{gradation 投影存在唯一解。}
}
]

---

### 12.3 若原始尺寸合法，则投影不改变结果

若

[
x^0\in\mathcal C,
]

则选择 (x=x^0) 时目标函数值为

[
\frac12(x^0-x^0)^\top M(x^0-x^0)=0.
]

目标函数非负，因此零为全局最小值。

由解的唯一性：

[
\boxed{x=x^0.}
]

所以该投影不会无条件平滑尺寸场，只会在存在违规边时产生修正。

---

## 13. 最终尺寸场

求得最终 log-size (x) 后，定义

[
\boxed{
h_i=e^{x_i}.
}
]

由约束可知：

[
h_{\min}\leq h_i\leq h_{\max},
]

并且对所有边：

[
\frac1g
\leq
\frac{h_i}{h_j}
\leq
g.
]

因此最终尺寸场同时满足：

1. 高曲率区域对应较小目标尺寸；
2. 低曲率区域对应较大目标尺寸；
3. 所有尺寸严格为正；
4. 尺寸位于预设范围内；
5. 相邻顶点尺寸比例受到显式控制。

---

## 14. 整体尺度协变性

将网格统一缩放为

[
p_i'=sp_i.
]

若尺寸上下界也按网格尺度定义，则

[
h_{\min}'=sh_{\min},
\qquad
h_{\max}'=sh_{\max}.
]

前文已经证明：

[
c'=c,
\qquad
u'=u.
]

因此

[
x_i^{0\prime}
=============

(1-u_i)\log(sh_{\max})
+
u_i\log(sh_{\min}).
]

展开得

[
x_i^{0\prime}
=============

x_i^0+\log s.
]

于是

[
h_i^{0\prime}
=============

# e^{x_i^{0\prime}}

# se^{x_i^0}

sh_i^0.
]

相邻 log-size 差保持不变：

[
x_i^{0\prime}-x_j^{0\prime}
===========================

x_i^0-x_j^0.
]

因此 gradation 比例约束也保持不变。

若需要进行约束投影，则缩放后的最优解满足

[
x_i'=x_i+\log s,
]

从而

[
\boxed{
h_i'=sh_i.
}
]

所以整个 CSF 到尺寸场构建过程对统一空间缩放具有正确的尺度协变性。

## 15. 完整算法流程

### 步骤 1：计算原始曲率

[
r_i
===

\frac1{|N(i)|}
\sum_{j\in N(i)}
\arccos
\left(
\operatorname{clamp}(n_i^\top n_j,-1,1)
\right).
]

### 步骤 2：装配质量矩阵和拉普拉斯矩阵

[
M=\operatorname{diag}(m_i),
]

[
L_{ii}=\sum_jw_{ij},
\qquad
L_{ij}=-w_{ij}.
]

### 步骤 3：计算 Screened CSF

[
\lambda_c=\alpha_c\bar\ell^2,
]

[
(M+\lambda_cL)c=Mr.
]

### 步骤 4：稳健归一化

[
u_i
===

\operatorname{clamp}
\left(
\frac{c_i-c_{\mathrm{lo}}}
{c_{\mathrm{hi}}-c_{\mathrm{lo}}},
0,1
\right).
]

若曲率范围退化，则采用统一尺寸。

### 步骤 5：确定目标尺寸范围

[
h_{\min}
========

\bar\ell,s_mf_{\min},
]

[
h_{\max}
========

\bar\ell,s_mf_{\max}.
]

### 步骤 6：线性 log-size 映射

[
\beta
=====

\log\frac{h_{\max}}{h_{\min}},
]

[
x_i^0
=====

## \log h_{\max}

\beta u_i,
]

[
h_i^0=e^{x_i^0}.
]

### 步骤 7：检查 gradation

计算

[
d_{\max}
========

\max_{(i,j)\in E}
|x_i^0-x_j^0|.
]

如果

[
d_{\max}\leq\log g,
]

则直接令

[
x=x^0.
]

否则求解约束投影：

[
\min_x
\frac12(x-x^0)^\top M(x-x^0)
]

满足

[
\log h_{\min}\leq x_i\leq\log h_{\max},
]

[
|x_i-x_j|\leq\log g.
]

### 步骤 8：输出最终尺寸

[
\boxed{
h_i=e^{x_i}.
}
]

## 16. 核心结论

该方法可以概括为

[

r

\overset{\text{robust normalization}}{\longrightarrow}
u
\overset{\text{linear log mapping}}{\longrightarrow}
x^0
\overset{\text{gradation projection}}{\longrightarrow}
x
\overset{\exp}{\longrightarrow}

]

其中：

[
(M+\alpha_c\bar\ell^2L)c=Mr
]

保证曲率场在保留原始信息的同时降低局部噪声；

[

## \log h_{\max}

给出最大 log-size 斜率最小的单调映射；

[

保证相邻尺寸比满足指定的 gradation 限制。
