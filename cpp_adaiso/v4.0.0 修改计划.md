# cpp_adaiso v4.0.0 CSF 固定点选择修改计划

## Summary
- 将 CSF Dirichlet Laplace 求解的固定点选择，从“每个连通分量固定最大/最小曲率点”改为“低/高曲率分位区内的最稳定点”。
- 只改 CSF 锚点选择策略；曲率计算、权重图构建、Laplace 求解、target length、CLI 和 JSON 结构保持不变。
- `Q30/Q70`、稳定性公式和退化处理作为内部实现细节，不新增配置项。

## Key Changes
- 在 `CsfSolver.cpp` 的匿名命名空间内替换 `selectFixedVertices` 的核心策略：
  - 对每个非退化连通分量计算 `Q30`、`Q70`，分位数采用当前代码已有风格的线性插值。
  - 对每个顶点计算邻域加权平均 `sum(w_ij*c_j)/sum(w_ij)`，再计算 `r_i = abs(c_i - avg_i) / (range + 1e-14)`。
  - 低锚点从 `c_i <= Q30` 的候选中选 `r_i` 最小者；高锚点从 `c_i >= Q70` 的候选中选 `r_i` 最小者。
  - Tie-break 固定为确定性顺序：低锚点优先更低曲率再更小顶点 id；高锚点优先更高曲率再更小顶点 id。
- 保留现有边界行为：
  - 空输入直接成功。
  - 单点分量、两点分量、常量曲率分量继续全部固定，避免不必要求解或奇异情况。
  - 输入校验、残差阈值、统计字段 `csf_fixed_vertices/free_vertices` 语义不变。
- 增加重合分位退化保护：
  - 若初选低/高锚点相同，或两者原始曲率值没有有效区分，则高锚点改从 `c_i > c_low + 1e-14` 的顶点中按稳定性重选。
  - 若仍无法找到高锚点，说明分量实际近似常量，应走“全部固定”退化路径。
- 不新增公开 API、CLI 参数、JSON 字段或 `AdaIsoConfig` 字段。

## Test Plan
- 更新现有 CSF 单元测试，确认经典链路和断开分量仍通过，`fixed_vertices` 计数和 harmonic residual 不退化。
- 新增稳定锚点测试：构造链式图，初始值如 `{0, 10, 10, 10, 20, 100}`，断言结果体现固定的是稳定的低/高分位点而不是全局最小/最大点。
- 新增 Q30/Q70 重合退化测试：构造 `{0, 0, 0, 0, 1}` 这类高分位阈值落在低平台的输入，断言仍固定两个不同锚点并保留高端值。
- 运行：
  ```powershell
  cmake --build cpp_adaiso/build --config Release
  ctest --test-dir cpp_adaiso/build --output-on-failure
  ```
- 额外运行一次 CLI smoke，使用 `examples/pyramid.obj`、`--iters 1`、`--project 0`，确认 summary 中 `csf_solver_success=true` 且残差低于阈值。

## Assumptions
- `v4.0.0 修改方向.md` 中的 Q30/Q70 和稳定性公式是本次实现的唯一算法目标。
- 稳定性使用传入 `solveDirichletCsf` 的同一套邻接权重和初始曲率值，不额外做预平滑。
- 本次不更新 release 文档、README 版本号或 CMake project version；只做代码行为和测试修改。
