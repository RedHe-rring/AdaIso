# cpp_adaiso v2.1.1 实验结果

## 实验配置

- 版本：`cpp_adaiso 2.1.1`
- 变更：支持 ASCII PLY 输出、每轮 global iteration 信息写入 summary JSON、支持与 GT 的面积采样 Chamfer Distance。
- 输入：
  - `cpp_adaiso/examples/hand.obj`
  - `cpp_adaiso/examples/bunny.obj`
  - `cpp_adaiso/examples/C0.obj` 到 `C9.obj` 中实际存在的 7 个文件：`C0,C1,C2,C3,C4,C6,C7`
  - `cpp_adaiso/examples/T0.off` 到 `T10.off`
- 缺失输入：`cpp_adaiso/examples/C5.obj`、`C8.obj`、`C9.obj`
- 输出目录：`cpp_adaiso/results/v2.1.1_experiments/`
- 输出格式：ASCII PLY
- 参数：`--variant code --mesh-scale 1.0 --iters 10 --preprocess 0 --project 1 --quiet`
- CD 设置：`--gt <input mesh>`，`--cd-samples 100000`
- 构建与测试：
  - `cmake --build cpp_adaiso/build --target adaiso_cli adaiso_tests` 通过
  - `ctest --test-dir cpp_adaiso/build --output-on-failure` 通过

命令模板：

```powershell
cpp_adaiso/build/adaiso_cli.exe <input> `
  -o cpp_adaiso/results/v2.1.1_experiments/<case>_v2.1.1_iter10_project1.ply `
  --variant code `
  --mesh-scale 1.0 `
  --iters 10 `
  --preprocess 0 `
  --project 1 `
  --gt <input> `
  --summary-json cpp_adaiso/results/v2.1.1_experiments/<case>_v2.1.1_iter10_project1.json `
  --quiet
```
