# cpp_adaiso v2.2.0 Release + v2.3.0 Clean CSF Screened Solver

## Summary
- 先提交并标记当前 v2.2.0。
- v2.3.0 删除旧 Dirichlet harmonic CSF 求解路径，改为唯一的 screened CSF：
  `(M + alpha h^2 L)c = M r`
- 不保留旧兼容字段、旧函数、旧 fixed/free anchor 逻辑或 fallback 特判。

## Implementation Changes
- Raw curvature：
  - 统一使用平均法向夹角：
    `r_i = mean_j acos(clamp(n_i dot n_j, -1, 1))`
  - `variant` 不再影响 CSF 曲率定义，只继续影响 remesh 阈值。
- Solver cleanup：
  - 删除 `solveDirichletCsf(...)`。
  - 删除 fixed vertex 选择、connected component anchor 选择、harmonic residual 相关 helper。
  - 新增唯一入口，例如 `solveScreenedCsf(mesh, raw_curvature, alpha)`。
- Screened system：
  - `m_i = 1/3 * sum incident face area`
  - `w_ij = max(kCsfEta, 0.5 * cotangent sum)`
  - `h = meanEdgeLength(mesh)`
  - `lambda = alpha * h * h`
  - diagonal：`m_i + lambda * sum_j w_ij`
  - off-diagonal：`-lambda * w_ij`
  - rhs：`m_i * r_i`
  - 使用 `Eigen::SimplicialLDLT` 求解，并计算 residual。
- Strict validation：
  - 不对空网格、无边网格、`alpha <= 0`、非正/非有限质量项做 fallback。
  - 这些情况直接抛出清晰 `runtime_error`。
  - 不静默返回 raw curvature。
- Public config / CLI：
  - 新增 `AdaIsoConfig::csf_smoothing_alpha = 0.5`。
  - 新增 CLI `--csf-alpha <positive double>`。
  - summary JSON `parameters` 写入 `csf_alpha`。
- Stats cleanup：
  - 删除 `csf_free_vertices`。
  - 删除 `csf_fixed_vertices`。
  - 保留有用统计：assembly/factorization/solve time、residual abs/scaled、matrix nonzeros、solver success。

## Tests
- 删除旧 Dirichlet 测试：
  - chain harmonic 插值测试。
  - fixed/free vertex 数量测试。
  - harmonic residual 测试。
- 新增 screened 测试：
  - 小链式系统解析解或手算线性系统验证。
  - 常量 raw curvature 经 screened solve 后保持常量。
  - residual 满足 `(M + lambda L)c - M r ~= 0`。
  - 非法输入测试：空网格、无边、`alpha <= 0`、退化质量项应抛错。
  - remesh smoke 验证 CSF screened solver 成功、residual 低于阈值。
- 验证命令：
  - `cmake --build cpp_adaiso\build`
  - `ctest --test-dir cpp_adaiso\build --output-on-failure`
  - CLI smoke：确认 `--csf-alpha 0.5` 可运行，summary 不再包含 fixed/free 字段。

## Assumptions
- v2.3.0 不提供 Dirichlet/screened 模式切换。
- `alpha` 必须为正数，默认 `0.5`。
- cotangent CSF 权重使用未 length-scaled 的 clamped cotangent 权重。
