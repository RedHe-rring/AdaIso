# v3.1.0 T6 批量塌缩实验结果

## Summary

v3.1.0 的实验目标是验证 `collapseEdgesBatch()` 是否能解决 v3.0.0 中 collapse 每个 pass 只处理 1 条边导致的耗时问题。该版本只改变 collapse 调度方式：尺寸场、split、flip、MLS 投影和 summary JSON 接口保持 v3.0.0 行为。

对比基准为 `cpp_adaiso/results/v3.0.0_T6_auto05_05_133_budget100/T6_v3.0.0_auto05_05_133_budget100_iter10_project1.json`。

## 配置

- input: `cpp_adaiso/examples/T6.off`
- v3.1.0 output: `cpp_adaiso/results/v3.1.0_T6_batch_collapse/T6_v3.1.0_batch_collapse_iter10_project1.obj`
- v3.1.0 summary: `cpp_adaiso/results/v3.1.0_T6_batch_collapse/T6_v3.1.0_batch_collapse_iter10_project1.json`
- auto sizing: `epsilon=0.05*meanEdgeLength`, `min=0.5*meanEdgeLength`, `max=4/3*meanEdgeLength`
- budgets: `max_split_passes=100`, `max_collapse_passes=100`, `max_flip_passes=200`
- iterations: `10`
- preprocess: `0`
- project: `1`

命令：

```powershell
cpp_adaiso/build/adaiso_cli.exe cpp_adaiso/examples/T6.off `
  -o cpp_adaiso/results/v3.1.0_T6_batch_collapse/T6_v3.1.0_batch_collapse_iter10_project1.obj `
  --variant code `
  --epsilon 0 `
  --min-edge-length 0 `
  --max-edge-length 0 `
  --iters 10 `
  --preprocess 0 `
  --project 1 `
  --summary-json cpp_adaiso/results/v3.1.0_T6_batch_collapse/T6_v3.1.0_batch_collapse_iter10_project1.json `
  --quiet
```

## 对比分析

- runtime 从 `125.899s` 降到 `10.376s`，约 `12.1x` 加速，耗时下降约 `91.8%`。
- v3.0.0 的 collapse total 被 `max_collapse_passes=100` 和 10 轮迭代限制在 `1000`；v3.1.0 的 collapse total 为 `14891`，说明 `iteration_stats.collapse` 已正确记录实际塌缩边数，而不是 pass 数。
- 输出规模从 `25928/51852` 降到 `13899/27794`，顶点和面数均减少约 `46%`，说明批量 collapse 缓解了 split 后无法及时回收短边的问题。
- 质量没有退化，反而提升：`qavg` 从 `0.773168` 升到 `0.860943`，`qmin` 从 `0.151212` 升到 `0.293175`。
- 目标边长贴合改善：最终 `target_error_avg` 从 `0.246808` 降到 `0.115345`，`target_error_max` 从 `0.798644` 降到 `0.539363`。
- 最小角从 `6.560` 度升到 `17.750` 度，局部三角形质量明显改善。

## 结论

T6 上 v3.1.0 批量 collapse 是明确改进：在相同尺寸场和预算参数下，runtime 大幅下降，输出规模更合理，`qavg/qmin`、目标边长误差和最小角均优于 v3.0.0。这个结果说明 v3.0.0 的主要瓶颈不是 sizing 参数本身，而是 collapse 调度过慢且预算语义过窄，导致短边无法及时消化。
