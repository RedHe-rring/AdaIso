# v3.1.0 批量塌缩实施计划

## Summary

v3.1.0 的目标是提升 collapse 性能：将 v3.0.0 中“每个 pass 只塌缩一条边并立即 cleanup”的流程，改为“每个 pass 选择一批一环不冲突的合法短边，批量替换 faces，再统一 cleanup/remap target_lengths_”。

## Key Changes

- `max_collapse_passes` 的语义改为 batch collapse pass 数，不再是单边塌缩次数上限。
- 每个 collapse pass 只构建一次边面表、邻接、顶点面表和边界集合。
- 短边候选按 `length / target` 从小到大排序，优先处理相对目标最短的边。
- 继续复用 `collapseValid()` 做 link condition、塌缩后邻边长度和局部质量检查。
- 被选中的 collapse 边必须一环不冲突：端点及端点一环邻点集合不能与已选边冲突。
- 新增 `collapseEdgesBatch()`，批量更新 keep 顶点位置和 sizing，建立 `remove -> keep` redirect，统一替换 faces，最后只 cleanup/remap 一次。
- `iteration_stats.collapse` 继续记录实际塌缩边数。

## Success Criteria

- 单测通过，输出网格 face 索引合法，无退化和重复三角形。
- smoke 测试中允许 `collapse` 统计值大于 `max_collapse_passes`，证明统计的是实际塌缩边数而不是 pass 数。
- T6 runtime 相比 `v3.0.0_T6_auto05_05_133_budget100` 明显下降。
- T6 的 `qavg/qmin`、`target_error_avg/max` 不出现明显退化。
