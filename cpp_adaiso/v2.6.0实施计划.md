# cpp_adaiso v2.6.0: Max-Angle CSF + Continuous Log-Size Gradation Field

## Summary
- 从 `v2.3.0` 的 histogram multiplier 尺寸场改为 `v2.6.0 尺寸场构建.md` 中的连续 log-size 尺寸场。
- 原始曲率从一环法向夹角平均值改为一环法向夹角最大值，用更保守的方式捕捉折痕和局部尖锐变化。
- 保留 screened CSF：`(M + alpha_c * mean_edge_length^2 * L)c = M r`。
- 删除旧 histogram、5 档 multiplier、target lookup mode、Gaussian kNN 目标场查询等不再需要的代码和配置，不保留兼容残余。
- 最终目标尺寸满足范围约束和相邻 gradation 约束：`h_min <= h_i <= h_max`，且每条边 `1/g <= h_i / h_j <= g`。

## Difference From v2.3.0

| 项目 | v2.3.0 | v2.6.0 |
| --- | --- | --- |
| 原始曲率 `r_i` | 一环法向夹角平均值 | 一环法向夹角最大值 |
| CSF | screened solve，`(M + alpha h^2 L)c = M r` | 保持 screened solve，但输入 raw curvature 改为 max-angle |
| 曲率到尺寸 | histogram 分箱后映射到 5 个 multiplier | robust percentile normalization 后做连续 log-size 映射 |
| 尺寸范围 | `mean_edge * mesh_scale * multiplier`，由 5 档 multiplier 间接决定 | 显式 `h_min = mean_edge * mesh_scale * target_min_factor`，`h_max = mean_edge * mesh_scale * target_max_factor` |
| 尺寸连续性 | 顶点目标长度分段常数；查询阶段可 nearest/Gaussian kNN 平滑 | 顶点 log-size 连续构造；查询时在 log-size 上插值 |
| 相邻尺寸比例 | 无显式保证 | 显式投影到 `|log h_i - log h_j| <= log(g)` |
| 旧参数 | `histogram_bins`、`multipliers`、`target_mode`、`target_k`、`target_sigma_factor` | 删除；改为 min/max factor、percentile、gradation ratio |

## Target Algorithm

### 1. Raw Curvature: Mean To Max
对每个顶点 `i`，先计算顶点法向 `n_i` 和一环邻居集合 `N(i)`。

v2.3.0 使用：

```text
r_i = mean_{j in N(i)} acos(clamp(dot(n_i, n_j), -1, 1))
```

v2.6.0 改为：

```text
r_i = max_{j in N(i)} acos(clamp(dot(n_i, n_j), -1, 1))
```

若 `N(i)` 为空，则 `r_i = 0`。

作用：
- 平坦区域仍接近 `0`。
- 折痕或局部尖峰只要出现在一个邻接方向上，就会被保留下来。
- 与平均值相比，最大值更不容易把尖锐特征摊薄。

### 2. Screened CSF
保留 v2.3.0 的 screened CSF 求解器：

```text
lambda_c = csf_smoothing_alpha * mean_edge_length^2
(M + lambda_c L)c = M r
```

要求：
- 继续使用 barycentric vertex mass。
- 继续使用 clamped non-negative cotangent weights。
- 求解器统计字段可以保留：装配时间、分解时间、求解时间、残差、非零元数、成功状态。
- 不恢复旧 Dirichlet harmonic solve，也不加入备用 smoothing 路径。

### 3. Robust Normalization
用分位数把 CSF `c` 映射到 `[0, 1]`：

```text
c_lo = percentile(c, target_percentile)
c_hi = percentile(c, 1 - target_percentile)
u_i = clamp((c_i - c_lo) / (c_hi - c_lo), 0, 1)
```

若 `c_hi - c_lo <= target_curvature_epsilon`，说明曲率排序退化，直接使用统一尺寸：

```text
h_i = clamp(mean_edge_length * mesh_scale, h_min, h_max)
```

### 4. Continuous Log-Size Mapping
显式定义目标尺寸范围：

```text
h_min = mean_edge_length * mesh_scale * target_min_factor
h_max = mean_edge_length * mesh_scale * target_max_factor
```

然后在 log-size 空间线性映射：

```text
x_i0 = (1 - u_i) * log(h_max) + u_i * log(h_min)
h_i0 = exp(x_i0)
```

含义：
- `u_i = 0`，低曲率，`h_i0 = h_max`。
- `u_i = 1`，高曲率，`h_i0 = h_min`。
- 曲率越大，目标边长越小。
- 使用 log-space 可以让尺寸变化按比例均匀，而不是按绝对长度均匀。

### 5. Gradation Projection
对 log-size 施加相邻比例约束：

```text
|x_i - x_j| <= log(target_max_adjacent_ratio), for every edge (i, j)
```

如果 `x0` 已满足全部约束，直接使用 `x = x0`。

如果存在违规边，则解带 box 约束的凸投影：

```text
min 0.5 * sum_i m_i * (x_i - x_i0)^2
subject to:
  log(h_min) <= x_i <= log(h_max)
  |x_i - x_j| <= log(target_max_adjacent_ratio)
```

实现要求：
- 投影 helper 必须是唯一的 gradation 修正路径。
- 不再加入无条件 Laplace smoothing 或 `target_smooth_alpha`。
- 投影收敛后必须再次验证所有边的相邻比例约束。
- 如果达到最大迭代仍未满足 tolerance，运行应失败并报告明确错误，而不是静默输出违规尺寸场。

### 6. Target Query
`TargetLengthField` 存储最终 log-size，而不是直接存储线性长度。

查询 `targetAt(point)` 时：
- 优先在输入网格表面上找到包含/最近的三角形，并用重心坐标插值 `log h`。
- 返回 `exp(interpolated_log_h)`。
- 只在几何查询失败时 fallback 到最近顶点的 `log h`。

这样可以避免线性长度插值导致比例空间不一致，也避免继续依赖 v2.3.0 的 nearest/Gaussian target lookup mode。

## Parameters

### `mesh_scale`
整体尺寸缩放因子。

参与：

```text
h_min = mean_edge_length * mesh_scale * target_min_factor
h_max = mean_edge_length * mesh_scale * target_max_factor
```

值越小，整体目标边长越小，输出网格越密。

### `csf_smoothing_alpha`
CSF 平滑强度，控制：

```text
lambda_c = csf_smoothing_alpha * mean_edge_length^2
```

值越大，曲率场 `c` 越平滑，局部尖峰对尺寸场的影响越弱。
值越小，尺寸场越贴近 raw max-angle curvature。

### `target_min_factor`
最小目标边长相对 `mean_edge_length * mesh_scale` 的比例。

高曲率区域最终接近：

```text
h_min = mean_edge_length * mesh_scale * target_min_factor
```

必须满足 `target_min_factor > 0`。

### `target_max_factor`
最大目标边长相对 `mean_edge_length * mesh_scale` 的比例。

低曲率区域最终接近：

```text
h_max = mean_edge_length * mesh_scale * target_max_factor
```

必须满足 `target_max_factor >= target_min_factor`。

建议初始默认值沿用 v2.3.0 multiplier 动态范围：

```text
target_min_factor = 0.6
target_max_factor = 1.8
```

### `target_percentile`
robust normalization 使用的裁剪分位数。

例如 `0.05` 表示用 `P5` 和 `P95` 映射曲率范围，减少极端离群点支配整个尺寸场。

约束：

```text
0 <= target_percentile < 0.5
```

建议默认值：

```text
target_percentile = 0.05
```

### `target_curvature_epsilon`
判断 CSF 是否退化为近似常量场的阈值。

当：

```text
c_hi - c_lo <= target_curvature_epsilon
```

直接输出统一尺寸，避免对数值噪声做过度放大。

该参数可以先作为内部常量；只有实验需要时再暴露到 CLI。

### `target_max_adjacent_ratio`
相邻顶点允许的最大目标尺寸比例，记为 `g`。

约束为：

```text
1 / g <= h_i / h_j <= g
```

等价于：

```text
|log h_i - log h_j| <= log(g)
```

必须满足 `target_max_adjacent_ratio > 1`。

建议默认值：

```text
target_max_adjacent_ratio = 1.25
```

该值越接近 `1`，尺寸场过渡越慢，可能需要更多网格环才能从 `h_min` 过渡到 `h_max`。
该值越大，尺寸场变化越快，但更可能导致 remeshing 操作震荡。

### `target_projection_max_iterations`
gradation 投影的最大迭代次数。

作用是防止病态输入导致无限循环。达到上限仍未满足 tolerance 时应报错。

可以先作为配置字段保留，不必优先暴露 CLI。

### `target_projection_tolerance`
gradation 约束验证容差。

用于判断：

```text
max_edge_abs_log_diff <= log(target_max_adjacent_ratio) + tolerance
```

该值只控制数值判定，不改变理论尺寸场。

## Tests

### Unit Tests
- max-angle raw curvature：
  - 构造一个顶点有多个邻居法向夹角的网格，确认 `r_i` 等于最大夹角而不是平均夹角。
  - 空邻接顶点返回 `0`。
- log-size mapping：
  - `u=0` 得到 `h_max`。
  - `u=1` 得到 `h_min`。
  - 曲率单调增加时 `h` 单调减少。
  - 常量 CSF 触发统一尺寸 fallback。
- percentile normalization：
  - 离群最大值不会单独支配 `c_hi`。
  - 输出 `u_i` 始终在 `[0, 1]`。
- gradation projection：
  - 已满足约束的 `x0` 不改变。
  - 违规边投影后满足 `|x_i - x_j| <= log(g) + tolerance`。
  - 投影后所有 `x_i` 仍在 `[log(h_min), log(h_max)]`。
- cleanup regression：
  - 代码中不再引用 `histogramMultipliers`、`TargetLookupMode`、`target_knn_k`、`target_gaussian_sigma_factor`。
  - 删除的 CLI 参数不再出现在 help、JSON 或 README 中。

### Smoke Tests

- `hand.obj`、`bunny.obj`、`C0.obj`、`model_001.off` 各跑一次默认参数。

  - `gradation_violation_count == 0`。
