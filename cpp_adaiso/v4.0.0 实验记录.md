# cpp_adaiso v4.0.0 T0-T10 实验结果

## 实验配置

- 版本：当前 `v4.0.0` 工作区代码，记录为 `v4.4.0` 实验。
- 变更重点：CSF Dirichlet Laplace 固定点选择改为 Q30/Q70 曲率分位区内的邻域稳定锚点。
- 输入：`T0.off` 到 `T10.off`。
- 输出目录：`cpp_adaiso/results/v4.4.0_T0_T10/`。
- 输出格式：ASCII PLY。
- 参数：`--variant code --mesh-scale 1.0 --iters 10 --preprocess 0 --project 1 --target-mode gaussian --target-k 8 --target-sigma-factor 1.0 --quiet`。
- CD 设置：`--gt <input mesh>`，`--cd-samples 100000`。
- 构建与测试：`cmake --build cpp_adaiso/build --config Release` 通过，`ctest --test-dir cpp_adaiso/build --output-on-failure` 通过。

命令模板：

```powershell
cpp_adaiso/build/adaiso_cli.exe cpp_adaiso/examples/<case>.off `
  -o cpp_adaiso/results/v4.4.0_T0_T10/<case>_v4.4.0_iter10_project1_gaussian.ply `
  --variant code `
  --mesh-scale 1.0 `
  --iters 10 `
  --preprocess 0 `
  --project 1 `
  --target-mode gaussian `
  --target-k 8 `
  --target-sigma-factor 1.0 `
  --gt cpp_adaiso/examples/<case>.off `
  --cd-samples 100000 `
  --summary-json cpp_adaiso/results/v4.4.0_T0_T10/<case>_v4.4.0_iter10_project1_gaussian.json `
  --quiet
```

## Edge Ratio 指标口径

- `Final Viol.` 为第 10 轮结束后的 `violation_rate`。
- `Tail Viol.` 为第 6-10 轮 `violation_rate` 平均值。
- `Tail Ops` 为第 6-10 轮 `split_count + collapse_count + flip_count` 平均值。
- `Delta Ops` 为第 6-10 轮相邻总操作数绝对变化的平均值。
