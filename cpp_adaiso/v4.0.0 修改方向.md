基于v2.2.0修改，原来是固定最大最小曲率值进行laplace扩散

> 用“当前值与邻域加权平均的差”衡量稳定性，然后分别在低曲率区和高曲率区选最稳定的点。

这相当于做一次隐形的局部平滑比较，复杂度是 (O(E))。不用先求一次预平滑，更不会出现“为了选固定点先选固定点”的循环喜剧。

## 1. 稳定性指标

现有代码已经有每个顶点的初始曲率 (c_i)，以及带权邻接图 (w_{ij})。初始曲率来自邻接法向夹角，图权重来自余切权重。 

对每个顶点计算邻域加权平均：

[
\bar c_i=
\frac{\sum_{j\in N(i)}w_{ij}c_j}
{\sum_{j\in N(i)}w_{ij}}.
]

再计算变化指标：

[
d_i=|c_i-\bar c_i|.
]

为了适应不同模型尺度，可以归一化：

[
r_i=
\frac{|c_i-\bar c_i|}
{c_{\max}-c_{\min}+\varepsilon}.
]

(r_i) 越小，说明这个点与邻域越一致，越适合作为固定点。

---

## 2. 不要直接选变化最小的两个点

因为那两个点大概率都在同一片平坦区域，数值也几乎一样。最后求出来一个接近常数的场，计算机很稳定，结果很没用。

每个连通分量选择：

[
v_{\text{low}}
==============

\arg\min_{c_i\le Q_{30}} r_i,
]

[
v_{\text{high}}
===============

\arg\min_{c_i\ge Q_{70}} r_i.
]

其中：

* (Q_{30})：该连通分量曲率的 30% 分位数；
* (Q_{70})：70% 分位数。

也就是：

* 在低曲率区域选一个最稳定点；
* 在高曲率区域选一个最稳定点。

固定值仍取原始值：

[
x_{v_{\text{low}}}=c_{v_{\text{low}}},
\qquad
x_{v_{\text{high}}}=c_{v_{\text{high}}}.
]
