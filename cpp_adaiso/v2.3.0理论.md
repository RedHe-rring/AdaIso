可以。先从数学上把两件事分清楚：

你现在的 Dirichlet harmonic solve 本质是在做 **无源调和插值**；我建议的 screened smoothing 是在做 **带数据保真项的正则化平滑**。二者形式很像，但数学性质完全不同。你的代码中 `computeCsf()` 先计算 raw curvature，然后把它传给 `solveDirichletCsf(...)`，最后 `buildTargetLengths()` 再用这个返回值进入 histogram 并生成目标边长场，所以 CSF 求解的数学形式会直接决定最终尺寸场。

## 1. 记号定义

设三角网格为：

$
\mathcal{M}=(V,F)
$

其中顶点数为 (n)，顶点为 (v_i)，每个顶点上有一个原始曲率值：

$
r_i
$

在你的代码里，(r_i) 基本来自邻接顶点法向夹角。`Code` 版本类似：

$
r_i=\frac{1}{|\mathcal{N}(i)|}
\sum_{j\in\mathcal{N}(i)}
\arccos\left(\mathbf{n}_i\cdot\mathbf{n}_j\right)
$

`Paper` 版本则取最大法向夹角：

$
r_i=
\max_{j\in\mathcal{N}(i)}
\arccos\left(\mathbf{n}_i\cdot\mathbf{n}_j\right)
$

这个 (r_i) 就是你可视化出来的 **raw curvature field**。从你发的图看，raw curvature 是合理的：局部特征处高，平滑区域低。

目标是从 noisy 的 (r_i) 得到一个更平滑但仍保留局部特征的曲率场：

$
c_i
$

这里 $c_i$ 就是我们希望拿去做 histogram / target length 的 CSF。

---

## 2. 你现在的 Dirichlet harmonic solve 在数学上是什么

你现在做的事情可以抽象为：

给定一部分固定顶点 (B)，例如 raw curvature 的极大点、极小点，把这些点的 (c_i) 固定为 (r_i)。其余自由顶点集合记为 (I)。

然后求一个最平滑的函数 (c)：
$
E_{\mathrm{harm}}(c)=\frac{1}{2}\sum_{(i,j)\in E}w_{ij}(c_i-c_j)^2
$
约束是：
$
c_i=r_i,\quad i\in B
$

这个能量只惩罚相邻点之间的差异。它没有要求自由点 (c_i) 接近自己的 raw curvature (r_i)。

对自由点 $i\in I$ 求一阶最优条件：
$
\frac{\partial E_{\mathrm{harm}}}{\partial c_i}=\sum_{j\in\mathcal{N}(i)}w_{ij}(c_i-c_j)=0
$

整理得到：

$
c_i=
\frac{\sum_{j\in\mathcal{N}(i)}w_{ij}c_j}
{\sum_{j\in\mathcal{N}(i)}w_{ij}}
$

这句话的意义很关键：

**每个自由点的值等于邻居值的加权平均。**

这就是调和函数。调和函数有一个重要性质：**最大值和最小值只能出现在边界或固定点上**。因此，如果你只固定极大点和极小点，其余区域会变成这两个极值之间的全局插值场。

所以你看到的现象并不意外：

```text
一个高曲率锚点附近变红
一个低曲率锚点附近变蓝
中间区域形成大尺度过渡
```

这就是典型 harmonic interpolation，而不是“局部曲率的平滑版本”。

矩阵形式写作：

令 (L) 是图 Laplacian：

$
L_{ii}=\sum_{j}w_{ij},\qquad L_{ij}=-w_{ij}
$

则自由点方程为：

$
L_{II}c_I=-L_{IB}c_B
$

这里没有 (r_I)。也就是说，自由点自己的原始曲率数据完全丢了。这就是它会把合理 raw curvature 场破坏成大块红蓝分区的根本原因。

---

## 3. Screened smoothing 的目标

我们真正想要的不是“找一个最调和的场”，而是：

1. (c) 要接近原始曲率 (r)
2. (c) 又要比 (r) 平滑
3. 平滑不能抹掉所有局部特征

因此设一个能量：
$
E(c)=\frac{1}{2}\int_{\mathcal{M}}(c-r)^2,dA+\frac{\lambda}{2}\int_{\mathcal{M}}|\nabla c|^2,dA
$
第一项：

$
\frac{1}{2}\int_{\mathcal{M}}(c-r)^2,dA
$

叫 **data fidelity term**，数据保真项。它要求 (c) 不要离 raw curvature (r) 太远。

第二项：

$
\frac{\lambda}{2}\int_{\mathcal{M}}|\nabla c|^2,dA
$

叫 **smoothness regularization term**，平滑正则项。它惩罚曲率场变化太剧烈。

参数 (\lambda) 控制平滑强度：

```text
λ = 0        → c = r，不平滑
λ 较小      → 轻微平滑，保留特征
λ 较大      → 强平滑，细节被抹掉
λ → ∞       → 接近常数场
```

这就是 screened smoothing 的核心。

---

## 4. 连续形式的一阶变分推导

对 (c) 做一个扰动：

$
c_\epsilon=c+\epsilon\eta
$

其中 $\eta$ 是任意测试函数。把它代入能量：

$
E(c_\epsilon)=
\frac{1}{2}\int_{\mathcal{M}}(c+\epsilon\eta-r)^2dA
+
\frac{\lambda}{2}\int_{\mathcal{M}}
|\nabla c+\epsilon\nabla\eta|^2dA
$

对 $\epsilon$ 求导，并令 $\epsilon=0$：

$
\frac{dE}{d\epsilon}\bigg|_{\epsilon=0} = 
\int_{\mathcal{M}}(c-r)\eta dA
+
\lambda\int_{\mathcal{M}}\nabla c\cdot\nabla\eta dA
$

最优解要求对任意 (\eta)，都有：

$
\int_{\mathcal{M}}(c-r)\eta dA
+
\lambda\int_{\mathcal{M}}\nabla c\cdot\nabla\eta dA=0
$

对第二项做分部积分：

$
\int_{\mathcal{M}}\nabla c\cdot\nabla\eta dA=
-\int_{\mathcal{M}}(\Delta c)\eta,dA
+
\int_{\partial\mathcal{M}}
\eta\frac{\partial c}{\partial n},ds
$

如果采用自然边界条件：

$
\frac{\partial c}{\partial n}=0
$

则边界项为 0，于是得到：

$
\int_{\mathcal{M}}
\left[
(c-r)-\lambda\Delta c
\right]\eta dA=0
$

由于 $\eta$ 任意，所以：

$(I-\lambda\Delta)c=r
$
这就是连续 screened Poisson / screened Laplace 方程。

注意符号：如果我们定义正半定 Laplace-Beltrami 算子为：

$
\mathcal{L}=-\Delta
$

那么方程写成：

$
(I+\lambda\mathcal{L})c=r
$

这和离散矩阵形式一致。

## 5. 离散到三角网格上

在三角网格上，用每个顶点的标量 (c_i) 表示曲率场。离散能量写成：
$
E(c)=\frac{1}{2}\sum_i m_i(c_i-r_i)^2+\frac{\lambda}{2}\sum_{(i,j)\in E}w_{ij}(c_i-c_j)^2
$
这里：

$
m_i
$

是顶点面积质量，通常取 barycentric mass：

$
m_i=
\frac{1}{3}
\sum_{f\ni i}A_f
$

也就是所有 incident triangle 面积的三分之一。

$
w_{ij}
$

是边权。常用 cotangent 权重：

$
w_{ij}=\frac{1}{2}(\cot\alpha_{ij}+\cot\beta_{ij})
$

其中 (\alpha_{ij})、(\beta_{ij}) 是边 ((i,j)) 对面的两个角。边界边只有一个对角时，可以用：

$
w_{ij}=\frac{1}{2}\cot\alpha_{ij}
$

如果三角形质量较差，cotangent 可能为负，工程上可以 clamp 到一个小正数，或者先用 uniform weight 做验证。

---

## 6. 离散能量的一阶导数

对某个 (c_i) 求导。

数据项：

$
\frac{\partial}{\partial c_i}
\frac{1}{2}m_i(c_i-r_i)^2=
m_i(c_i-r_i)
$

平滑项：

$
\frac{\partial}{\partial c_i}
\frac{\lambda}{2}
\sum_{(p,q)\in E}w_{pq}(c_p-c_q)^2=
\lambda\sum_{j\in\mathcal{N}(i)}w_{ij}(c_i-c_j)
$

令总导数为 0：

$
m_i(c_i-r_i)
+
\lambda\sum_{j\in\mathcal{N}(i)}w_{ij}(c_i-c_j)
=0
$

展开：

$
m_i c_i - m_i r_i
+
\lambda c_i\sum_j w_{ij}
------------------------

\lambda\sum_j w_{ij}c_j
=0
$

整理：

[
\left(m_i+\lambda\sum_j w_{ij}\right)c_i
----------------------------------------

# \lambda\sum_j w_{ij}c_j

m_i r_i
]

这就是每个顶点对应的一行线性方程。

---

## 7. 矩阵形式

定义质量矩阵 (M)：

[
M=\mathrm{diag}(m_1,m_2,\ldots,m_n)
]

定义 Laplacian 矩阵 (L)：

[
L_{ii}=\sum_{j\in\mathcal{N}(i)}w_{ij}
]

[
L_{ij}=-w_{ij},\quad i\neq j,\ (i,j)\in E
]

[
L_{ij}=0,\quad \text{otherwise}
]

于是离散系统是：

(M+\lambda L)c=Mr

这就是你要实现的核心公式。

这里 (M+\lambda L) 是对称正定的，前提是：

1. (m_i>0)
2. (w_{ij}\ge 0)
3. (\lambda\ge 0)

所以它比纯 Dirichlet harmonic solve 更稳定，也不需要手动选择 fixed vertices。

---

## 8. 为什么它不会变成你现在那种全局红蓝场

把 Dirichlet harmonic 和 screened smoothing 的顶点方程并排看。

Dirichlet harmonic 对自由点：

[
\sum_j w_{ij}(c_i-c_j)=0
]

等价于：

[
c_i=\frac{\sum_jw_{ij}c_j}{\sum_jw_{ij}}
]

自由点只听邻居的，不听自己的 (r_i)。

Screened smoothing：

[
m_i(c_i-r_i)+
\lambda\sum_jw_{ij}(c_i-c_j)=0
]

整理成：

[
c_i=
\frac{
m_i r_i+\lambda\sum_jw_{ij}c_j
}{
m_i+\lambda\sum_jw_{ij}
}
]

这个式子非常直观：

[
c_i
]

是两个东西的折中：

1. 自己的原始曲率 (r_i)
2. 邻居的平滑平均

当 (\lambda) 小时：

[
c_i\approx r_i
]

当 (\lambda) 大时：

[
c_i\approx
\frac{\sum_jw_{ij}c_j}{\sum_jw_{ij}}
]

所以 screened smoothing 是“逐渐靠近 harmonic smoothing”，而不是一开始就完全 harmonic。

这就是为什么它更适合你的情况：你的 raw curvature 已经合理，只是有噪声。你需要的是 denoising，而不是全局调和插值。

---

## 9. (\lambda) 的尺度问题

如果使用 cotangent Laplacian，(L) 的量纲大致是无量纲的，而质量矩阵 (M) 有面积量纲。

所以：

[
M+\lambda L
]

里两项要能相加，(\lambda) 应该有面积量纲，也就是长度平方。

通常可以写成：

[
\lambda = \alpha h^2
]

其中：

[
h
]

是平均边长，(\alpha) 是无量纲参数。

所以实际推荐用：

[
(M+\alpha h^2 L)c=Mr
]

其中：

```text
α = 0       不平滑
α = 0.25    轻微平滑
α = 0.5     推荐起点
α = 1.0     中等平滑
α = 2.0     较强平滑
α = 5.0+    可能过平滑
```

如果你用的是 uniform graph Laplacian，并且 (M=I)，则可以直接写：

[
(I+\alpha L)c=r
]

这时 (\alpha) 是纯图参数，没有物理尺度意义。

## 10. 和扩散方程的关系

Screened smoothing 也可以从隐式扩散角度理解。

热扩散方程：

[
\frac{\partial c}{\partial t}=\Delta c
]

从初始场 (r) 做一个 backward Euler 时间步：

[
\frac{c-r}{t}=\Delta c
]

整理：

[
c-r=t\Delta c
]

[
(I-t\Delta)c=r
]

这和 screened equation 一样：

[
(I-\lambda\Delta)c=r
]

所以 screened smoothing 可以理解为：**对 raw curvature 做一个隐式热扩散步**。

离散形式就是：

[
(M+tL)c=Mr
]

这里 (t) 就是扩散时间。(t) 越大，扩散越强。

这也解释了为什么它比反复显式邻域平均更稳定。显式平滑类似：

[
c^{k+1}=c^k-\tau M^{-1}Lc^k
]

步长 (\tau) 太大会不稳定；而隐式形式：

[
(M+tL)c^{k+1}=Mc^k
]

对大时间步仍稳定。

---

## 11. 如果想做多步 screened smoothing

单步：

[
(M+\lambda L)c=Mr
]

已经够用。

如果你想做多步，可以写成：

[
(M+\lambda L)c^{k+1}=Mc^k
]

初始：

[
c^0=r
]

迭代 (K) 次：

[
c^K
]

但在你的问题里，我不建议先做多步。因为你现在的问题是 CSF 被过度全局化，多步平滑可能又往过平滑方向走。先用单步 screened smoothing 更可控。

---

## 12. 和 target length 的关系

你的尺寸场后续是：

[
\ell_i = h_{\mathrm{base}}\cdot s_i
]

其中 (s_i) 是 histogram 后得到的 multiplier。高 CSF 应该给小 multiplier：

[
c_i \uparrow
\quad\Rightarrow\quad
s_i \downarrow
\quad\Rightarrow\quad
\ell_i \downarrow
\quad\Rightarrow\quad
\text{mesh denser}
]

因此整个链路应该是：

[
r_i
\rightarrow
c_i
\rightarrow
s_i
\rightarrow
\ell_i
]

你的 raw curvature (r_i) 已经合理；现在要保证 (c_i) 是 (r_i) 的平滑版，而不是由极值点决定的全局场。

Screened smoothing 正是为这个目的设计的：

[
c = \arg\min_c
\left[
\frac{1}{2}|c-r|_M^2
+
\frac{\lambda}{2}|c|_L^2
\right]
]

其中：

[
|c-r|_M^2=(c-r)^TM(c-r)
]

[
|c|_L^2=c^TLc
=============

\sum_{(i,j)}w_{ij}(c_i-c_j)^2
]

---

## 13. 最终推荐数学形式

对你的实现，我建议采用这个版本：

[
r_i=
\frac{1}{|\mathcal{N}(i)|}
\sum_{j\in\mathcal{N}(i)}
\arccos(\mathbf{n}_i\cdot\mathbf{n}_j)
]

[
m_i=\frac{1}{3}\sum_{f\ni i}A_f
]

[
w_{ij}=\max\left(
\epsilon,
\frac{1}{2}(\cot\alpha_{ij}+\cot\beta_{ij})
\right)
]

[
L_{ii}=\sum_j w_{ij},\qquad L_{ij}=-w_{ij}
]

[
\lambda=\alpha h^2
]

最终解：

[
(M+\alpha h^2L)c=Mr
]

然后用 (c) 代替现在 `solveDirichletCsf(...)` 的输出进入 histogram。

从数学性质上，这个方法有三个优点：

第一，(M+\alpha h^2L) 是稳定的正定系统，适合用 Cholesky / LDLT 解。

第二，每个顶点都有数据项 (m_i(c_i-r_i)^2)，不会丢掉原始曲率的局部结构。

第三，(\alpha) 有清晰含义：它控制在平均边长尺度上的平滑强度。你可以通过可视化直接调参。
