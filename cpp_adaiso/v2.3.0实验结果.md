# cpp_adaiso v2.3.0 实验结果

## 实验配置

- 版本：`cpp_adaiso 2.3.0`
- 变更：CSF 从 Dirichlet harmonic solve 改为 screened smoothing：`(M + alpha h^2 L)c = M r`。
- 输入：`hand.obj`、`bunny.obj`、`T0.off` 到 `T10.off`、`C0.obj` 到 `C7.obj`、`model_001.off` 到 `model_010.off`。
- 缺失输入：`cpp_adaiso/examples/C5.obj`、`cpp_adaiso/examples/model_008.off`。
- 输出目录：`cpp_adaiso/results/v2.3.0_experiments/`。
- 输出格式：ASCII PLY。
- 参数：`--variant code --mesh-scale 1.0 --iters 10 --preprocess 0 --project 1 --target-mode gaussian --target-k 8 --target-sigma-factor 1.0 --csf-alpha 0.5 --quiet`。
- CD 设置：`--gt <input mesh>`，`--cd-samples 100000`。
- 汇总 CSV：`cpp_adaiso/results/v2.3.0_experiments/run_summary.csv`。

命令模板：

```powershell
cpp_adaiso/build/adaiso_cli.exe <input> `
  -o cpp_adaiso/results/v2.3.0_experiments/<case>_v2.3.0_iter10_project1_gaussian.ply `
  --variant code `
  --mesh-scale 1.0 `
  --iters 10 `
  --preprocess 0 `
  --project 1 `
  --target-mode gaussian `
  --target-k 8 `
  --target-sigma-factor 1.0 `
  --csf-alpha 0.5 `
  --gt <input> `
  --cd-samples 100000 `
  --summary-json cpp_adaiso/results/v2.3.0_experiments/<case>_v2.3.0_iter10_project1_gaussian.json `
  --quiet
```

## Edge Ratio 指标口径

- `target(e) = min(targetAt(v0), targetAt(v1))`。
- `ratio(e) = length(e) / target(e)`。
- `violation = ratio < collapseFactor || ratio > splitFactor`，本组参数下为 `ratio < 0.8 || ratio > 1.33`。
- `Final Viol.` 为第 10 轮结束后的 `violation_rate`。
- `Tail Viol.` 为第 6-10 轮 `violation_rate` 平均值。
- `Tail Ops` 为第 6-10 轮 `split_count + collapse_count + flip_count` 平均值。
- `Delta Ops` 为第 7-10 轮相邻总操作数绝对变化的平均值。
