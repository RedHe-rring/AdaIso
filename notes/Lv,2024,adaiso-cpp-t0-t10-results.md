# C++ AdaIso T0-T10 测试结果与论文笔记对比

测试对象：`cpp_adaiso/examples/T0.off` 到 `T10.off`

测试命令口径：

```powershell
cpp_adaiso\build\adaiso_cli.exe cpp_adaiso\examples\T{i}.off `
  -o cpp_adaiso\results\T0_T10\T{i}_iter10_project1.obj `
  --variant code `
  --mesh-scale 1.0 `
  --iters 10 `
  --preprocess 0 `
  --project 1 `
  --summary-json cpp_adaiso\results\T0_T10\T{i}_iter10_project1.json `
  --quiet
```

构建环境：

- MSVC 19.50
- Ninja
- vcpkg: `e:/dev/vcpkg`
- 依赖：Eigen3、nanoflann

## 2. 与论文笔记中的结果对比

`notes/Lv,2024,adaiso.md` 中没有记录 T0-T10 逐模型的论文原始表格，因此这里不能做严格的同模型逐项对比。可对比的只有论文笔记中摘录的代表性质量指标和运行时间量级。

### 2.1 论文笔记中的代表性质量指标

笔记摘录的作者方法 `Ours` 代表值：

| 数据集/模型 | Qavg | Qmin |
|---|---:|---:|
| SHREC / centaur | 0.85 | 0.51 |
| SHREC / hand | 0.86 | 0.51 |
| SHREC / spider | 0.86 | 0.52 |
| ModelNet / bowl | 0.91 | 0.59 |
| ModelNet / bottle | 0.91 | 0.11 |
| ModelNet / sofa | 0.84 | 0.16 |

这些代表值的均值：

| 指标 | 论文笔记代表值均值 | 当前 C++ T0-T10 均值 | 差值 |
|---|---:|---:|---:|
| Qavg | 0.871667 | 0.782023 | -0.089644 |
| Qmin | 0.400000 | 0.208227 | -0.191773 |

直接观察：

- 当前 C++ 复现的 `Qavg` 平均约 `0.782`，低于论文代表值均值约 `0.09`。
- 当前 C++ 复现的 `Qmin` 平均约 `0.208`，低于论文代表值均值约 `0.19`。
- 如果和论文中的高质量 SHREC/bowl 示例比，差距明显。
- 如果和论文中的 ModelNet bottle/sofa 这类 `Qmin=0.11/0.16` 的难例比，当前复现的 `Qmin` 并不差，部分 case 更高。

### 2.2 输出点数口径不一致

论文笔记中写到：

> 各方法输出的重网格化结果控制在相近顶点数范围内，约 9000-13000 个点。

当前测试的输出点数是：

- 最小：`15417`
- 最大：`22772`
- 多数模型在 `18k-22k`

这说明当前 `mesh_scale=1.0` 和 10 轮设置下，输出网格明显比论文实验口径更密。点数不同会影响质量指标、几何误差和运行时间，因此不能直接说当前结果就是论文表格的复现结果。

### 2.3 运行时间对比

论文笔记中的作者方法运行时间表：

| 输出点数 / 输入点数 | 5k | 10k | 50k | 100k |
|---:|---:|---:|---:|---:|
| 1k | 26.2s | 34.06s | 100.96s | 150.36s |
| 5k | 32.5s | 52.256s | 161.68s | 189.63s |
| 10k | - | 61.88s | 200.68s | 249.36s |
| 50k | - | - | >5min | >5min |

当前 C++ 测试：

- 输入约 `8.3k-10k` 点。
- 输出约 `15.4k-22.8k` 点。
- 10 轮平均单模型 `19.241s`。
- T0 单模型 `19.373s`，外部墙钟此前记录约 `21.368s`。

结论：

- 当前实现的运行时间比笔记中论文表格的 `10k 输入 / 10k 输出 = 61.88s` 更短。
- 但硬件、实现语言、并行化、输出点数、迭代停止条件和数据集都不一致，这个速度优势不能作为论文级性能对比结论。
- 从工程角度看，当前 C++ 版本已经能在 10k 级输入上稳定跑完整 10 轮。

## 3. 差得多吗？

分指标看：

### Qavg

差距比较明显，但不是数量级错误。

当前复现：

```text
Qavg 平均 = 0.782
Qavg 范围 = 0.761 - 0.796
```

论文代表值：

```text
Qavg 多在 0.84 - 0.91
```

因此当前 C++ 版本的平均三角形质量低于论文代表结果，大约低 `0.06-0.13`。这说明当前实现还没有达到论文中展示的质量水平。

### Qmin

差距更明显。

当前复现：

```text
Qmin 平均 = 0.208
Qmin 范围 = 0.087 - 0.286
```

论文代表值：

```text
高质量示例 Qmin = 0.51 - 0.59
难例 Qmin = 0.11 - 0.16
```

当前复现对原始低质量输入有显著改善，但和论文中 SHREC/bowl 这类高质量结果比，最差三角形质量仍低很多。和 bottle/sofa 这类论文中 `Qmin` 较低的模型比，则处于相近或更好的范围。

### 运行时间

当前结果不差，甚至明显快于笔记中的代表运行时间。但不能严格比较，因为：

- 论文运行环境不同。
- 输入模型不同。
- 输出点数不同。
- 当前实现没有完全复刻论文/作者源码的全部行为。

### 几何一致性和曲率敏感性

当前还没有实现/记录：

- `Hd`
- `Md`
- 曲率-面积单调性曲线
- 视觉对比

论文优势很大一部分来自几何一致性和曲率敏感性，不只是 `Qavg/Qmin`。所以仅根据当前表格不能判断论文整体效果是否复现到位。

## 4. 主要差距来源判断

当前结果和论文代表值有差距，主要可能来自：

1. **输出点数未对齐**：当前输出点数偏高，不是论文笔记中约 `9000-13000` 的口径。
2. **没有严格复刻作者源码数据结构**：当前实现是行为复现，不是逐行移植。
3. **collapse 策略较保守**：为了稳定性和速度，局部质量检查和 link condition 更保守，可能影响最终等边化。
4. **flip/smoothing 仍是工程近似**：valence energy 和 tangent smoothing 已实现，但局部决策与作者源码不一定完全一致。
5. **目标边长场只初始化一次**：当前每次 remesh 开始计算一次 CSF 和目标边长，没有随迭代动态重估。
6. **缺少论文中的输出点数控制策略**：现在靠 `mesh_scale` 间接控制密度，未做“输出点数对齐”的搜索。

## 5. 后续建议

若目标是更接近论文表格，应优先做：

1. 对每个 T 模型搜索 `mesh_scale`，把输出点数控制到 `9000-13000`。
2. 在同一输出点数口径下重新统计 `Qavg/Qmin`。
3. 实现 `Hd/Md`，补几何一致性对比。
4. 增加曲率-三角形面积单调性统计。
5. 如果仍差距大，再针对 split/collapse/flip 与作者源码逐项对齐。

当前结论：

> 当前 C++ 复现能稳定运行，并显著改善输入网格质量；但从 `Qavg/Qmin` 看，还没有达到论文笔记中代表性高质量结果的水平。`Qavg` 有中等差距，`Qmin` 对高质量论文示例差距较大。运行时间表现较好，但目前不是严格同口径对比。
